    エアシリンダとは？仕組み・動き・どこを見るかを初心者向けに整理

    エアシリンダは、設備でよく使われる空圧機器のひとつです。この記事では、 エアシリンダが何をする部品なのか、どう動くのか、エアバルブやリードスイッチとどうつながるのかを、 現場で追いやすい形でやさしく整理します。

    向いている人

    • エアシリンダが何をする部品か知りたい人
    • 設備でよく見るけど、役割がまだあいまいな人
    • リードスイッチやエアバルブとの関係を整理したい人
    • 制御や設備保全を始めたばかりの人

    まだ不要な人

    • すでにエア回路や機器構成まで普通に読める人
    • シリンダ選定や細かい計算をしたい人
    • 空圧設計の細かい仕様差まで整理したい人

    先に結論

    • エアシリンダは、圧縮空気の力でまっすぐ動く部品です。
    • 動かす役目はエアバルブ、位置確認はリードスイッチで見ることが多いです。
    • 現場では、シリンダ単体ではなく、エアバルブ・配管・リードスイッチ・PLC とセットで見ると分かりやすいです。

    基本

    エアシリンダとは何か

    エアシリンダは、工場設備や自動機でよく使われる空圧機器のひとつです。 圧縮空気を使って、ロッドを押し出す・引っ込める動きを作ります。

    現場では、モータのように回転させる部品ではなく、 直線運動を作る部品として使われることが多いです。

    よくある使い方

    • ワークを押す
    • 部品を止める
    • 製品を横に逃がす
    • チャックを開閉する

    まずの理解

    「空気の力で、まっすぐ押す・戻す部品」と考えるとかなり入りやすいです。

    構造

    基本構造

    エアシリンダでまず見ておきたいのは、シリンダ本体、ピストン、ロッド、エア配管口です。

    シリンダ本体

    空気が入る本体部分です。内部でピストンが動きます。

    ピストン

    本体の中で動く部分です。空気で押されて移動します。

    ロッド

    外へ出てくる棒の部分です。実際にワークを押したり動かしたりします。

    エア配管口

    空気を入れたり抜いたりする口です。ここにチューブがつながります。

    動き

    どう動くのか

    エアシリンダの動きは、基本的にはかなりシンプルです。

    1. 片側に空気を入れる
    2. 内部のピストンが押される
    3. ロッドが前に出る、または後ろに戻る
    4. 反対側の空気は排気として抜ける

    前進するとき

    片側に空気を入れると、ピストンが押されてロッドが出ます。

    後退するとき

    反対側へ空気を入れると、ロッドが元の位置へ戻ります。

    まず覚えたいこと： エアシリンダは「空気を入れる向き」で動きが変わります。

    よく見るのは複動タイプ

    現場では複動シリンダをよく見ます。前に出す時も、戻す時も、どちらも空気で動かすタイプです。 制御しやすく、自動機で使いやすいからです。

    単動タイプもありますが、まずは複動をイメージしておけば大きくズレにくいです。

    周辺機器との関係

    エアバルブとリードスイッチとの関係

    エアシリンダは、単体で勝手に動くわけではありません。多くの設備では、 PLC → エアバルブ → エアシリンダ → リードスイッチ → PLC入力 という流れで見ます。

    エアバルブ

    空気の流れを切り替えて、シリンダを前進・後退させる役目です。

    リードスイッチ

    シリンダがちゃんと出たか、戻ったかの位置確認でよく使います。

    見方のコツ： シリンダだけを見るより、「何で動かして、どこで確認しているか」をセットで見た方が追いやすいです。
    現場での見方

    現場でどこを見るか

    1. ロッドが何を動かしているか

    まずはここです。何を押しているか、何を止めているかを見ると役割が見えやすいです。

    2. 前進と後退のどちらが本番動作か

    設備によっては「出る側が作業」「戻りは待機位置」ということがあります。

    3. 配管はどのエアバルブにつながっているか

    チューブを追うと、どのバルブで動かしているか見えてきます。

    4. リードスイッチが付いているか

    位置確認をしている設備かどうかが分かります。付いていない場合はタイマだけで見ていることもあります。

    5. 速度調整があるか

    スピコンで速度を落としていることがあります。速すぎると衝撃が大きくなるので、調整されていることが多いです。

    最初の見る順： ロッドの動き → 配管 → エアバルブ → リードスイッチ → PLC入力、の順で見ると整理しやすいです。
    トラブル時

    動きがおかしい時の見方

    動かない時

    • エアは来ているか
    • エアバルブは切り替わっているか
    • 配管が抜けていないか
    • ロッド先で引っかかっていないか

    戻らない時

    • 反対側に空気が入っているか
    • 排気が詰まっていないか
    • 機械的に噛み込みがないか

    動いているのに信号が入らない時

    • リードスイッチ位置がズレていないか
    • 配線が外れていないか
    • PLC入力が見えているか
    大事なこと： エアシリンダだけでなく、エアバルブ・配管・リードスイッチ・PLC入力までセットで見ないと切り分けしにくいです。
    まとめ

    エアシリンダは「動く部品」として見ると分かりやすい

    エアシリンダは、空気の力で直線運動を作る部品です。 現場では単体で見るより、

    • 何を動かしているか
    • どのエアバルブで動かしているか
    • どのリードスイッチで位置確認しているか

    を一緒に見ると理解しやすいです。 制御を始めたての人は、まず 「動かすのはエアバルブ、確認するのはリードスイッチ」 という整理で覚えておくと追いやすいです。
