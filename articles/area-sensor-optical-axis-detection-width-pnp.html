    エリアセンサとは

    この記事でいうエリアセンサは、パナソニック NA2-Nのように、投光側と受光側を向かい合わせ、複数の光軸で範囲を検出するタイプを指します。

    ● 1点ではなく範囲を見る

    複数の光軸を並べ、搬送物の通過や一定範囲への侵入を確認します。

    ↔ 投光側と受光側で構成

    基本イメージはコンベアの左右へ縦置きし、その間をワークが通過する配置です。

    📘 型式ごとに仕様確認

    光軸数、検出幅、検出距離、出力条件は製品ごとに異なります。

    呼び方で混同しやすい点

    AGV前方などで周囲を走査する回転・スキャン型センサを、この記事では「エリアセンサ」として扱いません。 また、外観が似ていても汎用エリアセンサと安全ライトカーテンは別の機器です。

    光電センサとの違い

    先に結論

    一般的な光電センサは「点」を見る用途が多く、今回のエリアセンサは「複数光軸で範囲」を見ます。

    比較項目一般的な光電センサエリアセンサ
    見る範囲設定した検出位置を中心に確認複数光軸で構成された範囲を確認
    得意な確認物体の有無・通過・位置一定の高さ・幅に物体が入ったか
    仕様で見る項目検出距離・検出方式・出力検出幅・光軸ピッチ・検出距離・検出物体・出力

    注意

    「範囲を検出できる」＝「どんな物でも確実に検出できる」ではありません。対象物の大きさ・形状・材質・通過位置を仕様と照合します。

    光軸・検出幅・検出距離の読み方

    ここは文章を全部読むより、4つの言葉の役割だけ先に押さえると仕様表を追いやすくなります。

    ① 光軸

    投光側から受光側へ向かう検出用の光の通り道。

    ② 光軸ピッチ

    隣り合う光軸の間隔。検出物体の条件とセットで確認します。

    ③ 検出幅

    センサが検出対象として扱う範囲の大きさ。開口寸法などと比較します。

    ④ 検出距離

    投光側と受光側を設置できる距離の目安。検出幅とは別物です。

    仕様表を見る順番

    用途 → 検出幅 → 光軸ピッチと対象物 → 検出距離 → 電源・出力・使用環境 の順で確認すると、数字を混同しにくくなります。

    PNP出力を確認するときの注意点

    PNPは「配線を決める答え」ではありません

    PNPは出力方式を確認する入口です。実際の接続は、センサ側とPLC・制御機器側の両方の仕様を照合して決めます。

    1. 出力方式

    対象型式がPNP出力か確認。

    2. 電源

    センサの電源種類・電圧範囲を確認。

    3. 入力仕様

    PLC側の入力方式・定格・信号条件を確認。

    4. 公式マニュアル

    端子番号・線色・極性・許容電流は対象型式の最新版で確認。

    ここは推測しない

    PNPという情報だけで、端子番号・線色・詳細配線を決めません。別型式の配線例を流用するのも避けます。

    導入前に確認する手順

    長い手順は文章で追うより、1項目ずつ確認できるカードで見る方が抜けを防ぎやすくなります。

    1. 用途を決める

    何を検出したいか。安全防護用か汎用検出用か。

    2. 対象物を確認

    大きさ・材質・透明/不透明・通過方向。

    3. 設置寸法を測る

    必要な検出幅と投光側・受光側の距離。

    4. 型式を特定

    実機銘板・購入記録・公式ページを一致させる。

    5. 仕様を照合

    検出幅・光軸ピッチ・検出距離・電源・出力。

    6. 接続資料を確認

    端子・線色・配線は対象型式の最新資料で確認。

    7. 試運転

    安全な状態で検出表示と制御側入力を確認。

    8. 記録を残す

    型式・資料名・改訂情報・確認日・確認者を記録。

    うまく検出できないときの切り分け

    順番を崩さない

    型式 → 電源 → 設置 → 検出物体 → 周囲環境 → 出力 → 最新資料 の順に確認します。いきなり配線を変更しません。

    確認項目見る内容
    型式実機銘板と対象資料が一致しているか
    電源公式仕様の電源条件に合うか
    設置投光側・受光側の向き、距離、光軸合わせ
    検出物体大きさ、材質、通過位置が条件に合うか
    周囲環境汚れ、遮光、振動、外乱光の影響
    出力PNP出力と接続先の入力条件が合うか
    資料対象型式の最新公式資料か

    安全上の注意

    汎用品と安全機器を混同しない

    NA2-N16-PNのような汎用エリアセンサを、安全ライトカーテン、安全スキャナ、安全リレーなどの代わりに使用しません。安全機能・カテゴリ・PL・SILなどを外観や名称から推測しません。

    • 端子番号、線色、配線、負荷条件は別型式から流用しない
    • 電源投入中の配線変更を行わない
    • 最新の公式製品ページ、取扱説明書、使用上の注意を確認する
