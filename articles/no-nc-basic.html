    NO / NCとは？

    NO / NC は、継電器やスイッチの平常時の接点状態を表す英語表記です。NO は Normally Open、NC は Normally Closed の略です。オムロンの技術解説では、NOはメーク接点（常時開路接点／A接点）、NCはブレーク接点（常時閉路接点／B接点）として整理されています。

    ここでいう平常時は、機械式スイッチなら非操作時、リレーならコイル非励磁時など、対象機器の基準状態です。設備全体が運転中か停止中かとは別に考えます。電子式センサではNO / NCや入光ON / 遮光ONなど、製品ごとに動作モードの表し方が異なるため、メーカー仕様を確認します。

    最初は英語をそのまま読む

    NO は Normally Open なので「通常開」、NC は Normally Closed なので「通常閉」です。まずOpen / Closedを接点の開路・閉路として理解すると、PLC入力表示やランプのON / OFFと混同しにくくなります。

    基本の意味：NOは通常開、NCは通常閉

    NO / NC の違いは、平常時に接点が開いているか閉じているか、その後の動作でどう切り替わるかで判断します。

    NO：Normally Open

    平常時は開路しています。操作・励磁などの動作で閉路する接点です。単純な直列回路では負荷がOFFからONへ変わる例もありますが、NOの定義は負荷状態ではなく接点が開いていることです。

    NC：Normally Closed

    平常時は閉路しています。操作・励磁などの動作で開路する接点です。単純な直列回路では負荷がONからOFFへ変わる例もありますが、NCの定義は負荷状態ではなく接点が閉じていることです。

    見分ける基準は「通常時」

    NO / NC は、動作後の状態だけで決めるものではありません。平常時に開路している接点がNO、平常時に閉路している接点がNCです。

    a接点・b接点との関係

    日本語の現場では、NO / NC と同じ意味で a接点・b接点 という呼び方もよく使います。メーカー技術資料でも、NO接点はA接点、NC接点はB接点として整理されています。

    英語表記 日本語の呼び方 通常時 動作時 覚え方
    NO a接点 開いている 閉じる 平常時：開 → 動作時：閉
    NC b接点 閉じている 開く 平常時：閉 → 動作時：開

    図面や機器の説明では、NO / NC 表記と a接点・b接点 表記が混ざることがあります。表記が違っても、通常時の状態を見れば意味は追えます。

    COM / NO / NC と書かれた端子もある

    a接点とb接点が共通端子を持つc接点では、製品によってCOM / NO / NCのように表示されます。COMは共通端子、NOは平常時に開いている側、NCは平常時に閉じている側です。端子番号や接点構成は機種ごとに異なるため、対象型式の回路図・仕様書を優先します。

    押しボタン・リレー・センサでの見方

    NO / NC は、押しボタン、リレー、電磁接触器、リミットスイッチなどの接点で使われます。また、一部の近接センサでは電子出力の動作モードとしてNO / NCが使われます。機械接点と電子出力は同じ構造ではないため、製品仕様に合わせて読み分けます。

    押しボタン

    非操作時を平常時として確認します。NO接点は平常時に開路し、操作で閉路します。NC接点は平常時に閉路し、操作で開路します。

    リレー・電磁接触器

    コイル非励磁時を平常時として見ます。コイルが励磁されると、NO接点は閉路し、NC接点は開路します。

    リミットスイッチ

    アクチュエータが操作されていない状態を基準に、接点構成と動作パターンをメーカー資料で確認します。安全用途のリミットスイッチは、通常の位置検出用とは別に安全機能・認証条件も確認が必要です。

    センサ出力

    近接センサにはNO / NCやNO+NCの動作モードを持つ製品があります。一方、光電センサでは「入光ON / 遮光ON」のような表記も使われます。センサは接点記号だけで決めつけず、対象型式の出力方式とタイムチャートを確認します。

    先輩NO / NC は、押した後だけじゃなくて「押す前にどうなっているか」を見ないと判断できないよ。

    後輩通常時を基準にするから、NOが通常開でNCが通常閉なんですね。

    PLC入力ではどう見る？

    PLC入力を見る時は、入力モニタのON/OFFだけでNO / NCを決めないことが大切です。PLCに電圧が入っているかどうかと、接点そのものがNOかNCかは、分けて考える必要があります。

    PLCのON/OFF表示と接点種別は別で考える

    入力モニタでX0がONだからNO、OFFだからNC、とは判断できません。PLC入力状態は接点種別だけでなく、電源・配線・入力回路・論理条件でも変わります。設備の図面・I/O割付・対象機器の仕様を合わせて確認します。

    見方 通常時 動作時 よくある例
    NO接点を使った単純な構成例 PLC入力OFF PLC入力ON スタートボタン、検出時ONのセンサ
    NC接点を使った単純な構成例 PLC入力ON PLC入力OFF 停止ボタン、断線検知を考慮した監視信号

    この表は単純な構成例です。実務では、入力モニタだけで接点種別を決めず、図面・I/O割付・機器仕様を照合します。PLC画面のON / OFFは「接点がNOかNCか」の定義そのものではありません。

    NO / NCは「表記 → 平常時 → 動作後 → PLC表示」の順で読む

    NO / NCを読む時は、略語だけで判断せず、対象機器の仕様と基準状態を先に決めると混乱しにくくなります。

    1. 表記・仕様を確認

    接点記号、NO / NC、a / b、COMなどの表記と、対象型式の接点構成・出力方式を確認します。

    2. 平常時を決める

    押しボタンなら非操作時、リレーなら非励磁時など、その機器で基準となる状態を確認します。

    3. 動作後の変化を見る

    平常時から動作時へ、接点が開から閉へ変わるのか、閉から開へ変わるのかを整理します。

    4. PLC表示は照合材料

    PLC入力表示は配線や論理条件の結果です。NO / NCの定義ではなく、図面や機器仕様との照合材料として扱います。

    現場で間違えやすいポイント

    NO / NC は基本用語ですが、実際の現場では「通常時」の取り方や、PLC入力表示との関係で混乱しやすいです。

    通常時を設備の停止状態と決めつける

    平常時は対象機器の基準状態です。機械式スイッチの非操作時やリレーの非励磁時などを指し、設備全体が運転中か停止中かとは分けて考えます。

    PLCのON/OFFだけでNO / NCを判断する

    PLC入力のON / OFFは、接点の種類だけでなく配線・電源・入力回路・論理条件にも左右されます。接点種別は図面・機器仕様と分けて確認します。

    NCなら必ず安全と考える

    安全性はNO / NCという名称だけでは決まりません。非常停止や安全スイッチでは、直接開路動作など安全用途向けの構造・認証・回路設計が別に必要です。

    センサ出力を機械接点と同じに扱う

    電子式センサではNO / NC、NO+NC、入光ON / 遮光ONなどの動作モードがあります。機械接点の構造をそのまま当てはめず、対象型式の出力仕様を確認します。

    停止系・安全系は必ず図面と仕様を確認

    安全に関わる信号は、NO / NCの名称だけで安全性を判断できません。非常停止・安全スイッチでは、直接開路動作など安全用途向けの機器仕様や適用規格、設備の安全設計を優先してください。配線変更・バイパス・強制入力は、設備の安全手順と権限に従って扱います。

    まとめ：NO / NCは通常時の状態で見分ける

    NO は Normally Open、つまり通常時に開いている接点です。NC は Normally Closed、つまり通常時に閉じている接点です。

    日本語の呼び方では、NOはa接点、NCはb接点に対応します。押しボタンやリレーでは平常時の接点状態を基準にし、電子式センサでは対象型式の動作モード、PLCでは入力表示と接点種別を分けて確認することが大切です。

    この記事の要点

    NOは「平常時に開 → 動作時に閉」、NCは「平常時に閉 → 動作時に開」。a接点・b接点との対応を押さえつつ、PLC表示やセンサ動作モードは別の情報として確認すると混乱しにくくなります。
