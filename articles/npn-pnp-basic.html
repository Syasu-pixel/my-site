    NPN / PNP とは？

    NPN / PNP は、主にセンサの出力方式や、PLC入力との組み合わせを考える時に出てきます。

    最初は難しく感じますが、初心者向けにかなりざっくり言うと、NPNは0V側、PNPは+24V側を見る考え方です。NO / NC のように「開く / 閉じる」を見るテーマではなく、どちら側へつながるかを見るテーマだと考えると整理しやすいです。

    まずは0V側か+24V側かで見る

    最初からシンク・ソースの言葉だけで覚えようとするより、NPNは0V側、PNPは+24V側と見た方が現場では追いやすいです。

    まずは基本の考え方

    NPN / PNP は、ON / OFF の種類ではありません。出力のつなぎ方、電流の流れ方、PLC入力との組み合わせを見る考え方です。

    NPN

    検出した時に出力が0V側につながるイメージです。よくシンク出力と呼ばれることがあります。

    PNP

    検出した時に出力が+24V側につながるイメージです。よくソース出力と呼ばれることがあります。

    入力ユニットとの組み合わせ

    センサだけではなく、PLC入力側がどの方式を受けるかも合わせて確認します。

    NO / NC とは別

    NO / NC は接点の開閉、NPN / PNP は出力方式や配線の流れを見るテーマです。

    ON/OFFと混ぜない

    NPN / PNP は「ONになるかOFFになるか」ではなく、ONした時にどちら側へつながるかを見る考え方です。

    センサ出力ではどう見る？

    現場で一番多いのは、近接センサや光電センサの出力方式でNPN / PNPを見る場面です。センサ本体や仕様書、カタログにNPN出力 / PNP出力と書かれていることがあります。

    この時に大事なのは、センサ単体で覚えようとしすぎず、PLC入力とセットで考えることです。

    項目 NPN PNP
    ざっくりした見方 0V側につながる +24V側につながる
    呼ばれ方 シンク出力と呼ばれることがある ソース出力と呼ばれることがある
    確認するもの センサ仕様、0V、入力ユニット センサ仕様、+24V、入力ユニット
    注意点 入力側との組み合わせが合うか確認 入力側との組み合わせが合うか確認

    PLC入力との組み合わせ

    実務ではここがかなり大事です。NPN / PNP はセンサだけの話ではなく、PLC入力ユニットとの組み合わせで考える必要があります。

    センサの出力方式と入力ユニット側の受け方が合っていないと、うまく入力が入らないことがあります。

    NPN側で見る時

    センサがNPNか確認し、0V側につながる流れで見ます。入力ユニットとの組み合わせも確認します。

    PNP側で見る時

    センサがPNPか確認し、+24V側につながる流れで見ます。入力ユニットとの組み合わせも確認します。

    GX Works3で確認

    入力モニタで、センサ反応時にX入力が入るか確認します。画面だけでなく現物も見ます。

    仕様 → 配線 → 入力変化

    センサ仕様、配線、実際の入力変化の順で見ると、かなり切り分けしやすくなります。

    センサとPLC入力はセットで見る

    センサLEDが反応していても、PLC入力が変わらなければ制御上は条件が成立しません。仕様、配線、入力モニタを合わせて確認します。

    現場で確認するポイント

    NPN / PNP で迷った時は、いきなり結線だけを追うより、仕様、電源、入力変化を順番に見ると整理しやすいです。

    まず仕様を確認する

    センサ本体、型番、仕様書、カタログでNPNかPNPかを先に確認します。見た目だけで判断しない方が安全です。

    24Vと0Vを見る

    テスターで24V / 0Vを確認してから見ると安心です。意外とここで配線ミスがあります。

    入力が変わるかを見る

    GX Works3 のデバイスモニタなどで、センサ反応時に入力がちゃんと変わるか確認します。

    混在に注意する

    NPNとPNPを混在させると、正常に動かないだけでなくトラブルの原因になりやすいです。

    先輩NPN / PNP は、センサだけじゃなくてPLC入力側とセットで見ないと間違えやすいよ。

    後輩なるほど。センサがNPNかPNPかだけじゃなくて、入力ユニット側も見るんですね。

    配線変更は電源と仕様を確認してから

    NPN / PNP まわりは、配線を間違えると入力が入らないだけでなく、機器トラブルにつながることがあります。電源、0V、+24V、入力仕様を確認してから作業してください。

    間違えやすい点

    NPN / PNP は、NO / NC やON / OFFと混ざりやすいテーマです。見るポイントを分けて考えると整理しやすくなります。

    NO / NC と混同する

    NO / NC は接点の開閉、NPN / PNP は配線や出力方式の考え方です。同じ意味ではありません。

    センサだけで判断する

    センサがNPN / PNPどちらかだけでなく、PLC入力側がどう受けるかも確認します。

    実際の入力変化を見ない

    仕様上は合っているように見えても、実際に入力が変わるかを確認しないと判断しきれません。

    24V / 0V を追わない

    電源の取り方や共通線の考え方を見落とすと、NPN / PNP の理解が崩れやすいです。

    まとめ：NPNは0V側、PNPは+24V側でまず整理する

    NPN / PNP は最初は難しく見えますが、まずは「NPN = 0V側」「PNP = +24V側」と整理すると理解しやすいです。

    そのうえで、センサ仕様、PLC入力ユニット、24V / 0V、実際の入力変化をセットで見ていくと、現場でも追いやすくなります。

    この記事の要点

    NPN / PNP はON / OFFの種類ではなく、センサ出力とPLC入力の組み合わせを見るための考え方です。仕様、配線、入力変化をセットで確認しましょう。
