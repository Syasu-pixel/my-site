    NPN / PNPの違いとは？
    センサ出力とPLC入力COMの関係を整理

    NPN / PNPは、トランジスタ出力のセンサとPLC入力を組み合わせる時に重要な考え方です。0V側・+24V側だけでなく、入力COMやNO/NCとの違いまで整理します。

    この記事でわかること

    NPN / PNPとは？ 電流の流れ PLC入力COM NO/NC・2線/3線との違い 確認する順番 よくある誤解 安全上の注意 まとめ

    1. NPN / PNPとは？

    NPN / PNPは、主にトランジスタ出力のセンサがONした時、出力端子をどちら側へつなぐかを表す方式です。近接センサや光電センサなどでよく見かけます。

    初心者向けには、NPNは0V側へ、PNPは+V側へ出力すると捉えると全体像をつかみやすくなります。ただし、実際の接続可否はセンサ単体では決まらず、PLC入力回路の仕様まで確認する必要があります。

    「NPN = 0V」「PNP = +24V」だけでは不十分

    この覚え方は入口として便利ですが、実務では「センサ出力がどちら側へつながるか」と「PLC入力がどのCOM構成で受けるか」をセットで見ます。型式が違えば端子構成や入力仕様も変わります。

    2. NPNとPNPは電流の流れ方が違う

    オープンコレクタ出力では、NPNとPNPで負荷を置く位置が変わります。オムロン公式では、NPNは電源＋とセンサ出力の間に負荷を置き、PNPはセンサ出力と電源－の間に負荷を置く方式として説明されています。

    NPN出力

    ON時に出力トランジスタが電流を0V側へ流す方向になります。センサ出力側では一般に「カレント・シンク」と呼ばれます。

    PNP出力

    ON時に出力トランジスタが+V側から電流を供給する方向になります。センサ出力側では一般に「カレント・ソース」と呼ばれます。

    言葉だけで覚えない

    「シンク / ソース」はセンサ側と入力回路側で説明の基準が変わり、混乱しやすい言葉です。回路図とCOM端子で確認します。

    24VDC設備でも型式確認

    24VDCを使う設備でも、すべての入力ユニットが同じ方式とは限りません。入力仕様を個別に確認します。

    センサ出力側の一般的な呼び方シンク出力ソース出力

    3. PLC入力ではCOMの見方が重要

    センサがNPNかPNPか分かったら、次はPLC入力側のCOM（共通端子）を確認します。ここが合っていないと、センサ本体が正常でもPLC入力として成立しません。

    オムロンのI/O機器には、入力用としてNPN対応（+コモン）、PNP対応（-コモン）と明記された製品例があります。これは分かりやすい代表例ですが、すべてのPLC・リモートI/Oへ一律に当てはめず、対象ユニットの回路図を確認してください。

    NPNセンサを見る時

    センサがONした時に出力が0V側へ引き込まれることを確認し、接続先入力がNPN対応か、COMの扱いがどうなっているかを見ます。

    PNPセンサを見る時

    センサがONした時に+V側へ出力されることを確認し、接続先入力がPNP対応か、COMの扱いがどうなっているかを見ます。

    入力LEDだけで決めない

    センサ表示灯、PLC入力LED、ソフト上の入力状態は別々に確認します。どこまで信号が届いているかを分けて考えます。

    交換時は同じ方式か確認

    外形や検出距離が同じでも、NPN / PNPが異なる型式があります。交換時は出力方式を型式表で確認します。

    「センサが反応しているのにPLC入力が入らない」時

    センサLEDが点灯していても、出力方式と入力回路が合わなければPLC入力は成立しません。センサ型式 → 出力方式 → PLC入力仕様 → COM → 実際の入力状態の順で確認すると切り分けしやすくなります。

    4. NPN / PNP、NO / NC、2線式 / 3線式は別の分類

    現場で混同しやすいポイントです。NPN / PNPだけを見て「ONの仕方」や「線の本数」まで判断してはいけません。

    NPN / PNP

    主にトランジスタ出力の方式。ON時に出力をどちら側へつなぐかを見る分類です。

    NO / NC

    検出時・非検出時に出力がON/OFFのどちらになるかという動作論理の分類です。

    2線式 / 3線式

    電源線と信号線の構成に関する分類です。NPN / PNPとは別軸で確認します。

    配線色

    一般的な配色例はありますが、色だけで方式を断定しません。型式と公式配線図を基準にします。

    交換時に「線数が同じだから大丈夫」は危険

    同じ3線式でもNPN / PNPが異なる製品があります。NO / NCや検出動作も別に確認し、型式末尾まで照合してください。

    5. 現場ではこの順番で確認する

    NPN / PNPで迷った時は、配線を触る前に資料と型式から確認します。安全手順に従い、通電状態での結線変更や無理な測定は行わないでください。

    1. センサ型式

    本体ラベル・図面・部品表から型式を確認し、メーカー資料でNPN / PNPを特定します。

    2. センサ出力回路

    出力回路図を見て、ON時に0V側へ引き込むのか、+V側へ出すのかを確認します。

    3. PLC入力仕様

    入力ユニットの型式と、NPN / PNPのどちらへ対応する入力回路かを確認します。

    4. COM接続

    入力ユニットの回路図を見て、COM端子が+24V側か0V側かを確認します。

    5. 入力状態

    設備の安全を確保したうえで、センサ表示・PLC入力表示・ソフト上の入力状態を分けて確認します。

    先輩「NPNだからこう配線」と先に決めるより、センサと入力ユニットの回路図を並べて見る方が間違いが少ないよ。

    後輩センサ側だけじゃなくて、COMまで見て一つの回路として考えるんですね。

    6. よくある誤解

    NPN = NO、PNP = NCだと思う

    別の分類です。NPN / PNPとNO / NCは独立して確認します。

    +COM / -COMを見ずに接続する

    入力ユニット側の共通端子を見ないと、方式の組み合わせを判断できません。

    シンク / ソースの言葉だけで判断する

    誰を基準に説明しているかで混乱しやすいため、回路図と電流の向きで確認します。

    型式末尾を見ない

    同じシリーズでもNPN / PNPで型式が分かれる場合があります。シリーズ名だけで判断しません。

    7. 確認・交換時の安全上の注意

    NPN / PNPの確認は低電圧DC回路で行うことが多いですが、設備全体にはモータ回路やAC電源、可動部が存在する場合があります。設備の停止・ロックアウト等の現場手順を優先し、資格・権限のある担当者がメーカー資料に従って作業してください。

    通電状態での結線変更を前提にしない

    誤配線は入力不成立だけでなく、機器故障や予期しない動作につながる可能性があります。安全装置を無効化せず、電源遮断や残留電圧確認など所属先の正式手順に従ってください。

    まとめ：NPN / PNPは「センサ出力 + PLC入力COM」で見る

    NPNはON時に0V側へ電流を流す出力、PNPは+V側から電流を供給する出力として整理できます。ただし、現場で本当に重要なのは、そのセンサが接続先PLC入力と組み合わせられるかです。

    センサ型式、出力方式、PLC入力ユニット、COM、実際の入力状態を一つずつ確認すれば、NPN / PNPは暗記ではなく回路として読めるようになります。

    この記事の要点

    NPN / PNP、NO / NC、2線式 / 3線式は別の分類です。センサだけを見ず、PLC入力COMまで含めて確認するのが基本です。
