制御盤・接地の基礎

PE・FG・SGの違いとは？
制御盤の接地を役割で整理

PE・FG・SGを「全部アース」とひとまとめにすると、図面や端子表記を読み違える原因になります。保護・フレーム・信号という役割の違いから整理します。

まず違いを見る現場での確認ポイント

PE

  • Protective Earth（保護接地）
  • 感電などの危険低減に関わる保護目的
  • 安全上の役割を最優先で扱う

FG

  • Frame Ground と表記される例がある
  • 筐体・フレームやEMC対策に関係する場合がある
  • 機器メーカーの定義を必ず確認する

SG

  • Signal Ground（信号グランド）
  • 通信・信号回路の基準電位として使われる例がある
  • PEやFGと同じ端子とは限らない

この記事の内容

3つの違いPEFGSG関係図確認ポイントよくある誤解公式資料

PE・FG・SGは「目的」で分けると理解しやすい

最初に結論です。PE・FG・SGは、名称が似ていても同じ意味ではありません。 とくにPEは保護目的の接地として扱われ、FGやSGは機器のフレーム・信号系など別の役割で使われることがあります。

表記代表的な読み方主な役割の考え方注意点
PEProtective Earth保護接地。故障時などの安全確保に関係する保護導体他のグランド端子で代用できるとは考えない
FGFrame Groundフレーム・筐体、シールド、ノイズ対策などに関係する表記例機種によって内部接続や用途が異なるためマニュアル確認が必要
SGSignal Ground信号・通信回路の基準電位として使われる表記例電源0V、PE、FGと同一とは限らない

重要：略号だけで接続先を決めない

FG・SGの意味や内部接続は機器ごとに異なります。端子名だけを見て「ここはアース」「ここは0V」と決めつけず、対象機器の最新マニュアル・配線図・安全指示を確認してください。

新人FGもSGも最後は大地につながると思っていました。

先輩そこが混同しやすいところです。まず「何を守るため・何の基準にするための端子か」を見て、実際の接続はその機器の資料で確認しましょう。

PE：Protective Earth は保護接地

PE は Protective Earth の略で、IEC系の資料で保護接地を示す代表的な表記です。安全目的の導体として、機器の露出導電部などが危険な電位にならないよう保護する考え方に関係します。

PEで最優先するのは「安全」

PEはノイズ対策のためだけの端子ではありません。メーカー資料でも、機能接地用の部品をPEとして使用しないよう明確に分けている例があります。

Schneider ElectricのTM3/TMS系資料では、Functional Ground（FE）用のグランド部品をProtective Ground（PE）として使用しないよう警告しています。この区別からも、保護接地と機能目的のグランドを同じ扱いにしないことが重要だと分かります。

なお、保護導体の選定や施工方法は設備・規格・機器条件に依存します。この記事では概念の整理に留め、実配線の施工寸法や接続方法は扱いません。

FG：Frame Ground はフレーム側のグランド表記例

FG は Frame Ground として使われる代表例があります。OMRON CP1Eのハードウェアユーザーズマニュアルでは、RS-232Cポートの端子表で FG = Frame ground と示されています。

ただし、ここで注意したいのは「FGという文字が出たら必ずPEに直結する」とは限らないことです。FG端子が筐体・コネクタシェル・機能接地・シールド処理とどのような関係にあるかは、機器の構造や設計によって異なります。

FGとFEは同義と決めつけない

Functional Earth（FE）という用語を使うメーカー資料もあります。FG（Frame Ground）とFE（Functional Earth）は似た場面に登場しますが、略号・定義・内部接続を機器横断で同一視せず、そのメーカーの用語定義に従うのが安全です。

SG：Signal Ground は信号回路の基準電位

SG は Signal Ground として使われる代表例があります。OMRON CP1EのRS-232C端子表では SG(0V) = Signal ground と示され、同じ端子表のFG（Frame ground）とは別項目になっています。

この例から分かるように、通信や信号回路では、信号が参照する基準電位とフレーム側のグランドを区別して記載することがあります。

「SG＝電源0V」と一般化しない

ある機器ではSGが0Vとして扱われる一方、別機器では絶縁・内部回路・通信方式が異なる場合があります。SG表記だけを見て電源0VやPEと同一と判断しないでください。

PE・FG・SGの関係をイメージ図で整理

以下は役割を理解するための概念図です。実際の内部接続や配線方法を示す図ではありません。

図面・端子台・マニュアルで確認するポイント

PE・FG・SGを見つけたときは、略号だけで判断せず、次の順で意味を絞り込みます。

1. 端子名称の定義

仕様表や端子説明に Protective Earth / Frame Ground / Signal Ground などの正式名称が書かれているか確認します。

2. 内部接続図

筐体、電源0V、通信回路、シールド端子との関係が示されているか確認します。

3. 接地・EMC章

配線図だけでなく、Installation / Grounding / EMC / Wiring Precautions などの章も確認します。

4. 最新版かどうか

同じシリーズでも改訂で注意事項が変わる場合があります。古い資料だけで判断しません。

新人図面にFGって書いてあったら、その線だけ追えばいいですか？

先輩線だけでなく端子説明と接地・EMCの注意事項までセットで見ます。機器の中でどうつながっているかが分からないまま、略号だけで判断しないのが大切です。

よくある誤解

誤解1：PE・FG・SGは全部同じアース

役割が異なります。とくにPEは保護目的です。FGやSGをPEの代用と考えないでください。

誤解2：SGは必ず電源の0V

機器によってはSG(0V)という表記例がありますが、すべての機器に一般化できません。

誤解3：FGは必ず大地へ直接つながっている

FGの内部接続や推奨処理は機器ごとに異なります。筐体やシールド、機能接地との関係をマニュアルで確認します。

誤解4：ノイズ対策なら接地は多いほど良い

接地・シールド・信号基準の設計は、EMC条件や回路構成を含めて判断する必要があります。むやみに端子同士を接続する考え方は避けます。

まとめ

3つを一言で分ける

PE＝保護、FG＝フレーム、SG＝信号。 まず役割で分け、その後に対象機器の最新マニュアルで内部接続と用途を確認する、という順番が基本です。

制御盤全体の接地の考え方を先に整理したい場合は「制御盤のアース・接地とは？」、シールド線との関係を知りたい場合は「シールド線とは？」も続けて確認してください。

参考にした公式資料

  • OMRON CP1E CPU Unit Hardware User’s Manual (W479) — RS-232C端子でFGをFrame ground、SG(0V)をSignal groundとして区別。
  • Schneider Electric: Grounding the M262 Logic/Motion Controller System — Functional earth ground (FE) と Protective earth ground (PE) を区別。
  • Schneider Electric: Grounding the TM3 System — FE用グランド部品をPEとして使わないよう明記。

資料の使い方

上記は用語の違いを確認するための代表例です。実際に扱う機器については、その型式・シリーズの最新版マニュアルを優先してください。
