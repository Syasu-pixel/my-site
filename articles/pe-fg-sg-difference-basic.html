    制御盤・接地の基礎

    PE・FG・SGの違いとは？
    制御盤の接地を役割で整理

    PE・FG・SGを「全部アース」とひとまとめにすると、図面や端子表記を読み違える原因になります。保護・フレーム・信号という役割の違いから整理します。

    まず違いを見る確認ポイント

    PE

    • Protective Earth（保護接地）
    • 安全上の保護目的
    • 他のグランドと同一視しない

    FG

    • Frame Ground の表記例
    • 筐体・フレームに関係
    • メーカー定義を確認

    SG

    • Signal Ground の表記例
    • 信号回路の基準電位に関係
    • PE・FG・0Vと同一とは限らない

    この記事でわかること

    3つの違いPEFGSG関係図確認方法よくある誤解公式資料

    PE・FG・SGは「目的」で分ける

    最初に結論です。PE・FG・SGは、名称が似ていても同じ意味ではありません。 とくにPEは保護目的の接地として扱われ、FGやSGはフレーム・信号系など別の役割で使われることがあります。

    表記代表的な読み方主な役割注意点
    PEProtective Earth保護接地。安全に関係する保護導体他のグランド端子で代用できると考えない
    FGFrame Groundフレーム・筐体などに関係する表記例内部接続・用途は機器ごとに確認
    SGSignal Ground信号・通信回路の基準電位として使われる表記例電源0V、PE、FGと同一とは限らない

    略号だけで接続先を決めない

    FG・SGの意味や内部接続は機器ごとに異なります。対象機器の最新マニュアル・端子説明・配線図を確認してください。

    後輩FGもSGも「アース」の仲間なら、同じところへつながると思っていました。

    先輩そこが混同しやすいところ。まず役割を分けて、実際の接続は機器ごとの資料で確認するのが基本だよ。

    PE：Protective Earth は保護接地

    PE は Protective Earth の略で、IEC系の資料で保護接地を示す代表的な表記です。機器の露出導電部などが危険な電位にならないよう、保護する考え方に関係します。

    PEで最優先するのは安全

    PEはノイズ対策のためだけの端子ではありません。Schneider Electricの資料では、Functional Ground（FE）用のグランド部品をProtective Ground（PE）として使わないよう明確に区別する例があります。

    この記事では概念の整理に留めます。実設備の施工・保護導体の選定は、対象設備の規格・設計・メーカー資料に従ってください。

    FG：Frame Ground はフレーム側のグランド表記例

    FG は Frame Ground として使われる代表例があります。OMRON CP1Eのハードウェアユーザーズマニュアルでは、RS-232Cポートの端子表で FG = Frame ground と示されています。

    ただし「FGなら必ずPEへ直結」とは限りません。FG端子が筐体・コネクタシェル・シールド処理などとどう関係するかは、機器の構造や設計で異なります。

    FGとFEも自動的に同義にしない

    Functional Earth（FE）という用語を使うメーカー資料もあります。FGとFEは似た場面に出ますが、略号・定義・内部接続をメーカー横断で同一視せず、各資料の定義を優先します。

    SG：Signal Ground は信号回路の基準電位

    SG は Signal Ground として使われる代表例があります。OMRON CP1EのRS-232C端子表では SG(0V) = Signal ground と示され、同じ表のFG（Frame ground）とは別項目になっています。

    通信や信号回路では、信号が参照する基準電位とフレーム側のグランドを区別して記載することがあります。

    「SG＝電源0V」と一般化しない

    ある機器ではSG(0V)という表記でも、別機器では絶縁や内部回路が異なる場合があります。SGの文字だけで電源0VやPEと同一と判断しません。

    PE・FG・SGを概念図で整理

    役割を理解するための概念図です。実際の内部接続や施工方法を示す図ではありません。

    図面・端子表・マニュアルで確認するポイント

    PE・FG・SGを見つけたときは、略号だけで判断せず、次の情報をセットで見ます。

    1. 端子名称の定義

    仕様表にProtective Earth / Frame Ground / Signal Groundなどの正式名称があるか。

    2. 内部接続図

    筐体、電源0V、通信回路、シールドとの関係が示されているか。

    3. Grounding / EMC章

    配線図だけでなく接地・EMC・配線注意事項を確認します。

    4. 改訂情報

    同じシリーズでも資料改訂があるため、最新版を優先します。

    後輩図面にFGと書いてあったら、その線だけ追えばいいですか？

    先輩線だけでなく端子説明と接地・EMCの注意事項までセットで見るよ。機器内部の関係が分からないまま、略号だけで決めつけないのが大切だね。

    よくある誤解

    PE・FG・SGは全部同じアース

    役割が異なります。とくにPEは保護目的です。FGやSGをPEの代用と考えません。

    SGは必ず電源の0V

    SG(0V)という表記例はありますが、すべての機器へ一般化できません。

    FGは必ず大地へ直接つながっている

    内部接続や推奨処理は機器ごとに異なります。筐体やシールドとの関係をマニュアルで確認します。

    ノイズ対策ならグランド同士を全部つなげればよい

    EMC条件や回路構成によって判断が必要です。端子名だけを根拠にむやみにグランド同士を接続する考え方は避けます。

    まとめ

    まずは3つを役割で分ける

    PE＝保護、FG＝フレーム、SG＝信号。 まず役割を分け、その後に対象機器の最新マニュアルで定義と内部接続を確認する、という順番が基本です。

    制御盤全体の接地を先に整理したい場合は「制御盤のアース・接地とは？」、シールド線との関係を知りたい場合は「シールド線とは？」も続けて確認してください。

    参考にした公式資料

    • OMRON CP1E CPU Unit Hardware User’s Manual (W479) — RS-232C端子でFGをFrame ground、SG(0V)をSignal groundとして区別。
    • Schneider Electric: Grounding the M262 Logic/Motion Controller System — Functional earth ground (FE) と Protective earth ground (PE) を区別。
    • Schneider Electric: Grounding the TM3 System — FE用グランド部品をPEとして使用しないよう明記。

    資料の使い方

    上記は用語の違いを確認する代表例です。実際に扱う機器は、その型式・シリーズの最新版マニュアルを優先してください。
