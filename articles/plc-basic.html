PLCとは何か？
電気工事士向けにやさしく整理

PLCは、設備や機械の入力を受けて、条件に合わせて出力を動かすための制御機器です。 最初は難しく見えますが、考え方の基本はそこまで複雑ではありません。 まずは 入力 → PLC → 出力 の流れで見るとかなり理解しやすくなります。 ラダー図やGX Works3に入る前に、この全体像をつかんでおくと後がかなり楽です。

向いている人

  • 制御盤や設備まわりの仕事でPLCを見る機会がある人
  • GX Works3を触る前に全体像を整理したい人
  • 入力と出力の違いを現場目線で理解したい人
  • ラダー図や自己保持の記事へ進む前に基礎をつかみたい人

まだ不要な人

  • 今のところ配線作業だけで制御に関わる予定がほぼない人
  • まずは図面や工具の使い方を優先したい人
  • 細かいプログラム命令だけを先に覚えたい人

先に結論

PLCは、押しボタンやセンサなどの入力を受けて、ランプや電磁弁、モータ接触器などの出力を動かす制御機器です。 リレー回路の考え方を引き継ぎつつ、プログラムで動きを組めるのが大きな特徴です。 最初は「難しい機械」よりも、信号を見て、条件に応じて動かす箱として考えると分かりやすいです。

全体像

PLCは「入力を受けて、条件に合わせて出力を動かす」ための制御機器です

PLCは、押しボタン、センサ、リミットスイッチなどから入ってくる信号を見て、 その条件に応じてランプ、ブザー、電磁弁、接触器などを動かします。

つまり、現場で起きている状態を入力として受け取り、それをもとに設備側へ出力を返す役目です。 難しく考えすぎず、まずは見ている側が入力、動かす側が出力と考えると整理しやすいです。

入力を見る

押しボタンやセンサなど、PLCへ状態を伝える側です。

PLCで判断する

入ってきた信号をもとに、どの出力を動かすかを決めます。

出力を動かす

ランプ、ブザー、電磁弁、接触器などを動かします。

ラダー図で組む

PLCの動きは、ラダー図で組まれていることが多いです。

最初は「PLC」という言葉に引っぱられがちですが、 やっていることは 入力を受ける → 条件を見る → 出力を返す です。 この流れだけでもかなり分かりやすくなります。
基本の考え方

入力と出力の違いは「PLCへ伝える側」と「PLCから動かす側」で見ると分かりやすいです

制御を見始めると、入力と出力の考え方で少し迷いやすいです。 ですが、ここはシンプルに整理できます。

  • 入力（X）：PLCへ状態を伝える側
  • 出力（Y）：PLCから動かす側

押しボタンやセンサは、今どうなっているかをPLCへ伝えます。 逆に、ランプや電磁弁、モータ接触器などは、PLCからの信号で動きます。

入力でよく見るもの

  • 押しボタン
  • 近接センサ
  • リミットスイッチ
  • フロートスイッチ
  • 各種接点信号

出力でよく見るもの

  • 表示ランプ
  • ブザー
  • 電磁弁
  • 接触器
  • リレー
現場で迷った時は、 「これはPLCへ知らせる側か？」 「それともPLCから動かされる側か？」 で見ると整理しやすいです。
混ざりやすい所

リレー回路との違いは「配線中心」か「プログラム中心」かで見ると分かりやすいです

PLCは、リレー回路の考え方を引き継いでいます。 だからラダー図も、リレー回路に近い見た目になっています。

ただし、違いもあります。

リレー回路
回路の動きそのものを配線で作る形です。変更するときは配線や機器構成を見直すことが多いです。
PLC
配線で入力・出力をつなぎ、内部の動きはプログラムで組む形です。動作変更はプログラム側で対応しやすいです。

つまり、考え方の元は近いですが、PLCは制御の中身をソフト側で持てるのが大きいです。

とはいえ、現場では配線も大事です。 プログラムだけ見ても原因が分からないことは多いので、入力機器、出力機器、端子、実機状態も合わせて見ることが大事です。
ラダー図との関係

ラダー図は、PLCの動きを追いやすくするための表現です

PLCの制御は、ラダー図で書かれていることが多いです。 ラダー図はリレー回路をベースにした見た目なので、電気系の人には流れを追いやすい形になっています。

例えば、

  • 押しボタンが入ったら出力を動かす
  • 自己保持で動きを続ける
  • インターロックで同時動作を防ぐ

といった動きも、ラダー図の中で表現されます。

なので、PLCを理解する時は PLC本体だけを見るより、ラダー図とセットで考える 方が実務ではかなり分かりやすいです。
実務で大事

GX Works3に入る前は「全部覚える」より「どこを見るか」を知っておく方が大事です

ユーザーさんのように三菱GX Works3を使うなら、最初から機能を全部覚える必要はありません。 まずは次の4つが分かるだけでもかなり進めやすいです。

  1. 入力がどこで入っているか
  2. 出力がどこで動いているか
  3. 自己保持やインターロックがどこにあるか
  4. 今どの信号がONしているか

現場では、新しくきれいに組むより、トラブル時に後から見た人でも追えることが大事です。 だからこそ、難しく書くより、シンプルで追いやすいラダーの方が役立つ場面が多いです。

「どこが入力で、どこが出力で、どこで保持して、どこで止めているか」 この見方ができるだけでも、GX Works3はかなり触りやすくなります。
ここだけ覚える

最初はこの4つを押さえるとかなり入りやすいです

  1. PLCは入力を受けて出力を動かす制御機器
  2. 入力はPLCへ伝える側、出力はPLCから動かす側
  3. ラダー図で動きを追うことが多い
  4. GX Works3では全部覚えるより、どこを見るかが大事
よくある疑問

PLCでよくある疑問

Q. PLCとシーケンサは同じですか？

A. ほぼ同じ意味で使われることが多いです。特に三菱系ではシーケンサという言い方もよく出てきます。

Q. PLCは難しいですか？

A. 最初は難しく見えますが、入力 → PLC → 出力 の流れで見るとかなり理解しやすくなります。

Q. まず何から覚えるといいですか？

A. 入力と出力の違い、ラダー図の見方、自己保持、インターロックあたりを順に押さえると進めやすいです。
