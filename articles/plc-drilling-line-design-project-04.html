    加工ステーション制御編

    第3回でCV04までの搬送条件を固定したので、第4回ではワークをCV04から横へ1ピッチ移載して加工し、加工後に同じ位置へ戻して搬送を再開する流れを、ラダーを書く前の条件に分解します。

    加工の流れを見るインターロックを見る

    今回決めること

    • CV04から横移載を開始する条件
    • 1ピッチ奥の加工治具で固定・穴あけする順番
    • 加工後にラインへ戻し、搬送を再開する条件

    追加する仮I/O

    • X11/X12：横移載の原点端・加工端
    • X13〜X20：クランプ・ドリル・主軸・加工位置確認
    • Y15〜Y21：横移載・クランプ・主軸・ドリル

    今回はまだやらないこと

    • GX Works2への完成ラダー入力
    • 手動運転と復旧操作の詳細
    • 実機の加工条件・速度・圧力の決定

    第4回でわかること

    搬送からの受入加工I/O加工シーケンス完了条件インターロックタイムアウトまとめ

    1. 第3回の終点を「横移載の受渡位置」にする

    第3回では、CV04にワークが到着し、加工側が受け取れるまでCV04側で保持するところまでを搬送側の責任範囲にしました。第4回では、CV04の受渡位置から横移載テーブルでワークを1ピッチ奥の加工治具へ運び、加工後に同じ受渡位置へ戻す構成にします。

    ライン側待機横移載テーブルが原点にあり、CV04のワークを受け取れる。
    横移載CV04を停止したまま、ワークをライン外の加工治具へ1ピッチ移す。
    加工後復帰加工完了後は横移載テーブルを原点へ戻し、ワークを再び搬送ラインへ返す。

    きりこを搬送ラインへ落とさない

    穴あけはCV04上では行わず、ラインから横へ逃がした専用加工位置で行います。加工位置の下に切りくず受けを置けば、MCナイロンの切りくずがコンベアや搬送センサ周辺へ溜まりにくくなります。

    2. 横移載を含めて加工ステーションのI/Oを確定する

    第2回で保留した加工部I/Oへ、横移載テーブルの両端確認を追加します。ここでは「ライン側原点」と「加工側到達」を別々に確認し、位置が確認できない状態では次動作へ進ませません。

    仮番地入力役割
    X11横移載 原点端テーブルがCV04側の受渡位置に戻っていることを確認
    X12横移載 加工端テーブルが1ピッチ奥の加工位置へ到達したことを確認
    X13クランプ前進端加工治具でワークを保持したことを確認
    X14クランプ後退端ワーク解放完了を確認
    X15ドリル上昇端加工ヘッドが原点側へ戻ったことを確認
    X16ドリル下降端仮想ライン上の加工終点を確認
    X17主軸運転確認主軸が運転状態になったことを確認
    X20加工位置ワーク横移載後、ワークが加工治具位置にあることを確認
    仮番地出力役割
    Y15横移載 前進横移載テーブルをCV04側から加工側へ送る
    Y16横移載 復帰加工後のテーブルをCV04側へ戻す
    Y17クランプ加工中にワークを保持する
    Y20主軸運転穴あけ用の主軸を運転する
    Y21ドリル下降加工ヘッドを下降させる

    横移載の弁方式はまだ固定しない

    ここでは前進・復帰を別出力として整理しますが、実機では電磁弁やアクチュエータ構成によって1出力方式・2出力方式のどちらもあり得ます。記事では動作の責任を分けるため2出力で仮置きし、最終I/Oは機器選定後に確定します。

    メーカー公式資料で確認

    FX3Uのハードウェア仕様は三菱電機「FX3Uシリーズ ユーザーズマニュアル［ハードウェア編］」（Ver.AA / JY997D16101-AA / 2024年6月）、内部リレーやタイマ、基本命令への落とし込みは「FX3S・FX3G・FX3GC・FX3U・FX3UCシリーズ プログラミングマニュアル［基本・応用命令解説編］」（Ver.V / JY997D11701-V / 2021年4月）を一次資料として確認します。X/Yは8進数で扱うため、X17の次をX20、Y17の次をY20として仮割付します。 三菱電機公式・MELSEC-Fマニュアル一覧を見る

    3. 横移載からライン復帰までを11の状態へ分ける

    加工ステーション全体を「加工する」だけでまとめず、横移載・保持・加工・復帰を別状態に分けます。加工位置は搬送ラインから1ピッチ奥にあるため、加工中はCV04と切り離して考えられます。

    ① 受入待ち

    X11原点端を確認し、CV04へワーク受入を許可する。

    ② CV04位置決め

    CV04上でワークを受渡位置に停止させ、搬送を止める。

    ③ 横移載

    Y15でテーブルを加工側へ送り、X12加工端を待つ。

    ④ 加工位置確認

    X12とX20がそろったら、加工治具にワークが入ったと判断する。

    ⑤ クランプ

    Y17を動かし、X13クランプ前進端を確認する。

    ⑥ 主軸確認

    Y20で主軸を運転し、X17の運転確認を待つ。

    ⑦ 穴あけ

    Y21でドリル下降。X16加工終点まで進める。

    ⑧ 原点復帰

    Y21を解除し、X15ドリル上昇端まで戻す。

    ⑨ クランプ解除

    主軸停止後にY17を解除し、X14後退端を確認する。

    ⑩ ラインへ復帰

    Y16で横移載テーブルを戻し、X11原点端を確認する。

    ⑪ 搬送再開

    横移載が完全に原点へ戻った後だけCV04から排出側への搬送を再開する。

    4. 加工完了と「ラインへ戻った」を分けて考える

    穴あけが終わっても、ワークはまだライン外の加工治具にあります。そこで第4回では、加工完了と搬送復帰完了を別の境界にします。

    加工完了

    X16で加工終点を確認したあと、X15ドリル上昇端まで戻り、主軸停止・クランプ解除が完了したところまでを加工完了とします。

    搬送復帰完了

    加工完了後に横移載テーブルをライン側へ戻し、X11原点端を確認して初めてCV04搬送を再開します。これにより、横移載途中でコンベアを動かす競合を防ぎます。

    実加工品質とは別

    φ8・深さ15 mmという加工品質を実機で保証するには、機械剛性、工具、送り、回転、位置決めなど別の設計が必要です。ここではPLCの通常シーケンスだけを扱います。

    5. 横移載とCV04を同時に動かさない

    今回の構造では、加工中だけでなく横移載中の競合防止が重要です。特にCV04搬送と横移載テーブルが同時に動くと、ワークの受渡位置が崩れるため明確に排他します。

    動作最低限そろえる状態狙い
    横移載 前進CV04停止・X11原点端・ドリル上昇・クランプ後退搬送中や加工機未退避で移載しない
    CV04搬送X11原点端・横移載出力OFFテーブルがライン外にいる間はコンベアを動かさない
    クランプX12加工端・X20ワークあり・ドリル上昇加工位置へ到達する前に保持しない
    ドリル下降X13クランプ前進端・X17主軸運転・X20ワークあり保持と主軸確認がそろう前に下降させない
    横移載 復帰X15ドリル上昇・主軸停止・X14クランプ後退加工機が退避する前にワークを動かさない
    次ワーク受入X11原点端・前ワークがCV04から排出済み加工済みワークが残った状態で次ワークを入れない

    安全機能は通常シーケンスと別

    非常停止やガードなど、人の安全に関わる機能は通常PLCシーケンスだけに依存させません。実機では安全回路・安全機器・リスクアセスメントを別途設計します。

    6. 横移載の往復もタイムアウト監視する

    加工動作だけでなく、ライン側から加工側への移載と加工側からライン側への復帰も監視対象にします。確認信号が来なければ次状態へ進めません。

    監視区間開始完了異常判定の考え方
    横移載 前進Y15要求X12加工端加工位置まで届かなければ停止対象
    クランプY17要求X13前進端保持確認が来なければ主軸へ進まない
    主軸Y20要求X17運転確認運転確認が来なければドリル下降しない
    加工下降Y21要求X16下降端加工終点が来なければ次へ進まない
    原点復帰Y21解除X15上昇端上昇端が来なければクランプ解除しない
    横移載 復帰Y16要求X11原点端ライン側へ戻らなければCV04を再始動しない

    具体的なタイマ値、異常表示、手動復旧は第5回で決めます。第4回では監視区間と正常完了信号を固定します。

    7. 第4回のまとめ

    POINT 1加工を搬送ラインから1ピッチ逃がす横移載テーブルで専用加工位置へ運び、切りくずをラインから分離する。
    POINT 2加工後は同じ経路でラインへ戻す加工完了と搬送復帰完了を別々に確認する。
    POINT 3横移載とCV04を排他する移載テーブルが原点でない限りCV04を動かさない。
    設計ステップ第4回で決めたこと
    設備構造CV04横に1ピッチ奥の加工治具を置き、横移載テーブルで往復する
    I/OX11〜X20、Y15〜Y21へ横移載・加工確認を仮割付
    シーケンスCV04受渡から加工、ライン復帰、搬送再開まで11状態に分割
    インターロック横移載中はCV04停止、加工機退避後だけラインへ復帰
    異常監視横移載の前進・復帰を含む各動作にタイムアウト監視点を置く

    この設備を、設計の順番でシリーズ化する

    今読んでいる位置と、次に進む記事がすぐ分かるようにシリーズ全体を並べています。

    1. 第1回設備仕様と全体構想完了
    2. 第2回PLC・I/O構成を決める完了
    3. 第3回CV01〜CV04の搬送制御を考える完了
    4. 第4回加工ステーションのシーケンスを作る今ここ
    5. 第5回手動運転・異常処理・復旧を設計する次ここ
    6. 第6回GOT画面と保守・生産情報を作る

    次回｜手動運転・異常処理・復旧を設計する
