    今回決めること

    • CV04からCV05へ受け入れて停止する条件
    • フリーローラー上昇→横移載→位置決め→穴あけの順番
    • 加工後にCV05へ戻し、ローラー下降→排出まで確認する条件

    第4回で固めるI/O

    • 加工STで扱う入力：16点
    • 加工STで扱う出力：14点（ダブルソレノイド前提）
    • 設備全体：約58DI / 32DO

    今回はまだやらないこと

    • GX Works2への完成ラダー入力
    • 手動運転と復旧操作の詳細
    • 実機の加工条件・速度・圧力の決定

    第4回でわかること

    搬送からの受入加工I/O加工シーケンス完了条件インターロックタイムアウトまとめ

    1. 第3回の終点からCV05へ受け渡す

    第3回はCV04までの搬送を設計しました。第4回では、その先にCV05（加工ステーションコンベア）を置き、CV04から受け取ったワークをCV05上でいったん停止させます。そこから横移載機構を使って、搬送ラインから1ピッチ奥の加工位置へワークを逃がします。

    CV05受入縦搬送ベルトでCV04から受け取り、CV05在荷X11で停止位置を確認する。
    横移載フリーローラーを上げ、搬入プッシャで加工位置へ横押しする。
    加工後復帰戻しプッシャでCV05へ戻し、ローラーを下げて縦搬送へ復帰する。

    きりこを搬送ラインへ落とさない

    穴あけはCV05上では行わず、ラインから横へ逃がした専用加工位置で行います。加工位置直下に切りくず受けを置き、MCナイロンの切りくずがコンベアや搬送センサ周辺へ溜まるのを避けます。

    2. CV05と横移載機構を含めてI/Oを確定する

    第2回では加工部の細かなI/Oを保留していました。第4回では、CV05の在荷・排出確認、昇降フリーローラー、搬入/戻しの2本のプッシャ、位置決め、クランプ、ドリルまで含めて加工部を具体化します。

    区分信号点数
    ワーク確認CV05在荷、加工治具在荷、排出通過3
    フリーローラー上昇端、下降端2
    搬入プッシャ前進端、後退端2
    戻しプッシャ前進端、後退端2

    第4回で直接扱う加工ST入力は合計16点です。これとは別に、設備全体では操作盤、安全監視、CV01〜CV04、ストッパ、駆動異常などの入力もあります。

    元の設備正本で全体点数を再計算

    記事だけの簡略I/Oではなく、操作・安全監視・ストッパ・駆動状態まで含む元のサンプルライン正本で数え直すと、今回仕様反映後は約58DI / 32DOです。加工STで扱う出力はダブルソレノイド前提で14点になります。

    GX Works2版は入力増設を1段追加

    従来のFX3U-80MT/DS + 16点入力増設では56DIまでだったため、今回の58DIには足りません。GX Works2教材版は8点入力増設も加えてDI64点を確保する構成へ更新します。物理X/Y番地はGX Works2プロジェクト上の割付確認後に最終確定します。

    3. CV05受入から排出までを順番に分ける

    今回の加工ステーションは、CV05上でそのまま穴あけする設備ではありません。いったんワークを横方向へ逃がして加工し、同じ経路でCV05へ戻してから縦搬送へ復帰させます。

    ① CV05受入

    CV04からCV05へ搬送し、X11在荷を確認して停止する。

    ② ローラー上昇

    Y16でフリーローラーを上げ、X13上昇端を確認する。

    ③ 加工側へ横移載

    Y17で搬入プッシャを前進させ、ワークをフリーローラー上で加工側へ押す。

    ④ 加工位置確認

    X30でワークを確認し、搬入プッシャを退避する。

    ⑤ 位置決め

    Y21を作動し、X21で位置決め完了を確認する。

    ⑥ クランプ

    Y22を作動し、X23で保持完了を確認する。

    ⑦ 穴あけ

    Y23主軸運転とX27確認後、Y24で下降しX26加工終点を確認する。

    ⑧ 加工機復帰

    ドリルを上昇原点X25へ戻し、主軸停止、クランプ・位置決めを解除する。

    ⑨ CV05へ戻す

    Y20で戻しプッシャを前進させ、ワークをフリーローラー上へ戻す。

    ⑩ ローラー下降

    X11在荷を確認後、プッシャ退避、フリーローラーを下降させX14を確認する。

    ⑪ 縦搬送再開

    Y15でCV05を運転し、ワークを終端のメカ式シュートへ送る。

    ⑫ 排出完了

    X12でライン外への排出を確認し、1サイクル完了とする。

    4. 「加工完了」「CV05復帰」「排出完了」を分ける

    穴あけが終わってもワークはまだライン外の加工位置にあります。そこで第4回では、加工機が安全位置へ戻ったこと、ワークがCV05へ戻ったこと、最後にライン外へ排出されたことを別々に確認します。

    加工完了

    加工終点を確認したあと、ドリル上昇端まで戻し、主軸停止、クランプ解除、位置決め解除までそろったところを加工完了とします。

    CV05復帰完了

    戻しプッシャでワークをCV05へ戻し、CV05在荷と両プッシャ退避を確認します。その後フリーローラー下降端が成立して初めて縦搬送へ戻せる状態とします。

    1サイクル完了

    CV05を再始動し、メカ式シュート側の排出通過確認が成立して初めて1サイクル完了とします。

    実加工品質とは別

    φ8・深さ15 mmという加工品質を実機で保証するには、機械剛性、工具、送り、回転、位置決めなど別の設計が必要です。ここではPLCの通常シーケンスだけを扱います。

    5. 縦搬送と横移載を同時に動かさない

    加工部で最も重要なのは、CV05の縦搬送と横移載機構を競合させないことです。フリーローラーが上がっている間はCV05を停止し、加工機が完全に退避するまでワークを戻しません。

    動作最低限そろえる状態狙い
    ローラー上昇CV05停止・CV05在荷・両プッシャ後退搬送中にワーク支持高さを変えない
    搬入プッシャローラー上昇端・加工側受入可ベルトから完全に浮いてから横押しする
    位置決め・クランプ加工治具在荷・搬入プッシャ後退移載途中で治具を動かさない
    ドリル下降位置決め完了・クランプ完了・主軸運転確認・ドリル上昇原点保持と加工準備を確認してから下降する
    戻しプッシャドリル上昇・主軸停止・クランプ解除・位置決め解除加工機退避前にワークを動かさない
    ローラー下降CV05在荷・両プッシャ後退ワークがCV05上へ戻る前に下降させない
    CV05再始動ローラー下降端・CV05在荷横移載機構が完全に退避してから縦搬送する

    安全機能は通常シーケンスと別

    非常停止やガードなど、人の安全に関わる機能は通常PLCシーケンスだけに依存させません。実機では安全回路・安全機器・リスクアセスメントを別途設計します。

    6. 昇降・横移載・加工・排出をそれぞれ監視する

    フリーローラー昇降、2本のプッシャ、位置決め、クランプ、穴あけ、CV05排出まで、それぞれ「動かしたあとに何を確認したら次へ進めるか」を決めます。確認信号が来なければ次状態へ進ませません。

    監視区間正常完了の確認次へ進ませない例
    ローラー上昇上昇端移載高さまで上がっていない
    加工側へ移載搬入プッシャ前進端 + 加工治具在荷ワークが加工位置へ入っていない
    位置決め位置決め端基準位置が成立していない
    クランプクランプ端保持完了を確認できない
    主軸運転確認主軸確認前にドリル下降しない
    穴あけ加工終点→ドリル上昇端ドリルが原点へ戻っていない
    CV05へ復帰戻しプッシャ前進端 + CV05在荷ワークがCV05へ戻っていない
    ローラー下降下降端縦搬送位置へ戻っていない
    最終排出排出通過確認ライン外へ出たことを確認できない

    具体的なタイマ値、異常表示、手動復旧は第5回で決めます。第4回では、監視区間と正常完了条件までを固定します。

    7. 第4回のまとめ

    POINT 1CV05で縦搬送から横移載へ切り替えるフリーローラーを上昇させ、ワークを縦ベルトから離して横押しする。
    POINT 2加工後は同じCV05へ戻す加工機退避後に戻しプッシャでワークをフリーローラー上へ戻す。
    POINT 3排出確認で1サイクルを閉じるローラー下降→縦搬送→シュート排出まで確認して完了にする。
    設計項目第4回で確定したこと
    加工ステーションCV05＋昇降フリーローラー＋往復2本のプッシャ＋加工治具
    I/O加工STで扱う入力16点・出力14点、設備全体は約58DI・32DO
    シーケンスCV05受入から横移載・加工・復帰・排出まで12状態に分割
    インターロック縦搬送・ローラー昇降・プッシャ・加工機の競合を防止
    完了境界メカ式シュート側の排出確認までを1サイクルとする

    この設備を、設計の順番でシリーズ化する

    今読んでいる位置と、次に進む記事がすぐ分かるようにシリーズ全体を並べています。

    1. 第1回設備仕様と全体構想完了
    2. 第2回PLC・I/O構成を決める完了
    3. 第3回CV01〜CV04の搬送制御を考える完了
    4. 第4回加工ステーションのシーケンスを作る今ここ
    5. 第5回手動運転・異常処理・復旧を設計する次ここ
    6. 第6回GOT画面と保守・生産情報を作る
    7. 最終GX Works2へ実装してシミュレーションする

    次回｜手動運転・異常処理・復旧を設計する

    第5回では、第3回の搬送タイムアウトと第4回の加工タイムアウトをつなぎ、どの異常を表示するか、どこまで手動で動かせるか、リセット後にどの状態へ戻すかを整理します。
