    追加する仮I/O

    第4回でわかること

    搬送からの受入加工I/O加工シーケンス完了条件インターロックタイムアウトまとめ

    1. 第3回の終点を、そのまま第4回の開始条件にする

    第3回では、CV04にワークが到着したあと、加工側が受け取れるまでCV04側で保持するところまでを搬送側の責任範囲にしました。第4回では、この境界から先だけを扱います。

    加工側が空き加工位置にワークがなく、クランプが戻り、ドリルが上昇原点にいる。
    受入許可加工側が安全な待機状態なら、CV04からの送り出しを許可する。
    位置確認加工位置センサがONになったら搬送を止め、加工シーケンスへ渡す。

    搬送と加工の責任範囲を分ける

    CV04の搬送完了と、加工位置でワークを保持できたことは別の状態として扱います。これにより、搬送の条件と加工機の条件が一つの長いロジックへ混ざりにくくなります。

    2. 加工ステーションで必要なI/Oをここで確定する

    第2回では加工部の細かなI/Oを保留していました。ここでは、仮想ラインの加工シーケンスを説明できる最小構成として次の信号を追加します。

    仮番地入力役割
    X11加工位置ワークワークが加工位置まで入ったことを確認
    X12クランプ前進端ワーク保持完了の確認
    X13クランプ後退端クランプ退避完了の確認
    X14ドリル上昇端加工ヘッドが原点側へ戻ったことを確認
    X15ドリル下降端仮想ライン上の加工終点を確認
    X16主軸運転確認主軸が運転状態になったことを確認
    X17排出完了加工済みワークが加工位置を離れたことを確認
    仮番地出力役割
    Y15クランプ加工中にワークを保持する仮出力
    Y16主軸運転穴あけ用の主軸を運転する仮出力
    Y17ドリル下降加工ヘッドを下降させる仮出力
    Y20排出動作加工後のワークをシュート側へ送る仮出力

    番地は教材用の仮割付

    FX3UのX/Yは8進数で扱うため、Y17の次を仮にY20としています。実際の点数・増設構成・配線は選定したCPUやI/O構成に合わせて最終確定します。

    メーカー公式資料で確認

    FX3Uのハードウェア仕様は三菱電機「FX3Uシリーズ ユーザーズマニュアル［ハードウェア編］」（Ver.AA / JY997D16101-AA / 2024年6月）、内部リレーやタイマ、基本命令への落とし込みは「FX3S・FX3G・FX3GC・FX3U・FX3UCシリーズ プログラミングマニュアル［基本・応用命令解説編］」（Ver.V / JY997D11701-V / 2021年4月）を一次資料として確認します。第4回では完成ラダーにはまだ落とし込みません。 三菱電機公式・MELSEC-Fマニュアル一覧を見る

    3. 加工を8つの状態へ分ける

    加工ステーション全体を一つの条件式で動かすのではなく、今どこまで進んだかが分かるように状態を分けます。後で内部リレーMやステップへ割り付けやすい形にしておくのが狙いです。

    ① 受入待ち

    加工位置が空き、クランプ後退、ドリル上昇を確認してCV04へ受入許可を出す。

    ② 位置確認

    X11でワーク到着を確認し、搬送側から加工側へ制御の主役を渡す。

    ③ クランプ

    Y15を動かし、X12の前進端確認後だけ次へ進む。

    ④ 主軸確認

    Y16で主軸運転を要求し、X16の運転確認を待つ。

    ⑤ 加工下降

    保持と主軸確認がそろっている間だけY17で下降を許可し、X15で仮想加工終点を確認する。

    ⑥ 原点復帰

    下降出力を解除し、X14の上昇端確認まで加工完了扱いにしない。

    ⑦ クランプ解除

    主軸停止と上昇端確認後にクランプを解除し、X13で後退完了を確認する。

    ⑧ 排出

    加工ヘッド退避・主軸停止・クランプ解除がそろったらY20で排出し、X17で1サイクル完了とする。

    4. 「穴が開いた」ではなく、制御で確認できる完了条件を決める

    PLCは加工結果そのものを目で見るわけではありません。そこでこの仮想ラインでは、加工工程を加工終点を確認 → 加工ヘッドが原点へ戻る → 主軸を止める → クランプを解除するという状態の連続として扱います。

    第4回の加工完了

    X15の加工終点だけでは完了にせず、X14の上昇端まで戻ったところを加工動作の完了境界にします。これで「加工ヘッドが下がったまま排出へ進む」状態を避けやすくなります。

    実加工品質とは別

    φ8・深さ15 mmという加工品質を実機で保証するには、機械側の剛性、工具、送り、回転、位置決めなど別の設計が必要です。この記事ではPLCのシーケンス設計だけを扱い、実機の加工条件は決めません。

    5. 次工程へ進ませない条件を先に決める

    加工ステーションでは「動かす条件」と同じくらい、「条件がそろわなければ動かさない」設計が重要です。第4回では次の関係をシーケンス上のインターロックとして固定します。

    動作最低限そろえる状態狙い
    クランプ加工位置ワークあり・ドリル上昇加工位置にワークがない状態で加工へ進まない
    ドリル下降クランプ前進端・主軸運転確認・ワークあり保持と加工準備がそろう前に下降させない
    クランプ解除ドリル上昇端・主軸停止加工ヘッドが退避する前にワークを解放しない
    排出ドリル上昇端・主軸停止・クランプ後退端加工部が待機姿勢へ戻ってから排出する
    次ワーク受入加工位置空き・排出完了加工中のワークへ次ワークを重ねない

    安全機能は通常シーケンスと分けて考える

    非常停止やガードなど、人の安全に関わる機能は通常の加工シーケンスだけに依存させず、実機では適切な安全回路・安全機器・リスクアセスメントを別途設計します。ここでは仮想ラインの通常動作条件だけを整理します。

    6. 各動作に「待ち続けない」監視点を置く

    クランプ、主軸確認、下降、上昇、排出のどこかで確認信号が来なければ、次の状態へ進ませません。第3回と同じく、動作開始後だけタイムアウト監視を持たせる考え方にします。

    監視区間開始完了異常判定の考え方
    クランプY15要求X12前進端所定時間内に前進端が来なければ停止対象
    主軸Y16要求X16運転確認運転確認が来なければ下降へ進まない
    加工下降Y17要求X15下降端加工終点が来なければ次へ進まない
    原点復帰Y17解除X14上昇端上昇端が来なければクランプ解除しない
    排出Y20要求X17排出完了排出完了が来なければ次ワークを受けない

    具体的なタイマ値や異常復旧の操作は、第5回「手動運転・異常処理・復旧」で整理します。第4回では、どの区間に監視が必要かまでを固定します。

    7. 第4回のまとめ

    POINT 1搬送と加工の境界を明確にするCV04到着と加工位置確認を別状態にする。
    POINT 2加工を状態遷移で組み立てる受入→保持→加工→復帰→解放→排出へ分ける。
    POINT 3完了確認を次動作の条件にする端検出・運転確認・排出完了を見てから進める。
    設計ステップ第4回で決めたこと
    加工受入加工側の待機姿勢がそろった時だけCV04から受け入れる
    I/OX11〜X17、Y15〜Y20の仮割付を追加
    シーケンス受入から排出までを8状態に分割
    インターロック保持・主軸・原点・クランプ解除の順序関係を固定
    異常監視各動作にタイムアウト監視点を置く
