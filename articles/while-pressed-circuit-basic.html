    押している間だけ動く回路とは？

    押している間だけ動く回路は、押しボタンなどの入力がONしている間だけ条件が成立し、その間だけ出力をONする回路です。ボタンを離して入力がOFFになると、出力もOFFへ戻ります。

    PLCの基本ラダーで考えると、X入力のa接点を条件にしてY出力コイルを駆動するシンプルな形です。三菱電機の入門資料でも、入力接点の状態に応じて出力コイルがON/OFFする基本例が示されています。

    自己保持接点やSET命令などで状態を保持していないため、入力がなくなれば出力も保持されません。この点が、起動ボタンを一度押せば運転を継続する自己保持回路との大きな違いです。

    覚え方は「押す → ON、離す → OFF」

    入力条件をそのまま出力条件として使うのが基本です。押し続ける時間が長ければ、その間は出力もONし続けます。

    「押している間だけ」を作るモーメンタリ押しボタン

    制御盤で使う押しボタンスイッチには、押している間だけ操作状態になるモーメンタリ形と、押すたびに状態を切り替えるオルタネイト形があります。

    オムロンの現行押しボタンスイッチ資料では「Momentary」と「Alternate」が区別され、IDECの押しボタンスイッチでも動作方式として「モメンタリ」が明記されています。この記事では、基本的にモーメンタリ形の押しボタンを想定します。

    押しボタンの機械動作とPLCプログラムは分けて考える

    ボタンがモーメンタリ形でも、PLC側で自己保持やSET処理を組めば出力を継続させることはできます。「ボタンの動作方式」と「プログラムで出力を保持するか」は別の話です。

    どんな時に使うのか

    この回路は、自動運転を継続させる用途よりも、作業者が操作している間だけ一時的に動かしたい場面で使いやすい基本回路です。

    手動送り・位置合わせ

    コンベアや機構を少しだけ動かし、ワーク位置や機械位置を合わせたい時に使います。

    試運転・動作確認

    出力先が正しく動くかを短時間だけ確認したい場面で使います。

    一時的な出力操作

    ランプ、ブザー、電磁弁などを操作中だけONしたい場合に使えます。

    手を離したら停止させたい操作

    操作をやめた時点で出力条件も切れるため、保持させたくない手動操作に向いています。

    「手動運転＝安全」ではない

    手動モードでも、出力先がモーター・シリンダ・搬送機構なら設備は実際に動きます。手動操作用の回路であることと、安全が保証されることは別です。

    押している間だけ動く回路の基本動作

    基本の流れは、押しボタン → PLC入力X → ラダーのa接点 → 出力Yです。入力条件が成立している間だけ出力コイルが駆動されます。

    1. 押しボタンを押す

    モーメンタリ押しボタンの接点が切り替わり、PLC入力がONします。

    2. X入力がONする

    PLCは外部入力の状態を取り込み、対応するXデバイスをONとして扱います。

    3. a接点の条件が成立する

    ラダー上のX接点が導通条件となり、右側の出力命令まで条件がつながります。

    4. Y出力がONする

    出力条件が成立している間だけYがONし、入力条件が切れるとYもOFFになります。

    ラダーで見ると「X入力 → a接点 → Y出力」

    GX Works3などでラダーを読む時は、まずどのX入力を見て、その接点条件でどのY出力を駆動しているかを追うと分かりやすくなります。

    Xは何の入力か

    押しボタン、センサ、リミットスイッチなど、どの外部信号を受けているかを確認します。

    接点はa接点か

    基本例ではX入力のa接点を使い、XがONの時に条件を成立させます。

    Yは何を動かすか

    ランプ、リレー、電磁弁、接触器など、実際の出力先を確認します。

    保持回路がないか

    並列の自己保持接点やSET命令などがあれば、単純な「押している間だけ」の動作にはなりません。

    先輩まずはX入力の接点がONしている間だけY出力がONする、一番シンプルな形として見ると理解しやすいよ。

    後輩自己保持やSETが追加されると、ボタンを離しても動く別の回路になるんですね。

    自己保持回路やワンショット回路との違い

    同じ押しボタン入力を使っていても、プログラム側で「入力中ずっとON」「入力後も保持」「変化した瞬間だけON」のどれを作るかで動作は大きく変わります。

    回路 出力の動き 代表的な用途
    押している間だけ動く回路 入力ON中だけON。離すとOFF 手動送り、試運転、一時操作
    自己保持回路 起動条件が切れてもON状態を保持 通常運転、継続運転
    ワンショット回路 入力の立上り・立下りなど変化時に短時間だけON 1回だけ処理を実行するトリガ

    三菱電機資料でもOUTとSETは動きが異なる

    三菱電機の入門資料では、通常のOUT命令は駆動条件がOFFになるとコイルもOFFになる一方、SET命令では条件がOFFになってもON状態を保持する例が示されています。単純な押下中動作と保持動作を分けて理解するのに役立ちます。

    現場で注意したいポイント

    回路が正しくても、出力先が設備の可動部なら危険はあります。特に手動操作・試運転では、通常運転とは違う動かし方をするため、使い方と安全条件をあわせて確認することが重要です。

    押している間は動作が続く

    長く押せば長く出力します。短時間だけ動かしたい場合も、操作時間そのものが動作時間になります。

    意図しない保持がないか確認

    自己保持接点、SET命令、別条件からの並列回路があると、ボタンを離しても出力が残る場合があります。

    安全装置・必要なインターロックを無効化しない

    非常停止、安全扉、エリアセンサなどの安全機能や、設備仕様・リスクアセスメントで必要なインターロックは、点検・調整時も有効な状態で確認します。

    実機の運転モードを確認

    手動／自動の切替状態、周辺設備の状態、作業者の位置を確認し、意図した運転モードになっていることを確かめてから操作します。

    可動部へ手を入れた状態で動作確認しない

    三菱電機のシーケンサ入門資料でも、通電中の端子への接触や可動部へ手を入れることを避け、安全を確認して作業するよう注意されています。実設備では機械メーカーの取扱説明書、リスクアセスメント、現場ルールを優先してください。

    まとめ：押している間だけ動く回路は手動操作の基本

    押している間だけ動く回路は、モーメンタリ押しボタンなどの入力がONしている間だけPLCの入力条件が成立し、その間だけ出力をONする基本回路です。

    ラダーでは「X入力 → a接点 → Y出力」の流れから確認すると理解しやすく、自己保持やSET処理が追加されていないかを見ることで、ボタンを離した後の動きも判断しやすくなります。

    この記事の要点

    「押す → 入力ON → 出力ON」「離す → 入力OFF → 出力OFF」が基本です。手動送りや試運転で便利な一方、設備が実際に動く以上、安全条件やインターロックの確認は別途必要です。
