# 記事作成エージェント手順

## 役割
- 完成済み記事HTMLを完全コピーして、新規記事HTMLを作る
- title、meta、canonical、OGP、h1、本文、画像パス、関連記事、side-railを差し替える
- 画像ファイルは未生成でも、予定ファイル名で `.png` パスを先に指定する
- 5記事制作の場合は、まず5記事分のHTMLをすべて作成する

## 重要ルール
- 新規記事HTMLは完成済み記事HTMLを完全コピーして必要箇所だけ差し替える
- CSS・クラス名・検索ヘッダー・会話構造・カード構造・関連記事構造を作り直さない
- 独自CSSテンプレートを作らない
- `site-search.js` を重複読み込みしない
- 記事固有画像は原則 `.png` で指定する
- `.svg` を記事固有画像に使わない
- OGP画像は `.png` を指定する
- `@media (min-width:744px) and (max-width:1100px)` を落とさない
- hero画像の中間幅指定は `right center / auto 92% no-repeat` 相当を維持する
