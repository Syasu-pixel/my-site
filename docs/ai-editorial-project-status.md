# AI編集部 プロジェクト状態

## 現在の状態: 一時閉鎖（TEMPORARILY CLOSED）

**決定日: 2026-09-09**

AI編集部は解体・削除しない。ただし、現在はプロジェクトを**一時閉鎖**とする。

この状態ファイルは、AI編集部の運用可否に関して `docs/ai-editorial-master-rules.md`、`docs/ai-editorial-weekly-routine.md` その他のAI編集部関連文書より優先する。再開決定が明示されるまでは、既存の週次ルール・自動制作ルールを実運用しない。

## 閉鎖中のルール

- 新規のAI編集部案件を開始しない。
- 月〜日の定例AI編集部運用を停止する。
- OpenAI / Gemini 等を使う自動記事生成、画像生成、AI監査、再生成ループを実行しない。
- AI編集部を理由とする新規のAPI消費を発生させない。
- 既存コード、Supabase Edge Functions、GitHub履歴、ドキュメント、ダッシュボード、過去の案件ログは削除せず保存する。
- AI編集部の解体や全面削除は行わない。
- 保守上必要な重大セキュリティ修正を除き、閉鎖中はAI編集部の機能追加・改善開発を原則停止する。
- 再開前に、古いモデル名・API仕様・Cloudflare/Supabase/GitHub構成をそのまま信用せず、現行仕様を再監査する。

## 再評価の目安

**約6か月後、またはAI/APIの能力・価格・安定性に大きな改善があった時点**で再評価する。

再評価では最低限、以下を確認する。

1. 記事本文を人間の細かな介入なしで安定して完成できるか。
2. 技術図解・OGP・hero画像を、許容コスト内で安定生成できるか。
3. 1記事あたりのAPI費用が実運用に見合うか。
4. Previewまで途中停止せず自走できるか。
5. 管理者の確認を最終1回程度に抑えられるか。
6. 現行のChatGPT単体運用と比べて、AI編集部を採用する明確なメリットがあるか。

上記を検証したうえで、**AI編集部を再採用する / 設計を変更して再開する / 閉鎖を継続する**のいずれかを管理者が判断する。

## 再開条件

AI編集部は、管理者が明示的に「再開」と決定するまで運用再開しない。

単にコードが残っていること、API残高があること、モデルが更新されたこと、ダッシュボードを開いたことだけでは再開扱いにしない。

この文書の目的は、現在の実装資産を保存したままAPI消費と運用を止め、将来のモデル/API進化後に公平に再評価できる状態を維持することである。
