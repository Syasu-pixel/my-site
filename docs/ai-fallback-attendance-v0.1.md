# AI fallback and attendance v0.1

Temporary governance/infrastructure marker for the fallback + attendance implementation.

Rules:
- Primary provider failures must not be mislabeled as another AI's output.
- Controller fallback is explicitly labeled as degraded provider diversity.
- Important decisions remain provisional until an independent provider reviews them.
- Dashboard attendance reflects observed runtime events, retries, failures, fallback use, and recovery.
- Production/content/image/payment human gates are unchanged.
