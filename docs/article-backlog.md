# 日本語ベーシック記事候補バックログ

このファイルは、Denkicontrol / Denki Control Lab の日本語ベーシック記事候補を管理するためのバックログです。

## 運用ルール

- 未着手の記事候補は `- [ ]` で管理する。
- 記事を公開したら `- [x]` に変更する。
- 記事公開後は、必要に応じて以下も確認する。
  - `articles/{slug}.html` が作成されている
  - `sitemap.xml` に追加されている
  - `assets/data/search-index.json` に追加されている
  - 関連記事導線が追加されている
  - カテゴリページ導線が追加されている
  - 必要なら英語版候補として別途検討する
- 工具・比較系は、現時点では英語化対象外方針を維持する。
- 新規記事作成時は、既存記事との重複を確認してから着手する。
- 新規記事候補を進める前に、現在の `articles/{slug}.html`、`assets/images/{slug}/`、`sitemap.xml`、`assets/data/search-index.json`、カテゴリ導線、過去コミットの削除・差し替え履歴を確認し、「新規作成」「既存記事強化」「統合済み」「保留」に分類してから着手する。
- 記事作成は、基本的に「ベーシック難易度」「現場目線」「初心者にも追いやすい説明」を優先する。
