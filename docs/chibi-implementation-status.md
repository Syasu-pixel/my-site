## 今回追加した会話

chibi-dialogues.js に編集・調査の考え方136組、休憩雑談24組、合計160組・320発言を手書きで追加。語句を置換した組み合わせ数ではない。内容には近いテーマもあるため、160種類の小芝居とは呼ばない。

通常案件中は136組（約125分の55秒枠）、待機中は160組（約147分の55秒枠）を利用できる。各組は先輩8秒＋後輩8秒で、その後は静かな時間。発話そのものが2時間続くわけではない。

候補は未使用・最も古いものを優先し、同一IDを全モード共通で7200000ミリ秒除外。履歴をlocalStorageへ保存。確認待ち・エラー・履歴閲覧中は状況に対応する限定会話にして、正常稼働を演出しない。これらの状態に2時間分の会話は用意していない。複数タブ間の同時選択排他は未対応。

## 追記：パーツ分離の試作

通常セルをCSS clip-pathで頭・胴体・左右脚に分け、口開きセルの口周辺のみ位置合わせして重ねる方式を追加。会話中は移動停止、聞き手の頭だけ小さく回転。左右脚は逆位相で回転する簡易人形アニメーションで、厳密な足の接地を解く歩行ではない。仕事中はクリップボードの絵文字を小物として表示。

休憩時は到着後に簡易テーブルが左からスライドし、給湯器の図形・湯の線・湯気を順に表示。手で運ぶ・ボタンを押す・カップを持つ・飲む動作は未実装。梯子も未実装。

構文確認と口開閉、発話時の胴体不変、左右脚の逆位相の関数検証済み。ローカル検証用ブラウザが未導入のため実画面確認は未完。口の位置合わせ、パーツ境界、脚の見え方はプレビューでの確認が必要。

次の低コスト候補：視線移動、まばたき、片手の小さな挨拶、メモを読む、相手の到着を待つ。顔と腕の専用透過パーツに置き換えると位置合わせの信頼性が上がる。
