# AI編集部ちびキャラ・本番組込み

最新の作成ルール・確定値・未対応事項は [モーション作成ルール正本](ai-editorial-chibi-motion-rules.md) を参照。この文書は本番組込み時点の記録。

ユーザー承認に基づき、Netlify Previewを経由せず既存の本番index.htmlへ2本のscriptを追加。

- chibi-dialogues-live.js：160組の会話データ。
- chibi-companions.js：透過素材、88px/68px、淡い水色/桃色の名前なし吹き出し、口・脚・顔のパーツ演出、小物、休憩、梯子の試作。
- ダッシュボードのチャット・管理者確認・案件操作を演出が書き換えない。キャラレイヤーはpointer-events:none。認証中は非表示。OFFと一時停止が利用可能。

## 活動ルール

ページ全体を活動場所とし、下端を地面とする。左側に余白がある場合は休憩場所。上への移動は梯子を使い、空中で斜めに移動させない。スクロール等で登り先が変わったら途中から降りる。通常登降と登り先削除時の地面復帰は関数シミュレーションで検証済み。実ブラウザの表示確認は未実施。

## 今回の梯子

PC幅で、画面下部から160〜370px上に表示中の対象がある場合に実行。近づく・梯子の表示拡大・上昇・見下ろす台詞・下降・縮小を順に再生する。厳密な手の握りや物体の運搬ではない。小物もメモ・虫眼鏡・スポンジの簡易表示。動作完成数を設計カタログ218項目と混同しない。

## 復旧

演出のみ外す場合はindex.html末尾のchibi-dialogues-live.jsとchibi-companions.jsのscriptタグを外す。素材ファイルだけではページに影響しない。
