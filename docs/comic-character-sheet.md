# Denkicontrol 四コマ漫画 キャラクター設定

更新日: 2026-10-06  
状態: 条件付き制作ルール

## 1. 目的
四コマ漫画を何本制作しても、先輩・後輩が同一人物として見える状態を維持する。

## 2. 見た目の正本
四コマ漫画では、ユーザー採用済みの次の画像を**最優先のキャラクター正本アンカー**とする。

- `assets/images/comic-character-anchors/yonkoma-chibi-senpai-kouhai-anchor-01.png`

四コマ制作・レビュー・ルール確認時は、ファイルの存在確認だけで終えず、**この画像そのものを開いて先輩・後輩の見た目を目視確認してから進める。**

通常の記事画像で使う既存テンプレート:
- `assets/images/character-templates/senpai-kouhai-character-template.png`

優先順位:
1. 四コマ用ちびキャラ正本アンカー
2. 正式採用済みパイロット `assets/images/comics/sensor-basic/sensor-basic-yonkoma-01-pilot.png`
3. 通常記事用 character template
4. `docs/image-generation-rules.md`

四コマ漫画では、通常記事用 character template と差がある場合、**四コマ用ちびキャラ正本アンカーを優先**する。

`assets/images/guide-characters/` はHTML本文の会話素材であり、四コマ画像生成の正本ではない。

## 3. 先輩
固定条件:
- 白ヘルメット
- 青系作業服
- 親しみやすい実務者
- 落ち着いた説明役
- 年齢感・顔つき・体格・髪型・色味は四コマ用ちびキャラ正本アンカーに合わせる
- ヘルメットに文字やロゴを追加しない

演技:
- 穏やか
- 冷静
- 困っている後輩を見下さない
- 技術的な要点を短く整理する
- 過剰に驚いたり、ギャグ顔を多用しない

## 4. 後輩
固定条件:
- ライトブルー系ヘルメット
- ライトグレー〜ライトブルー系作業服
- 学ぶ姿勢が伝わる親しみやすい人物
- 年齢感・顔つき・体格・髪型・色味は四コマ用ちびキャラ正本アンカーに合わせる
- ヘルメットに文字やロゴを追加しない

演技:
- 素朴な疑問
- 少し困る
- 気づく
- 納得する
- 読者を代弁するが、極端な無知・失敗役にはしない

## 5. 2人の関係性
- 基本は「後輩の疑問 → 先輩の整理」。
- **教える側は先輩、質問・気づき側は後輩**を原則固定する。
- 後輩が後輩へ専門説明する、先輩が質問役として後輩から教わる等の役割逆転は、ユーザーが明示的に指定した場合を除き不採用。
- 同一作品内で役割のために別の先輩・別の後輩を追加生成しない。
- 対立や叱責ではなく、現場で教えてもらう自然な距離感。
- 先輩だけが正解を言い続ける単調な構成を避け、後輩にも理解・気づき・要約の役割を持たせる。
- 後輩の「気づき・要約」と「専門説明の主担当」は区別する。

## 6. NG
以下は別人化として原則不採用:
- ヘルメット色が変わる
- 作業服の系統が大きく変わる
- 髪型・髪色・顔立ち・年齢感が大きく変わる
- 頭身が作品ごとに極端に変わる
- 実写風、劇画風、別アニメ作品風へ変化する
- 先輩と後輩の役割・見た目が入れ替わる
- ロゴ、実在企業名、不要な文字を服やヘルメットへ入れる

## 7. 正式採用パイロット
最初の正式採用四コマは、四コマ用ちびキャラ正本アンカーに加えてシリーズ用の第二アンカーとする。

- `assets/images/comics/sensor-basic/sensor-basic-yonkoma-01-pilot.png`
- 採用日: 2026-09-25
- ユーザー承認: 正式採用
- 後続作品の制作前に、正本キャラクター画像とこのパイロット画像の両方を実際に開いて目視確認する。

後続作品は次を合わせる:
- 顔
- 髪型
- 服装
- ヘルメット
- 頭身
- 線の太さ
- 配色
- 表情の強さ
- キャラ同士の距離感

パイロットと四コマ用ちびキャラ正本アンカーが食い違う場合は、ユーザーの採用判断を確認し、必要なら本設定を更新してから量産する。


## 8. サイト案内用ちびキャラ・再利用テンプレート

記録日: 2026-11-14。ユーザーは通話で、既存の先輩・後輩ちびキャラをサイト案内に使い、再利用テンプレートをGitHubに残すことを希望した。

### 適用範囲と公開状態
- トップページの目的別案内は管理者の公開承認を受け、PR #1881（merge: `5c161fb05a7797ea74dec895ac589bdd070a66c8`）で本番反映済み。
- 採用済み配置は、既存トップの相談サービス案内の下にある「基礎から学びたい」「困りごとから探したい」「部品・テーマから探す」の3つの入口。
- この文書追記は2026-11-14に管理者がmainへの反映と文書のサイト配信を承認（PR #1884）。サイトの見た目は変更しない。カテゴリページ・個別記事への展開や画像の一括置換は承認対象ではない。
- 第1〜7節の四コマ正本、通常記事用テンプレート、HTML会話素材の用途と優先順位は変更しない。新たなキャラクター正本は作らない。

### キャラの固定基準
サイト案内では、既存採用済みの四コマ用ちびキャラ正本アンカーを参照し、先輩・後輩の同一性を維持する。制作・レビュー時は画像そのものを開き、第2〜6節の見た目・役割・NGと照合する。
- 先輩: 白ヘルメット・青系作業服。落ち着いて要点を整理し、読む先や安全の注意へ案内する。
- 後輩: ライトブルー系ヘルメット・ライトグレー〜ライトブルー系作業服。読者の疑問、気づき、納得を代弁する。
- 顔・髪・年齢感・頭身・配色・線幅を変えない。新しい文字やロゴを描き足さない。既存アンカーとの相違を独断で正本へ反映しない。
- 専門説明の主担当は先輩。後輩を見下す表現、極端な無知や失敗役、役割逆転は避ける。

### 再利用する表情・口調のひな形
以下は今後の制作時の表現候補であり、独立画像6枚が制作・採用済みという意味ではない。
| 用途 | キャラ・表情 | 文言例 |
| --- | --- | --- |
| welcome | 両者の穏やかな笑顔 | 先輩「今日は、どこから調べようか。」 |
| learn | 後輩が少し考える | 後輩「まず、何から読めばいいですか？」 |
| guide | 先輩が穏やかに案内 | 先輩「用語をひとつずつ、つなげていこう。」 |
| check | 先輩が落ち着いて整理 | 先輩「作業を始める前に、症状を整理しよう。」 |
| understand | 後輩が納得 | 後輩「ここまで分かれば、次へ進めそうです。」 |
| caution | 先輩が落ち着いて注意 | 先輩「作業前に、安全手順を確認しよう。」 |

### 素材と実装の扱い
- 現在のトップ案内は既存アンカーをCSSの背景位置・倍率で表示している。新しい独立キャラ素材を作成したものではない。元の正本画像を上書きしない。
- 独立素材が必要になった場合は正規の画像生成・編集手順で制作し、自然な手、同一人物、表情の区別を確認する。文章はHTMLに置き、画像へ描き込まない。
- 既存の `assets/images/character-templates/`、`assets/images/guide-characters/`、四コマ用アンカーの用途区分を守る。既存正本と競合する設定ファイルを新設しない。
- 再利用時の記録項目: `character / expression / asset / alt / message / destination / version / anchor`。未制作の素材パスを実在するものとして記録しない。
- 現行トップの案内部品は `index.html` の `dc-home-guide` 名前空間内。共通部品への移行や他ページへの追加は今回の採用範囲とは分けて判断する。

### 案内の設計と確認
- キャラは補助役とし、読む先が分かる短文とリンクを主役にする。画像だけのボタンにしない。装飾画像の説明は重複させず、必要な情報は可視テキストで伝える。
- スマホでは64〜88px程度を目安に、本文へ重ねず通常フローに置く。固定ポップアップ・自動点滅・常駐吹き出しを追加しない。
- 展開操作はキーボードで使え、フォーカスと開閉状態を示す。既存の検索・全カテゴリ・人気/新着・4コマ・言語・相談/支援導線を維持する。
- 次回変更では320px幅・200%ズーム・ライト/ダークを含めて確認し、未実施を合格扱いしない。今回トップ案の実測検証はPC幅1165px・狭幅323px・ライト/ダーク・展開・検索/カテゴリ操作。厳密320pxおよび200%は未実施。
- 確認用配信は検索除外・本番計測分離を確認する。採用済みトップの本番計測は維持する。本番反映は確認用PRの保存とは分けて承認を得る。
