# Denkicontrol 四コマ漫画 キャラクター設定

更新日: 2026-10-06  
状態: 条件付き制作ルール

## 1. 目的
四コマ漫画を何本制作しても、先輩・後輩が同一人物として見える状態を維持する。

## 2. 見た目の正本
四コマ漫画では、ユーザー採用済みの次の画像を**最優先のキャラクター正本アンカー**とする。

- `assets/images/comic-character-anchors/yonkoma-chibi-senpai-kouhai-anchor-01.png`

四コマ制作・レビュー・ルール確認時は、ファイルの存在確認だけで終えず、**この画像そのものを開いて先輩・後輩の見た目を目視確認してから進める。**

通常の記事画像で使う既存テンプレート:
- `assets/images/character-templates/senpai-kouhai-character-template.png`

優先順位:
1. 四コマ用ちびキャラ正本アンカー
2. 正式採用済みパイロット `assets/images/comics/sensor-basic/sensor-basic-yonkoma-01-pilot.png`
3. 通常記事用 character template
4. `docs/image-generation-rules.md`

四コマ漫画では、通常記事用 character template と差がある場合、**四コマ用ちびキャラ正本アンカーを優先**する。

`assets/images/guide-characters/` はHTML本文の会話素材であり、四コマ画像生成の正本ではない。

## 3. 先輩
固定条件:
- 白ヘルメット
- 青系作業服
- 親しみやすい実務者
- 落ち着いた説明役
- 年齢感・顔つき・体格・髪型・色味は四コマ用ちびキャラ正本アンカーに合わせる
- ヘルメットに文字やロゴを追加しない

演技:
- 穏やか
- 冷静
- 困っている後輩を見下さない
- 技術的な要点を短く整理する
- 過剰に驚いたり、ギャグ顔を多用しない

## 4. 後輩
固定条件:
- ライトブルー系ヘルメット
- ライトグレー〜ライトブルー系作業服
- 学ぶ姿勢が伝わる親しみやすい人物
- 年齢感・顔つき・体格・髪型・色味は四コマ用ちびキャラ正本アンカーに合わせる
- ヘルメットに文字やロゴを追加しない

演技:
- 素朴な疑問
- 少し困る
- 気づく
- 納得する
- 読者を代弁するが、極端な無知・失敗役にはしない

## 5. 2人の関係性
- 基本は「後輩の疑問 → 先輩の整理」。
- **教える側は先輩、質問・気づき側は後輩**を原則固定する。
- 後輩が後輩へ専門説明する、先輩が質問役として後輩から教わる等の役割逆転は、ユーザーが明示的に指定した場合を除き不採用。
- 同一作品内で役割のために別の先輩・別の後輩を追加生成しない。
- 対立や叱責ではなく、現場で教えてもらう自然な距離感。
- 先輩だけが正解を言い続ける単調な構成を避け、後輩にも理解・気づき・要約の役割を持たせる。
- 後輩の「気づき・要約」と「専門説明の主担当」は区別する。

## 6. NG
以下は別人化として原則不採用:
- ヘルメット色が変わる
- 作業服の系統が大きく変わる
- 髪型・髪色・顔立ち・年齢感が大きく変わる
- 頭身が作品ごとに極端に変わる
- 実写風、劇画風、別アニメ作品風へ変化する
- 先輩と後輩の役割・見た目が入れ替わる
- ロゴ、実在企業名、不要な文字を服やヘルメットへ入れる

## 7. 正式採用パイロット
最初の正式採用四コマは、四コマ用ちびキャラ正本アンカーに加えてシリーズ用の第二アンカーとする。

- `assets/images/comics/sensor-basic/sensor-basic-yonkoma-01-pilot.png`
- 採用日: 2026-09-25
- ユーザー承認: 正式採用
- 後続作品の制作前に、正本キャラクター画像とこのパイロット画像の両方を実際に開いて目視確認する。

後続作品は次を合わせる:
- 顔
- 髪型
- 服装
- ヘルメット
- 頭身
- 線の太さ
- 配色
- 表情の強さ
- キャラ同士の距離感

パイロットと四コマ用ちびキャラ正本アンカーが食い違う場合は、ユーザーの採用判断を確認し、必要なら本設定を更新してから量産する。


## サイト案内への展開案（2026-11-14、構想Preview限定）

状態: 管理者から制作・Previewまでの依頼あり。本番適用・全記事適用は未承認。既存の四コマ正本と通常記事正本の優先順位は変更しない。

既存 docs/comic-character-sheet.md に追記する案（採用・本番反映未実施）

サイト案内用ちびキャラ・再利用テンプレート
目的: 先輩・後輩を「飾り」ではなく、読む入口と次に読む先を案内する補助として使う。
見た目: 既存採用のちびキャラアンカーを参照し同一人物を維持。先輩=白ヘルメット・青作業服・茶髪。後輩=水色ヘルメット・淡灰色作業服・茶色ボブ。顔、髪、配色、頭身、線幅を変えない。新しい文字やロゴは追加しない。元アンカーのヘルメット記号と文章の「ロゴを追加しない」は別扱いとし、既存記号を勝手に増減させない。
通常記事正本との関係: この節はサイト案内用ちびキャラに限定。既存記事・四コマの正本や採用画像を自動で置換しない。
役割: 先輩=落ち着いて整理し道を示す。後輩=読者の疑問・発見・納得を代弁。叱責、見下し、極端な失敗役、専門説明役の逆転は禁止。
表情バリエーション:
1 welcome: 両者やさしく笑う。「どこから知りたいですか？」
2 learn: 後輩が少し考える。「初めてなら、ここから。」
3 guide: 先輩が手のひらで方向を示す。「まずは仕組みを見てみよう。」
4 check: 先輩がチェック表を見る。「症状を分けて整理しよう。」
5 understand: 後輩が納得。「ここまで分かれば、次へ進めそう。」
6 caution: 先輩が落ち着いて注意。「作業前に安全の確認を。」
画像を作る場合は1枚ずつ独立した透過素材、手は単純な自然な形、キャラに文字を描き込まず文言はHTML。自動再生・点滅・常駐ポップアップなし。
再利用データ項目: character / expression / asset / alt / message / destination / version / anchor。
案内部品: 画像+短文+明確なリンクの静的HTML。画像だけをボタンにしない。リンク名は目的を表し、キーボードでも操作可能。装飾画像altは空、説明内容は可視テキストで提供。
スマホ: キャラは64〜88px程度、画面占有よりリンクを優先。本文へ重ねず通常フロー配置。固定フッターや吹き出しポップアップ禁止。最低320px幅・200%ズーム・ライト/ダークで確認。
配置: トップの入口2か所＋カテゴリ冒頭の短い案内。各記事への一括挿入はこのパイロットの対象外。
保管: 採用画像は既存 character-templates/guide-characters の用途分離を維持。キャラ設定正本を新設しない。実装部品は既存 .github/site-shells のページ種別責務を確認後に配置。
受入検査: 同一人物/自然な手/違う表情/スマホ非遮蔽/コントラスト/リンク名/既存検索・カテゴリ・支援・言語導線保持/noindex/計測分離/既存URL維持。公開前に最終プレビュー承認。
