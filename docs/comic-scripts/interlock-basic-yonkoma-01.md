## 3. 正式採用内容
- 2×2の四コマ構成
- 青系のDenkicontrol四コマ世界観
- KDSロゴなし
- ラダー図を四コマ内に入れず、詳細説明は記事側へ分離
- 1コマ目: 後輩が「正転と逆転のボタンを両方押したら？」と疑問
- 2コマ目: 後輩が「モーターが混乱してどうなっちゃう？」と漫画的に想像
- 3コマ目: 先輩が、同時に動いてほしくない動作は片方が動いている間もう片方を動かせないようにする、と説明
- 4コマ目: 後輩の「どっちも動け！じゃダメなんですね！」を軽いオチとして採用
- CTA: 「インターロック回路とは？」の記事へ誘導

## 4. 技術ガード
- インターロックを「必ずb接点を使うもの」と定義しない
- 通常PLCのインターロックを安全回路そのものとして扱わない
- 正逆転の詳細な主回路・ラダー回路は四コマ内で完結させない
- 本質は、競合する動作を同時成立させない制御上の考え方として扱う
- 2コマ目の「モーターが混乱」は漫画上の比喩であり、物理現象の定義として扱わない
