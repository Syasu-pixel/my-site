## 5. 採用内容
- 2×2の四コマ構成
- 正本のちびキャラ先輩・後輩を維持
- 青系のDenkicontrol四コマ世界観を維持
- 「normal = 正常」ではなく「ふだんの状態」という初学者がつまずきやすい点を主題化
- NOは通常時に開、NCは通常時に閉という接点状態を中心に説明
- 4コマ目で「normal = 正常」だと思っていた勘違いを軽いオチとして回収
- CTAから元記事へ誘導する

## 6. 技術ガード
- 「NO = PLC入力OFF」「NC = PLC入力ON」を定義として扱わない
- 「NO = 負荷OFF」「NC = 負荷ON」を定義として扱わない
- センサの電子出力を機械式a接点/b接点と一律に扱わない
- 「NCなら安全」と断定しない
- 端子番号や接点構成を全製品共通として一般化しない
- 実在メーカーの型式・銘板・ロゴを再現しない
- 実機の配線変更、バイパス、強制入力、安全回路変更を促さない
