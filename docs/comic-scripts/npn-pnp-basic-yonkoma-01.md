## 2. 採用テーマ
**NPNとPNPって、どう違うの？**

## 3. 採用版の構成
- 2×2四コマ、青基調、先輩・後輩の固定キャラクター
- KDSロゴなし
- 1コマ目: 後輩がNPN/PNPの違いを質問
- 2コマ目: N=ネガティブ、P=ポジティブという文字だけで覚えようとする
- 3コマ目: ON時の出力方向を入口として、NPNは0V側へ引き込む、PNPは+24V側から出すことを簡潔に提示
- 4コマ目: 「NとPの暗記テストじゃなかったんですね！」をオチにし、実配線では接続先の入力仕様確認を促す
- CTA: 「NPN・PNPセンサとは？」の記事へ誘導
- フッター: 「NPNとPNPは、センサの出力方式の違いです。機器の入力仕様に合わせて、正しく選びましょう。」

## 4. 技術ガード
- NPN/PNPを文字の意味だけで判断させない
- 四コマでは入口理解に留め、詳細な配線・端子・メーカー差は記事側で説明する
- 実際の選定・配線では接続先機器の入力仕様を確認する
- 採用版3コマ目のPNP補足文は簡略表現を含むため、将来再編集時は「ON時に出力から+24V側を供給する」等の表現を優先する
