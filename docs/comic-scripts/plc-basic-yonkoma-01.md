## 採用構成と技術ガード

1. 後輩「PLCって、やりたい動きを察してくれるんですか？」
2. 先輩「動きを決めるのはプログラム。入力の状態をもとに、決めた条件に従うんだ。」入力→プログラムの条件→出力の基本イメージ。
3. 後輩が配線だけで全部おまかせではないと気づき、先輩が配線とプログラムの両方が大事と説明。
4. 後輩「私の『おやつが欲しい』も入力したいです！」先輩「それは言葉で伝えてね。」

一般概念に限定。図は配線図ではない。機種ごとの仕様・更新タイミング・電源方式を一般化せず、正式マニュアルと安全ルールを優先。PLC出力が負荷を直接駆動するとは述べない。
