## 採用構成と技術ガード

1. 後輩「直列と並列…『同じ』になるのは何でしたっけ？」
2. 先輩が、直列は1本道で同じ電流が順番に流れると説明。A−R1−R2−Bの接続模式図。
3. 先輩が、並列は同じ2点につながる各枝の電圧が同じと説明。A/B間の2枝に各1抵抗、短絡線なし。
4. 後輩「覚えることが枝分かれしてきました！」先輩「まずは2つ。直列は電流、並列は電圧だね。」

理想的な抵抗回路の基本に限定する。図は接続模式図であり、電源・閉回路を省略したものと明記。実機の正式図面・安全ルールを優先。並列枝の電流が同じとは述べない。
