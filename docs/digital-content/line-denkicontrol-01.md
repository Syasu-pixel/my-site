# 第1弾 LINEデジタルコンテンツ商品仕様 — Denkicontrol 先輩・後輩

更新日: 2026-10-02
状態: 試作・管理者確認前
上位ルール: `docs/digital-content-production-rules.md`

## 1. 目的
株式会社ケイディエスのLINE Creators Market第1弾として、Denkicontrolの既存キャラクター「先輩・後輩」を使い、日常会話で使える商品を試作する。
第1弾の最優先目的は売上最大化ではなく、ChatGPT中心の制作からLINE申請までの製造ラインを実証すること。

## 2. 商品展開
- 第1試作: アニメーション絵文字
- 派生候補: 通常絵文字 / アニメーションスタンプ / 通常スタンプ
- 同一素材の単純拡大縮小はしない。商品形式ごとに構図・文字量・動きを最適化する。

## 3. キャラクター正本
必須参照:
- `assets/images/character-templates/senpai-kouhai-character-template.png`

小型・ちびキャラ表現を使う場合の追加参照:
- `assets/images/comic-character-anchors/yonkoma-chibi-senpai-kouhai-anchor-01.png`
- `docs/comic-character-sheet.md`

固定:
- 先輩: 白ヘルメット、青系作業服、親しみやすい説明役。
- 後輩: ライトブルー系ヘルメット、ライトグレー〜ライトブルー系作業服、親しみやすく前向き。
- 顔、髪型、年齢感、色味、人物同一性を崩さない。
- ヘルメットへ企業名・ロゴを追加しない。

## 4. 商品コンセプト
「仕事でも日常でも使いやすい、先輩・後輩の分かりやすいリアクション」。

電気・PLCの専門知識を知らなくても使える。
企業広告ではなく、コミュニケーション商品として成立させる。

## 5. 初期リアクション候補
量産前の企画候補。試作採用後に正式点数を確定する。

- OK / 了解
- ありがとう
- お疲れさま
- お願い
- ごめん
- うれしい
- 笑う
- 驚く
- 困る
- 考える
- 応援
- おやすみ

文字依存を減らし、小表示では表情・ポーズだけでも意味が分かることを優先する。

## 6. 最初の1点
テーマ: 「OK / 了解」
狙い:
- 使用頻度が高い
- 表情とジェスチャーで意味を伝えやすい
- 文字なしでも成立させやすい
- アニメーション検証に向く

試作は1点だけ作り、管理者が採用するまで次を量産しない。

## 7. アニメーション設計
- 1フレーム目で「OK / 了解」の意味が伝わる完成ポーズにする。
- 小さなトークバルーン内でも読める大きな表情・ジェスチャー。
- 動きは短く明快にする。
- 細かな装飾や小文字に依存しない。
- 背景透過。
- LINE公式の最新フレーム数・再生時間・サイズ・容量要件を最終書き出し時に再確認する。

暫定モーション案:
1. 1フレーム目: 笑顔＋はっきりしたOKジェスチャー
2. 軽くうなずく
3. 手・上半身を小さく弾ませる
4. 完成ポーズへ戻る

## 8. 採用ゲート
- 正本キャラクターと同一人物に見える
- 180px級の小表示でも意味が分かる
- 背景透過で輪郭が明確
- 表情差が大きく読み取りやすい
- 1フレーム目だけでも成立
- 不要なロゴ・広告表現なし
- 生成側自己評価後、管理者が採用 / 微調整 / 不採用を判断
- 採用後のみ次のリアクションへ進む


## 9. LINE公式仕様テンプレート（2026-10-02確認）

申請直前に必ず公式ガイドラインを再確認する。以下は今回確認時点の制作基準。

### 通常スタンプ
- 販売単位: 8 / 16 / 24 / 32 / 40個
- スタンプ画像: 最大370 x 320px、PNG
- メイン画像: 240 x 240px、1個
- トークルームタブ画像: 96 x 74px、1個
- 1画像1MB以下

### アニメーションスタンプ
- 販売単位: 8 / 16 / 24個
- スタンプ画像: 最大320 x 270px、APNG（拡張子.png）
- 横または縦のいずれかが270px以上となる条件にも従う
- メイン画像: 240 x 240px、APNG
- トークルームタブ画像: 96 x 74px、PNG
- 5〜20フレーム
- 最大4秒
- ループ1〜4回、合計4秒以内
- 1フレーム目だけでも伝えたい意味が分かること

### 通常絵文字
- 絵文字パッケージ: 8〜40個
- 各画像: 180 x 180px
- トークルームタブ画像: 96 x 74px
- ファイル名は選択パッケージの番号規則に従う（001〜等）

### アニメーション絵文字
- 絵文字パッケージ体系は通常絵文字と共通
- 各画像はLINE公式のアニメーション絵文字仕様に従う
- 5〜20フレーム
- 最大4秒
- 1フレーム目を静止表示しても感情・意味が伝わること
- 太く濃いアウトライン、明確な表情差、少ない余白を優先する
- 販売情報保存後、画像をZIP化してアップロードし、メイン画像に使う絵文字4個を選択する

公式参照:
- https://creator.line.me/ja/guideline/sticker/
- https://creator.line.me/ja/guideline/animationsticker/
- https://creator.line.me/ja/guideline/animationsticker/detail/
- https://creator.line.me/ja/guideline/emoji/
- https://creator.line.me/ja/guideline/emoji/detail/
- https://creator.line.me/ja/guideline/animationemoji/

## 11. 提出用ファイル制作ルール

- 企画確認用一覧画像とLINE提出用画像を混同しない。
- 提出用は1点ずつ独立ファイルとして生成・採用する。
- 元データは可能な限り大きく・透過前提で制作し、最終工程でLINE規格へ正確にリサイズ・APNG化する。
- アニメーションでは全フレームのキャンバスサイズを統一する。
- 採用済み静止基準フレームからモーションを派生させる。
- 文字入りスタンプは最終サイズで可読性を確認する。
- LINE提出用exportと、再編集可能なsourceを分けて保存する。
- ZIPアップロード対象は公式ファイル名規則に合わせ、提出直前に個数・寸法・容量・透過・フレーム・再生時間を機械検査する。


## 12. LINE商品専用キャラクターデザインゲート

2026-10-02の001「OK / 了解」初回APNG試作で、180 x 180px・透過・APNG化そのものは成立したが、商品デザインとしては不採用とした。

不採用理由:
- 記事用キャラクターを小型化しただけに近く、LINE商品としてのかわいさ・親しみやすさが弱かった。
- 眉・目・顔つきが硬くなり、既存の先輩の雰囲気からずれた。
- 小サイズで意味は伝わっても「買って使いたい」商品価値の確認が不足していた。
- アニメーションが画像全体の小さな揺れ中心で、感情・ジェスチャーの変化として弱かった。

以後の必須ルール:
- 記事画像を単純縮小してLINE商品にしない。
- 人物同一性（顔、髪型、髪色、ヘルメット、服装、配色）は既存正本へ合わせる。
- LINE商品専用スタイルとして、丸く柔らかいちびキャラ感、大きな表情、明確なジェスチャー、太く読みやすい輪郭を優先する。
- 180px表示で「意味が分かる」だけでなく、「商品として親しみやすく使いたい見た目か」を採用条件にする。
- 最初に静止状態のLINE専用アンカーを1点だけ制作する。
- 管理者がLINE専用アンカーを明示採用するまで、APNG化・残り15点の量産へ進まない。
- アンカー採用後、後続16点は同じ顔・線・頭身・配色・デフォルメ強度へ統一する。
- 動きは画像全体を揺らすだけにせず、表情、手、頭、上半身等の意味のある動作で感情を強化する。
- 「OK / 了解」なら、笑顔 → 親指を明確に出す → 大きくうなずく → アクセント → 完成ポーズ、のように小サイズでも動作意図が分かる設計を優先する。
