# 第1弾 LINEデジタルコンテンツ商品仕様 — Denkicontrol 先輩・後輩

更新日: 2026-10-02
状態: 試作・管理者確認前
上位ルール: `docs/digital-content-production-rules.md`

## 1. 目的
株式会社ケイディエスのLINE Creators Market第1弾として、Denkicontrolの既存キャラクター「先輩・後輩」を使い、日常会話で使える商品を試作する。
第1弾の最優先目的は売上最大化ではなく、ChatGPT中心の制作からLINE申請までの製造ラインを実証すること。

## 2. 商品展開
- 第1試作: アニメーション絵文字
- 派生候補: 通常絵文字 / アニメーションスタンプ / 通常スタンプ
- 同一素材の単純拡大縮小はしない。商品形式ごとに構図・文字量・動きを最適化する。

## 3. キャラクター正本
必須参照:
- `assets/images/character-templates/senpai-kouhai-character-template.png`

小型・ちびキャラ表現を使う場合の追加参照:
- `assets/images/comic-character-anchors/yonkoma-chibi-senpai-kouhai-anchor-01.png`
- `docs/comic-character-sheet.md`

固定:
- 先輩: 白ヘルメット、青系作業服、親しみやすい説明役。
- 後輩: ライトブルー系ヘルメット、ライトグレー〜ライトブルー系作業服、親しみやすく前向き。
- 顔、髪型、年齢感、色味、人物同一性を崩さない。
- ヘルメットへ企業名・ロゴを追加しない。

## 4. 商品コンセプト
「仕事でも日常でも使いやすい、先輩・後輩の分かりやすいリアクション」。

電気・PLCの専門知識を知らなくても使える。
企業広告ではなく、コミュニケーション商品として成立させる。

## 5. 初期リアクション候補
量産前の企画候補。試作採用後に正式点数を確定する。

- OK / 了解
- ありがとう
- お疲れさま
- お願い
- ごめん
- うれしい
- 笑う
- 驚く
- 困る
- 考える
- 応援
- おやすみ

文字依存を減らし、小表示では表情・ポーズだけでも意味が分かることを優先する。

## 6. 最初の1点
テーマ: 「OK / 了解」
狙い:
- 使用頻度が高い
- 表情とジェスチャーで意味を伝えやすい
- 文字なしでも成立させやすい
- アニメーション検証に向く

試作は1点だけ作り、管理者が採用するまで次を量産しない。

## 7. アニメーション設計
- 1フレーム目で「OK / 了解」の意味が伝わる完成ポーズにする。
- 小さなトークバルーン内でも読める大きな表情・ジェスチャー。
- 動きは短く明快にする。
- 細かな装飾や小文字に依存しない。
- 背景透過。
- LINE公式の最新フレーム数・再生時間・サイズ・容量要件を最終書き出し時に再確認する。

暫定モーション案:
1. 1フレーム目: 笑顔＋はっきりしたOKジェスチャー
2. 軽くうなずく
3. 手・上半身を小さく弾ませる
4. 完成ポーズへ戻る

## 8. 採用ゲート
- 正本キャラクターと同一人物に見える
- 180px級の小表示でも意味が分かる
- 背景透過で輪郭が明確
- 表情差が大きく読み取りやすい
- 1フレーム目だけでも成立
- 不要なロゴ・広告表現なし
- 生成側自己評価後、管理者が採用 / 微調整 / 不採用を判断
- 採用後のみ次のリアクションへ進む
