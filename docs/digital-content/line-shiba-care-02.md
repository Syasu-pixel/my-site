## 4. マスター生成ルール
- 4行×6列、24セルを均等配置
- 各セルに柴犬1体のみ
- 各セル内に上記のセリフ1つのみ
- 商品名、番号、説明、ロゴ、透かし、セル見出しは入れない
- 各セル中央70〜80%に主要キャラ・文字を収める
- 耳、尻尾、手足、文字、エフェクトはセル境界を越えない
- 同一シリーズとして毛色、顔、体型、線幅、首輪を統一
- 文字は太く、短く、スマホでも読める
- 白または単純背景を優先し、後工程で背景除去しやすくする
- 文字崩れ・読めない日本語はNG

## 5. QC
- PASS
- CROP
- MARGIN
- STYLE
- ANATOMY
- DUPLICATE
- MEANING
- SPEC
- RIGHTS
- TEXT（文字崩れ・誤字・可読性不良）

PASS済みセルは固定し、NGセルだけ再生産する。
