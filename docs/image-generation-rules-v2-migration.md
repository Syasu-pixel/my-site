# 画像生成ルール v2 移行オーバーライド

> 正本: `docs/ai-editorial-master-rules.md`。`docs/image-generation-rules.md` 内の旧「5枚固定」記述と矛盾する場合、この文書とマスタールールを優先する。

## 枚数
- hero: 原則1枚
- OGP: 原則1枚
- 本文画像: 内容に応じて1〜4枚を目安
- 標準総数: 原則3〜6枚
- 本文説明上不要な画像は、枚数合わせのために作らない。
- `overview / comparison / flow / check-flow` は用途候補であり固定セットではない。

## 統一感
- heroをアンカー画像として先に採用する。
- キャラクター入り後続画像は正本character template + 採用heroを参照する。
- キャラクターなしの純粋な図解は、heroの配色・線・教育図解トーンとの整合を確認する。

## 品質ゲート
1. 生成側が各成果物を自己評価する。
2. 95点未満は採用候補にしない。
3. 95点以上でも独立IMAGE REVIEWERへ送る。
4. IMAGE REVIEWERが技術的正確性、文字可読性、キャラクター一致、構図、用途一致、サイト統一感を確認する。
5. 両方を通過した画像だけをPreviewへ組み込む。
6. 管理者が記事全体のPreviewで最終確認する。

## 再生成
- 固定回数上限を設けず品質を優先する。
- 同じ失敗が続く場合は同一プロンプトを反復せず、構図・情報量・プロンプト設計を変更する。
- 技術的誤りを発見した場合は画像だけを直さず、記事本文と公式資料まで戻って整合性を再監査する。
