# Denkicontrol Image Quality Gate v0.1

## 目的
画像生成を人間との試行錯誤だけに依存せず、AI側で低品質候補を落としてから人間へ提示する。最終採用権は当面ユーザーに残す。

既存の詳細な生成ルールは `docs/image-generation-rules.md` を正本として参照し、本書は品質判定ゲートを追加する。

## 100点評価
### 1. 技術的正確性 — 30点
- 記事本文・公式資料・技術原理と矛盾しない。
- 誤配線、誤記号、誤った因果関係、危険な表現がない。
- 簡略図の場合も誤解を生む省略を避ける。

### 2. 公式キャラクター一致 — 25点
- 正本テンプレートの人物として認識できる。
- 顔、髪、服装、ヘルメット、色、役割、年齢感、雰囲気が一致する。
- 記事目的に応じて通常頭身 / chibiを適切に選択する。
- キャラクターを使わない画像では、必要に応じてこの項目を画像目的に適した整合性評価へ読み替え、総合判定理由を記録する。

### 3. 構図・情報設計 — 20点
- 画像の目的が一目で分かる。
- 視線誘導と情報階層が自然。
- キャラクターが技術図解を邪魔しない。
- hero / overview / comparison / flow等の役割が混在しない。

### 4. 文字の可読性 — 15点
- 日本語・英数字・記号が崩れていない。
- スマホ表示を考慮した文字サイズと情報量になっている。
- 長文や過剰な注釈を詰め込まない。

### 5. サイト全体の視覚的一貫性 — 10点
- Denkicontrolの既存採用画像と並べて違和感がない。
- 白背景・青系中心など既存の教育図解トーンを尊重する。
- 同一記事内では採用済みhero等と統一する。

## 提出基準
- 原則 95 / 100 以上のみ人間へ採用候補として提示する。
- 技術的正確性は原則 28 / 30 以上。
- 公式キャラクター一致は人物を含む場合、原則 24 / 25 以上。
- 文字の可読性は原則 14 / 15 以上。
- 総合95点以上でも重大な技術誤り、安全上の問題、文字崩れ、別人化があれば不採用。

## 自動再生成
生成AI自身の評価が基準未満なら、原則として人間へ提示せず修正・再生成する。ただし無限再生成は禁止し、連続失敗時は原因と候補を上位Reviewerまたは人間へ上げる。

## 独立レビュー
自己評価95点以上の候補は、可能な限り生成担当とは別のIMAGE REVIEWERが再評価する。独立Reviewerが基準未満と判断した場合は、人間へ完成候補として出さず修正へ戻す。

## 人間レビュー
当面、最終採用はユーザーが決める。単体画像だけでなく、可能な場合は記事Previewに組み込んだ状態で確認する。

## 学習・再校正
人間の採用 / 修正 / 不採用と理由を記録する。AIが95点以上と判定した画像の人間採用率が低い場合、画像モデルではなく評価基準やReviewer自体が間違っている可能性も検討する。

画像モデルの進化に応じて閾値、評価項目、人間承認範囲を再検討できる。
