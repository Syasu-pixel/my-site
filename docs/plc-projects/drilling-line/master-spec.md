# 穴あけ加工ライン設計プロジェクト — 設備構想・I/O正本

- 対象シリーズ: `articles/plc-drilling-line-design-project-01.html` 〜
- 更新日: 2026-09-19
- 状態: 第4回設計時点の採用仕様
- PLC基準: FX3U-80MT/DS + FX2N-16EX
- I/O容量: 入力56点 / 出力40点

## 1. 設備全体の役割

MCナイロンワークをCV01〜CV04で順送りし、加工エリア内のCV05（加工ステーションコンベア）へ搬送する。
CV05でワークを停止したあと、搬送方向と直角の横方向へワークを移載し、専用加工位置で位置決め・クランプ・穴あけを行う。
加工後は同じ横移載経路でCV05へ戻し、縦搬送ベルトへ復帰させ、終端のメカ式シュートへ排出する。

## 2. ワーク・加工条件

| 項目 | 採用仕様 |
|---|---|
| ワーク | MCナイロン W100 × D60 × H20 mm |
| 加工 | 上面中央へ φ8・深さ15 mmの止まり穴 |
| 搬送方向 | CV01 → CV02 → CV03 → CV04 → CV05 → 排出シュート |
| 加工位置 | CV05の横、搬送方向と直角に1ピッチ奥 |
| 切りくず | 加工位置直下の専用受けへ落とし、コンベアへ落とさない |

## 3. CV05・横移載機構

CV05はCV01〜CV04と同じ縦方向搬送用ベルトを持つ。
ベルト間に横移載用のフリーローラーを配置し、通常搬送時はフリーローラーを下降させてワークを縦ベルトへ載せる。

横移載時は次の順で動く。

1. CV05在荷センサでワーク到着を確認し、CV05を停止する。
2. 横移載用フリーローラーを上昇させ、ワークを縦搬送ベルトから浮かせる。
3. コンベア反対側の搬入プッシャシリンダを前進させる。
4. ワークはフリーローラー上を横へ滑り、加工ステーション内の加工位置へ入る。
5. 加工位置ワーク確認後、位置決め機構を作動する。
6. クランプして穴あけ加工する。
7. ドリル原点復帰、主軸停止、クランプ解除、位置決め解除を確認する。
8. 加工ステーション側の戻しプッシャシリンダを前進させ、ワークをCV05のフリーローラー上へ戻す。
9. CV05在荷を確認し、戻しプッシャを退避する。
10. フリーローラーを下降させ、下降端を確認する。
11. ワークが縦搬送ベルトへ載った後にCV05を再始動する。
12. メカ式シュートへ搬送し、排出確認センサでライン外へ出たことを確認して1サイクル完了とする。

| X13 | 横移載ローラー 上昇端 | フリーローラーが横移載高さまで上昇 |

| X20 | 戻しプッシャ 後退端 | 加工側プッシャの退避完了 |
| X21 | 位置決め 前進端 | 加工位置決め機構のセット完了 |

## 5. 加工部I/O — 出力8点

| 仮番地 | 出力名 | 用途 |
|---|---|---|
| Y15 | CV05 運転 | 加工ステーションコンベアの縦搬送 |
| Y16 | 横移載ローラー 上昇 | フリーローラーを持ち上げて縦ベルトからワークを離す |
| Y17 | 搬入プッシャ | CV05から加工位置へワークを横押し |
| Y20 | 戻しプッシャ | 加工位置からCV05へワークを横押しで戻す |
| Y21 | 位置決め | 加工治具の位置決め機構を作動 |
| Y22 | クランプ | 加工中のワークを固定 |
| Y23 | 主軸運転 | 穴あけ主軸を運転 |
| Y24 | ドリル下降 | 加工ヘッドを下降 |

### 電磁弁について

上記出力は、教材上の機能単位で仮割付している。
エアシリンダの電磁弁をシングルソレノイドとするかダブルソレノイドとするかは、実機機器選定時に確定する。
ダブルソレノイド化する場合は必要出力点数が増えるため、最終I/O表を再計算する。

## 6. 現時点のI/O点数

### 既存搬送部

- 入力: X0〜X7 = 8点、X10 = 1点 → 9点使用
- 出力: Y0〜Y3 = 4点、Y4〜Y7 = 4点、Y10〜Y13 = 4点、Y14 = 1点 → 13点使用

### 加工ステーション追加後

- 加工部入力: 16点
- 加工部出力: 8点
- 合計入力: 9 + 16 = **25点**
- 合計出力: 13 + 8 = **21点**

### PLC構成に対する残り

FX3U-80MT/DS + FX2N-16EX の設計容量を入力56点・出力40点とした場合:

- 入力余裕: 56 - 25 = **31点**
- 出力余裕: 40 - 21 = **19点**

したがって、第4回で追加した加工ステーションだけを理由に追加I/Oユニットを増設する必要はない。
ただし、第5回で手動/自動、操作PB、異常監視、表示、その他の信号を追加した後に最終点数を再確認する。

## 7. 制御上の重要インターロック

- CV05運転中は横移載ローラーを上昇させない。
- 横移載ローラー上昇中または上昇端ではCV05を運転しない。
- 搬入プッシャはローラー上昇端確認後のみ許可する。
- 位置決め・クランプは加工位置ワーク確認後のみ許可する。
- ドリル下降は、加工位置ワーク・位置決め完了・クランプ完了・主軸運転確認・ドリル上昇原点が成立した場合のみ許可する。
- 戻しプッシャは、ドリル上昇・主軸停止・クランプ解除・位置決め解除後のみ許可する。
- フリーローラー下降は、ワークがCV05へ戻り、両プッシャが退避してから行う。
- CV05再始動は、フリーローラー下降端とCV05在荷を確認してから行う。
- 排出確認が成立するまで1サイクル完了にしない。

## 8. 記事シリーズとの境界

- 第1回: 設備全体構想。加工エリアの存在まで。
- 第2回: 搬送部I/OとPLC構成。加工部I/Oは第4回で確定する前提。
- 第3回: CV01〜CV04の搬送制御。X7はCV04から次工程への通過確認候補。
- 第4回: 本文書のCV05・横移載・加工・復帰・排出シーケンスを説明。
- 第5回: 手動運転、異常処理、復旧、追加操作I/Oを確定。
- 最終回: M/T等の内部デバイスを割り付けてGX Works2へ実装。
