# 設備運転仕様書（案）テンプレート

## 表紙・基本情報

- 文書名：`［設備名］ 設備運転仕様書（案）`
- 提出先：`［会社名］ 御中`
- 作成：`株式会社ケイディエス　中村 宏樹`
- 対象設備：`［設備名／ライン名／CV番号など］`
- 作成日：`YYYY年MM月DD日`

## 1. 設備の役割

`［設備が何を搬送・制御し、最終的に何をする設備かを、PLC記号を使わず1〜3文で説明］`

例：
- 複数台のコンベアでワークを段階的にバッファし、最終端の手投入位置まで搬送する。
- 後工程の受入状態に合わせて搬送を継続・停止し、ライン上に一時的なバッファを確保する。

## 2. 主な操作部

| 操作部 | 役割 | 操作時の設備動作 |
|---|---|---|
| 手動／自動セレクタ | 運転モード切替 | `［切替時の動作］` |
| 運転開始PB | 運転許可開始 | `［押した時の動作］` |
| 停止PB | 共通停止 | `［手動・自動のどちらに効くか］` |
| リセットPB | 異常解除／INVリセット | `［復帰条件］` |
| 個別運転SS | 手動個別運転 | `［対象CV］` |
| その他 | `［速度選択・品種切替など］` | `［動作］` |

## 3. 手動運転

1. `［手動モードを選択］`
2. `［運転開始PBを押す］`
3. `［個別SSで対象機器を運転］`
4. `［停止PB・異常時の停止動作］`
5. `［再開時の条件］`

### 手動運転の注意

- 手動時に無視するインターロック：`［あれば記載］`
- 手動でも有効な共通停止条件：`［非常停止、INV異常など］`
- 個別SSが運転位置のまま停止PBを押した後、再度運転PBを押した場合の動作：`［即再始動／再操作必要など］`

## 4. 自動運転

### 通常運転開始

1. 自動モードを選択
2. 運転開始PBを押す
3. `［後工程・センサー等の開始条件］`
4. `［コンベア／機器がどの順序で動くか］`

### 通常運転中の制御

- `［センサーA］` → `［停止するCV／機器］`
- `［センサーB］` → `［停止するCV／機器］`
- `［センサーC］` → `［停止するCV／機器］`

動作の目的も必ず記載すること。
例：`後工程停止時に約20秒搬送を継続し、ワークをコンベア上へバッファする。`

## 5. 特殊運転・モード切替（必要な場合）

例：満杯後一斉前詰めモード

- 切替条件：`［各センサー条件＋タイマ等］`
- モード成立後：`［通常制御との違い］`
- 再運転条件：`［エンドセンサーOFF等］`
- 停止条件：`［エンド満判タイマ成立等］`
- モード解除条件：`［停止PB、異常、自動許可解除、電源断等］`

### サイクル表記例

`手投入 → エンド満判OFF → 全台運転 → 全体前詰め → エンド満判成立 → 全台停止`

## 8. 技術補足

本文ではPLC記号を極力使わず、必要な場合だけここにまとめる。

- 入力：`X___ = ［用途］`
- 出力：`Y___ = ［用途］`
- 内部リレー：`M___ = ［モード／許可］`
- タイマ：`T___ K__ = ［時間／用途］`

## 作成ルール

- 本文は現場オペレーター目線で書く。
- 「何秒後に止まる」だけでなく「なぜその動作をするか」を書く。
- PLCのX/Y/M/Tは本文の中心にしない。
- 未確定事項は「現地確認後確定」と明示する。
- 見積段階ではタイトルに「（案）」を付け、現地確認後に完成版へ更新する。
