# 人気記事 週次更新ルール

トップページ右側の「人気記事」TOP10は、毎週月曜日に検索実績を確認して更新する。

## 対象

- 日本語の技術解説記事のみ。
- 工具紹介、工具比較、商品比較、物販寄りの記事は対象外。
- TOP10は `assets/data/popular-articles.json` を正本とし、`index.html` を手編集しない。

## 順位決定

- 基本は直近28日間の Google Search Console と Bing Webmaster Tools の検索クリック実績を使う。
- Google と Bing を別々に確認したうえで、取得できる週はクリック数を合算して順位付けする。
- 同順位は合算インプレッション、その次に CTR を参考にする。
- Bing を取得できない場合は推測値を作らない。管理者が Google 単独更新を明示した週だけ Google 単独順位を採用できる。それ以外は前週順位を維持する。
- AI引用数だけで人気順位を決めない。

## 更新方法

1. 月曜調査で順位を確定する。
2. `assets/data/popular-articles.json` の `updated_at`、`basis`、`items` を更新する。
3. 各 item は `href`、`title`、`kind: technical` を持たせる。
4. GitHub Actions `Sync popular articles` が10件、重複、記事ファイル存在、`kind` を検証して `index.html` の人気記事ブロックだけを同期する。
5. 同期失敗時は `index.html` を部分的に壊した状態でコミットしない。エラー内容を確認してデータ側を修正する。

## 変更範囲

人気記事更新では、原則として以下だけを変更する。

- 人気記事の順位
- 人気記事のリンク
- 人気記事の表示名
- 更新日と順位根拠のメタ情報

新着記事、特集、カテゴリ、ヘッダー、本文、広告・支援導線などを同じ更新に巻き込まない。
