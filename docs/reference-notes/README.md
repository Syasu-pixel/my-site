# Reference Notes

このフォルダは、記事ごとの公式参照元・確認対象マニュアル・記事で使う範囲・断定しない範囲・画像ルールを記録するためのメモ置き場です。

## 目的

- 記事本文の根拠を後から確認できるようにする。
- メーカー公式資料を確認した範囲と、断定しない範囲を分ける。
- ChatGPT / Codex が次回以降の記事作成・修正時に同じ参照方針を再利用できるようにする。
- 取扱説明書PDF本体は原則としてGitHubに保存せず、公式URL・公式マニュアル名・確認日・使用範囲を記録する。

## ファイル名

記事スラッグに合わせる。

例:
- got-touch-panel-basic.md
- servo-motor-basic.md
- inverter-basic.md

追記ルール:

- メーカー公式資料を参照する記事では、必要に応じて `docs/reference-notes/{slug}.md` に公式用語・採用表記を記録する。
- 英語記事では、英語公式資料の用語を優先して記録する。
- 画像生成時は、reference-notes に記録された「画像内で使用してよい表記」を優先する。
- reference-notes に未記録の用語を画像内に入れる場合は、公式資料または既存英語記事で確認してから使う。

## 英語記事の参照元記録

英語記事では、可能な限り英語公式資料を優先して記録する。

記録する内容:
- 英語公式URL
- 英語版マニュアル名・英語版カタログ名
- 日本語公式資料を併用した場合は、そのURLと理由
- 英語公式が見つからなかった場合の扱い
- 英語記事で採用した用語
- 断定しない範囲
