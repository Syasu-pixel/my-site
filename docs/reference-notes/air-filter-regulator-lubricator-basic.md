# エアフィルタ・FRLの公式参照メモ

- 対象：日本語既存記事。公式資料確認：2026-11-22 JST。
- [SMC エアコンビネーション AC-D 取扱説明書 AC-OMX0033](https://www.smcworld.com/assets/manual/ja-jp/files/ACx-OMX0033.pdf)：空気源・保守点検（p.9–10）、用途（§2）、標準仕様（§3.1–3.3）。固形異物と過飽和水分の分離、圧力制御、必要な給油。水位・ケース劣化・エレメントによる流れにくさを区別。滴下最小流量は入口圧力、使用油、温度、滴下の試験条件を伴う型式固有値。期間、差圧、圧力値、滴下・給油作業の手順を一般記事では転載・推奨しない。
- [SMC AC-Dシリーズ公式Webカタログ](https://www.smcworld.com/webcatalog/ja-jp/modular-frl-units/modular-frl-units-air-combination/AC-D)：AC20-D（F＋R＋L）、AC20A-D（F/R一体＋L）、AC20B-D（F＋R）の構成例。名称を見ただけで装置側の給油要否・空気品質を決定しない。
- [SMC レギュレータ ARシリーズ カタログ](https://www.smcworld.com/catalog/FRL/mpv/S40-69-AR-D/data/S40-69-AR-D.pdf)：AR20-D～60-Dの流量特性と入口側条件。静止時の圧力だけでは空気の流れや機器を使うときの圧力を確認したことにならない。図を縮尺付きの再現値として掲載しない。
- [SMC AC-D 交換要領](https://www.smcworld.com/upfiles/maint/rep/rep-modular.pdf)：交換時に機器内に圧力がないことの確認警告。担当者、設備手順、支持とエネルギー隔離を優先。締め付け、活線・加圧下調整、排出・分解の手順は掲載しない。

## 現場知識、図、掲載しない内容

- もとの実務項目（ドレンの手動／自動、油の有無と滴下、圧力と流れ方向、ケースの白化やひび、入口側から末端まで）を維持。未照合の現場経験談を事実とせず、複数同時／単一支線の対比を判断材料の例に。水位だけで目詰まりと断定せず、同じ使用条件のフィルタ直前・直後が分かる場合のみ差を見る。他の圧調機器を挟む値では原因を分離できない。
- 記事図は、F/R/Lの機能、ドレン水位と流れにくさの別、複数／1台の症状の対照をそれぞれ独立に示す。ポート寸法や接続位置、流量実測、メーカー設定値、工具・手や危険設備への接触を示さない。HeroとOGPのFRLユニットは教育用展示イメージで、実在製品型式の写真ではない。
