## 一次資料と確認箇所

1. [Festo 圧力レギュレータ](https://www.festo.com/jp/ja/c/zhi-pin/kong-qi-ya-diao-zhi-ji-qi/ya-li-regiyureta-id_pim146)
   - 「圧力レギュレータはどのように機能するか」：入口、弁座、出口、ばねとダイヤフラム、出口圧力変化に応じた弁開度調整の説明を確認。
   - 本文では機構を一文に簡略化。メーカー断面図の複製や、特定製品の実構造を推定した生成図は採用しない。供給圧力の一般例を国内設備の共通値にはしない。
2. [SMC レギュレータ AR-D カタログ](https://ca01.smcworld.com/catalog/FRL/mpv/S40-69-AR-D/data/S40-69-AR-D.pdf)
   - PDF p1–2（冊子93–94）：AR-Dと逆流機能付きARK-D、リリーフ／ノンリリーフ、流れ方向の仕様差。
   - PDF p4–5（冊子96–97）：流量特性・圧力特性は代表値。使用量や入口圧力が変わっても二次圧が完全に一定という説明はしない。
   - PDF p6（冊子98）：IN/OUTの配管ポートと圧力計接続ポートを区別。現行本文の圧力計が主流路に直列にあるような列挙を修正する根拠。
   - 製品固有の差圧・設定範囲・流量を一般設定値にしない。
3. [SMC AR-B 取扱説明書 AR※-OMS0031](https://www.smcworld.com/assets/manual/ja-jp/files/ARx-OMS031.pdf)
   - PDF p4–5（冊子3–4）：逆流機能がない型式では入口排気だけによる残圧処理が確実でないこと、長時間無消費時の設定圧変動、IN/OUT、圧力設定上の注意。
   - PDF p2：安全確保、落下・暴走の防止、エネルギー源遮断等。圧力計一つだけでは設備全体の安全確認にならないという本文の注意は、残圧・回路条件・機器取外し前の安全措置から整理した一般注意。
   - これはAR-Bの資料でありAR-Dの取扱説明書と表記しない。入口85％以下、時計回り、ロック解除方法などは全レギュレータ共通手順として採用しない。安全上必要な装置の選定・設計は本記事の範囲外。
4. [SMC デジタル圧力スイッチ ISE35-1 取扱説明書](https://www.smcworld.com/assets/manual/ja-jp/files/PSxx-OMJ0003.pdf)
   - PDF p11–19：設定圧力、スイッチ出力、ヒステリシス／ウインドコンパレータ、NO/NCなどの設定差。
   - 圧力スイッチは圧力を検出して条件に応じて信号を出す。『高ければ必ずON』『表示値の設定で空気圧そのものが変わる』という説明はしない。
5. [SMC JMB エアシリンダ取扱説明書](https://www.smcworld.com/assets/manual/ja-jp/files/JMB-J.pdf)
   - PDF p4：フィルタとレギュレータで調整した空気の供給。
   - PDF p9「2-5 速度制御」：スピコンによる給気／排気流量の調整。
   - 役割比較の根拠。特定シリンダの最高使用圧力や速度値、調整操作は一般化しない。『圧力は速度に一切影響しない』とは書かない。

## 本文・図の範囲

基礎向け7節。『設定を整える機器』『実際に表示される圧力』『スイッチの判定設定』を区別する。無消費と使用中の違いは、通常運転で安全に観察できる条件の比較とし、読者に試運転を指示しない。設定値や変動幅の万能な合否基準は設けない。

本文4図：
1. 一次側・二次側と圧力計の枝接続。主流路を圧力計へ通さない。
2. レギュレータ／圧力計／圧力スイッチ／スピコンの役割比較。
3. 無消費／通常使用中の観察条件比較。数値や正常異常の断定なし。
4. 設定変更前の確認観点。指定値・測定位置／一次側供給／使用中の変化／配管・流量・負荷。操作手順ではない。

内部機構の精密断面図は作らず、『二次圧は完全一定ではない』という概念を文章と観察比較で扱う。汎用外観・模式図として制作し、型番・ロゴ・実配管の再現を避ける。Hero・OGPと本文図は同じちびキャラクター基準で統一する。
