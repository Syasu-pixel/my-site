対象は日本語既存記事。確認：2026-11-23 JST。学習向けの空気経路・仕様の読み方。現場の作業、機械操作、導通、加圧試験や安全機能の設計は扱わない。

- [SMC SY5000 ベース配管形 SY5140](https://www.smcworld.com/assets/support/faq/images/pdf/SY5140.pdf)：原本PDF 1枚目（印刷p.420）「切換方式」の2位置シングルの記号をレンダリング・拡大読解。接続線の引出しがある右側・復帰位置はP→B（1→2）、A→EA（4→5）。反対側・切換済み位置ではP→A（1→4）、B→EB（2→3）。番号=1供給、4/2機器側、5/3主弁排気。この記号の表示は通電や故障を測るものではない。p.421は内部・外部パイロット、ランプ／電圧・仕様の違い、p.422は2位置シングルの例SY5140(R)とサブプレート付き仕様。本文では電圧の種類の例だけを挙げ、ランプと弁位置を結び付けない。写真・外形・端子・口径・圧力数値は記事図へ転用していない。
- [SMC SYシリーズ公式Webカタログ](https://www.smcworld.com/webcatalog/ja-jp/series/SY-5)：1→4/2をP→A/B、4/2→5/3をA/B→EA/EBと照合。類似型式・別ベースの位置・表示・排気組合せを一律扱いしない。A/Bと設備の「前進/後退」は図面の話。
- [SMC 3・4・5ポート電磁弁 共通注意事項](https://ca01.smcworld.com/catalog/SMC-HP/mpv/m-03-3-seihin/data/m-03-3-seihin.pdf)：手動で機械が動く、取り外し時に荷の落下／暴走対策と隔離・残圧の確認が必要。手順（再加圧を含む）は教材に掲載せず、設備担当者・製品資料へ。
- [SMC JSYシリーズ取扱説明書](https://www.smcworld.com/assets/manual/ja-jp/files/JSY1000V-OMW0001.pdf) 「5ポート電磁弁／共通注意事項①」：空気の圧縮性、漏れが停止位置・保持に影響することを確認。JSYの製品値はSY5140へ転用しない。
