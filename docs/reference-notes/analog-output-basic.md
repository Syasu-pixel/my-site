確認日：2026-11-19

## 記事で使う範囲

- PLCのAOから受け側のAIへ量を指令する信号の向き。FX5-4DAの出力レンジと許容外部負荷、およびFR-E800の周波数設定入力仕様・入力選択の別管理を実機資料で照合。
- 電流と電圧の負荷確認の分け方。直線割付の計算例として4–20mAまたは0–10Vの下限・中点・上限を算出。機器側の動作は設定・運転許可と分ける。
- 書き換えや強制出力を一般向けの確認手順にしない。COM・FG・シールドの扱いは対象機種・盤の設計へ委ねる。

## 断定しない範囲

- すべてのPLCの端子名・アナログ生データ・許容負荷・共通端子・シールド接続先が同じとはしない。断線検知の有無や異常判定値、運転条件、出力信号に対する機器動作も型式・設定による。
- 現場知識のFK15-001（海外フォーラム観測、B／JP-B、PLC出力トラブル記事向け）は、国内対象モデルでの実行条件や修復後波形を確認できないため故障事例として不採用。現場記録の定性的な示唆とメーカー仕様を混同せず、本文は「PLC指令、相手側の受信値、実際の動作を分ける」一般的な確認視点に限定。0–10Vのふらつき事例R13はアナログ入力側の候補として区別し、AO原因の裏付けには使わない。
