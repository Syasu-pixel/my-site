# cable-cutter 公式参照メモ

## 参照した公式元・確認対象
- フジ矢 [600-240 製品仕様](https://www.fujiya-kk.com/products_fujiya/600-240/)：「仕様」「切断能力」のIV 60 mm²（φ13.6 mm）とVCTを別に扱う。VCT表の面積単位は用途説明と公式カタログで補完。本文ではVCTの線種・心数別参照のみとし、切断能力の数字を他の線種・製品に流用しない。
- ホーザン [N-18 製品仕様](https://www.hozan.co.jp/corp/g/g6018/)：IV 22 mm²、VVF 2.0 mmφ×2心、167 g、ハンドルカバーは絶縁ではない。VVFの寸法表記を被覆を含む仕上外径と混同しない。
- マーベル [MRC-325 発売情報](https://www.marvelcorp.co.jp/1170.html)、[製品情報・取り扱い注意](https://www.dourakukai.com/products/detail.php?product_id=2591)、[メーカー動画一覧](https://www.dourakukai.com/movies/)：銅線専用、CV線325 mm²をメーカー例として採用。硬銅線・ACSRは不可、通電中の線と能力超過に使わない。メーカー製品情報のヘッダーに単位の省略があるため他の公式箇所を照合。口径は未採用。
- パナソニック [EZ45A7 仕様・能力](https://www2.panasonic.biz/jp/densetsu/powertool/recommend/ez45a7/specification.html)、[EZ45A7X取扱説明書](https://www2.panasonic.biz/jp/densetsu/powertool/torisetu/pdf/p_ez45a7_03.pdf) p.15・17と付属品・別売品：[EZ45A7X-Bは本体のみ](https://ec-plus.panasonic.jp/store/ap/storeaez/a2A/ProductDetail?HB=EZ45A7X-B)。CV 250、CVT 3心60、IV 325、VVR 3心38 mm²。銅・アルミ以外、ACSR等は対象外。説明書の図・本文は「φ1 mm未満」、公式仕様とFAQ注意欄は「φ1 mm以下」で境界表現が異なる。ちょうどφ1.0 mmが可と断定せず、付近は型式と線材を示してメーカーに確認とする。口径32 mmを全線種で共通の切断可否基準としない。
- 松阪鉄工所 [ケーブルカッタ CC-0301／0302／0303](https://mcccorp.co.jp/product/cc/)：No.1（CC-0301）は銅・アルミ線用、最大径22 mm、鉄心入り不可。既存4機種の追加推薦や切断可能性の保証ではなく素材判定の例。
- フジクラエナジーシステムズ [送電事業・架空送電線](https://www.fes.fujikura.com/business/power_transmission/index.html)：ACSRは中心の鋼より線にアルミ線を撚り合わせる。架空線への作業・施工方法は扱わない。

## 記事で使う範囲
- 「材質と構造／線種と心数／寸法」を確認し、その後に本数・工具方式・作業スペースを比較。公称断面積・導体径・素線径・仕上外径・工具口径は別。
- メーカー事実を使った説明例：同じ60 mm²でもEZ45A7のCVT 3心欄（60）をVVR 3心欄（38）に流用しない。執筆者の体験談ではなく、持ち出し前の選定例。
- 既設線は有資格者が現場手順に従い遮断・再投入防止・対象と無電圧確認。一般用製品の活線使用を扱わない。適合不明／刃停止・傷で中断し無理に続行しない。

## 断定しない範囲
- 他機種や未記載線種、アルミ導体の任意構造、鋼線・ACSR専用工具との互換、境界素線径、線種を超えた公称面積や口径の読み替え。切断負荷、刃の寿命、調達価格や在庫は比較しない。
- 対象の選定ミス例は公開の製品仕様に基づく。現場知識のサイト方針第16節、GitHub上の2026-11-07〜11-08国内・海外調査メモ（第13〜19回含む）について、ケーブルカッター、ケーブル切断、鉄心／鋼心相当の該当知識なし。台帳の体験談採用なし。
