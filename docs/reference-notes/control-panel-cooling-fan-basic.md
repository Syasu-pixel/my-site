## 参照した公式元・確認範囲
1. オリエンタルモーター [ファンモーターの選定手順](https://www.orientalmotor.co.jp/ja/tech/calculation/select-fan01)
   - 装置内部の発熱量、目標内部温度、周囲温度、必要風量を確認する考え方。
   - 実装時の風量は風量－静圧特性と装置の圧力損失に関係する。最大風量をそのまま実装時の風量としない説明に使用。
   - 資料中の選定倍率を、全設備共通の余裕率として記事へ追加しない。
2. オリエンタルモーター [プロペラファン用フィルター／交換用フィルターメディア](https://www.orientalmotor.co.jp/ja/products/accessories/fan/propeller-filter)
   - フィルターの防塵目的、使用時の風量－静圧特性変化、目詰まりによる冷却効果低下。
   - 同資料の洗浄可能な製品例を、全フィルターが水洗い可能という説明へ一般化しない。
3. 日東工業 [熱関連機器](https://www.nito.co.jp/guide/joutsuu/product/equipment.html)
   - 強制換気、密閉放熱（熱交換器）、密閉冷却（クーラー）の区別。
   - 外気を直接取り入れる方式と、外気を取り入れず熱を移す方式を分ける一般説明に使用。個別製品の能力・保護等級を全設備へ適用しない。
4. オリエンタルモーター [ブラシレスDCファン MDPシリーズ取扱説明書 HF-3145](https://www.orientalmotor.com/products/pdfs/opmanuals/HF-3145JE.pdf)
   - 適切な資格を有する人による取扱い、開口部への指・物の挿入禁止、回転部接触防止、通風を妨げないこと、異常発生時の電源遮断など安全上の注意。
   - MDPシリーズの機種別資料。電源条件・規格・保護回路・作業方法を他機種へ転用しない。PDF本体は保存しない。
5. 日東工業 [FN-BN 換気扇セット](https://ntec.nito.co.jp/content/ppreview.html?code=C840-C854-S11218M3)
   - 可変式温度調節器による動作温度設定の製品例を確認。
   - ファン停止だけで故障と断定しない説明の補助例。すべての制御盤が温度連動で停止するとは扱わない。

## 記事で使う範囲・安全留保
- 換気と盤内循環を区別し、換気だけでは外気より低温へ冷却できないこと、循環だけで熱が消えるわけではないことを説明する。
- 空気対空気の熱交換器の温度差による放熱を説明する。水冷式など異なる方式を一律に扱わない。
- 入口・通り道・出口、フィルター、周囲温度を合わせて考える基礎説明に限定する。具体的な容量計算、施工、配線変更、通電測定の手順は掲載しない。
- 初心者の確認範囲は外から安全に確認できる表示・外観・警報記録まで。異常時は現場手順と担当者判断を優先する。
- 点検・清掃・交換は権限と知識のある担当者が対象製品の最新資料と現場手順に従う。停止・遮断・再投入防止・必要な無電圧確認・残留エネルギー対処を省略できるとはしない。
- 全設備共通の正常温度、清掃周期、ファン交換サイズ、洗浄方法、保護性能は断定しない。
