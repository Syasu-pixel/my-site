- 旧本文の基本構成、操作表示・警告、色や見た目だけで同定しないこと、改造後の表示更新、図面と実物を照合する考えを維持。用語を盤の銘板、機器ラベル、端子台と端子、電線の線番へ分けた。
- 照合例の搬送盤A・K1・E-12（版B）・X1の05番は架空の資料用例。メーカーの命名法や一般規定、給電や物理結線、現物の無電圧、作業許可を示さない。
- 現場知識：FK12-006（交換で失われない識別、B/JP-B）は課題仮説として参照。海外個別事例を事実として流用せず、国内で読める上記ラベル資料の例を代表根拠とした。FK16-005（複合品のモーター銘板、B/JP-B）は機種/主題が離れるため不採用。現場の体験談は創作していない。
- HeroとOGPの既存キャラクターはサイト正本に基づく。本文図は機器の識別関係または架空の資料照合を描いた説明図で、仕様・結線・施工図ではない。本体・ラベルとも実機のデザインを保証しない。
- 追加図は同じ2台で識別表示の対象が曖昧な例と明確な例を比較する。施工位置を指定せず、双信電機の同じ参照資料の「部品の略号の表示」を根拠に、本文側に取外し時の注意を補足した。
