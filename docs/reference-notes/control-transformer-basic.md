## 現行からの重要変更
- 『まず電圧を変えるより制御電源を分ける』は、単巻まで絶縁と誤認しやすい。交流電源の用途と一次/二次から説明、複巻/単巻は別節。
- 200→100Vの普遍化や『必ず降圧』を避ける。同電圧製品あり、AC24VとDC24Vを明確化。
- 直接的な『二次側電圧は必ず測る』『実測する』の初心者指示を除去。図面→銘板→把握済み状態→適切な作業者への引継ぎへ。
- 一次電圧/二次電圧/VA/Hz/巻線方式を読める初歩説明。定格電圧だけの交換選定、VA=W、全機50/60共用を避ける。
- 現行のIEC60204-1への漠然とした引用は今回原典未確認のため踏襲しない。規格適合を断定しない。
- 押しボタンを独立した電力負荷のように扱わず、接点が開閉する先の負荷との関係を述べる。
