# CT・電流センサの公式参照メモ
対象：日本語の既存記事のみ。公式資料の初回確認：2026-11-22 JST。図はいずれも解説用で実製品・配線・取付・測定手順ではない。
- [富士電機テクニカ：貫通形変流器の定格電流の読み方](https://www.fujielectric.co.jp/technica/products/instrument-transformers/faq/instrument-transformers/05.html) に100AT/5Aの資料例。本文100/5 Aは適合定格を仮定した読解例、変流比20:1、一次50 A→二次約2.5 A→一次換算設定時に約50 A。異なる適用比やターン数の施工は説明しない。
- [富士電機テクニカ：二次電流5A品と1A品](https://www.fujielectric.co.jp/technica/faq/meter/06.html)：別規格と対応計器の前提。[CT二次側開放の注意](https://www.fujielectric.co.jp/technica/faq/meter/07.html)：一次電流が流れている状態での二次開放、高電圧、絶縁破壊・焼損。感電リスクから具体的な測定や開閉の手順は示さない。
- [三菱電機 FAQ 17530](https://fa-faq.mitsubishielectric.co.jp/faq/show/17530?site_domain=default)：CT併用計器には計器定格とCT比の記載。指示電気計器カタログ [Y-0418E 1503](https://www.mitsubishielectric.co.jp/dl/fa/document/catalog/pmd/ym-c-y-0418/y0418e1503.pdf) はトランスデューサ出力注意や変流器の諸特性（表18-5、印刷p106）も確認。計器用CTの二次電流とトランスデューサの出力を混同しない。高圧専用 [CD-25 Y-0765A 1704](https://dl.mitsubishielectric.co.jp/dl/fa/document/catalog/pmd/ym-c-y-0765/y0765a1704.pdf) は2017年の機種資料：一般的な低圧入門の仕様根拠には不採用。
- [エムティティ：MS3420](https://mtt.co.jp/?pcat=sub0401-func04-func-b)：専用変換器の入力1A AC／5A ACおよび出力例4～20 mA・0～10 Vを仕様欄で確認。[津田電気計器：電流検出器](https://www.tsuda-em.co.jp/products/detail//?serial=dc22)：ホール素子・直流機器、電圧/mA各出力、形状や呼称だけで単一仕様とはしない。[日置電機：CM4002/4003](https://www.hioki.co.jp/file/cmw/hdInstructionManual/95338/pdf/?action=browser&log=1) は負荷電流と漏れ電流を測る目的の違い、[同社サポートFAQ](https://hiokisupport.zendesk.com/hc/ja/articles/9370496139023) は往復の磁束の相殺を説明。手順ではなく対象を図面で照合する根拠。
- 現場知識：第16節と第16・19回の索引を検索し、FK16-001/R19-06（ABB ACH580の警報・著者の推定、B、他記事）を確認。測定部の不具合・故障原因を独立に確証できないため不採用。本文例は既設表示・記録を区別する編集上の架空例であり、現場で観測した事例や新しい数値根拠ではない。
