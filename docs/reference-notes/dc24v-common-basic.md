# DC24VのCOM：四コマ技術参照メモ

2026-11-14確認。既存記事の説明を4コマへ再利用するための根拠。記事本文の内容更新日や90日間隔を変更しない。

## 対象と一次資料
- 対象: articles/dc24v-common-basic.html。main本文とPR1825の公開反映記録を確認。
- 三菱電機FAQ [S/S]端子について: https://fa-faq.mitsubishielectric.co.jp/faq/show/24170
  - FX5U/FX5UC/FX5UJ/FX5Sの例で、S/Sの接続先はシンク/ソース入力によって+24Vまたは0V側となる。すべてのPLCの端子名・接続・内部接続へ一般化しない。
- OMRON FAQ00379: https://www.ia.omron.com/support/faq/answer/41/faq00379/
  - NPN/PNPでセンサ出力に対する負荷の位置が異なる。PLCとセンサの仕様を合わせて確認する根拠。

## 採用する要点
PLC入力のCOMは共通側として読むが、名前だけから0Vと決めつけない。対象機種の図面・仕様書・公式接続図を優先する。『プラス/マイナスコモン』の呼び方を一律のNPN/PNP判定や全メーカー共通仕様としない。

## 断定しない範囲
全COMの内部共通、全PLCで同一端子名、電源線のつなぎ替え手順、短絡や活線作業による試験、安全回路設計。四コマは入口であり施工指示ではない。
