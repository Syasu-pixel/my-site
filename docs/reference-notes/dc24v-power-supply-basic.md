## 断定しない範囲
- 全パワーサプライがAC入力/DC24V出力、全PLCがDC24V入力、表示灯点灯で負荷端の電圧正常、とは断定しない。
- 0Vと保護接地を同一視せず、端子配列・ジャンパー・接地方式を図から推測しない。
- 一律の余裕率、取付間隔、ディレーティング温度、過電流保護復帰時間、任意の並列運転を提示しない。
- 24V×2A=48Wは電力計算例で、推奨機種・必要容量決定ではない。
- 通電測定、端子接触、増締め、配線変更、交換は一般読者向け手順ではない。設備・メーカー安全手順と担当者判断を優先。
