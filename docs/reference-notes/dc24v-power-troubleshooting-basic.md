# DC24V電源が落ちる時の確認手順：技術参照メモ

- 対象: 日本語の既存記事。確認日: 2026-11-20（日本時間）。
- [オムロン S8VK-G 定格／性能](https://www.fa.omron.co.jp/products/family/3178/specification/): 過電流保護は自動復帰。過電圧保護は出力遮断後の復帰条件が異なる。緑色の出力表示灯は定格電圧に対する点灯しきい値があり、負荷端での正常電圧を保証しない。
- [オムロン S8VK-S 定格／性能](https://www.fa.omron.co.jp/products/family/3485/specification/): 30～120 W品は不足電圧検出出力なし、240/480 W品はあり。同シリーズでも端子機能の有無は個別型式を確認。過電流・過電圧保護の復帰条件は個別に扱う。
- 図は電源元・分岐・負荷を追う判断の見取り図。全系統／一分岐の範囲と、負荷が動く時だけ発生するかの時系列は別々に整理。原因や再起動可否は断定しない。活線作業、現場での故障再現、保護無効化、具体的な復旧操作は対象外。
- 分担: DC24V電源の基本は選定・配線・電源の役割、PLC入出力の総合ガイドは制御全体の診断、この記事はDC24Vの症状から原因範囲を絞る入口に限る。
