# 遅延起動回路：メーカー資料と学習例の範囲
対象は日本語既存記事。公式資料確認：2026-11-23 JST。

- [三菱電機「マイクロシーケンサ基礎（iQ-F編）」JY997D68101-E](https://dl.mitsubishielectric.co.jp/dl/fa/members/document/manual/school_text/jy997d68101/jy997d68101e.pdf) 4.3.3「タイマの計時」印刷4-12：タイマTと積算ST、OUT T0の100 ms×K30、論理条件OFFで現在値が0・a接点OFF。4.3.1の通常OUT・a接点も照合。4.1でM（内部リレー）・T（タイマ）・Y（出力リレー）を照合。公式例X0/Y0/Y1は転載せず、学習例はM0→OUT T0 K30、M0のa接点とT0のa接点の直列→OUT Y0。M0割当元・外部配線は対象外、Y0は学習用表示灯の出力のみ。別段書込み・自己保持・設備起動・安全回路を含めない。2秒中断→無完了でY0はOFF、5秒の条件→3秒でT0とY0がON、条件OFFでT0完了とY0がOFF。軸は同一の理想化、入力更新、実行順、タイマ評価と表示の正確な遅延は機種命令と実装に依存。
- [オムロン「タイマ／タイムスイッチ 概要」](https://www.fa.omron.co.jp/guide/technicalguide/19/89/?vm=r) 動作の説明：オンディレイとオフディレイを区別。外付けタイマの電源／信号開始タイプをPLCのTに流用しない。二次図に起動手順、停止回路、インターロック実装、設備配線を含めない。
