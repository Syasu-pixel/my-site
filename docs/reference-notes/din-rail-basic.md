## 主張と編集境界

- basic/devices：対応する機器を固定する取付レール。取付対応は機種・付属品依存。端子台、リレーソケット、PLC/I/O、電源などの分類は例であって全製品の互換表ではない。
- overview：レールを盤へ固定／機器をレールへ保持／必要な横ずれ防止金具の3役割を分ける。エンドプレート・エンドクランプ等はメーカーで呼称と目的を照合する。
- compatibility：代表的な35mmトップハット形だけを扱う。幅だけでなく断面形状・高さ・厚さ・材質・取付方向・付属品と対象機器の仕様を確認する。
- comparison：直付けとDINレールの優劣を一律に決めない。適合、交換、配線、空間条件を比較する編集上の整理。
- mounting：停電・再投入防止・残留電荷など設備ごとの安全手順が前提。個別機器の取付説明を読み、必要な固定・ロックを確認する。通電点検や配線を引っ張る試験は説明しない。
- field：S3の配置原則を、放熱・配線・交換という初心者向け3観点へ編集。特定の事故実話・故障頻度・性能改善実証として述べない。
