# 電気工事のドライバー：一次資料確認

2026-11-28 JST。刃先・工具の形・指定トルクは条件を分ける。活線作業、叩く・こじる実演、端子の施工手順は扱わない。

- [ベッセル No.220（+2×100）](https://www.vessel.co.jp/product/screwdriver/125356/)：+2は刃先、100 mmは軸長、全長200 mmは別欄。
- [ベッセル No.220（-6×100）](https://www.vessel.co.jp/product/screwdriver/125352/)：マイナス幅6 mm、厚さ0.9 mm。溝の適合調査用で任意のマイナスねじに使えるとはしない。
- [ベッセル No.250（+2×150）](https://www.vessel.co.jp/product/screwdriver/112108/)：「安全貫通」は正式製品名、絶縁ドライバーではない。活線で使わない。
- [TONE PGPD-003](https://www.tonetool.co.jp/product/detail.php?no=PGPD-003)：プラスNo.3、貫通型、電気絶縁を意味しない。打撃手順は転載しない。
- [サンフラッグ 99-HB](https://www.sunflag.co.jp/wp-content/uploads/2022/09/99HB_220715.pdf?20211109134217=)：ウルトラミニの短い柄・付属ビット。手前の空間と奥行きで区別。
- [ベッセル TD-56](https://www.vessel.co.jp/product/screwdriver/251382/)・[9903](https://www.vessel.co.jp/product/screwdriver/125611/)：セット内容を二者で区別。9903の軸長は組み合わせ固有。
- [オムロン XW2R（PLC接続タイプ）定格/性能](https://www.fa.omron.co.jp/products/family/3153/specification/)：「電源端子なし・プラススクリュータイプ」の0.5 N·mのみ。ほかの型式・ねじへ外挿しない。手回しの感触やモーターの出力トルクとは別。
