## 記事で確認した範囲
- 漏電遮断器は漏電による感電事故や火災を防ぐため、規定値に達した漏れ電流を検出して回路を遮断する保護機器であること
- 一般的な漏電遮断器は ZCT（零相変流器）・漏電検出回路／漏電リレー・遮断器の組合せで漏電を検出し、引き外し機構で電路を遮断すること
- 配線用遮断器は主に過電流・短絡保護、漏電遮断器は漏電保護を加えた保護機器として扱われること
- 定格感度電流や動作時間は製品・用途で異なり、具体値は対象機種の仕様確認が必要なこと
- TESTボタンは漏電時に遮断器がトリップするかを確認するための機能であり、操作条件は対象製品の説明に従うこと
- Type AC / Type A / Type B は漏電検出特性の区分であり、負荷や回路条件に応じて適用を確認すること
- 高調波・サージへの不要動作対策など、漏電検出特性には製品差があること

## 断定しない範囲
- 15mA・30mA・100mA等の具体値を用途と1対1で固定しない
- 動作時間を全製品共通の固定値として扱わない
- TESTボタンの操作頻度・操作条件・復帰操作を全機種共通の手順として示さない
- Type AC / Type A / Type B の選定を負荷条件なしで決めない
- 特定製品の極数、適用電圧、漏電表示方式、復帰方式、端子・配線を一般化しない
- 実設備の復旧可否を記事だけで判断させず、設備手順・対象製品資料・必要な担当者判断を優先する
