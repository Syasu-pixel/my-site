## 断定しない範囲
- 個別設備への適合、特定の安全カテゴリ・PL・SIL、停止時間・停止カテゴリ、配線・設定・改造手順は提示しない。
- 非常停止はガードやインターロック、保守時のエネルギー隔離に代わるものではない。
- 通常PLCと安全PLCを区別する。二重化だけで安全性能が決まるとはしない。
- ボタン解除、安全リセット、別の起動操作を概念として分け、3個の物理ボタンを普遍的要件としない。
- メーカーの公開解説を参照しており、規格全文や個別機器マニュアルを網羅確認したとはしない。

## 公式用語・採用表記
|日本語|英語|採用方針|
|---|---|---|
|非常停止|Emergency stop|危険時に人が操作する安全機能|
|b接点／NC接点|Normally closed|通常の接点状態。直接開路動作と区別|
|直接開路動作|Direct opening mechanism|規定条件下の機械的開離|
|解除・安全リセット・再起動|Release / safety reset / restart|役割を区別し、解除で始動させない|
|エネルギー隔離|Energy isolation|非常停止と別の保守作業上の方策|
