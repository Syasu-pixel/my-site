## 公式資料と使う範囲
1. [オムロン：タイマの概要](https://www.fa.omron.co.jp/guide/technicalguide/19/89/index.html)
   - フリッカは出力のON/OFFを反復する動作。他の時間動作と区別する。
2. [オムロン：H3YNの動作モード](https://faq.fa.omron.co.jp/tech/s/article/faq05430)
   - オンスタート／オフスタートが存在する。電源スタート・リセットの製品例。端子配線は転載しない。
3. [オムロン：H3CR-Fの特長](https://www.fa.omron.co.jp/products/family/194/feature/)
   - ON時間とOFF時間を別設定できるツインタイマの例。開始動作は製品・形式による。
4. [三菱電機：MELSEC iQ-R Programmable Controller CPU Module User's Manual, SH-082488ENG-F](https://www.mitsubishielectric.com/dl/fa/document/manual/plc/sh082488eng/sh082488engf.pdf)
   - 実PDF p.152のクロック説明を確認。運転開始前から動くクロックは最初の区間が通常の幅と一致しない場合がある。処理途中で状態が変わるクロックを複数箇所で使う場合、各スキャン冒頭で内部リレーへ取り込む考慮例。
   - 本記事は対応CPU、特殊デバイス番号、設定項目、実行可能ラダーを示さない。この版の説明をすべてのPLCに一般化しない。
5. [オムロン：タイマの注意事項](https://www.fa.omron.co.jp/product/cautions/19/91/index.html)
   - 接点定格、突入電流、開閉頻度と寿命。ランプとブザーを同じ負荷と見なさない。
6. [オムロン：一般リレーの用語解説](https://www.fa.omron.co.jp/guide/technicalguide/36/67/index.html)
   - バウンス・チャタリングを意図的なフリッカ動作と区別する。接点の不安定動作をすべてタイマ設定の問題としない。
   - 旧スイッチFAQリンクはリダイレクト先本文を確認できなかったため不採用。上記本文を実読した公式資料へ変更。

## 独自の説明・断定しない範囲
- 周期＝ON時間＋OFF時間は時間の定義を整理した教育用説明。0.5秒＋0.5秒＝1秒は計算例であり推奨警報周期ではない。
- 「表示条件 AND 点滅信号 → 表示灯」は論理概念。異常保持を入力例に使うが、異常検出・保持・復帰条件の実装を保証しない。
- 警報表示の消灯半周期でも異常保持を消す必要はない。点灯＝正常、点滅＝異常という普遍的な意味付けはしない。
- 回路変更、強制出力、保護機能の無効化、通電中の端子作業は案内しない。設備固有の取扱説明書と権限・安全手順を優先する。
- 所有者の未確認の現場経験、実験結果、改善成果は創作しない。
