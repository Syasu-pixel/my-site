## 採用表記と図の境界

- 正転：設備で基準にした方向。CWと同義に固定しない。軸を見る側も記録する。
- MC：電磁接触器。PB：押しボタン。a接点：動作で閉じる、b接点：動作で開く接点。
- 図の接点は有接点制御の概念。PLC入力ビット・ラダー命令へそのまま転記しない。
- phase図：A=R→U/S→V/T→W、B=R→W/S→V/T→U。Aを普遍的な正転と呼ばない。
- logic図：自己保持a接点を起動PBと並列、反対側MCのb接点を直列。上下の停止は共通停止操作を各枝に示す。保護・停止検出・再起動防止を省略した概念図であり、同時操作の優先や設備安全を保証しない。
- flow図：正転中→停止指令→回転停止・切替許可→逆転起動。接触器OFFを停止確認と混同しない。
- インターロック短絡、接触器手押し、PLC強制ONを確認手順にしない。
