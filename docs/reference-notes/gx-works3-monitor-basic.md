## 記事で使う範囲と断定しない範囲
- 回路のつながりを見るモニタと、番号を指定して値を見るモニタを使い分ける。PLC内部YがON、盤内通電、設備の動作はそれぞれ別の観察。表示が古い可能性は、更新状態を裏づける時刻等が不明な場合として扱う。
- X10・M20・Y0の直列例は説明用の仮想回路。上書き・強制なし、その段が実行される前提。実設備の事例、メーカー配線、実機操作手順ではない。
- 端子の測定、バイパス、強制、書込み、設定変更、意図的な再運転は対象外。モニタの表示名や対応項目はCPUとGX Works3の版で異なり得る。
- メーカー資料を用いた編集上の教材例に限定し、現場経験談は採用しない。

## 画像ルール
- 実在製品の外観・UI・ロゴを再現しない。教材一段はa接点X10・a接点M20・通常コイルY0。画面更新不明は第三の機械状態ではなく、観察の信頼性の分岐。ON/OFFは色だけに依存せず文字も付ける。
