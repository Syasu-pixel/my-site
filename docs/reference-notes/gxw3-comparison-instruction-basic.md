## 記事で使う範囲と断定しない範囲
- FX5をGX Works3で読む教材として接点形の比較条件を説明する。符号付き16ビットD100と十進定数K100の値を別々の2段で比較し、2つの内部通常コイルの状態を紙上で求める。数値例は当記事で設定したもので、メーカー推奨値ではない。
- 16ビット用と32ビット用のD参照範囲の違いを扱う。別CPUシリーズ、他言語、CMP等の詳しい動作、PLCへの値書込みや試運転は説明しない。
- メーカー資料を用いた編集上の教材例に限定し、現場経験談は採用しない。

## 画像ルール
- 2段を独立して表示。上段はLD> D100 K100 → OUT M10、下段はLD>= D100 K100 → OUT M11。母線・比較接点・通常コイルを見分けられる構成。実配線・実出力・安全回路は描かない。色だけでON/OFFを伝えない。
