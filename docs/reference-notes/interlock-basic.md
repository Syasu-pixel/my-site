## 目的と範囲
基礎記事のまま、定義を「同時ON防止・相手b接点だけ」に固定せず、禁止条件では動作を許可しない考え方を説明する。自己保持との違い、正逆転接触器例、論理状態と実機状態、通常制御と安全機能の境界を整理する。実配線図、活線測定、強制出力、バイパス、再起動手順は提供しない。

1. [三菱電機：全電圧始動、電気的インタロックと機械的インタロック](https://www.mitsubishielectric.co.jp/fa/ssl/learn/el/eln/course/fa_0136/cha_3/03020003.html)
   - ページ本文全16行を取得して確認。可逆式運転で接触器2台の同時投入が相間短絡につながる点、補助b接点によるコイル励磁の禁止、機構による相手側投入の阻止を確認。
   - 適用範囲は接触器を使う可逆式の例。インバータの制御入力やすべての駆動方式に同じ故障結果を一般化しない。本文は配線手順ではなく仕組みの説明に限定。
2. [オムロン：非常停止回路と安全インターロック回路の違い](https://www.fa.omron.co.jp/product/special/safetynavi/tips/emergency_stop_07/)

   - 通常PLCの相互禁止を人身安全保証としない。一方でインターロック全般が安全機能ではない、とも断定しない。規格本文を読んだとは扱わず、PL等の具体要求値は記載しない。
