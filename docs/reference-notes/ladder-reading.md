# ラダー図の読み方 公式参照メモ

確認日：2026-11-24 JST。対象は日本語記事 `articles/ladder-reading.html`。共通ひな形や英語版には適用しない。

- [三菱電機「はじめてのシーケンサ 入門編」JY997D41501E](https://www.mitsubishielectric.co.jp/fa/service-support/global/satellite/pdf/jy997d41501e.pdf) の日本語公開PDFを参照。§4.1.3（印刷4-4）のa/b接点と通常OUT、§4.1.4〜4.1.6（4-5〜4-7）の直列・並列の条件、§4.1.8（4-9）の自己保持を採用。GX Works2教材なのでGX Works3の画面・色・操作の根拠にしない。
- 独自学習段は通常OUT M10 = M0 AND (M1 OR M2) AND NOT M3。一段のみを評価し、機器を動作させない。独自の自己保持段は M22(next) = NOT M21 AND (M20 OR M22(previous))、M22初期OFFかつ他に書き込みなし。要求と解除が同時ONなら、両枝より左の解除が優先されOFF。保持の説明は通常の判定中であり、電源再投入・停電後を保証しない。図は独自作図でありメーカー画面転載でない。
- ラダービットの成立、PLC外部出力の状態や機器の実動作、設備の安全機能を分ける。現場例は図面・既存画面・記録を読む範囲。操作、強制書き込み、実配線の指定は行わない。
