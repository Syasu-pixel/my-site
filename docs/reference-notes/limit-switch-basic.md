## 公式資料
| 資料 | 確認した内容 | 本文での使い方 |
| --- | --- | --- |
| [オムロン「リミットスイッチ テクニカルガイド」p.4](https://www.fa.omron.co.jp/data_pdf/commentary/limitswitch_apparatus_tg_j_3_1_1-5.pdf#page=4) | FPは無操作、OPは操作時の反転、RPは外力を減らしたときの反転、TTPは操作部の動作限度。PTはFP–OP、MDはOP–RP、OTはOP–TTP。 | 概念図に位置と操作方向を示す。図の間隔・形状は型式の寸法や設定値ではない。 |
| [オムロン「リミットスイッチの接点が切り替わる位置を教えてください」FAQ04970](https://faq.fa.omron.co.jp/tech/s/article/faq04970) | 一般的な切替接点のNO/NCの切替と、押す側・戻る側の位置の違い。 | 接点の状態、PLC入力表示、ラダーの条件を別の段として説明。 |
| [オムロン D4C-1220 型式仕様](https://www.fa.omron.co.jp/product/item/D4C-1220/)・[PDF p.4](https://www.fa.omron.co.jp/product/item/D4C-1220/ja/pdf/#page=4) | ローラ・レバー形。PT最大25°、MD最大3°、OT最小40°。 | 「最大・最小」の読み方だけに用いる。規格値の引き算で個体のRPを算定しない。機械側のストローク設定、停止位置、押し増し量として転用しない。 |
| [オムロン「リミットスイッチ トラブルシューティング」](https://www.fa.omron.co.jp/guide/technicalguide/30/332/index.html) | 当て金・カムの形状、操作方向、過大ストローク、復帰不良の見方。 | 図面・型式資料・既存入力記録の照合に絞る。稼働中に実機を押す・調整する・強制入力する手順は案内しない。 |
| [オムロン「リミットスイッチ共通の注意事項」](https://www.fa.omron.co.jp/product/cautions/30/195/index.html) | ローラー端方向の斜め荷重を避け、当て金で外周の幅中央へ当てる考え方。 | 図は側面と上面の概念で、取付角度や寸法を指定しない。 |
| [オムロン「D4C-1220 回路構成」p.7](https://www.fa.omron.co.jp/product/item/D4C-1220/ja/pdf/#page=7) | 表示灯なしの引出し線式1c。無操作時COM–NC、動作後COM–NOの一般概念。 | 芯線色や端子位置を描かず、EはCOMではない。 |

この資料は通常制御の基礎を対象とし、安全回路・非常停止・安全扉の設計例ではない。図は一般的な仕組みの説明で、D4C-1220の寸法図・取付図・実機写真ではない。
