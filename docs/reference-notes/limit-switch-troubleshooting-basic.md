# リミットスイッチが反応しない時の確認手順｜公式参照メモ

## 参照した公式元と確認対象

- オムロン [リミットスイッチ 概要・技術解説](https://www.fa.omron.co.jp/guide/technicalguide/30/41/)：機械位置を接点状態へ変換する仕組み、動作特性の呼称。
- オムロン [小形リミットスイッチ D4C-1320 形式別仕様](https://www.fa.omron.co.jp/product/item/D4C-1320/)：形式別仕様の動作までの動き（PT）と動作後の動き（OT）の区別、回路構成図の所在。寸法・角度の実数を記事の推奨値にしない。
- オムロン [D4N 小形セーフティ・リミットスイッチ マニュアル一覧](https://www.fa.omron.co.jp/products/family/1497/download/manuals/)：安全用途で個別形式の取扱説明書や設計条件を別途確認するための案内。汎用品からの置換、安全カテゴリ、適合性、保守時の操作をこの一覧だけで判断しない。
- 三菱電機 [MELSEC iQ-F FX5S/FX5UJ/FX5U/FX5UC ユーザーズマニュアル（ハードウェア編）SH-082451-L](https://dl.mitsubishielectric.co.jp/dl/fa/members/document/manual/plcf/sh082451/sh082451l.pdf)：入力動作表示、応答時間の説明。掲載機種の例として参照し、他形式へ適用しない。

## 記事で使う範囲

- 位置・接点/配線・PLC表示を別々に照合する一般的な考え方。
- 機械側の当たり・動作位置から接点期待状態を区別し、NO/NCとラダーの論理を混同しない。
- 一般位置検出を対象とし、機械安全回路の適合・作業許可や入力表示による安全判定をしない。

## 断定しない範囲

- 配線・端子番号、PLCの感度やフィルタ値、スイッチの位置・角度・使用限界は現場の対象形式と資料による。
- 担当者の設備手順を省略して、通電作業、短絡、PLC入力の強制、ガードを開けた試運転を勧めない。
- 位置・接点・表示の不一致から、故障部品を一義的に確定しない。現場事例の創作・転載をしない。

## 現場知識と画像

- 国内・海外の現場知識台帳でリミットスイッチ、ローラ、可動ケーブル関連を点検。対象型式のスイッチ不良と結びつく独立検証済みのケースを確認できなかったため、外部の事例は採用しない。
- 画像は写実の製品図や配線図ではなく、位置の観察・図面の照合・PLC表示の切り分けを示す模式図。読者が端子の操作を再現できる表示、ロゴ・銘板は掲載しない。
- 旧 #1475 の安全表現・手順を再利用。旧原稿に残っていた通電測定を示す画像および単純な点灯判定を描いた旧図は再利用しない。
