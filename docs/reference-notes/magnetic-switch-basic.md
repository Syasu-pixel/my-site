## 記事で使う範囲

- 電磁接触器は、コイルの電磁力で接点を開閉し、主接点でモーター等の負荷電流を開閉する機器として説明する。
- 電磁接触器には主接点と補助接点があり、補助接点は制御・状態信号などに使われることを説明する。
- 電磁開閉器（マグネットスイッチ）は、電磁接触器とサーマルリレーを組み合わせ、モーターの始動・停止と過負荷保護に用いる機器として整理する。
- サーマルリレーは、モーターの過負荷・拘束・欠相等による過電流を検出し、接点出力で電磁接触器等を開路させる保護機器として説明する。
- PLCや押しボタン等の制御信号でコイルを動作させ、主接点を開閉する基本概念を説明する。
- 実機ではコイル電圧、接点定格、補助接点構成、保護方式、端子番号、PLC出力との接続可否を対象型式の公式資料で確認する。

## 断定しない範囲

- 「マグネットスイッチ」「電磁開閉器」「電磁接触器」を完全な同義語として扱わない。
- 現場で「マグネット」と略称される対象が設備・会社によって異なるため、正式用語と現場呼称を区別する。
- 電磁接触器単体にサーマルリレー機能が必ず含まれるとは書かない。
- サーマルリレーが短絡保護を行うとは書かない。
- PLC出力がどの型式のコイルでも直接駆動できるとは書かない。
- コイル電圧、主接点定格、補助接点構成、端子番号を全製品共通として断定しない。
- R/S/T、U/V/Wの配線色を法規・規格上の固定色として断定しない。

## 画像ルール

- 実在メーカーのロゴ、型式銘板、製品ラベルを再現しない。
- 電磁接触器単体を描く場合は、電磁開閉器（マグネットスイッチ）と誤認させない。
- 電磁開閉器を説明する図では、必要に応じて電磁接触器とサーマルリレーの組合せが分かる構成にする。
- コイル、主接点、補助接点の役割を分けて表示する。
- 主回路と制御回路を視覚的に区別する。
- 配線色は説明用の例示とし、規格上の固定色として扱わない。
- PLC出力番号や端子番号を実機固有仕様に見せない。
- 物理的・電気的に矛盾する接点動作や配線経路を描かない。

## メモ

- 富士電機公式では、電磁接触器はコイルの電磁力で主接点・補助接点を開閉する機器、電磁開閉器は電磁接触器とサーマルリレーを組み合わせたものとして明確に区別されている。
- 三菱電機公式でも、電磁開閉器をモーター制御・焼損保護、電磁接触器を電磁石の力による負荷電流の開閉、サーマルリレーを過負荷・欠相電流の検出として区別している。
- 現行記事の「マグネットスイッチ／電磁開閉器／電磁接触器」の呼称説明は、次回本文修正時にこの正式区分がより明確に伝わる表現へ調整する。
