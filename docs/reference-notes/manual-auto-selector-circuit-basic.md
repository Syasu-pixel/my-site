## 学習例と画像の境界

- 四状態の表は、手動／自動の選択を二つの論理信号で読む架空の学習例。両方OFFを停止位置だけに特定せず、両方ONを受け付けない設計例として説明。実際の信号の意味は設備固有。
- 本文の図は選択側の新規要求と通常運転許可に基づく内部受付の概念図。切替前・不許可中の保持要求を新規要求として扱わない想定であり、新規要求の生成、自己保持、物理出力は範囲外。
- 通常運転許可や停止表示は安全機能、電源遮断、機械停止あるいは作業許可の証明ではない。実機への書き込み、配線、保護機能の無効化、試運転・復旧の手順は扱わない。設備の承認済み資料と採用機種の最新資料を優先する。
- Hero・OGPのセレクタはメーカー・機種・接点動作を特定しない外観イメージ。本文図と役割を分け、端子番号や操作手順を描かない。
