## 用語・安全・図の条件
- 採用：過負荷、短絡、主回路、補助接点、電磁接触器、電磁開閉器、マニュアルモータスタータ（MMS）、保護協調。
- 「マグネット」の曖昧さは比較表で正式名の電磁接触器を使い、接触器＋サーマルの組合せを電磁開閉器と補足。
- サーマルは主回路電流を検出する。補助接点→接触器のコイルOFF→主接点開放。制御回路だけを保護する意味ではない。
- 図は役割模式図で、全設備に使える施工図ではない。電源→MMS→接触器→モーターの構成例として説明する。実端子番号・メーカー外観・配線細部は生成しない。
- 主回路遮断と安全停止完了を区別。惰性・残留エネルギー・予期しない再起動を考慮した設備の安全手順が必要。
- 原因不明の再投入、保護設定を上げて回避、通電したままの点検を勧めない。
