# ノイズフィルタ：公式資料の照合と掲載範囲
対象：既存日本語記事の本文・図。公式確認：2026-11-23 JST。実地での測定、保護装置の変更、配線手順は掲載しない。

- [オムロン S8V-NF 定格／性能](https://www.fa.omron.co.jp/products/family/3688/specification/) 「定格/性能」「減衰量周波数特性（代表例）」：形S8V-NFS203/206、単相AC250 V（50/60 Hz）またはDC250 V、定格電流3/6 A、機種・温度条件による電流制限と漏洩電流。代表減衰特性は入力と出力の両インピーダンス50 Ωという測定条件。実機の電源ライン、配線、負荷は同じとは限らず、同じ減衰を保証しない。50 Ωは配線抵抗・接地抵抗を指定する値ではなく、各周波数の試験条件を定義する。図に用いる数値は50 Ωのみ、測定回路・規格適用試験・取り付け詳細は掲載しない。
- [三菱電機「7. ノイズについて」](https://www.mitsubishielectric.co.jp/fa/learn/semi/school/inv/reference/inv1.pdf)：電源線伝導、誘導や空間からの影響、設置・配線条件を区別。旧資料内の機種ごとの距離や接地接続の詳細を実務手順にしない。
- [TDK 電源ライン用EMCフィルタFAQ](https://product.tdk.com/ja/contact/faq/emc-components-0129.html) と [TDK-Lambda EMC技術解説](https://product.tdk.com/system/files/dam/doc/product/emc/emc/power-line/general_tech_info/generaltec_power-line_ja.pdf) の伝導／放射・入出力の回り込み節：フィルタ周辺の線の近接でも回り込み得る。物理的な経路のイメージのみ採用し、接続図は転載しない。
- [オムロン「パワーサプライ 参考資料」](https://www.fa.omron.co.jp/guide/technicalguide/22/308/index.html)：入力・出力近接による誘導、ライン側およびリレーの影響候補。一般の入力用製品をインバータ出力へ使えるという根拠にしない。

現場知識候補：サイト方針第16節、FK16-008（B、V16-10 三菱旧型FAQ）および第13回R13-23（パラつき、来歴未確認）を照合。複数の回り込み候補を残す理由を補強するが、センサ値の特定原因・旧型式の施工条件・交換実績を採用しない。本文のコンベヤは現場経験と称さない例示で、同じ時刻・共通電源・影響範囲から読む順序を説明する。9/6に追加された既存の制御盤ノイズ対策ガイド導線はそのまま保持する。
