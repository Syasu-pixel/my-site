## 記事・四コマで使う範囲
- NPN出力はON時に出力を0V側へ引き込む考え方。
- PNP出力はON時に出力を+V側へ持ち上げる考え方。
- センサ出力方式とPLC入力COMの組み合わせをセットで確認すること。
- NPN / PNPとNO / NC、2線式 / 3線式は別の分類軸であること。
- 実機ではセンサ型式とPLC入力ユニットのマニュアル・回路図を優先すること。

## 断定しない範囲
- 「NPN = 必ずPLC入力OFF」「PNP = 必ずPLC入力ON」と定義しない。
- 「NPN = +COM、PNP = -COM」を全機種共通の固定表記として扱わない。
- シンク / ソースの呼び方をメーカー・機器の文脈を無視して一律に言い換えない。
- NO / NC、2線式 / 3線式、NPN / PNPを同じ意味として扱わない。
- 端子番号・配線色・入力回路を全製品共通として一般化しない。
- 実機の配線変更や短絡、強制入力を四コマだけで促さない。

## 画像ルール
- NPNは「ON時に0V側へ引き込む」、PNPは「ON時に+V側へ出す」概念を簡略化して示す。
- PLC入力COMとの組み合わせが必要であることを示すが、特定端子番号は固定しない。
- NO / NCや2線式 / 3線式と混同する図にしない。
- 実在メーカーの型式・ロゴ・UI・端子番号を完全再現しない。
- 電流経路を描く場合は、電源極性とセンサ・PLC入力の関係が物理的に矛盾しないようにする。
