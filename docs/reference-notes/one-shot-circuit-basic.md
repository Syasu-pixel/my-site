# ワンショット回路記事の技術参照メモ
確認日: 2026-11-13。対象は日本語の既存基礎記事。公開は管理者による最終Preview承認後。既存の基礎検索意図を維持し、内部信号と外部I/O、命令のメーカー差を整理する。

## 原典を開いて確認した一次資料
1. 三菱電機 FAQ14427「ワンショット回路」 https://fa-faq.mitsubishielectric.co.jp/faq/show/14427?site_domain=default
   質問は入力ONの最初・最後に一定時間出力する回路。回答はPLS/PLF利用。ワンショットという語を1スキャンだけに限定しない根拠。図そのものは転載しない。対象CPU確認なしの実装例は載せない。
2. オムロン FAQ01470 https://www.ia.omron.com/support/faq/answer/26/faq01470/index.html
   DIFUで内部ビット1スキャンON、次スキャンDIFDで別ビットONの説明。機器間ストローブには時間条件が必要。この記事では遅延回路は転載せず、内部1スキャン信号の基礎のみ採用。
3. オムロン FAQ01823 https://www.ia.omron.com/support/faq/answer/26/faq01823/
   CS/CJのUPとDIFUの違い。DIFUは作業ビット、UPは実行条件の扱い。微分信号と保持された後段を混同しない根拠。
4. オムロン PLC用語解説 https://www.fa.omron.co.jp/guide/technicalguide/26/129/index.html
   I/Oリフレッシュと内部メモリの違い。サイクルは処理内容を含み、変動し得る。短い入力を取得できない可能性。外部機器応答を内部波形だけから断定しない。
5. オムロン CP1E W483-E1-06命令リファレンス https://assets.omron.com/m/5192831b7c68f638/original/CP1E-CPU-Unit-Manual.pdf
   原典PDFを開き、PDFページ60/61のスクリーンショットも確認。印刷p2-25/2-26: DIFUは条件のOFF→ONでRをON、次サイクル同命令に到達するとOFF。条件付き/ジャンプ/サブルーチン実行の注意あり。PDF119–120: CNTRが入力立上りで増減。カウンタに微分を必須追加としない根拠。

## 未確認として採用しない資料
三菱入門PDF JY997D68101E はブラウズが会員ログインへリダイレクト。全文未読であり、取得済みと書かない。PLSの具体的な初回RUN挙動をこのPDFから断定しない。

## 主要修正
- 一瞬=固定ミリ秒ではなく、通常周期実行の内部1スキャンに範囲を限定。
- 立上り/立下り/タイマーで設定時間パルスを区別。
- Y0実出力の例を削除し、A→内部P概念図にする。既存ラダー画像がY0なら必ず置換。
- GXWorks3節内でPLS/ONS/DIFU同列に扱う誤解を除去。ONSは説明不要のため削除。
- カウンタへのワンショット必須という誤解を除去。
- 起動初回/条件実行は機種依存。記事は一般論から具体挙動を保証しない。
- チャタリング除去や取り逃し回復をワンショットに期待しない。

## 画像案
1. overview: 入力A 0,1,1,1,0,1 と内部P 0,1,0,0,0,1。横軸スキャン、二回の立上りに揃えたパルス。外部電圧グラフではない。
2. ladder: A→立上り検出→内部P→処理のきっかけ。汎用概念図、実機命令や安全回路ではない。Y端子/電磁弁/動く機械を描かない。
図は実機命令を示すラダーではなく、入力A→立ち上がり検出→内部Pの概念図とする。
