## 記事で使う範囲
- 代表3方式について、対向側の部品・光の戻り方・検出距離の両端を区別する。
- 鏡面ワークの戻り光、透明体で入光量の差が小さい場合、拡散反射型での表面・背景条件を別々に扱う。M.S.R.は鏡面対策の一例。距離設定形は背景対策の候補であり、背景・実物とも確認する。
- 受光、出力、PLC入力の順で切り分けるのは編集上の確認の流れ。メーカー固有のトラブルシュートや設置・調整手順の代替ではない。感度・ティーチングは光路と条件を確認した後、対象型式の説明に従う。
- 既存のメーカー資料追記案 #1480 のオムロン「概要」「参考資料」を現行ページで再確認して継承。確認日、記事内容の更新日、検証範囲は改稿時点で区別。

## 断定しない範囲
- 型式別の数値、透明の全材質への適合、ミラー種類や入射角の一律指定、LEDの色・意味、NPN/PNPの端子／電圧、応答時間・PLCの読込条件、感度変更での解決。
- 稼働部の近くでの作業、安全回路の無効化・代用、機器の交換中の通電を推奨しない。安全目的の選定は、用途・設備リスクと対象機器の公式条件に依存する。
