# 配管入線のコツ：技術参照メモ

- 対象：`articles/pipe-wiring-tips.html`
- 公式資料確認日：2026-11-22（JST）
- 範囲：通線具（呼び線）の先端が未到達なのか、先端は届いたが後から接続した電線束が通らないのかを分ける読み方。活線作業や設計・施工条件の代用ではない。
