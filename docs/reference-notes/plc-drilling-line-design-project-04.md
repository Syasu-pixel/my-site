## シリーズ内の前提

- 仮想ライン: CV01〜CV04 → CV05（加工ステーションコンベア）→ 排出シュート
- ワーク: MCナイロン W100×D60×H20 mm
- 加工: 上面中央へφ8・深さ15 mmの止まり穴
- PLC: MELSEC-F FX3U系を教材上の基準にする
- 第3回まででCV04到着までの搬送条件を整理済み
- 第4回ではCV05・横移載・位置決め・クランプ・穴あけ・復帰・排出までを整理し、完成ラダーや実機加工条件は扱わない

## 第4回で採用した機械構造

1. CV04からCV05へ縦搬送する。
2. CV05在荷確認で停止する。
3. ベルト間の横移載フリーローラーを上昇させ、ワークを縦ベルトから浮かせる。
4. コンベア反対側の搬入プッシャでワークを加工側へ押す。
5. 加工位置で位置決め・クランプして穴あけする。
6. 加工終了後、位置決め・クランプを解除する。
7. 加工側の戻しプッシャでワークをCV05へ押し戻す。
8. CV05在荷とプッシャ退避を確認してフリーローラーを下降する。
9. CV05を再始動し、終端のメカ式シュートへ搬送する。
10. 排出確認センサでライン外へ出たことを確認して1サイクル完了とする。

切りくずは加工位置直下の専用受けへ落とし、搬送コンベアへ落とさない構成とする。

## 第4回のI/O点数

- 加工部入力: 16点
- 加工部出力: 8点
- 既存搬送部との合計: 入力25点 / 出力21点
- 第2回のPLC構成: FX3U-80MT/DS + FX2N-16EX
- 設計容量: 入力56点 / 出力40点
- 現時点の余裕: 入力31点 / 出力19点

詳細な番地・信号名は `docs/plc-projects/drilling-line/master-spec.md` を正本とする。

## 設計上の注意

- X/Y番地は教材用の仮割付であり、実機機器選定後に最終確定する。
- エアシリンダの電磁弁方式がダブルソレノイドの場合は必要出力点数が増える。
- 主軸機種、加工速度、圧力、保持力等の実機加工条件は断定しない。
- 非常停止、ガード、危険源の除去等の安全機能は通常PLCシーケンスと分離し、実機では別途適切な安全設計・リスクアセスメントが必要。
