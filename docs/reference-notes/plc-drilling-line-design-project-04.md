## シリーズ内の前提

- 仮想ライン: CV01〜CV04 → 加工エリア → 排出
- ワーク: MCナイロン W100×D60×H20 mm
- 加工: 上面中央へφ8・深さ15 mmの止まり穴
- PLC: MELSEC-F FX3U系を教材上の基準にする
- 第3回まででCV04到着までの搬送条件を整理済み
- 第4回では加工部I/Oと通常シーケンスを整理し、完成ラダー・実機加工条件・復旧操作は扱わない

## 設計上の注意

- 本記事のX11〜X17、Y15〜Y20は仮想ラインを説明するための仮割付。
- 実機のCPU点数、増設I/O、電磁弁方式、主軸制御、加工条件を断定しない。
- 非常停止、ガード、危険源の除去等の安全機能は通常PLCシーケンスと分離し、実機では別途適切な安全設計・リスクアセスメントが必要。
- 第4回では安全回路の具体配線や実機調整手順は扱わない。


## 第4回で確定した加工ステーション構造（2026-09-19）

- CV04の受渡位置から、横移載テーブルでワークを搬送方向と直角に1ピッチ移動させる。
- 1ピッチ奥に専用加工治具・ドリルユニットを配置する。
- 加工はコンベア上では行わず、切りくずは加工位置直下の専用受けへ落とす。
- ワークはMCナイロンのまま扱い、金属ワークへ変更しない。
- 加工完了後、横移載テーブルでCV04側の元位置へ戻す。
- 横移載テーブルが原点端へ戻ったことを確認してからCV04搬送を再開する。
- 横移載中とCV04搬送は同時許可しない。

### 横移載を含む仮I/O

入力:
- X11: 横移載 原点端
- X12: 横移載 加工端
- X13: クランプ前進端
- X14: クランプ後退端
- X15: ドリル上昇端
- X16: ドリル下降端
- X17: 主軸運転確認
- X20: 加工位置ワーク

出力:
- Y15: 横移載 前進
- Y16: 横移載 復帰
- Y17: クランプ
- Y20: 主軸運転
- Y21: ドリル下降

補足:
- 横移載の前進/復帰を別出力としたのは教材上の仮置き。実機の電磁弁・アクチュエータ方式により1出力または2出力になり得る。
- X7は第3回でCV04から先への通過確認候補として残した信号。第4回ではCV04受渡境界の確認に接続して考える。
