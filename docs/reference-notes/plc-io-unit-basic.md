## 参照した公式元・確認対象資料

1. オムロン「プログラマブルコントローラ 用語解説」
   - https://www.fa.omron.co.jp/guide/technicalguide/26/129/index.html
   - 内部I/Oメモリと外部I/Oのリフレッシュ、I/O割付。内部状態と実端子が常に同時に切り替わるとの誤解を避ける。
2. オムロン「CJシリーズ 入力ユニット 定格／性能」
   - https://www.fa.omron.co.jp/products/family/2054/specification/
   - DC入力とAC入力、ON/OFF条件、COM単位、外部結線、デバイス変数との対応。全入力をDC24Vとしない。
3. オムロン「CJシリーズ 出力ユニット 定格／性能」
   - https://www.fa.omron.co.jp/products/family/2055/specification/
   - リレー／トライアック／トランジスタ、1点・COM・全体の許容電流、外部供給電源、漏れ電流、残留電圧、応答、突入電流。具体値は対象型式の資料で照合する。
4. 三菱電機FA eラーニング「入出力信号（I/O信号）」
   - https://www.mitsubishielectric.co.jp/fa/ssl/learn/el/eln/course/common/term_0002/0122.html
   - CPUと各ユニットの信号授受における入力リレーX・出力リレーY。点数等は製品資料へ委ね、特殊ユニットのX/Yをすべて物理端子と1対1とはしない。

## 記事で使う範囲

- 入力は現場からPLC、出力はPLCから外部回路という情報の方向。センサーの出力はPLC側の入力になる。
- 内蔵I/Oと増設ユニットの形態差。入力・内部処理・出力を役割で区別する。
- 入力表示、内部条件、出力指令／表示、実際の機器動作を別の確認事項として読む。
- 物理端子番号、線番、I/Oアドレスを混同せず図面とI/O割付を照合する。
- 接続可否は機器名だけで決めず、方式・電圧・許容電流・負荷特性を対象型式で確認する。

## 断定しない範囲・安全

- COMを必ず0Vと固定しない。共通端子のグループや接続方式を機種別結線図で確認する。
- X/Yは三菱電機の例で、全メーカー共通表記ではない。
- I/O更新方式・タイミング、入力電圧、出力電流、LEDの意味を全PLCの共通仕様にしない。
- PLC出力がモータ等へ必要な電力を自由に供給するとはしない。接触器・ドライブ機器等の介在と制御側の適合も必要。
- LED点灯だけで配線・負荷電源・接続先・実動作が正常と断定しない。
- 活線測定、配線変更、強制出力、安全機能解除を初心者向けの確認方法として勧めない。実設備は担当者・現場の停止／遮断等の安全手順を優先。

## 画像ルール・使用表記

- 正本キャラクターとちびキャラ補助、採用Hero v2を参照し、記事内の先輩・後輩を統一。
- Hero／OGPは一般的な現場入力機器→PLC→適合する表示灯・リレーの情報の流れ。メーカー名・型式・実在UIは再現しない。
- 本文overviewはPLCの括り内に入力ユニット・内部処理・出力ユニットを入れる。「矢印は情報の流れです。配線図ではありません。」を明示。
- observationは「入力の状態」「内部の条件」「機器の動作」を分ける。左のLEDは入力表示の概念例であり、機種固有の電源／RUN表示や正常判定を示さない。本文にもその限定を付ける。
- 使用可：PLC、I/O、入力、出力、入力ユニット、出力ユニット、PLC内部処理、LED、情報の流れ。
- 使用不可：汎用COM=0V、汎用X/Y固定、実配線を示す端子番号、根拠のない定格、LED点灯＝すべて正常。
