## 追記図：内部リレーMの読み書き

ラダー中央の補助図は「通常の順次処理」「更新済みのX0がON」「M0を別の場所から書き換えない」という学習条件。上段のX0（a接点）で内部M0を書き、同じスキャンの次段で同一M0（a接点）を参照して内部M1を更新。物理出力端子の出力更新、割込み、複数タスク、強制操作、現場配線を示さない。FX5応用編 §1.1 のプログラム演算とI/O更新の区切り、FX5U-32MT/ES公式仕様のデバイス分類を再確認した。図中文字・接点配置は記事専用の原案で、キャラ小カットは承認済み四コマ用正本の一部を使用。
