## 独立図解と境界

- タイマ図: X条件と可視の現在値、T0接点を別列で読む。設定時間の通過点を、値と接点が反映されるコイル命令の実行点より前に配置。
- カウンタ図: 数える条件の三つの立上がり、途中のOFF、計数値の保持、RSTでの0・OFFを分ける。
- ラダー図: 説明用の左右母線間の五段。X0→T0、T0接点→内部M20、X1→C0、C0接点→内部M21、X2→RST C0。外部出力・設備動作・安全回路は含まない。実機への書込み手順や新規の銘柄推奨を意図しない。
