## 現場知識と図

- サイト方針第16節候補21「サイレンサ目詰まりと動作遅れ」の原典は [SMCワンポイントアドバイス](https://www.smcworld.com/support/advice/get.do?id=43)。目詰まりとバルブ応答遅れは別々の候補として採用。原典の取り外して動かす確認は、安全上の前提が省略された抜粋であるため本文に載せない。
- 「戻りだけ時間がかかる」は観測項目を説明する条件例であり、現場で発生した事例・原因を確定するものではない。
- 図1は一般的な複動シリンダの一方向を論理経路に限って図化。ポート番号・接続・切替のタイミングを省略。図2は多孔質材料の役割を伝える概念画で、内部形状、実測流量、圧力、汚れの色による判定は示さない。Hero/OGPの展示品は一般的な金属製外観、本文で比較する樹脂製AN型式の製品写真ではない。
