- 電力と情報の役割から定義。色・太さ・電圧のみで区別しない。
- DC24Vでも電源/入力/出力負荷を区別。4–20mAを微小電圧信号と同一視しない。
- 交差角度だけで適合としない。離隔寸法やシールド処理を一律化しない。
- 通電状態での接触・端子変更を勧めない。非常停止と電源隔離を区別し、残留電圧に注意。
- 保護接地解除・安全機能迂回を対策にしない。
