## 根拠の範囲と採否

- 入口・レギュレータ直後・負荷付近の枝取りは測定点を説明する概念図。実機の配管図や測定点増設手順ではない。
- 待機 0.50／動作中 0.32／動作後 0.50 MPa は同一測定点の読み方を説明する編集例で、実測やメーカー指定値ではない。確かめるのは同じ動作の時点。供給低下・漏れ・詰まり・計器不良を単一表示から断定しない。
- 0.50 MPa = 500 kPa = 5.0 bar は単位の定義から換算。図面と計器で単位を確認してから換算する。
- 0表示は他の区画も含めた残圧ゼロや機械安全を証明しない。計器を叩く・継手を緩める・圧を上げる・再始動する操作は案内しない。
