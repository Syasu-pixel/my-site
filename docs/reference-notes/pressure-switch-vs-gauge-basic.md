# 圧力スイッチと圧力計の比較：公式資料・適用範囲
- 対象：`articles/pressure-switch-vs-gauge-basic.html`（日本語）
- 最終内容更新・公式資料確認：2026-11-23 JST

## 採用の根拠
1. [SMC デジタル圧力スイッチ ZSE20A(F)/ISE20A 取扱説明書](https://www.smcworld.com/assets/manual/ja-jp/files/ZISE20A.jpn.pdf) の「圧力の設定」「ファンクション選択モード」。測定表示と設定表示、正転出力で設定値を超えるとON・応差分低下でOFFになる説明図、ウィンドウコンパレータ／出力反転／遅延の別条件。正転ヒステリシスの図だけを根拠とし、設定操作・調整は案内しない。
2. [SMC ISE20A 詳細取扱説明書 PSxx-OMU0002](https://www.smcworld.com/upfiles/manual/ja-jp/files/PSxx-OMU0002.pdf) の「型式表示」「出力仕様」：X／Yはスイッチ2出力、R／Tはスイッチ2出力に電圧、S／Vはスイッチ2出力に電流、アナログ機能の切換注記。機種例としてのみ扱い、他型式への転用・端子番号の断定・結線はしない。
3. [SMC 一般用圧力計 Gシリーズ](https://www.smcworld.com/webcatalog/ja-jp/silencers-exhaust-cleaners-blow-guns-pressure-gauges/pressure-gauges/G_)：指示値を読む計器の製品例。全圧力計が無出力とは断定しない。特定品のレンジ、流体、接続は個別確認。
4. [SMC 空圧機器 取扱説明書「安全上のご注意」](https://www.smcworld.com/assets/manual/ja-jp/files/AS-J.pdf)：機器取り外し前の供給・電源遮断とシステムの排気、飛び出し等の防止。OUT OFFや0表示を残圧・設備安全の証拠としない。

## 図と記事の範囲
- 「圧力計の表示」「スイッチの現在圧」「機器のOUT表示」「対応PLC入力記録」は観測層の区別。OUT表示を信号到達と同一視せず、時刻差・出力番号・入力番号の対応だけを先に確認。どの要因か確定しない。
- 0.50 MPa（上側）と0.40 MPa（戻り側）の帯、0.45 MPa（観測値）、0.55 MPa（すでにONした経緯）は説明用の仮定。仕様・初期設定・推奨設定ではない。境界の等号、反転・範囲窓・遅延設定の動作は一般化しない。
- 0.50 MPa入口／0.36 MPa分岐の例は異なる測定点を比べて機器誤差としないための概念例。実測・規定ではない。配管図、結線図、ライブ設備の設定・保護解除・PLC強制入力・測定を行う手順は掲載しない。

## 初心者向けプレビュー改訂の確認
- 同じISE20A資料の詳細版（PS※※-OMU0002-H）で、印刷12～13ページに現在圧／動作表示灯、応差とアナログ出力の定義、24～25ページに出力記号、27ページに正転時の設定値と応差の関係を確認。別系列ISE20Cの情報は使わない。
- 旧本文の出力記号を削ったのは誤りが理由ではなく、この比較を理解するのに不要なため。製品選定では実際の型式と公式資料の「出力仕様」を見るよう案内する。
- 二つの履歴の出発点を 0.35／0.55 MPa と図に表示。どちらも 0.45 MPa に到達するが、前者は0.50 MPaを超えておらずOFF、後者は既にONし0.40 MPaまで低下していないのでONを維持する。作図例の圧力を推奨値・工場設定と混同しない。
