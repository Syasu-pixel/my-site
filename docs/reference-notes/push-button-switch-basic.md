- 呼称：「入力が来ている」は現場での一義的な標準語と断定しない。会話の疑問として使い、対象アドレスと信号の意味へ戻す。

## 画像ルール・編集者への指定
- メーカーロゴ、製品の実在型式、端子番号、実在PLC画面を生成しない。概念図のみ。
- 接点図は「モーメンタリの例」を明記。NO/NCの無操作・押下・復帰で開閉が正しいこと。
- 動作方式図はa接点の例に限定し、操作部の位置と接点保持を混同させない。機械が運転を続ける/止まる絵をボタン単体の必然として示さない。

- 使用可：押す前／押している間／離した後、開／閉、接点、表示灯、PLC入力、a接点（NO）、b接点（NC）、モーメンタリ、オルタネイト。
- 使用不可：押せば安全、b接点なら安全、点灯＝入力ON、全製品共通の端子番号、架空の規格適合。
