## 編集判断

- ソケットは配線端子を取り出す部品であり、コイルが接点側に給電するわけではないことを明確化。COMは接点一組の共通端子で、システム共通線やコイルのマイナスと同義ではない。
- 既存の概念図 `relay-socket-basic-wiring-flow.png` は、負荷例にモーターがあり安全を一律に述べていたため、本文では端子表示のリストと視点比較に置き換えた。画像データ自体は削除していない。Hero・専用OGP・概要／比較図は維持。
- 作業前はコイルと接点側それぞれの対象電源、再投入防止、無電圧確認を設備の手順と作業権限に従って扱う。通電状態での測定手順は追加しない。
- 最新検索実績は公開文書に数値を載せない。定義と端子表示・型式照合を読み手が見つけやすい構成に変更。現場の個人例・台帳の二次情報は、既存の説明と重複し得るため本文追加なし。
