## 記事で使う範囲
- センサを一種類の機器として一般化せず、検出対象・検出原理・信号方式・接続先の違いを整理する。
- 近接、光電、リミット、磁気・リード、圧力・流量・温度、エンコーダ等を、用途と信号の入口として説明する。
- ON/OFF、アナログ、パルス、通信を別の信号方式として整理する。
- NPN/PNP、NO/NC、2線式/3線式をそれぞれ別軸の分類として扱う。
- 実機では検出距離、電源、出力、環境、接続先仕様を対象型式の公式資料で確認する。

## 断定しない範囲
- 「センサ＝PLCのON/OFF入力」と限定しない。
- 「近接センサ＝金属だけ」など、方式差を無視した一般化をしない。
- 検出距離、応答速度、精度、配線方式、出力方式を全製品共通として断定しない。
- 一般用センサを安全用途にそのまま使えると表現しない。
- NPN/PNP、NO/NC、2線式/3線式を同じ分類軸として扱わない。

## 画像ルール
- 実在UIを完全再現しない。
- メーカーロゴを入れない。
