## 記事・四コマで使う範囲
- サーボ系は、サーボアンプとサーボモータを組み合わせて制御すること。
- 位置・速度などの指令を受けてモータを駆動すること。
- エンコーダ等の検出情報をフィードバックして制御に利用すること。
- 高精度な位置決め用途で使われること。
- PLC / モーション側からの指令、サーボアンプ、サーボモータ、エンコーダの関係を概念図として示すこと。

## 断定しない範囲
- すべてのサーボシステムで信号名称・配線・構成が同一とは扱わない。
- サーボON、原点復帰完了、位置決め完了、アラームの名称・論理・配線を全機種共通仕様として一般化しない。
- エンコーダ方式、分解能、通信方式、制御周期、位置決め精度を一律に断定しない。
- PLCからサーボモータへ直接駆動電流を出すような構成には描かない。
- 具体的なパラメータ変更・調整値・試運転手順を四コマだけで完結させない。

## 画像ルール
- 基本構成は「PLC / モーション → サーボアンプ → サーボモータ」とする。
- エンコーダのフィードバックはサーボアンプへ戻る関係を明確にする。
- 実在メーカーの型式・ロゴ・UI・端子番号を完全再現しない。
- 位置決め用途は「同じ位置へ繰り返し止める」ことが伝わる簡略図で表現する。
- 位置・速度・回転量などの概念説明を優先し、数値精度を勝手に入れない。

## メモ
- 実機の配線、信号名称、パラメータ、アラーム処置は対象型式の最新マニュアルを優先する。
