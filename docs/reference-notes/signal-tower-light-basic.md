## 設備依存の条件と編集判断

- ブザー停止=音だけ止める設計なら、原因解消とは別。すべての機種にブザー停止ボタンがあるとは書かない。
- 点滅の意味・同時点灯・表示優先順位は設備仕様次第。点滅=必ず警報、赤=必ず非常停止、緑=必ず安全としない。
- 制御側出力指示と実際の光・音は別の観察対象。出力強制・端子短絡・活線測定は案内しない。
- 状態を知らせる機能と安全を成立させる機能は区別する。安全機器認証の有無を外観だけで推測しない。
- 用語は積層信号灯/タワーライト/積層表示灯で統一。特定企業名を製品全体の一般名称と断定しない。
