## 編集上の判断

- 旧本文から、手動操作部の役割、試運転・保全で担当者が使う理由、ノンロック式・ロック式、PLCと空圧を区分する考え方、可動部・治具・ワーク・自動復帰の注意、既存リンクを保持した。
- 「手動で動いたら空圧側は健全」「非常停止で可動部は安全」「押し方を試せる」等の解釈を避ける。既存の許可済み記録という架空例で、電気指令・コイル・弁位置・機械動作の観測層を分け、時刻や圧力・負荷が異なれば動作の比較だけで故障箇所を決めない。
- 一般的な現場体験を実測・実体験として掲載しない。関連した現場資料があっても個別設備の操作手順、機種横断で使える圧力値、解除方法は転載しない。
