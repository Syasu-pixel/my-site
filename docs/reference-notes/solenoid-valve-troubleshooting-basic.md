## 記事で使う範囲
- 電磁弁を、制御信号を受けて空気の流れを切り替える機器として説明する。
- 故障原因を「制御・電源/コイル側」「空圧側」「負荷側」に分けて整理する。
- 型式ごとにポート構成、コイル仕様、使用条件、配線・表示仕様等が異なるため、対象型式の公式資料を優先する。
- 安全上の注意は、メーカー資料と設備側の安全手順を優先する。

## 断定しない範囲
- 型式未指定の端子番号、配線方法、定格電圧、使用圧力、流量特性。
- 「この症状なら必ずこの部品が故障」といった単一原因の断定。
- 通電中測定、手動操作、空圧条件変更など、設備を動かす可能性がある具体操作手順。
- SMC以外のメーカー製品へSYシリーズ固有仕様を一般化すること。

## 画像ルール
- 実在メーカーUI、ロゴ、型式銘板、製品ラベルを再現しない。
- 型式固有の端子番号・定格値・配線を想像で描かない。
- 「電気側 / 空圧側 / 負荷側」の概念図として描く。
- 手動操作や通電測定を促す描写は主題にしない。
- スマホで読める短いラベルと大きな図を優先する。
