- [SMC スピードコントローラ取扱説明書一覧](https://www.smcworld.com/manuals/ja-jp/category/flow-control-equipment/speed-controllers)
- [SMC AS-FS*A 取扱説明書 AS*-OMZ0097-B](https://www.smcworld.com/assets/manual/ja-jp/files/ASx-OMZ0097.pdf): p5 調整方向、全閉から徐々に開く初期調整、取付方向、停止弁に使わないこと。p10 取り外し前の落下・暴走防止、空気・電源遮断、残圧排気、再起動時飛出し防止。p11 速度調整不良の確認事項。時計回り等は当該型式の例と明記し、一般設備の操作手順にしない。
- [ニッタ スピコン・バルブFAQ](https://www.nitta.co.jp/product/moore/faq/spicon_valve/): メータインはシリンダ給気、メータアウトは排気の流量を制御。一方向制御と両方向絞りの区別、取付位置での働き方を確認。
- [SMC MWP取扱説明書](https://www.smcworld.com/upfiles/manual/ja-jp/files/MWP.pdf): p16 基本回路、p18 不安定な作動と残留圧変化による長時間停止後の急動作。製品固有の症状例であり、全シリンダの万能診断として扱わない。

## 採用した説明

流量調整と圧力調整を区別するが、圧力・背圧・負荷も速度へ影響する。絞り弁と逆止弁による一方向流量制御。自由流れは圧力損失ゼロの意味ではない。一般的な複動片ロッドシリンダの両ポートをメータアウトにした場合、前進はロッド側、後退はヘッド側の排気絞りが関係する。特殊回路へ一般化しない。エネルギー遮断・残圧・落下・再加圧の安全は設備手順と担当者を優先する。

## 現場知識候補の採否

- F-036 / PB-017: 空気源・レギュレータ・弁・配管・負荷の分類は既存本文と重複し、公式資料に沿う一般的な切り分け観点のみ維持。個人ブログの割合・体験を実証事実として採用しない（B）。
- FK13-018: メータアウトで全不具合が解決するという一般化は除外。保護機能の迂回や危険な診断操作を推奨しない。
- R18-07 / FK18-008: 個人のロッド部漏れと交換改善の自己申告から内部原因を断定できず（B）、同一著者の記事を独立証拠に数えない。ホース取外し・手動操作等は手順に採用しない。原典 https://syouraibochibochi.com/eashirinnda-sokudogacyouseidekinai-naze/ は候補の所在記録であり、今回本文の技術根拠には用いていない。
