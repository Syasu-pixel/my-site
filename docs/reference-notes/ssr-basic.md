# SSR（ソリッドステートリレー）公式参照メモ

確認日：2026-11-22。対象：既存日本語 `articles/ssr-basic.html`。

| 一次資料 | 確認した事項 | 適用・限界 |
| --- | --- | --- |
| [オムロン：SSR用語解説](https://www.fa.omron.co.jp/guide/technicalguide/18/78/index.html) | 入力定格・動作・復帰と出力側の区別。ゼロクロス付きは負荷電圧ゼロ付近から導通。 | 型式により動作方式が違う。ONの電圧とトライアック出力のOFFにかかわる電流を分け、誘導性負荷で一致と断定しない。 |
| [オムロン：SSR共通の注意事項](https://www.fa.omron.co.jp/product/cautions/18/76/index.html) | 入力側（駆動用半導体出力）で生じる漏れと、SSR出力側の漏れが別。突入、発熱、短絡故障で負荷を遮断できない可能性。 | 安全停止はSSR単体に依存させない。負荷側OFF判断を入力表示に依存せず、安全機器・保守の具体的な選定は当該設備の設計・安全手順を優先。 |
| [オムロン：G3NAシリーズ公式データシート](https://www.ia.omron.com/data_pdf/cat/g3na_j166-e1_2_9_csm1057968.pdf) | P.4 Output、Engineering Data。G3NA-210B-UTUはAC負荷用、G3NA-D210B-UTUはDC負荷用。 | 製品例で、他機種や実際の盤への流用不可。入力側仕様は電圧表記まで含めた型式を照合。端子、結線、電源を入れた状態での点検は説明対象外。 |
| [オムロン：G3NA-D210B-UTU AC100-240 個別仕様書](https://www.fa.omron.co.jp/product/item/G3NA-D210B-UTU_AC100-240/ja/pdf/) | 定格表でAC100〜240V入力・DC負荷、40℃で負荷電流0.1〜10A（指定放熱条件）・0.1〜4A（放熱器なし）を確認。 | この発注型式のみ。DC5-24入力型式などに数値を流用しない。 |
