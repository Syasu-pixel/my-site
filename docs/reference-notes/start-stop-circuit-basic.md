## 記事で使う範囲
- 自己保持は、補助a接点等で操作コイルのON状態を維持し、OFF操作などで解除する基本回路として説明する。
- 一般的な起動・停止のハード回路では、停止ボタンにb接点（NC）、起動ボタンにa接点（NO）を使う基本構成を説明する。
- PLC例では、物理接点のNC/NOとラダー上の接点命令を同一視しない。停止ボタンをNC配線し、通常時にPLC入力がONになる一例では、その入力のa接点命令を「停止許可」として使えることを、前提を明記した概念例として説明する。
- 通常の起動・停止回路と、非常停止・ガード監視等の安全機能は役割を分ける。

## 断定しない範囲
- すべての設備で停止入力が同じ極性・同じデバイス番号になるとは断定しない。
- PLCメーカーや機種ごとの命令表記、入力回路、保持デバイス、停電保持設定は共通仕様として断定しない。
- 通常のNC停止ボタンだけで安全要求を満たすとは断定しない。
- 非常停止、安全リレー、再起動防止、リスク低減方策の具体設計はこの記事だけで完結させない。
- 実機の配線・復帰条件・安全要求は、対象設備の回路図、仕様、使用機器の公式資料を優先する。
