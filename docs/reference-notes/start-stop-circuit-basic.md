## 記事で使う範囲
- 自己保持は、補助a接点等で操作コイルのON状態を維持し、OFF操作などで解除する基本回路として説明する。
- 一般的な起動・停止のハード回路では、停止ボタンにb接点（NC）、起動ボタンにa接点（NO）を使う基本構成を説明する。
- PLC例では、物理接点のNC/NOとラダー上の接点命令を同一視しない。簡略ラダーは M0=運転準備（運転許可）、X1=起動、Y0=運転出力とし、Y0のa接点でX1だけをバイパスする自己保持例として説明する。M0は直列条件として残し、M0がOFFなら自己保持中でもY0がOFFする構成を採用する。
- 通常の起動・停止回路と、非常停止・ガード監視等の安全機能は役割を分ける。

## 断定しない範囲
- すべての設備で停止入力が同じ極性・同じデバイス番号になるとは断定しない。
- PLCメーカーや機種ごとの命令表記、入力回路、保持デバイス、停電保持設定は共通仕様として断定しない。
- 通常のNC停止ボタンだけで安全要求を満たすとは断定しない。
- 非常停止、安全リレー、再起動防止、リスク低減方策の具体設計はこの記事だけで完結させない。
- 実機の配線・復帰条件・安全要求は、対象設備の回路図、仕様、使用機器の公式資料を優先する。

## 公式用語・採用表記

| 種別 | 日本語表記 | 英語表記 | 参照元 | 記事・画像での採用方針 |
|---|---|---|---|---|
| 物理接点 | a接点（NO） | NO / Normally Open | IDEC | 起動ボタン等の物理接点を説明するときに使用 |
| 物理接点 | b接点（NC） | NC / Normally Closed | IDEC | 停止ボタン等の物理接点を説明するときに使用 |
| 回路 | 自己保持 | self-holding | 三菱電機FA | 補助a接点等でON状態を維持する基本概念として使用 |
| PLC例 | 運転準備（運転許可）M0 | run permissive / ready | 一般化した記事表現 | 自己保持の外側に残る直列条件として使用 |
| PLC例 | 起動 X1 | start input | 一般化した記事表現 | M0成立中にY0をONする起動条件として使用 |
| PLC例 | 運転出力 Y0 | run output | 一般化した記事表現 | 自己保持用のY0 a接点と対で使用 |
