# タイマーリレー記事のメーカー資料と編集判断

- [オムロン H3CR-A8-301 型式別資料](https://www.fa.omron.co.jp/product/item/H3CR-A8-301_AC100-240_DC100-125/ja/pdf/)の動作チャート：Aのオンディレー、Eのインターバル。いずれも電源スタートの型式。設定時間より長い電源ONの単純例に限って、限時NOの開閉を自主作図。電源再投入、瞬時動作、設定時間より短い給電は図に含めない。
- [オムロン H3CR-H8L AC100-120 S 型式別資料](https://www.fa.omron.co.jp/product/item/H3CR-H8L_AC100-120_S/ja/pdf/)の動作チャート：リセット入力なしの電源オフディレー例。S/Mで最小電源投入時間が異なるため、本文では規定以上とのみ記載。限時NO接点を描くが、負荷電源の状態は示さない。
- [オムロン H3CR-A-301 型式別資料](https://www.fa.omron.co.jp/product/item/H3CR-A-301_AC24-48_DC12-48/ja/pdf/)のDモード：電源が維持されている状態から別のスタート信号を落とす。H3CR-A8-301のA/E、H3CR-H8Lの電源断型とは起点と仕様が異なる。
- [タイマの技術解説](https://www.fa.omron.co.jp/guide/technicalguide/19/89/index.html)。端子番号、機種間の互換や負荷、電源電圧、時間レンジは例示図から一般化しない。通電作業、安全保護系の変更や回避は扱わない。
- 一次資料確認：2026-11-21。Hero/OGPは特定型式を再現しない概念イラスト、波形は一次資料の条件から独立に作図。
