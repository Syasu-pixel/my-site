# 真空発生器（エジェクタ）の公式参照メモ

- 対象：日本語既存記事、確認日：2026年11月22日（JST）。SMCの型式例は全製品への一般化をしない。
- [SMC 真空エジェクタ ZHシリーズ](https://www.smcworld.com/catalog/ja/vacuum/ZH_DSA/7-7-2-p0745-0768-ZH/data/7-7-2-p0745-0768-ZH.pdf)：p.745–746、p.754、p.755–757。直接配管形とサイレンサ内蔵形、供給 P/SUP.・真空 V/VAC.・排気 E/EXH. を照合。直接配管形 ZH05DSA／ZH05DLA の到達真空圧力−90／−48 kPa（供給圧力0.45 MPaでの値）、最大吸込流量6／13 L/min（ANR）。p.754「流量特性の見方」では、吸込流量ほぼゼロ側と最大側で真空圧力が異なること、漏れのある実使用は型式別流量特性で読むことを確認。数値は設定値でも同時に得られる性能でもない。
- [SMC 真空用機器 技術資料](https://ca01.smcworld.com/catalog/BEST-technical-data/pdf/Vacuum-Common.pdf)「真空用機器のトラブルシューティング」：吸着面・通気性による漏れ、真空回路の内容積、供給時の圧力、圧力降下、従来は吸着したか等を候補として使う。調整や機器取り外しを含む実機手順は転載・要約で指示しない。
- [SMC 真空機器の技術用語](https://www.smcworld.com/support/glossary/ja-jp/vacuum_device/)：「真空圧力」「（最大）吸込流量」「吸着確認」等。圧力スイッチの観測点と機械的な保持・安全状態の保証を分ける。定量的な保持力・専用制御や設定値は対象外。
- [SMC ZKJシリーズ 製品個別注意事項](https://ca01.smcworld.com/catalog/New-products/mpv/s100-140-ZKJ/data/s100-140-ZKJ.pdf)：別途の落下防止及び保守点検時の残圧開放への注意。機器固有回路を真似せず、ワークを支持/安全に置く、遮断・残圧/残留真空の確認を設備手順と管理者に委ねる。

## 現場知識・画像の採否

- 方針と既存の真空スイッチ参照メモを照合。登録された未検証の経験談や一律の規定値を採用せず、公式の症状別切り分けから説明例を構成。段ボール例は通気性および密着による漏れを考える例で、実際の製品や事故の再現ではない。仕様値はモデルを明示して限定使用。
- 画像に「供給口 P」「真空口 V」「排気口 E」。真空を作っているときの二流が排気へ合流する概念図とし、実配管図・組立・作業順を示さない。別体で展示したHero/OGP部品は実在品の形状保証や選定対象ではない。
- パッド比較は同じ支持台上のワークに縁のすき間ができる例。右では外気が縁側から入り得る。左の絵はすき間がない一例であり、別箇所の漏れ無しや保持可否を保証しない。


## 圧力表示・スイッチ出力・PLC入力の切り分け

- [SMC ZSE20/ZSE20F/ISE20取扱説明書 PSxx-OMS0006](https://www.smcworld.com/assets/manual/ja-jp/files/PSxx-OMS0006.pdf)（2026年11月22日確認）。真空圧仕様ZSE20の例で、NPN／PNPオープンコレクタの型式違いと、ヒステリシス、ウインドコンパレータ、エラー出力、出力オフによる動作の違いを確認。他の型式のロジックや設定値に一般化しない。
- 圧力表示・指定出力の表示・PLCの該当入力の違いは、同じ時点の既存表示／保存記録と、承認済みの設定記録・図面および両機器の仕様で照合。表示だけで電気的な原因・保持成功を断定せず、通電中の測定や接続、設定の変更は扱わない。

- 追加図は同じ時点の表示・記録を並べる2例。スイッチの「表示ON」は実端子を測った状態ではなく、PLC入力の「OFF」は該当アドレスの表示例。原因を特定する配線・信号経路、作業の指示、安全保持や許可条件の図ではない。
