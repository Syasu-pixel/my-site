# 真空スイッチの技術参照メモ

- 対象：`articles/vacuum-switch-basic.html`
- 公式資料確認日：2026-11-20（JST）
- SMC：[ZSE20(F)/ISE20シリーズ 取扱説明書（No. PS※※-OMS0006-J）](https://www.smcworld.com/upfiles/manual/ja-jp/files/PSxx-OMS0006.pdf)。p.25の圧力設定と型式別既定値、p.33–35のOUT1出力設定・モードの一覧、仕様表を確認。ZSE20（真空圧）の定格圧力範囲は0.0～−101.0 kPa。連成圧ZSE20Fと正圧ISE20へは範囲を一般化しない。OUT1の「設定値」「応差」「出力モード」「正転／反転」は資料の用語に沿う一方、図は真空が強くなってONとなる向きを仮定した独自の教育例であり、特定型式の既定動作や推奨設定を示さない。
- SMC：[WEBカタログ ZSE20□(F)/ISE20□](https://www.smcworld.com/webcatalog/ja-jp/seriesList/?id=ZSE20%28F%29-ISE20)。型式群の真空圧・正圧・連成圧の区別、個別型式を確認する入口に使用。
- 図：−60 kPaでON、−50 kPaでOFFと定義した例で、応差の絶対値は10 kPa。測定点・符号・モード・遅れ・吸着力を別に説明。真空が成立しない場合、OUT1のみ期待と違う場合、PLC入力のみ来ない場合を切り分ける。実機の設定変更、配線操作、活線測定、保持力保証は示さない。
- 既存記事との境界：併設の真空発生器（エジェクタ）の記事は負圧を作る側。本記事は負圧を検出し信号として追う側。相互の技術説明を重複させず、リンクのみ。
