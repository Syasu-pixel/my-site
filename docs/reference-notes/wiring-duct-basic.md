旧図にあった一律の収容率目安は扱わず、外径・本数、分岐の曲げ、点検空間、増設・発熱条件を区別する。現場知識の索引には製品固有の判断を裏付ける直接該当資料を見つけられず、経験談は追加していない。図の機器・配線・色は位置関係の概念表現で、特定型式の施工例ではない。
