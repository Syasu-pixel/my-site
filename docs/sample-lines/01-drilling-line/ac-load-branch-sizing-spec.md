# 01 Drilling Line — AC負荷一覧 / 主幹・分岐一次検討

Status: Draft / 教材用一次設計

## 1. 目的

E03の主回路構成をもとに、AC200V側の負荷を一覧化し、Q0～Q6の主幹・分岐保護を最終選定する前に必要な条件を整理する。

本資料は教材用の概念設計であり、実機の遮断器定格、電線サイズ、短絡容量、漏電保護、保護協調、接地、端子締付等を確定するものではない。実機では正式採用機器の最新マニュアル、受電条件、規格要求に基づき有資格者が最終設計する。

## 3. FR-E820-0.2K-1で確定していること

三菱電機の現行公式仕様を基準として、CV01～CV04は `FR-E820-0.2K-1` を候補とする。

確認済みの設計前提：

- FREQROL-E800シリーズ
- 3相200Vクラス
- 0.2kW級
- 電源：3相200～240V、50/60Hz級
- 定格出力電流：0.8A級

ただし、Q1～Q4の遮断器定格は0.8Aという出力電流から直接決めない。

入力側保護は、

- 正式な入力電流
- 電源インピーダンス
- メーカー推奨保護機器
- 漏れ電流
- 突入
- 配線条件
- 上位保護との協調

を確認して決める。

## 4. INV05 / M05で確定したこと

主軸は `spindle-drive-spec.md` を基準とし、初級教材では次を標準構成とする。

- INV05：FR-E820-0.4K-1候補
- M05：三相200V 0.4kW級モータ
- 初期運転：固定速度
- PLC指令：Y30
- 運転確認：X66
- 異常：X67

FR-E820-0.4K-1は0.4kW級で、定格出力電流1.4A級を基準値として扱う。

ただしQ5の分岐保護を1.4Aから直接決めない。Q1～Q4と同様、入力側推奨保護条件、漏れ電流、突入、配線条件、上位Q0との協調を確認して決める。

正式モータ形名、工具保持方式、回転数、送り速度は未確定とする。

## 5. PS01で確定していること

PS01候補 `S8VK-G24024` の公式仕様：

- 出力：DC24V / 10A / 240W
- 入力：AC100～240V、単相
- AC200V時入力電流：1.5A typ.
- AC200V時効率：91% typ.
- AC200V時突入電流：32A typ.（25℃コールドスタート）

したがってQ6は定常電流だけではなく、突入電流も考慮して選定する。

また、設備全体の受電を3相AC200V級としていても、PS01自体は単相入力機器であるため、制御電源分岐は三相モータ系負荷とは別の性格を持つ。実機では相間負荷バランスと上位電源条件を含めて最終設計する。

## 6. 現時点の負荷評価

### 6.1 CV01～CV04

4台とも0.2kW級であり、設備全体の主回路負荷としては比較的小さい。

ただしインバータは単純な抵抗負荷ではないため、モータ容量の単純合算だけで主幹を決めない。

### 6.2 主軸M05

主軸方式は、

`FR-E820-0.4K-1候補 → 三相200V 0.4kW級M05`

に一本化した。

これによりQ5は「駆動方式未確定」ではなく、「保護定格未確定」の段階へ進んだ。

残る確認項目：

- INV05正式入力電流
- メーカー推奨入力側保護
- M05正式形名
- 加減速条件
- 制動条件
- 工具保持方式

### 6.3 PS01

PS01は制御系としては負荷が大きくないが、コールドスタート時の突入があるため、Q6選定では瞬時動作特性を含めてメーカー資料を確認する。

## 8. 主幹Q0の考え方

Q0は次の順で決める。

1. Q1～Q6対象機器の正式入力条件を確定
2. 同時運転条件を整理
3. 将来負荷Q7 / PS02の扱いを決める
4. 上位受電条件・短絡条件を確認
5. 配線サイズ・敷設条件を確認
6. 分岐との保護協調を確認
7. 盤内発熱を再評価

単純に分岐定格の合計値をQ0へ採用しない。

## 9. 盤クーラー判定への反映

初期構成の主要発熱源は、

- INV01～INV04：0.2kW級 ×4
- INV05：0.4kW級 ×1
- PS01
- PLC / I/O

となる。

INV05をCP01内へ追加したため、旧評価より盤内発熱は増える。一方、CP01はW800×H1200×D350 mm級で余裕を持たせているため、現時点では引き続き「盤クーラー初期なし + 後付け余地確保」を基準とする。

正式損失値と周囲条件が確定した時点で `control-panel-thermal-spec.md` を再評価する。
