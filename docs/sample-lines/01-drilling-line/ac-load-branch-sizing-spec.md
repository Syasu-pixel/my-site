## 1. 目的

E03の主回路構成をもとに、AC200V側の負荷を一覧化し、Q0～Q6の主幹・分岐保護を最終選定する前に必要な条件を整理する。

本資料は教材用の概念設計であり、実機の遮断器定格、電線サイズ、短絡容量、漏電保護、保護協調、接地、端子締付等を確定するものではない。実機では正式採用機器の最新マニュアル、受電条件、規格要求に基づき有資格者が最終設計する。

## 3. FR-E820-0.2K-1で確定していること

三菱電機の現行公式仕様を基準として、CV01～CV04は `FR-E820-0.2K-1` を候補とする。

確認済みの設計前提：

- FREQROL-E800シリーズ
- 3相200Vクラス
- 0.2kW級
- 電源：3相200～240V、50/60Hz級
- 定格出力電流：0.8A級

ただし、Q1～Q4の遮断器定格は0.8Aという出力電流から直接決めない。

入力側保護は、

- 正式な入力電流
- 電源インピーダンス
- メーカー推奨保護機器
- 漏れ電流
- 突入
- 配線条件
- 上位保護との協調

を確認して決める。

## 4. PS01で確定していること

PS01候補 `S8VK-G24024` の公式仕様：

- 出力：DC24V / 10A / 240W
- 入力：AC100～240V、単相
- AC200V時入力電流：1.5A typ.
- AC200V時効率：91% typ.
- AC200V時突入電流：32A typ.（25℃コールドスタート）

したがってQ6は定常電流だけではなく、突入電流も考慮して選定する。

また、設備全体の受電を3相AC200V級としていても、PS01自体は単相入力機器であるため、制御電源分岐は三相モータ系負荷とは別の性格を持つ。実機では相間負荷バランスと上位電源条件を含めて最終設計する。

## 5. 現時点の負荷評価

### 5.1 CV01～CV04

4台とも0.2kW級であり、設備全体の主回路負荷としては比較的小さい。

ただしインバータは単純な抵抗負荷ではないため、モータ容量の単純合算だけで主幹を決めない。

### 5.2 主軸M05

現在は0.4kW級という機械側基準だけで、

- モータ種別
- 駆動方式
- 定格入力電流
- 加減速条件
- 制動方式
- 過負荷条件

が未確定である。

Q5とQ0を決める上で、主軸駆動方式の確定を最優先項目とする。

### 5.3 PS01

PS01は制御系としては負荷が大きくないが、コールドスタート時の突入があるため、Q6選定では瞬時動作特性を含めてメーカー資料を確認する。

## 7. 主幹Q0の考え方

Q0は次の順で決める。

1. Q1～Q6対象機器の正式入力条件を確定
2. 同時運転条件を整理
3. 将来負荷Q7 / PS02の扱いを決める
4. 上位受電条件・短絡条件を確認
5. 配線サイズ・敷設条件を確認
6. 分岐との保護協調を確認
7. 盤内発熱を再評価

単純に分岐定格の合計値をQ0へ採用しない。

## 8. 盤クーラー判定への反映

本負荷表から、初期構成の発熱源は主に、

- INV01～INV04
- 主軸駆動機器
- PS01
- PLC / I/O

となる。

現時点では盤クーラーなしを基準とするが、主軸駆動機器が確定したら `control-panel-thermal-spec.md` を更新する。

再判定条件：

- 主軸ドライブの損失
- FR-E820×4の実損失
- PS01実負荷
- 周囲温度
- 盤密閉度
- PS02追加有無
