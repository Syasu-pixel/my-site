# 01 Drilling Line — Alarm / Timeout Specification

Status: Draft / 設計進行中

このファイルは、MCナイロンワーク穴あけ仮想生産ラインのタイムアウト監視・異常分類・GOT表示方針を整理する。

## 1. 基本方針

- 各動作は「指令を出した」だけでは完了扱いにせず、端確認・在荷・運転確認などの実状態を確認して次ステップへ進む。
- 動作開始後、所定時間内に完了条件が成立しない場合は個別異常を保持する。
- タイムアウト値は現時点では設計仮値とし、実機選定後にシリンダ速度・搬送速度・主軸立上り時間などを確認して最終調整する。
- 異常発生時は自動運転保持および運転準備保持を解除する。
- 異常原因が解消しても自動復帰しない。RESET後、必要に応じて手動復旧し、運転準備から再実施する。
- 単なる待機状態（下流満杯、加工ST受入待ち等）は異常にしない。

## 2. 搬送系異常

| Alarm | 内容 | 主な監視条件 |
|---|---|---|
| A101 | CV01→CV02 搬送タイムオーバー | 搬送開始後、送出元通過完了＋送出元在荷OFF＋CV02在荷ONが規定時間内に成立しない |
| A102 | CV02→CV03 搬送タイムオーバー | 同上 |
| A103 | CV03→CV04 搬送タイムオーバー | 同上 |
| A104 | CV04→加工ST 搬送タイムオーバー | 同上。加工ST受入開始後、加工ST搬送位置在荷ONまで成立しない |

搬送タイムアウト仮値は約5秒を基準とする。目標搬送時間は1区間約3秒以内。

## 3. ストッパー異常

| Alarm | 内容 |
|---|---|
| A111 | ST01 動作異常 |
| A112 | ST02 動作異常 |
| A113 | ST03 動作異常 |
| A114 | ST04 動作異常 |

上昇要求時は上昇端、下降要求時は下降端が規定時間内に成立することを確認する。

また、上昇端・下降端が同時成立した場合はセンサ矛盾として異常扱いとする。

| Alarm | 内容 |

| A403 | INV03 異常 |

主軸については、主軸運転要求後に運転確認が規定時間内に成立しない場合も異常判定対象とする。

## 6. 安全異常

| Alarm | 内容 |
|---|---|
| E001 | 非常停止作動 |
| E002 | 安全回路未成立 |
| E003 | 安全扉開 |
| E004 | ライトカーテン遮光 |
| E005 | 安全リレー異常（採用機器に応じて） |

安全系そのものは安全リレー等のハード安全回路で成立させ、PLCは状態監視と設備制御許可に使用する。

安全異常復帰後も自動再起動は禁止し、運転準備から再操作する。

## 7. 警告・状態表示

以下は原則として設備異常にはしない。

- 搬出満杯
- 加工ST受入待ち
- ワーク投入待ち
- 下流空き待ち
- 目標タクト超過

これらはGOT上で「状態表示」または「警告」として表示し、必要以上に設備停止異常へ格上げしない。

## 9. GOT表示・ブザー方針

- 状態表示：履歴不要を基本とする。
- 警告：設備継続または待機可能。ブザーなし、または短時間通知を基本とする。
- 異常：自動運転停止。異常保持、履歴記録、ブザーあり。
- 安全異常：最高優先度で表示し、自動運転および運転準備を解除する。
- ブザー停止操作は音だけを停止し、異常保持は解除しない。
- 異常リセットは原因解消後のみ受け付ける。

## 10. タイムアウト設定値の考え方

タイムアウトをラダー内に定数で散在させず、将来的にはDレジスタの設定値としてまとめる方向とする。

例：

- 搬送監視時間
- ストッパー動作監視時間
- CY01～CY05動作監視時間
- 主軸立上り監視時間
- 排出監視時間

GOTから変更可能にする場合は、保守画面・権限制限・上下限値を設ける。
