# 01 Drilling Line — 電気回路図ページ構成

Status: Draft / 回路図化直前のページ設計

## 1. 目的

本ファイルは、これまで確定してきた設備仕様、物理I/O、端子台、盤間配線、DC24V分岐、INV・空圧I/Oを、実際の電気回路図へ落とし込むためのページ構成を定義する。

回路図は「電源 → PLC → 入力 → 出力 → 駆動 → 端子台 → 盤間 → 安全監視」の順で追える構成とし、初級教材でも信号の流れを見失いにくくする。

安全機能そのものの回路は通常PLC回路と混在させず、正式な安全設計が確定するまで別冊・別ページ群として扱う。

## 2. 図面体系

| E-04 | DC24V電源分配 | PS01、将来PS02、F24-01～F24-06 |
| E-05 | PLCハード構成 | FX5U、FX5-CNV-IF、FX5-C32EX/DS-TS、Ethernet |
| E-06 | PLC入力 1 | OP01操作入力、安全監視入力 |
| E-07 | PLC入力 2 | CV01～04在荷・通過、ST01～05端確認 |
| E-08 | PLC入力 3 | 加工ST、CY01～05、INV、主軸入力 |
| E-09 | PLC出力 1 | CV01～04、INV RUN、ST01～05 SOL |
| E-10 | PLC出力 2 | CY01～05 SOL、主軸RUN |
| E-11 | PLC出力 3 | PL01～03、BZ01、予備出力 |
| E-12 | INV制御I/O | INV01～04 RUN、運転確認、異常、共通 |
| E-13 | 主軸制御I/O | 主軸RUN、運転確認、異常、駆動機器との境界 |
| E-14 | OP01操作盤 | PB01～06、SW01、PL01～03、BZ01、GOT01 |
| E-15 | OP01盤間配線 | CBL-OP-01、CBL-GOT-PWR-01、CBL-GOT-01 |

## 4. E-02～E-04 — 電源ページ

### E-02 電源系統概略

設備全体の電力の流れを一枚で示す。

概念：

`設備受電 → 主遮断 → INV / 主軸系`

`設備受電 → PS01 → DC24V制御系`

`将来：PS02追加可能`

PE系統も別線で示す。

### E-03 AC主回路

対象：

- INV01～INV04
- M01～M04
- 主軸駆動機器
- M05

ただし主回路保護器の定格、配線サイズ、短絡保護、モータ保護は、正式モータ仕様と受電条件確定後に決定する。

### E-04 DC24V分配

`dc24v-distribution-common-spec.md` を正とし、

- F24-01 PLC入力・センサ
- F24-02 GOT・OP01表示
- F24-03 電磁弁・空圧出力
- F24-04 INV・主軸制御信号
- F24-05 補助リレー・通信
- F24-06 将来増設

を図面化する。

PS02は未実装でも、取付・分岐追加が可能な予約領域を破線で表現する。

## 5. E-05 — PLCハード構成

表示順：

`FX5U-64MT/ES → FX5-CNV-IF → FX5-C32EX/DS-TS`

併記：

- CPU入力 X0～X37
- 追加入力 X40～X77
- CPU出力 Y0～Y37
- Ethernet → GOT01
- 電源・コモン端子

GX Works3の実プロジェクト作成時にXY Assignment Displayと照合する。

## 6. E-06～E-08 — PLC入力回路

入力は機能ごとにページ分割する。

### E-06 OP01・共通条件

- X0～X7：PB / SW
- X10～X15：安全回路監視、エア圧等

ここでは「安全監視入力」と「安全機能そのもの」を明確に区別して注記する。

### E-07 搬送入力

- X16～X25：CV01～04 在荷 / 通過
- X26～X37：ST01～05 上昇端 / 下降端

### E-08 加工・駆動入力

- X40～X55：加工ST、CY01～05、搬出
- X56～X67：INV01～04、主軸
- X70～X77：予備

予備入力は端子台XT8との将来接続欄を残す。

## 7. E-09～E-11 — PLC出力回路

### E-09 搬送出力

- Y0～Y3：INV01～04 RUN
- Y4～Y15：ST01～05 上昇 / 下降SOL

### E-10 加工出力

- Y16～Y27：CY01～05
- Y30：主軸RUN

ダブルソレノイド対は図面上でもペアとして並べ、相反出力であることを注記する。

### E-11 表示・予備

- Y31：投入可
- Y32：運転
- Y33：異常
- Y34：ブザー
- Y35～Y37：予備

## 8. E-12～E-13 — 駆動I/O

### E-12 INV

`drive-io-wiring-schedule.md` を正とする。

INV01～04ごとに、

- RUN指令
- 運転確認
- 異常
- 24V / 0Vまたは必要な共通端子

を一つのブロックとして描く。

実際のFR-E800端子名称、シンク/ソース設定、リレー出力／トランジスタ出力条件は正式回路化時にメーカー仕様へ合わせる。

### E-13 主軸

主軸はPLCからモータを直接駆動しない。

図面境界は、

`PLC Y30 → 主軸駆動機器 RUN入力`

`主軸駆動機器 運転確認 → X66`

`主軸駆動機器 異常 → X67`

までを基本とする。

## 11. E-20～E-22 — 端子・ケーブル一覧

端子台表は回路図の最後近くにまとめる。

- E-20：XT1～XT4
- E-21：XT5～XT8

`PLC I/O → 盤内線 → XT端子 → ケーブル → 現場機器`

の順で追えることを合格条件とする。

## 12. E-23 — 通信構成

Ethernetは通常I/O配線と別図面にする。

現状：

`PLC01 Ethernet ↔ GOT01`

`PLC01 ↔ 産業用Ethernet Switch ↔ GOT01 / 保守PC / 追加機器`

将来スイッチ追加時も配線し直しが少なくなるよう、CP01に取付余地を確保する。

## 15. 図面作成ルール

教材全体で以下を統一する。

- 左から右、上から下へ信号を追える配置
- PLC I/O番号と機器タグを必ず併記
- 端子台番号を省略しない
- 外部ケーブルにはケーブルタグを付ける
- 線番を端子の両側で一致させる
- 予備は「SPARE」と明示する
- 未確定値は仮値を確定値に見せない
- 安全機能と通常PLC制御を混同しない
- 主回路と制御回路はページを分ける
- INV / モータ線とセンサ・通信線の分離方針を注記する

## 16. 回路図化の着手順

実際に図面を起こす順番は以下とする。

1. E-04 DC24V分配
2. E-05 PLCハード構成
3. E-06～E-08 PLC入力
4. E-09～E-11 PLC出力
5. E-14～E-15 OP01
6. E-16～E-19 現場外部配線
7. E-12～E-13 駆動I/O
8. E-20～E-22 端子・ケーブル一覧
9. E-02～E-03 主電源・主回路
10. E-23～E-24 通信・予備
11. E-01 表紙・索引を最後に確定
12. E-30以降は安全設計確定後

この順番にすることで、I/Oと24V制御側を先に確定し、モータ・安全機器など未確定部分に引きずられずに図面化を進められる。
