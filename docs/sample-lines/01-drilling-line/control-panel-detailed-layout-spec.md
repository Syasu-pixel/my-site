# 01 Drilling Line — CP01 盤内詳細レイアウト / 冷却予約

Status: Draft / 教材用概念配置

## 1. 目的

CP01（W800 × H1200 × D350 mm級）について、INV01～INV05を含む主要機器の配置、発熱ゾーン、配線ダクト、将来I/O、PS02、冷却機器の予約領域を具体化する。

本資料は教材用の概念配置であり、AC主回路の実配線、保護協調、絶縁距離、接地、冷却能力の最終値を確定するものではない。実機では正式機器の外形図・設置間隔・発熱損失・盤メーカー条件・周囲環境・規格を確認して最終設計する。

## 2. 基本方針

- INV01～INV05を盤右側の発熱ゾーンへ集約する。
- PLC、DI、将来DOは盤中央～左寄りへ配置し、INV上部の熱流から離す。
- PS01とPS02予約領域は左中段へまとめる。
- 端子台XT1～XT8は盤下部へ集約する。
- 主回路ダクトとDC24V・センサ・Ethernet系ダクトを分ける。
- INV列の上方は熱気排出を妨げない空間として扱い、後付け循環ファン / 熱交換器 / 盤クーラーの候補位置を塞がない。

## 3. 推奨ゾーン

### A — 受電 / 分岐ゾーン

盤左上。

- Q0主幹
- Q1～Q7分岐保護機器
- 補助開閉・サージ対策用余地

ここから発熱機器ゾーンと制御電源ゾーンへ分岐する。

### B — PLC / 制御ゾーン

盤中央上～中央左。

- PLC01 FX5U-64MT/ES
- DI01 FX5-C32EX/DS-TS
- 将来DO増設ユニット 16～32点級 ×1予約
- Ethernetスイッチ等の通信機器予約
- 中継インターフェース余地

PLC列の右側・上側をINV排熱の直通経路にしない。

### C — DC24V電源ゾーン

盤左中段。

- PS01 S8VK-G24024
- PS02 24V / 10A級予約
- F24-01～F24-06分岐部
- 24V / 0V分配

PS02を後付けしても既存PS01配線を全面的に組み替えない配置を優先する。

### D — INV / 発熱ゾーン

盤右側。

- INV01 FR-E820-0.2K-1
- INV02 FR-E820-0.2K-1
- INV03 FR-E820-0.2K-1
- INV04 FR-E820-0.2K-1
- INV05 FR-E820-0.4K-1（主軸）

5台を一塊に密集させず、メーカー指定の離隔・通風条件を確保する。

教材用レイアウト案は **3台 + 2台の2段配置** を基準候補とする。

```text
INV01   INV02   INV05

INV03   INV04   [予備/通風]
```

INV05は主軸用で連続負荷率が高くなる可能性があるため、上段外側または通風のよい位置を優先する。

## 5. 冷却予約位置

### 5.1 初期状態

- 盤クーラー：非搭載
- 吸排気ファン：未搭載を基準
- 盤内循環ファン：必要時追加

### 5.2 予約位置

候補：

- 盤上部：排熱 / 循環用領域
- 盤側面上部：熱交換器または盤クーラー取付候補
- INV列直上：局所循環ファン用の取付余地

ただし、将来冷却機器の取付で扉開閉、盤間配線、保守通路、INV離隔を損なわないこと。

## 6. 温度測定ポイント

試運転時の測定候補：

- T01：盤内上部中央
- T02：INV01～INV05列上部
- T03：PLC01周辺
- T04：PS01周辺
- T05：盤下部端子台付近
- TAMB：盤外周囲温度

連続運転で熱的に安定した状態を確認し、単なる電源投入直後では判断しない。

## 7. 冷却追加判断

一次判断：

- INV列上部に顕著な熱だまり → まず盤内循環の改善
- 周囲空気が清浄で盤内平均温度が高い → 吸排気ファン + フィルタ候補
- 高温・粉じん・オイルミスト・密閉要求 → 熱交換器 / 盤クーラー候補
- PS02、画像処理、追加ドライブ等で発熱が増える → 熱計算を再実施

## 8. 配線ダクト配置

概念的に3系統を分ける。

- DUCT-PWR：AC主回路 / INV・モータ関連
- DUCT-CTL：DC24V出力 / SOL / 表示
- DUCT-SIG：PLC入力 / センサ / Ethernet

INV出力線とセンサ・Ethernetを同じ経路へ長距離並走させない。

## 9. 将来拡張領域

必ず確保する。

- FUTURE-DO：16～32点級 ×1
- PS02：24V / 10A級 ×1
- XT8：約24端子
- DR6：将来機器・端子用
- 通信機器：小型Ethernetスイッチ級
- 冷却機器：側面 / 上部取付候補領域

## 10. CP01寸法評価

INVが4台から5台になったため、W800 × H1200 × D350 mm級を維持する。

現時点では盤を小さくする方向へは進めない。

理由：

- INV05追加
- PS02予約
- 将来DO予約
- XT8拡張端子
- 冷却後付け余地
- ダクト充填率の余裕

初期盤クーラーなし方針を成立させるには、機器を詰め込みすぎないこと自体が熱対策になる。
