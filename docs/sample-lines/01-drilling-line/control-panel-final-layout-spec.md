# 01 Drilling Line — CP01 盤内レイアウト最終基準

Status: Draft / 教材用レイアウト最終基準

## 1. 目的

CP01（W800 × H1200 × D350 mm級）について、これまで確定してきた主要機器、DINレール、端子台、配線ダクト、PE / シールド、将来増設余地、冷却予約を1枚の基準へ統合する。

本資料は盤内レイアウトの最終基準であり、実機のAC主回路施工、保護協調、配線サイズ、安全回路、接地施工、端子締付条件を確定するものではない。実機製作時は正式採用機器の最新マニュアル、盤メーカー実寸、受電条件、規格要求、リスクアセスメントを優先する。

## 2. 盤外形

CP01基準：

- 外形：W800 × H1200 × D350 mm級
- 前面片開き
- 全面取付板
- 下部ケーブル引込
- 上部冷却予約
- GOT01はOP01側へ配置

現段階では盤サイズを縮小しない。

## 3. 主要機器

盤内主要機器：

- PLC01：FX5U-64MT/ES
- FX5-CNV-IF
- DI01：FX5-C32EX/DS-TS
- FUTURE DO / COMM 予約
- PS01：S8VK-G24024
- PS02：将来DC24V電源予約
- INV01～INV04：FR-E820-0.2K-1
- INV05：FR-E820-0.4K-1
- Q0～Q7：主幹・分岐機器（定格・正式形名TBD）
- XT1～XT8
- PE端子群
- シールドクランプ群
- 中継リレー / I/F
- DC24V分岐機器

## 4. 取付板設計グリッド

盤外形W800 × H1200に対し、一次設計上の有効取付板領域を約W700 × H1050 mmとして扱う。

縦方向：

```text
0～120      冷却・上昇気流・後付け予約
120～360    PLC / 主回路補助 / INV上段
360～610    PS01 / PS02予約 / INV下段
610～760    DC24V分岐 / リレー / 予備DIN
760～1000   端子台3段 / PE / SHIELD
1000～1050  ケーブル固定・下部引込
```

## 5. 横方向ゾーニング

一次基準：

```text
左側 約360 mm                    右側 約340 mm
┌────────────────┬────────────────┐
│ 主回路補助      │ INV01 INV02 INV05 │
│ PLC / I/O       │                  │
│ PS01 / PS02     │ INV03 INV04 OPEN  │
│ 24V / Relay     │                  │
└────────────────┴────────────────┘
```

左側は弱電・制御中心、右側はINV・モータ系中心とする。

## 6. INV配置

基準：

```text
上段：INV01  INV02  INV05
下段：INV03  INV04  OPEN
```

OPEN部は将来INV増設位置ではなく、まず通風・保守・補助機器・温度測定余地として保持する。

INV05は主軸用で負荷率が高くなる可能性があるため、最も通風を確保しやすい位置を優先する。

最終離隔はFR-E800最新施工マニュアルを優先する。

## 7. PLC / I/O配置

基準並び：

`PLC01 → FX5-CNV-IF → DI01 → FUTURE DO → FUTURE COMM`

PLC系には約350 mm級の横方向帯を確保する。

現在DO予備はY35～Y37の3点のみのため、4点以上の将来DO追加では追加出力ユニットを採用する方針を維持する。

## 8. 電源配置

PS01：S8VK-G24024。

PS02は将来追加用スペースとして予約し、PS01との常時並列を前提にしない。

DC24Vは機能別分岐を維持し、センサ系、GOT、SOL、INV/主軸制御、補助・通信、将来用を整理する。

## 9. DINレール

一次基準：

| Rail | 主用途 | 基準長 |
|---|---|---:|
| DR1 | 主回路補助 / Q分岐 | 500 mm級 |
| DR2 | PS01 / PS02 / DC24V分岐 | 500 mm級 |
| DR3 | PLC / DI / 将来DO・通信 | 500 mm級 |
| DR4 | 中継リレー / I/F | 500 mm級 |
| DR5A | XT1～XT4 | 600 mm |
| DR5B | XT5～XT7 | 600 mm |
| DR6 | XT8 / PE / SHIELD / FUTURE | 500 mm |

## 10. 端子台

XT1～XT8総端子数：178。

通常端子一次候補：Phoenix Contact PT 2,5級 / 5.2 mmピッチ。

基準配置：

```text
DR5A : XT1 → XT2 → XT3 → XT4
DR5B : XT5 → XT6 → XT7
DR6  : XT8 → FUTURE → PE → SHIELD → RESERVE
```

DR5A / DR5Bは600 mmを維持し、実ピッチで余ったスペースは端子追加、セパレータ、マーカ、保守余地に使う。

## 11. DR6

DR6 500 mmの一次配分：

- XT8：約145 mm級
- FUTURE：約80 mm級
- PE：約100 mm級
- SHIELD：約80 mm級
- RESERVE：約95 mm級

PE端子は12～16極級、シールドクランプは8～12点級を一次予約とする。

## 12. 配線ダクト

一次基準：

- WD-A：60 mm級 — AC受電 / 主回路
- WD-M：60 mm級 — INV出力 / モータ系
- WD-C：40～60 mm級 — DC24V出力 / SOL・補助
- WD-S：40～60 mm級 — センサ / PLC入力
- WD-N：30～40 mm級 — Ethernet / 通信

INV出力とセンサ/Ethernetを長距離並走させない。

交差が必要な場合も、無条件に同一ダクトへまとめない。

## 13. 外部ケーブル引込

基準：盤下部引込。

ケーブル群は機能別に整理する。

- CBL-OP-*：操作盤
- CBL-CV-*：搬送
- CBL-PROC-*：加工ST
- CBL-INV-*：INV制御
- CBL-MTR-*：モータ系
- CBL-GOT-*：GOT / Ethernet / 電源
- Safety関連：通常制御と別管理

弱電系、一般制御、INV/モータ系を盤下部でも混在させすぎない。

## 14. 冷却

初期方針：

- 盤クーラー：なし
- 盤内循環ファン：必要時追加
- 吸排気ファン / フィルタ：環境により追加
- 上部・側面：将来冷却機器予約
- 温度監視：追加余地あり

初期盤内発熱レンジはINV05追加後で約100～150W級を一次想定とし、将来増設後は約140～200W級を一次想定する。

試運転時は周囲温度、盤上部、INV列上部、PLC周辺、PS01周辺を測定し、盤クーラー要否を再判定する。

## 15. 保守・増設余地

盤内を初期状態で満杯にしない。

維持する余地：

- PLC右側の追加DO / 通信
- PS02 1台分
- DR4の補助リレー追加
- XT8 24端子
- DR6 FUTURE / RESERVE
- INV OPEN領域
- 上部冷却予約
- 配線ダクト空き

## 16. 最終成立性評価

現時点で、CP01 W800 × H1200 × D350 mm級は以下を同時に満たせる見込み。

- PLC / DI / 将来DO
- INV5台
- PS01 / PS02予約
- XT1～XT8 178端子
- PE / SHIELD
- 配線ダクト分離
- 下部ケーブル引込
- 冷却後付け余地
- 20～30%級の将来増設思想

したがって本サイズを盤内レイアウト基準として維持する。

## 17. 残課題

1. Q0～Q7正式機器外形
2. FX5-CNV-IF正式外形
3. FUTURE DO正式候補
4. 端子台正式注文形名
5. PE / シールドクランプ正式品
6. FR-E800正式施工離隔
7. 盤メーカー実取付板寸法
8. 実際のケーブル引込口数・サイズ
9. 安全機器確定後の専用領域
10. 連続運転時の実測温度
