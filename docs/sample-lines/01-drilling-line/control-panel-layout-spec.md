# 01 Drilling Line — 制御盤サイズ / 盤内レイアウト仕様

Status: Draft / 教材用概念設計

## 1. 目的

本設備の制御盤 CP01 について、現時点で採用している主要機器と将来拡張余地を前提に、盤サイズ・機器配置・DINレール・配線ダクト・予備スペースの基準を定める。

本資料は教材用の概念設計であり、実機製作時の盤設計・熱設計・安全回路・保護協調・配線サイズは、正式採用機器の取扱説明書、規格、周囲条件、リスクアセスメントに基づき資格者が再確認する。

## 2. 盤外形の基準

CP01 は以下を基準寸法とする。

- 外形：W800 × H1200 × D350 mm級
- 扉：前面片開き
- 取付板：全面取付板
- 下部：外部配線・端子台ゾーン
- 上部：制御・電源機器ゾーン
- 中央～右側：インバータ・発熱機器ゾーン

将来の電源増設、I/O追加、通信機器追加を考慮し、現時点で盤内を満杯にしない。

## 3. 将来拡張方針

既存の DC24V 負荷は約3.3A、将来想定負荷は約6.8Aを基準とする。

PS01 は DC24V / 10A を維持し、PS02 として将来 24V / 10A 級電源を追加できる盤内スペースを予約する。

現在のPLC出力は32点中29点使用で予備3点しかないため、将来拡張では電源だけでなくDO不足も早期に発生しうる。したがってPLC周辺には **16～32点級の追加トランジスタ出力ユニット1台分** を取り付けられるスペースを最初から予約する。正式形名はGX Works3のモジュール構成・接続条件と将来負荷が確定した時点で決める。

予備スペースは次を確保する。

- DINレール：最低20～30%空き
- 端子台：各機能群20～30%程度の予備端子
- XT8：将来拡張専用として24端子程度を確保
- 配線ダクト：現配線で満杯にしない
- PLC右側：追加DO / DI / 通信アダプタ用余地
- 電源部：PS02追加スペース
- インバータ部：補助リレー / EMC対策部品追加スペース

## 4. 盤内ゾーニング

盤内は大きく5ゾーンに分ける。

### Zone A — 主回路 / 受電

盤左上を基準とする。

配置候補：

- 主電源開閉器
- 主遮断器
- 分岐保護
- PE端子
- 必要なサージ・ノイズ対策機器

### Zone B — DC24V / 制御電源

Zone A の下または隣接位置。

配置候補：

- PS01：DC24V / 10A
- PS02予約スペース：DC24V / 10A級
- DC24V分岐保護
- 24V / 0V分配端子

PS01 と PS02 を将来並列運転する前提ではなく、必要に応じて負荷系統を分離して増設できる構成を優先する。

### Zone C — PLC / 制御

盤中央左～中央上を基準とする。

配置：

- PLC01 FX5U-64MT/ES
- DI01 FX5-C32EX/DS-TS
- 将来DO増設ユニット予約位置（16～32点級×1）
- 将来I/O増設余地
- Ethernet関連機器が必要になった場合の余地
- 中継リレー / インターフェース

PLC周辺はインバータ・主回路配線から離して配置する。

### Zone D — INV / 発熱機器

盤中央右～右側を基準とする。

配置：

- INV01～INV04 FR-E820-0.2K-1
- 必要な分岐保護
- モータ側配線用端子

インバータは放熱と配線施工を優先し、上下左右の離隔は採用機器のメーカー要求に従う。

### Zone E — 端子台 / 外部配線

盤下部を基準とする。

配置：

- XT1～XT7：現在機能用
- XT8：将来拡張専用24端子程度
- PE端子
- 予備端子
- シールド処理部
- ケーブル固定 / 引込余地

端子台は外部ケーブル引込方向から配線を追いやすい順序に並べる。

## 5. レイアウトイメージ

概念配置：

```text
┌──────────────────────────────┐
│ Zone A      │ Zone C          │
│ 主回路      │ PLC / DI        │
│ 遮断器      │ DO増設予約      │
│             │ I/O・通信予備   │
├─────────────┼────────────────┤
│ Zone B      │ Zone D          │
│ PS01        │ INV01  INV02     │
│ PS02予備    │ INV03  INV04     │
│ DC24V分岐   │ 発熱機器         │
├──────────────────────────────┤
│ Zone E  XT1～XT7 / XT8(拡張) / PE            │
│ 外部配線引込・ケーブル固定                  │
└──────────────────────────────┘
```

実際の寸法は各機器外形と配線ダクト幅を反映して調整する。

## 6. DINレール基準

DINレールは機能ごとに分ける。

- DR1：主回路補助・分岐
- DR2：PS01 / PS02予約 / DC24V分岐
- DR3：PLC / 現行I/O / 将来DO増設
- DR4：中継リレー / インターフェース
- DR5：端子台 XT1～XT7
- DR6：XT8 / 将来増設端子 / 追加I/O関連

DR3は追加DOユニット1台を実装してもなお小規模な追加変更ができる余白を残す。DR6は初期状態で大きく空け、後付け機器と端子の受け皿とする。

## 7. 配線ダクト基準

配線ダクトは、主回路系と制御系を可能な範囲で分離する。

基本方針：

- AC主回路 / モータ配線
- DC24V制御配線
- アナログ / 通信 / センサ配線

を同一ダクトへ無条件に混在させない。

主回路とPLC・センサ系は配置上も距離を取る。

将来増設で配線が増える前提から、初期施工時のダクト充填率を高くしすぎず、少なくとも1系統分の追加I/O配線を通せる余裕を残す。

## 8. GOT配置

GOT01 はCP01扉面ではなく、OP01操作盤側を基準とする。

理由：

- 投入作業位置から見やすい
- 手動復旧時に機械を見ながら操作しやすい
- CP01を設備脇の制御盤として独立させやすい

CP01扉面には必要最低限の盤側表示・電源操作のみとし、通常運転操作はOP01へ集約する。

## 9. 盤内発熱の考え方

主な発熱源：

- INV01～INV04
- PS01
- 将来PS02
- PLC / I/O
- 将来DO増設ユニット
- 中継リレー等

現時点では強制冷却を即決せず、正式機器の損失値と周囲温度を積算してからファン / フィルタ / 熱交換器の必要性を判断する。

ただし将来PS02追加と盤内負荷増加を考え、上部または側面に冷却機器を追加できる余地を確保する。

## 10. 予備スペースの具体基準

教材上の基準として次を採用する。

- PLC系：横方向200 mm程度を将来I/O・通信追加領域として予約
- DO：16～32点級追加出力ユニット1台分を明示予約
- 電源系：PS02 24V / 10A級1台分＋分岐保護分の余地
- リレー系：8～16点程度の追加余地
- 端子台：各機能群20～30%予備 + XT8約24端子
- ダクト：初期配線状態で充填率を高くしすぎない
- 盤内取付板：総面積の20%以上を将来変更可能領域として残す

### 10.1 将来DO増設時の考え方

現行Y35～Y37の3点は小変更用として残す。

4点以上のDO追加が必要になった時点で、既存3点を無理に使い切るのではなく追加DOユニットを採用する方針とする。これにより、

- 追加SOL
- 追加表示灯
- NG排出機構
- 追加ブザー / パトライト
- 補助機器RUN

などを後から追加しやすくする。

追加DOのフィールド配線はXT8または将来追加端子台へ収容し、既設XT4 / XT5を無理に組み替えない。

## 11. CP01基準寸法の評価

W800 × H1200 × D350 mm級は、今回の規模に対してやや余裕を持たせたサイズとする。

この寸法を採用する理由：

- INV4台を無理なく配置したい
- PS02の将来追加余地を持たせたい
- PLC / I/Oの追加余地を確保したい
- 端子台と配線ダクトを窮屈にしたくない
- 教材として盤内の機能分離を見せやすい

盤を小さくすることより、保守性・増設性・配線の追いやすさを優先する。

## 12. 次工程

次に以下を決める。

1. 回路図ページ構成
2. 主回路の単線系統図レベルの構成整理
3. 24V分岐保護の図面ページ割付
4. PLC / I/O / 将来DO増設の図面表現
5. XT1～XT8の端子図ページ割付
6. PE / シールド処理位置
7. 盤内発熱一次計算

安全回路の具体配線や保護協調は本資料だけで確定しない。
