# 01 Drilling Line — CP01 取付板寸法割付

Status: Draft / 教材用レイアウト一次確定

## 1. 目的

CP01（W800 × H1200 × D350 mm級）について、正式候補機器の外形寸法と将来増設余地をもとに、取付板上の機能ゾーンをmm単位で割り付ける。

本資料は機器配置・保守性・熱余裕を確認するための教材用概念設計であり、AC主回路の施工寸法、電線サイズ、保護協調、安全回路、端子締付、接地施工を確定するものではない。実機では各メーカーの最新施工要領と資格者による設計確認を優先する。

## 2. 今回確認できた主要機器外形

### PLC01

`FX5U-64MT/ES`

- W220 × H90 × D83 mm
- 取付板上ではCPU単体寸法だけでなく、右側増設機器と配線作業余地を含めて配置枠を取る。

### DI01

`FX5-C32EX/DS-TS`

- W20.1 × H90 × D93.7 mm
- FX5Uとの接続にはFX5-CNV-IFを使用する。

### PS01

`S8VK-G24024`

- W60 × H125 × D150 mm級
- DINレール取付
- 240W / DC24V 10A

### INV01～INV04

`FR-E820-0.2K-1`

- 1台あたり W68 × H128 × D112.5 mm級

### INV05

`FR-E820-0.4K-1`

- W68 × H128 × D132.5 mm級

インバータの上下左右の最終離隔は、正式採用時の最新施工マニュアル値を優先する。本資料では本体寸法ぎりぎりには配置しない。

## 3. 取付板の有効設計領域

盤外形W800 × H1200に対し、扉フランジ、盤縁、配線引込、ダクト、保守作業余地を考慮し、取付板上の一次設計領域を次のように扱う。

- 横方向設計領域：約700 mm
- 縦方向設計領域：約1050 mm
- 最上部：冷却・上昇気流・後付け機器予約帯
- 最下部：端子台・ケーブル固定・外部引込帯

これは盤メーカーの最終取付板実寸ではなく、レイアウト検証用の設計グリッドである。

## 4. 横方向の一次割付

基準グリッド：

```text
0                                                     700 mm
|---------------------------------------------------------|
|  A/B/C 制御・電源側  約360 mm |  D INV側 約340 mm     |
|---------------------------------------------------------|
```

### 左側 約360 mm

用途：

- 主回路補助・分岐機器の概念領域
- PS01 / PS02予約
- PLC01 / DI01 / 将来DO
- 補助リレー / 通信

PLC01本体がW220 mmあるため、PLC列は横方向を詰めすぎない。

PLC列の一次予約幅：

- PLC01：220 mm
- DI01 + 変換インターフェース：小型増設領域
- 将来DO / 通信：100～150 mm級予約

したがってPLC系は横方向 **約350 mm級の専用帯** を確保する。

### 右側 約340 mm

用途：INV01～INV05。

3台横並び時の本体幅：

`68 × 3 = 204 mm`

本体幅だけなら十分収まるが、施工・通風・配線ダクトを含め、INV列の設計幅は約300～340 mm級を確保する。

## 5. 縦方向の一次割付

取付板有効高さ約1050 mmを次の帯に分ける。

```text
上端
│  0～120 mm    冷却・上昇気流・後付け予約
│
│ 120～360 mm   上段：PLC / 主回路補助 / INV01,02,05
│
│ 360～610 mm   中段：PS01 / PS02予約 / INV03,04 / 補助機器
│
│ 610～760 mm   中継リレー・DC24V分岐・予備DIN
│
│ 760～1000 mm  端子台3段：DR5A / DR5B / DR6
│
│ 1000～1050 mm ケーブル固定・引込余地
下端
```

寸法は機器本体の固定座標ではなく、機能帯の一次割付とする。

## 6. INVゾーン詳細

一次配置：

```text
┌──────────────────────┐
│ INV01   INV02   INV05 │  上段
│                      │
│ INV03   INV04   OPEN  │  下段
└──────────────────────┘
```

OPEN位置は次の用途を兼ねる。

- 通風
- 将来補助部品
- 温度測定
- 配線作業
- INV増設ではなく、まず熱余裕として保持

INV05は0.4kW級で奥行きも大きいため、上段外側または最も通風を確保しやすい位置を優先する。

## 7. PLCゾーン詳細

一次配置：

```text
PLC01 → FX5-CNV-IF → DI01 → FUTURE DO → FUTURE COMM
```

PLC01本体W220 mmに対し、右側へ将来モジュールを追加できるよう、PLC系全体で約350 mm級の横方向帯を確保する。

現在DO予備は3点しかないため、将来DO領域を初期状態から塞がない。

## 8. PS01 / PS02ゾーン

PS01はW60 × H125 × D150 mm級であるため、電源単体は小さいが、分岐・保守・将来PS02を含めて余裕を取る。

一次予約：

```text
PS01   PS02 FUTURE
DC24V BRANCH / AUX
```

PS02は初期未搭載。PS01との常時並列を前提にせず、将来負荷を機能別に分離するための追加電源として扱う。

## 9. 端子台ゾーン

詳細は `din-rail-terminal-capacity-spec.md` を正とする。

XT1～XT8は合計178端子となるため、1段へ集約しない。

端子台メーカー未確定の一次レイアウトでは1極6 mm級を設計包絡値として計算し、次の3段構成を採用する。

```text
DR5A 600 mm : XT1 → XT2 → XT3 → XT4
DR5B 600 mm : XT5 → XT6 → XT7
DR6  500 mm : XT8 → PE / SHIELD → FUTURE
```

概念高さ：

```text
760 mm  ─ DR5A
840 mm  ─ DR5B
920 mm  ─ DR6
1000 mm ─ ケーブル固定・引込帯
```

実際のレール中心間隔は、採用端子台高さ・配線ダクト・曲げ半径・マーカ視認性を確認して最終化する。

この構成により、現在信号だけでなく各XTの予備端子とXT8の将来24点を保持しながら、下部端子ゾーンへ収容できる見込み。

## 10. DINレール基準長

一次基準：

| Rail | 主用途 | 基準長 |
|---|---|---:|
| DR1 | 主回路補助 / Q分岐関連 | 500 mm級 |
| DR2 | PS01 / PS02予約 / DC24V分岐 | 500 mm級 |
| DR3 | PLC / DI / 将来DO・通信 | 500 mm級 |
| DR4 | 中継リレー / インターフェース | 500 mm級 |
| DR5A | XT1～XT4 | 600 mm |
| DR5B | XT5～XT7 | 600 mm |
| DR6 | XT8 / PE / SHIELD / FUTURE | 500 mm |

DR1～DR4は取付板全幅を横断する意味ではなく、各機能ゾーン内で確保する有効DIN長とする。

## 11. 冷却予約領域

上部約120 mm級を、機器で埋めない設計帯として扱う。

用途：

- INV上昇気流の逃げ
- 盤内温度測定
- 将来循環ファン
- 必要時の吸排気 / 熱交換器 / 盤クーラー取付検討

初期方針は盤クーラーなしだが、冷却機器の後付けを妨げる機器配置にはしない。

## 12. 配線ダクト / ルート分離

詳細は `control-panel-wiring-duct-routing-spec.md` を正とする。

一次ダクト基準：

- WD-A：AC受電 / 主回路 60 mm級
- WD-M：INV出力 / モータ系 60 mm級
- WD-C：DC24V出力 / 補助 40～60 mm級
- WD-S：DC24V入力 / センサ 40～60 mm級
- WD-N：Ethernet / 通信 30～40 mm級

盤内では、

- 左側：PLC・PS01・センサ・DC24V制御
- 右側：INV入力・INV出力・モータ系
- 下部：端子台3段
- 通信：PLC近傍から独立経路

を基本とする。

INV出力 / モータ系はPLC入力・センサ・Ethernetと長距離並走させず、INV入力側と出力側も可能な範囲で別経路とする。

外部ケーブル引込は一次基準として盤下部とし、XT1～XT8へ短く導ける構成を優先する。

## 13. 成立性評価

今回確認した主要機器寸法、端子台178点の3段配置、配線ダクトの機能分離を当てはめた結果、CP01 **W800 × H1200 × D350 mm級は維持可能**と判断する。

理由：

- PLC01がW220 mmと比較的大きいが、左側350 mm級帯で将来I/Oまで確保できる。
- INV5台は3+2配置により右側340 mm級帯へ収容できる見込み。
- PS01はW60 mmで、PS02予約を含めても電源帯を確保可能。
- XT1～XT8を3段へ分割することで、端子台178点を下部240 mm級ゾーンへ整理できる見込み。
- 制御系とINV / モータ系を左右へ分ける配線ルートを確保できる。
- 上部に冷却予約帯を残せる。
- D350 mmに対し現時点の主要機器奥行きはPS01約150 mm、INV05約132.5 mm級であり、配線・ダクト・扉側余地を検討できる。

したがって盤サイズは現段階で縮小しない。
