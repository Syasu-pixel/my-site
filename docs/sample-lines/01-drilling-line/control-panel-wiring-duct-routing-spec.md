# 01 Drilling Line — CP01 配線ダクト / 盤内ルート分離仕様

Status: Draft / 教材用盤内配線レイアウト一次確定

## 1. 目的

CP01（W800 × H1200 × D350 mm級）の盤内配線について、AC主回路、インバータ出力、DC24V制御、センサ、Ethernet / 通信を機能ごとに分離して通せるよう、配線ダクトの一次幅とルートを整理する。

本資料は教材用のレイアウト基準であり、実機の電線サイズ、絶縁距離、保護協調、接地施工、安全回路、EMC適合を確定するものではない。正式施工時は採用機器の最新マニュアルと現場条件を優先する。

## 2. 基本方針

盤内配線は次の5系統へ分ける。

1. AC受電 / 主回路系
2. INV出力 / モータ系
3. DC24V出力 / SOL・補助機器系
4. DC24V入力 / センサ系
5. Ethernet / 通信 / 低レベル信号系

異種系統を同一ダクトへ無条件に混在させない。

特に、

- INV出力線
- PLC入力線
- センサ線
- Ethernet

は可能な範囲で経路を分離し、盤内で長距離並走させない。

## 3. ダクト一次仕様

正式メーカー・シリーズは未確定のため、一次レイアウトでは以下を設計包絡値とする。

| Duct | 用途 | 一次幅 | 備考 |
|---|---|---:|---|
| WD-A | AC受電 / 主回路 | 60 mm級 | Q0～Q7、INV入力、PS01入力側 |
| WD-M | INV出力 / モータ系 | 60 mm級 | INV01～05から機外へのモータ系 |
| WD-C | DC24V出力 / 補助 | 40～60 mm級 | SOL、表示、補助機器 |
| WD-S | DC24V入力 / センサ | 40～60 mm級 | X入力、センサ電源、監視信号 |
| WD-N | Ethernet / 通信 | 30～40 mm級 | GOT Ethernet、将来通信 |

ここでの幅は部品注文値ではなく、盤内成立性を見るための一次基準とする。

## 4. 盤内縦ルート

### 左側縦ルート

主に制御系を通す。

- DC24V分配
- PLC入力
- PLC出力
- OP01 / センサ系
- 将来通信

一次配置：

```text
左外周
│ WD-S : センサ / PLC入力
│ WD-C : 24V出力 / 補助
│ PLC / PS01 / DR4
```

### 右側縦ルート

主に駆動系を通す。

- INV入力側
- INV出力側
- モータ側外部配線

一次配置：

```text
INVゾーン
│ WD-A : INV入力側
│ INV01～05
│ WD-M : INV出力 / モータ系
右外周
```

INV入力側と出力側も、可能な範囲で別ルート扱いとする。

## 5. 盤内横ルート

横方向は機能帯ごとに分ける。

### 上段 120～360 mm

- PLC / 主回路補助 / INV上段
- PLC側：WD-S / WD-N
- INV側：WD-A / WD-M

PLC上部にモータ系を横切らせない。

### 中段 360～610 mm

- PS01 / PS02予約
- INV下段
- DC24V分岐

PS01の24V側はWD-C / WD-Sへ分岐し、INVモータ系WD-Mとは分ける。

### 中下段 610～760 mm

- DR4 中継リレー / I/F
- DC24V分配
- 将来補助

ここはDC24V制御の集約帯として使う。

### 下段 760～1000 mm

- DR5A / DR5B / DR6
- XT1～XT8
- PE / SHIELD

端子台への最終立下りは、対応する縦ダクトから機能ごとに入れる。

## 6. 端子台との対応

### DR5A

`XT1 → XT2 → XT3 → XT4`

主な流入：

- WD-S：XT1センサ電源、XT2入力、XT4搬送入力
- WD-C：XT3出力、XT4ストッパーSOL

### DR5B

`XT5 → XT6 → XT7`

主な流入：

- WD-S：XT5加工入力、XT6 INV状態、XT7監視
- WD-C：XT5 CY / 主軸指令
- WD-A / WD-MはXT6通常I/O端子へ直接混在させず、主回路とは機能分離する

### DR6

`XT8 → FUTURE → PE / SHIELD`

- 将来DI/DO
- 予備24V / 0V
- PE端子
- シールドクランプ

将来増設でも既存ダクトを満杯にしないことを優先する。

## 7. Ethernet / 通信ルート

GOT01はOP01側にあり、CP01とはEthernet接続を基準とする。

通信線はWD-Nを使用し、

- INV出力線
- AC主回路
- SOL束

と長距離並走させない。

盤内ではPLC近傍から盤外引込部まで短く明快な経路を確保する。

将来Ethernetスイッチ等を追加する場合も、PLCゾーン内でWD-Nへ接続する。

## 8. INVゾーンの配線ルール

INV01～05は3+2配置を基準とする。

```text
INV01   INV02   INV05
INV03   INV04   OPEN
```

配線思想：

- 入力側はWD-A
- 出力側はWD-M
- PLC RUN / 状態I/OはWD-C / WD-S
- Ethernetやセンサ線をINV出力の直近へ通さない
- OPEN位置は通風と配線引回し余地として残す

本資料では具体的な主回路端子接続や配線サイズは固定しない。

## 9. シールド / PEとの関係

PE / SHIELDはDR6周辺を基準とする。

シールド対象線は、盤内を長く引き回した後で処理するのではなく、盤入口～対応機器近傍で整理できるレイアウトを優先する。

具体的な片端 / 両端接地の決定は、各機器メーカーのEMC推奨と実機条件を優先する。

## 10. ダクト充填余裕

初期施工でダクトを満杯にしない。

一次方針：

- 初期配線後も将来I/O 1系統以上を追加できる余裕を残す
- WD-S / WD-Cは特にXT8増設分を見込む
- WD-Nは将来通信追加用に余裕を持つ
- WD-A / WD-Mは将来PS02や補助機器追加時に再評価する

最終的なダクトサイズは、正式電線サイズ・本数・曲げ条件を積算して決める。

## 11. ケーブル引込方向

一次基準は盤下部引込とする。

理由：

- XT1～XT8が下部にある
- 外部ケーブルを端子台へ短く導ける
- 上部冷却予約領域を塞がない
- INV上昇気流の妨げを減らせる

ただし設備レイアウト上の実ケーブルラック方向が確定した時点で最終決定する。

## 13. 成立性評価

現在のCP01 W800 × H1200 × D350 mm級では、

- 制御系を左側
- INV / モータ系を右側
- 端子台を下部3段
- 通信を独立経路

とすることで、配線分離と保守性を両立できる見込み。

盤サイズは引き続き変更しない。
