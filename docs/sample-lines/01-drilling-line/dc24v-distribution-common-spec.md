# 01 Drilling Line — DC24V分岐・PLCコモン構成

Status: Draft / 教材用回路図化前の設計基準

## 1. 目的

本ファイルは、PS01のDC24V電源をどの機能群へ分配するか、またPLC入出力のコモンをどの単位で整理するかを、回路図作成前の基準としてまとめる。

対象PLCは `FX5U-64MT/ES + FX5-C32EX/DS-TS` とし、物理I/Oは `physical-io-map.md` を正とする。

本内容は教材用の設計基準であり、実機製作では採用機器の最新マニュアル、各コモン端子定格、配線サイズ、保護機器、リスクアセスメントを有資格者が確認する。

## 2. DC24V電源の全体方針

PS01は DC24V / 10A 級を基準とする。

将来増設を考慮して、PS01直後で機能別に分岐し、1系統へ全負荷をまとめない。

概念構成：

`PS01 → DC24V分岐部 → 各機能群`

分岐群は次を基準とする。

- F24-01：PLC入力・センサ系
- F24-02：GOT / OP01表示系
- F24-03：電磁弁・空圧出力系
- F24-04：インバータ / 主軸制御信号系
- F24-05：補助リレー・通信・保守機器系
- F24-06：将来増設予約

各分岐の具体的な保護素子定格は、正式負荷電流・配線サイズ・機器仕様を確認して回路図段階で決める。

## 3. 0V系統の考え方

DC24Vの0Vは設備内で基準電位を共有するが、配線上は機能群ごとに戻り経路を整理する。

目的：

- センサ系とソレノイド系を同じ細線戻りへ集中させない
- ノイズ源の電流変動を低レベル信号へ回り込ませにくくする
- トラブル時に機能群単位で追いやすくする
- 将来増設時の誤配線を減らす

教材上の呼称：

- 0V-SEN：センサ / 入力系
- 0V-HMI：GOT / OP01系
- 0V-SOL：電磁弁 / 出力系
- 0V-DRV：INV / 主軸制御信号系
- 0V-AUX：補助機器系

実際のスター接続位置・接地との関係は、ノイズ対策とメーカー推奨回路に合わせて最終化する。

## 4. PLC入力コモン方針

FX5U内蔵入力およびFX5-C32EX/DS-TSはDC24V入力でシンク/ソース対応とする。

今回の外部センサ基準はNPN系としているため、入力側はNPNセンサと整合する方式に統一する。

重要：

- センサ型式だけでなくPLC側入力コモン結線も一致させる
- NPN / PNPを設備内で無秩序に混在させない
- X入力の電気極性とGX Works3の論理コメントを混同しない
- 実配線はFX5UおよびFX5-C32EX/DS-TSの正式配線図で最終確認する

### 4.1 入力群の論理分け

CPU内蔵入力：

- X0～X7：OP01操作入力
- X10～X15：共通 / 安全監視
- X16～X25：搬送ワーク検出
- X26～X37：ST01～ST05端確認

追加入力：

- X40～X55：加工STセンサ / CY端確認
- X56～X67：INV / 主軸状態
- X70～X77：将来予備

入力コモンの実端子単位はPLCマニュアルに合わせるが、回路図では上記機能群が追えるページ構成とする。

## 5. PLC出力コモン方針

FX5U-64MT/ESの内蔵出力はトランジスタ・シンク出力である。

出力は29点使用するが、機能上は次の群へ分けて管理する。

- Y0～Y3：INV RUN
- Y4～Y15：ST01～ST05 SOL
- Y16～Y27：CY01～CY05 SOL
- Y30：主軸RUN
- Y31～Y34：表示灯 / ブザー
- Y35～Y37：予備

### 5.1 出力設計ルール

- PLC出力のコモンごとの許容電流を超えない
- SOL群と表示群を論理上明確に分ける
- 電磁弁コイルのサージ抑制仕様を確認する
- インバータ / 主軸入力は受け側仕様を確認し、必要に応じてインターフェースを介す
- 将来出力追加時に既存コモン負荷を再計算する

実機では、PLC出力から直接負荷を駆動するか、中継リレー / インターフェースを用いるかを各負荷仕様から決定する。

## 6. 分岐ごとの負荷割付

### F24-01 — PLC入力 / センサ系

対象：

- E3Z系ワークセンサ
- D-M9系オートスイッチ
- PS12圧力スイッチ信号部
- OP01のPB / SW入力回路
- 安全回路からPLCへ返す監視信号

設計意図：センサ入力系を電磁弁系から分離して追いやすくする。

### F24-02 — GOT / 表示系

対象：

- GOT01
- PL01 投入可
- PL02 運転
- PL03 異常
- BZ01

GOTは単体負荷が大きいため、OP01への24V供給は信号線とは別系統で扱う。

### F24-03 — 電磁弁系

対象：

- ST01～ST05 10コイル
- CY01～CY05 10コイル
- AV01

電磁弁群は負荷変動とサージの影響を考慮し、センサ電源分岐と分ける。

### F24-04 — INV / 主軸制御信号系

対象：

- INV01～04 RUN入力関連
- INV01～04状態出力関連の補助電源（必要時）
- 主軸駆動機器の制御I/O

インバータ主回路電源やモータ電源はこのDC24V分岐には含めない。

### F24-05 — 補助・通信系

対象候補：

- 中継リレー
- 産業用Ethernetスイッチ
- 保守用表示機器
- 将来追加の小型補機

### F24-06 — 将来増設予約

用途：

- 追加センサ
- 追加ソレノイド
- NG判定機器
- 追加表示灯
- 通信機器

現在は未使用とし、盤内スペースと端子のみ予約する。

## 7. 端子台との対応

XT1をDC24V / 0V分配の外部接続基準とする。

既存方針：

- XT1-01～04：OP01用
- XT1-05～08：搬送センサ用
- XT1-09～12：加工STセンサ用
- XT1-13～16：INV・主軸信号用
- XT1-17～20：予備

将来回路図ではXT1の前段に機能別分岐保護を置き、どの分岐から供給されるかをクロスリファレンスする。

## 8. 電源異常時の考え方

分岐ごとに切り離せる構成とするが、PLCロジックでは電源断を異常として誤認しないよう、監視対象を明確にする。

例：

- センサ電源断 → 複数センサOFFとして現れる可能性
- ソレノイド電源断 → 指令ONでも動作端確認が来ない
- GOT電源断 → PLC自体は運転継続できる可能性

したがってGOT画面・アラーム設計では「単体機器故障」と「共通電源系統異常」を区別できる余地を持たせる。

## 9. 将来増設基準

今回の設計では、現在負荷約3.3Aに対して10A電源を採用し、将来負荷約6.8Aまでを一次想定とする。

さらに大きな増設時は、PS01を無理に使い切るのではなく、予約済みのPS02を追加して系統分離する。

PS02候補用途：

- 追加センサ群
- 追加空圧機器
- 画像処理 / 判定機器
- 通信機器
- 後付けユニット

## 10. 回路図化時のチェック項目

1. FX5U入力コモン端子の正式結線確認
2. FX5-C32EX/DS-TS入力コモン端子の正式結線確認
3. FX5U出力コモンごとの許容電流確認
4. SY3000コイルの正式仕様確認
5. INV / 主軸I/Oの入力方式・共通端子確認
6. 各分岐の保護定格決定
7. 配線サイズと電圧降下確認
8. 0V戻り経路とノイズ対策確認
9. PE / FG / シールド処理をメーカー推奨で確認
10. 安全系電源を通常24V系とどう分けるかはリスクアセスメント後に別途決定
