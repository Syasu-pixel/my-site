# 01 Drilling Line — DC24V負荷積算

Status: Draft / 教材用一次負荷計算

## 1. 目的

本設備のDC24V電源について、現時点の負荷だけでなく、将来のセンサ追加、電磁弁・中継リレー追加、ネットワーク機器・補機追加まで見込んだ余裕設計とする。

本計算は教材用の一次設計値であり、実機製作時は正式採用機器のデータシート、起動時電流、配線電圧降下、周囲温度によるディレーティング、同時通電条件を含めて再計算する。

## 2. 重要な前提

PLC `FX5U-64MT/ES` はAC100～240V電源タイプであるため、外部DC24V電源の連続負荷には直接加算しない。

GOT `GT2708-STBD` はDC24V電源タイプなので外部DC24V電源負荷へ加算する。

追加DIユニット `FX5-C32EX/DS-TS` はPLCシステム側の内部電源条件を別途確認する対象とし、本表では外部DC24V負荷へ重複計上しない。

## 6. 将来増設を前提にした設計ルール

本設備は、現状ぎりぎりの容量で設計しない。

将来、以下の追加が起こる前提で余裕を持たせる。

- 在荷・確認用センサの追加
- シリンダオートスイッチの追加
- 中継リレー / インターフェースリレーの追加
- 電磁弁ステーションの追加
- 表示灯、ブザー、盤内補機の追加
- Ethernetスイッチ等のネットワーク機器追加
- 保全用・品質確認用の小型DC24V機器追加

設計目標：

- 初期完成時は電源定格の約50%以下を目安とする
- 将来増設後でも常用負荷をおおむね70%以下に抑える考え方とする
- 盤内には追加DC24V電源を設置できるDINレール、端子、配線スペースをあらかじめ確保する
- 予備I/Oだけでなく、予備電力・予備端子・予備配線経路も設計余裕として扱う

## 7. 将来増設用の電力予算

現状約3.26Aに対して、将来増設用として次の設計予算を別枠で確保する。

| 増設枠 | 設計予算 |
|---|---:|
| センサ・スイッチ追加 | 0.8A |
| リレー・インターフェース追加 | 0.7A |
| 電磁弁・空圧機器追加 | 0.5A |
| Ethernet / 通信・補機追加 | 0.5A |
| その他未定義予備 | 1.0A |

将来増設予算合計：`約3.5A`

したがって設計上の将来想定負荷は、

`3.26A + 3.5A = 約6.8A`

とする。

## 8. 電源容量方針

### 初期PS01

初期電源は `DC24V / 10A` 級を維持する。

- 初期負荷：約3.3A → 約33%
- 将来想定負荷：約6.8A → 約68%
- 定格10Aに対して約3.2Aの余力を残す

このため、現時点で20A電源へ単純に大型化する必要はない。

### 将来拡張PS02

ただし制御盤は、将来 `DC24V / 10A級` の追加電源PS02を増設できるスペースを最初から確保する。

増設が大きくなった場合は、1台の大容量電源へ集約するより、用途ごとに電源系統を分ける案を優先検討する。

例：

- PS01：PLC周辺、センサ、GOT、基本制御
- PS02：追加電磁弁、追加補機、将来拡張機器

実機の電源系統分離、0Vの扱い、保護方式は正式回路設計時に決定する。

## 9. SY3000の同時通電について

設備制御上、ダブルソレノイドの正逆2コイルを同時ONさせないため、実運転時のSY3000電流は本表の0.292Aより通常は小さい。

ただし負荷計算では設計変更や保守時も含めた余裕を見るため、20コイル全数相当で計上する。

## 10. GOTの影響

GT2708-STBDは本設備のDC24V負荷で最大クラスの単体負荷となる。

ただし本設備は運転準備、復旧、手動操作、アラーム、生産・保全画面を重視するため、電源容量を理由にGOTを小型化しない。

## 11. 電源系統の考え方

DC24Vは機能別に分岐・保護できる構成を前提とする。

- PLC入力・センサ系
- GOT / 表示系
- 電磁弁系
- リレー・補助機器系
- 将来拡張系

具体的な保護機器容量、配線サイズ、0V共通方式は正式回路設計時に決定する。

- 現在の一次設計負荷：約3.3A

- 将来想定負荷：約6.8A
- PS01：DC24V / 10A級を維持
- 初期完成時は約33%使用
- 将来想定時でも約68%使用
- 制御盤はPS02（追加10A級）を後付けできる構成で設計する
