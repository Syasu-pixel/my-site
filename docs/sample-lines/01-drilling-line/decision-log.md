# 01 Drilling Line — Decision Log

このファイルは、チャット内で確定した重要な設計判断を議事録として残すためのログです。

## 2026-09-12 初期設計会議

### プロジェクト方針

- denkicontrol.com の初級内容を組み合わせた教材用の仮想生産ラインを作る。
- 実設備の新規設計に近い順番で、仕様書 → レイアウト → 機器 → I/O → PLC → GOTまで進める。
- 今後ほかのサンプル設備も同じ方式で追加できる構造にする。
- 重要な仕様・ルールが確定した段階でGitHubへ記録し、会話だけに情報を残さない。

### 設備概要

- MCナイロン製ワークを作業者が手投入する。
- 仮ワーク寸法：W100 × D60 × H20 mm。
- 搬送面：FL +800 mm。
- CV01～CV04の4ゾーン独立搬送。
- CV02～CV04で最大3個の待機ワークをストック。
- 下流空き条件で自動前詰め。
- 穴あけ加工STを設ける。
- 加工後は電動搬出を設けず、傾斜ローラー／シュートで自然搬出。

### タクト

- 目標タクト：30秒/個以下。
- 理論能力：120個/時。
- 加工ST設計サイクル：約25秒。
- 搬送1ゾーン：約3秒以内を目標。

### 搬送制御

- 各CVに在荷確認と通過確認を設ける。
- 各ゾーンにエアストッパーを設ける。
- ストッパー通常位置は上昇。
- 通過センサは立ち下がりで通過完了判定する。
- ただし最初からOFFで完了扱いにはせず、一度ONを確認した後のOFFを使用する。
- 搬送完了は送出元通過完了と受入先在荷確認の両方を見る。
- 離れたゾーンの同時搬送は許可する。
- 搬送タイムアウト監視を設ける。

### 入力処理

- PLCの外部X入力は原則生で本体ロジックに使わない。
- K2程度の入力確定処理を基準に内部Mへ起こす。
- 通過センサは専用処理とする。

### 出力・ラダー設計

- ダブルコイル禁止。
- 実Y出力は出力処理エリアに集約する。
- シーケンス中では内部の出力要求Mを使用する。
- 空圧系はダブルソレノイド方式。
- 前進／後退出力の同時ONは禁止。
- 指令だけで次工程へ進まず、端確認・在荷確認を取って進む。
- ラダーは大項目コメントで区切り、後から見る人が理解しやすい構成にする。

### 加工ステーション

決定した基本動作：

ストッパー着 → 搬送面切替 → 搬送面から加工エリアへ移載 → 位置決め → クランプ → 穴あけ → 加工エリアから搬送面へ戻す → 搬送面復帰 → 排出。

### 制御盤・操作盤

- CP01制御盤とOP01操作盤を分離する。
- 操作盤にはGOT、運転、停止、リセット、投入完了、手動／自動切替、非常停止等を設ける。
- 個別手動操作は主にGOTへ集約する。
- 暫定I/O規模：DI約49点、DO約29点。
- 設計上はDI64点、DO32点を確保する方向。

### 安全

- 安全PLCは今回の初級教材では採用せず、安全リレー中心のハード安全回路を基本とする。
- 非常停止、安全扉、ライトカーテン等を安全系で処理する。
- PLCは安全回路状態を監視する。
- ワーク通過部ではライトカーテンのミューティング概念に触れるが、詳細は別途扱う。

### GOT / アラーム

- GOT側に異常コメントを登録する。
- PLC側は異常判定と異常保持を担当する。
- 分類は「状態表示」「警告」「異常」「安全異常」の4段階。
- 異常／安全異常は発生、復旧、確認の履歴を残す方向。
- 単なるワーク待ちなどは異常扱いしない。

### 今後

- このプロジェクトを1号機としてサンプル設備シリーズのテンプレート化を進める。
- 共通ルールは `_shared/control-design-rules.md` に蓄積する。
- 設備固有仕様は `master-spec.md` を更新する。
- 以後、重要な決定が発生した時点でこのdecision logにも追記する。

## 2026-09-13 PLCプログラム構成決定

### 正式なプログラム構成

ラダー全体は以下の順で大項目を分ける。

1. 入力処理
2. 通過センサ処理
3. 安全・共通運転条件
4. モード・運転管理
5. CV01搬送
6. CV02搬送
7. CV03搬送
8. CV04搬送
9. 加工ST自動工程
10. 手動操作
11. 出力要求整理
12. 実出力処理
13. タイムアウト・異常監視
14. 警告・ブザー
15. GOT表示
16. 生産・タクト管理
17. メンテナンス

### 追加ルール

- 自動・手動ともに実Yを各所で直接駆動しない。
- 自動要求Mと手動要求Mを整理し、最終的な出力要求を作ってから実Yへ出力する。
- 実Yは出力処理セクションだけで使用する。
- ダブルソレノイドは最終出力段でも相互インターロックを取る。
- 通常停止では加工ステップを無条件リセットせず、途中状態を保持する方向。
- 異常時は原因を保持し、自動運転停止。原因解消後にRESETで復帰する。
- 中間位置のワーク・機構は手動で安全位置へ戻してから自動再開する。

### デバイス番号帯

- M100～：入力確定
- M200～：通過センサ処理
- M300～：設備共通・運転条件
- M400～：搬送制御
- M500～M517：加工STステップ
- M700～：警告・異常
- M800～：出力要求
- M900～：GOT表示
- D100～：工程・タクト・アラーム・設定値

## 2026-09-13 運転準備・自動起動手順を追加

### 操作手順

- 操作盤に「運転準備PB」を設ける。
- 手動／自動セレクトSWを設ける。
- 自動運転開始は「運転準備成立 → セレクトSWを自動へ → 自動起動PB」の順とする。
- 運転準備条件が不足している場合は、GOTの手動画面から各機器を個別操作し、原点・待機位置へ復旧できるようにする。
- 手動操作でも実Yを直接駆動せず、手動要求Mと干渉防止条件を通して出力する。

### 運転準備条件

運転準備PBを受け付ける前提として、少なくとも以下を確認する。

- 安全回路OK
- エア圧OK
- 設備異常なし／安全異常なし
- INV・主軸の異常なし
- 加工ST各機構が自動開始可能な位置にある
- 相反する端確認が同時成立していない
- 自動開始を阻害するワーク・機構の中間状態がない

条件成立中にオペレーターが運転準備PBを押すことで「運転準備ON」を保持する。

### 異常停止後の復旧ルール

- 設備異常または安全異常が発生した場合、自動運転保持と運転準備保持を必ずOFFする。
- 異常復帰だけで自動再始動しない。
- オペレーターは必要に応じて手動モードへ切替え、GOT手動画面で機構・ワーク位置を正常な開始可能状態へ戻す。
- 原因解消・RESET後、運転準備条件を再度成立させる。
- 運転準備PBを再度押す。
- セレクトSWを自動へ切替える。
- 自動起動PBを押して初めて自動運転を再開する。
- 異常停止後はこの再起動手順を省略できない仕様とする。

### 通常停止との区別

- 通常停止では運転準備保持を原則維持する。
- 通常停止は自動運転保持のみ解除し、設備条件に異常がなければ自動起動PBで再開可能とする。
- 異常停止・安全停止では運転準備保持を必ず解除し、運転準備からやり直す。

## 2026-09-13 搬送自動制御の基本方針

- CV01→CV02、CV02→CV03、CV03→CV04、CV04→加工STの4区間を独立した搬送区間として扱う。
- 各区間は「送出元在荷、受入先空き、自動運転中、設備運転許可、隣接区間非使用」を開始条件とする。
- 搬送開始前に送出側ストッパーを下降し、下降端確認後に必要なコンベヤ運転要求を出す。
- 搬送完了は、送出元の通過完了ワンショット、送出元在荷OFF、受入先在荷ONを基本条件とする。
- 搬送完了後はコンベヤ運転要求をOFFし、ストッパーを通常位置へ復帰させる。
- 各区間に搬送タイムアウト監視を設け、どの区間で停止したかを個別にアラーム表示する。
- 隣接する搬送区間は同時動作させず、離れた区間は条件成立時に同時搬送を許可する。
- CV04→加工STのみ、加工ST側の「受入可能」条件を追加する。

## 2026-09-13 加工ST受入可能条件を追加

### 基本方針

CV04から加工STへワークを送る前に、加工ST側が本当に受入可能な状態かを1つの内部信号へまとめる。仮に `M330 加工ST受入可能` とする。

`M330` は少なくとも以下を満たした場合のみ成立させる。

- 自動運転中である。
- 設備運転許可が成立している。
- 加工STが待機ステップである。
- 加工ST搬送位置に既存ワークがない。
- 加工治具位置に既存ワークがない。
- 搬送面切替機構が搬送側の待機位置にある。
- 横移載機構が戻り位置にある。
- 位置決めシリンダが解除位置にある。
- クランプシリンダが解除位置にある。
- 穴あけユニットが上昇原点にある。
- 主軸が停止状態である。
- 搬出満杯ではない。
- 加工ST固有異常がない。

### 受入不可時の扱い

- `M330` がOFFの間、CV04は加工STへワークを送らない。
- 受入不可をすべて異常扱いにはしない。加工中、搬出満杯、次工程待ちなどは正常な待機状態として扱う。
- 本来待機位置であるべき機構が成立しない、相反する端確認が同時成立する等は異常監視側で別途判定する。
- GOTには「加工ST受入不可」の原因を個別表示できるようにする。

### CV04→加工ST開始条件

CV04→加工STの開始条件は、他の搬送区間共通条件に加えて `M330 加工ST受入可能` を必須とする。


## 2026-09-19 加工ST横移載機構を更新

### 第4回記事設計との整合

第4回「加工ステーションのシーケンス」を詰める過程で、加工STの物理構造を再確認した。

採用する構造：

- CV04の次にCV05（加工ST搬送コンベヤ）を置く。
- CV05は通常時、縦搬送ベルトでワークを搬送する。
- 横移載時はベルト間のフリーローラーをCY01で上昇させる。
- CY02を加工側への搬入プッシャとして使用する。
- 加工位置でCY03位置決め、CY04クランプ、CY05ドリル昇降を行う。
- 加工後は専用のCY06戻しプッシャでCV05へ戻す。
- CV05在荷と両プッシャ退避を確認してフリーローラーを下降する。
- CV05縦搬送を再開し、傾斜搬出部の排出通過確認でサイクル完了とする。
- 穴あけは搬送ライン上では行わず、切りくずを搬送部から分離しやすい加工位置で行う。

### I/Oへの影響

既存正本の全I/Oを基準に再計算し、概算を次へ更新する。

- DI：約58点
- DO：約32点
- GX Works3基準：DI64 / DO32
- GX Works2版：FX3U-80MT/DS + FX2N-16EX + FX2N-8EX-ES/UL を一次構成とする

従来のGX Works2版56DI構成は、今回の追加後は不足するため更新する。
