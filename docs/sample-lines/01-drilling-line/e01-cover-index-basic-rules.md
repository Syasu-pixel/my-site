# 01 Drilling Line — E01 表紙・図面索引・基本ルール

Status: Draft / 電気図面セット基準

## 1. 設備基本情報

設備名：01 Drilling Line / 穴あけサンプルライン

教材目的：GX Works3 + MELSEC iQ-F を使い、搬送・空圧・インバータ・加工・GOT・端子台・盤内設計を一体で学べる総まとめ教材とする。

主な制御構成：

- PLC01：FX5U-64MT/ES
- DI01：FX5-C32EX/DS-TS
- GOT01：GT2708-STBD候補
- INV01～INV04：FR-E820-0.2K-1候補
- INV05：FR-E820-0.4K-1候補
- PS01：S8VK-G24024候補
- CP01：W800 × H1200 × D350 mm級
- OP01：W500 × H700 × D250 mm級

## 2. E01の役割

E01は回路そのものではなく、図面セット全体の入口とする。

## 4. 基本電源条件

教材上の一次基準：

- 設備受電：3相 AC200V級、50/60Hz
- 制御電源：DC24V
- PS01：DC24V / 10A級
- 将来PS02追加余地あり

AC主回路の遮断器定格、配線サイズ、短絡容量、保護協調、接地施工はE01では確定しない。

## 5. PLC / I/O基準

CPU：FX5U-64MT/ES

追加DI：FX5-C32EX/DS-TS

物理I/O基準：

- CPU DI：X0～X37
- 追加DI：X40～X77
- CPU DO：Y0～Y37

現在使用：

- DI：約56点
- DO：29点

予備：

- DI：X70～X77
- DO：Y35～Y37

## 6. 図面表記の基本

各信号は、可能な範囲で以下を併記する。

- PLC X/Y
- 信号名称
- 機器タグ
- 端子番号
- 線番
- ケーブルタグ
- 参照ページ

一つの信号をI/O表、端子台、配線表、回路図で別名にしない。

## 7. タグ命名

基準例：

- PLC01：PLC
- DI01：追加DI
- GOT01：GOT
- INV01～INV05：インバータ
- M01～M05：モータ
- PS01 / PS02：DC24V電源
- XT1～XT8：端子台
- CY01～CY05：加工シリンダ
- ST01～ST05：ストッパー
- PBxx：押しボタン
- SWxx：選択スイッチ
- PLxx：表示灯
- BZxx：ブザー

## 8. 線番ルール

機能群ごとに番号帯を分ける。

- 100番台：OP01操作入力
- 150番台：OP01表示・ブザー
- 200番台：共通 / 安全監視
- 300番台：搬送センサ
- 400番台：加工STセンサ
- 500番台：搬送SOL
- 600番台：加工SOL
- 700番台：INV / 主軸制御・状態
- 800番台以降：将来予約または別途定義

採用済みの主要例：

- 701～704：INV01～04 RUN
- 711～714：INV01～04 RUN feedback
- 721～724：INV01～04 fault
- 731：主軸 RUN
- 741：主軸 RUN feedback
- 742：主軸 fault

## 9. 端子台ルール

XT1～XT8を機能別に分ける。

- XT1：DC24V / 0V分配
- XT2：OP01入力
- XT3：OP01表示・報知
- XT4：搬送
- XT5：加工ST
- XT6：INV I/O
- XT7：安全監視
- XT8：将来拡張

通常端子一次候補は5.2 mmピッチ級を基準とし、PEは専用PE端子を使う。

## 10. ケーブルタグルール

基本プレフィックス：

- CBL-OP-*：操作盤
- CBL-GOT-*：GOT電源 / Ethernet
- CBL-CV-*：搬送
- CBL-PROC-*：加工ST
- CBL-INV-*：INV制御
- CBL-MTR-*：モータ系

ケーブルタグは端子台表、盤間配線、クロスリファレンスで統一する。

## 11. 盤内レイアウト基準

CP01は `control-panel-final-layout-spec.md` を正とする。

基準：

- W800 × H1200 × D350 mm級
- 左側：PLC / PS / 弱電制御
- 右側：INV5台 / モータ系
- 下部：XT1～XT8 / PE / SHIELD
- 上部：冷却予約
- 下部引込

初期盤クーラーなし、後付け余地あり。

## 12. クロスリファレンス

E18を信号追跡の正とする。

最低限追える項目：

`PLC I/O → 信号 → 機器 → 端子 → 線番 → ケーブル → 参照ページ`

例：

`X42 → CY01搬送面復帰端 → XT5-03 → 線番423 → CBL-PROC-* → E09`

## 13. 安全関連

E07 / E17で扱うのは通常PLCへ返す監視信号のみ。

以下の安全機能は通常PLC回路だけで成立させない。

- 非常停止
- 安全扉
- ライトカーテン
- 安全リレー / 安全PLC
- STO
- 空圧安全排気

安全回路の詳細はリスクアセスメントと必要安全性能が確定した後に別ページ群で扱う。

## 14. 変更管理

I/O、端子、線番、機器タグを変更した場合は、少なくとも以下を同時更新する。

1. physical-io-map.md
2. terminal-block-spec.md
3. 対応wiring schedule
4. E06～E18該当ページ
5. E18 cross reference
6. GX Works3デバイスコメント
7. 必要に応じてBOM / 盤レイアウト

一部だけ変更して不整合を残さない。

## 15. 改訂欄の考え方

図面化時はE01に改訂欄を設ける。

最低項目：

- Revision
- Date
- Change summary
- Drawn / Checked

教材用Markdown段階ではGit履歴を変更履歴の一次記録として扱う。

## 16. 教材上の注意

本図面セットは学習用の設計資料であり、そのまま実機施工指示書として使用するものではない。

特にAC主回路、保護、接地、安全回路、短絡容量、電線選定、施工方法は、正式採用機器の最新資料、現場条件、規格、資格者による確認を必要とする。
