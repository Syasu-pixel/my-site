# 01 Drilling Line — E02 電源系統概要

Status: Draft / 回路図ページ定義

## 1. 目的

E02は、設備全体の電源の流れを単線系統レベルで示すページとする。

本ページでは詳細な遮断器定格や保護協調までは確定せず、どの電源がどの負荷群へ供給されるかを一目で追える構成にする。

実機製作では、受電条件、短絡電流、配線サイズ、遮断器定格、接地、保護協調、規格要求を有資格者が再確認する。

## 2. 基本受電条件

暫定基準：

- 設備受電：三相 AC200V級 50/60Hz
- 主回路：INV01～INV04、主軸駆動系
- 制御電源：PS01でAC200V級からDC24Vへ変換
- 将来：PS02 DC24V電源追加余地を確保

正式な主幹容量は、INV、主軸、PS01、将来余裕を含めた負荷計算後に決める。

## 3. E02 単線構成イメージ

```text
設備受電 3φ AC200V級
        │
      Q0 主幹
        │
        ├─ Q1 → INV01 → CV01モータ
        ├─ Q2 → INV02 → CV02モータ
        ├─ Q3 → INV03 → CV03モータ
        ├─ Q4 → INV04 → CV04モータ
        ├─ Q5 → 主軸駆動機器 → M05 主軸モータ
        │
        └─ Q6 → PS01 AC/DC → DC24V BUS
                         │
                         ├─ F24-01 PLC入力・センサ
                         ├─ F24-02 GOT・表示
                         ├─ F24-03 SOL・空圧出力
                         ├─ F24-04 INV・主軸制御I/O
                         ├─ F24-05 補助・通信
                         └─ F24-06 将来増設予約
```

## 4. ページ上の表記ルール

E02では、詳細な端子番号よりも系統の関係を優先する。

必須表記：

- 受電種別
- 主幹機器タグ
- 各主要分岐タグ
- INV01～INV04
- 主軸駆動系
- PS01
- PS02予約
- DC24V BUS
- F24-01～06
- PE系統への参照

詳細は次ページへクロスリファレンスする。

- AC主回路詳細：E03
- DC24V分岐詳細：E04
- PLC / I/O：E05
- PE / シールド：E17

## 5. 機器タグ方針

暫定タグ：

- Q0：主幹遮断・開閉機器
- Q1～Q4：INV01～04分岐
- Q5：主軸駆動系分岐
- Q6：PS01分岐
- PS01：DC24V / 10A級
- PS02：将来DC24V / 10A級予約
- INV01～INV04：CV01～CV04用インバータ
- M01～M04：CV01～CV04モータ
- M05：穴あけ主軸モータ

実際の遮断器種別・定格・補助接点有無は未確定とする。

## 6. 将来余裕

E02上でも将来余裕を明示する。

- PS02追加可能
- 予備分岐1系統以上
- 将来追加DO / 通信機器用24V余力
- 盤内スペース・端子台・ダクト余裕

現在必要負荷だけで主幹・盤内構成を完全固定しない。

## 7. 安全系との関係

非常停止、安全扉、ライトカーテン、STO、空圧残圧排気等の安全機能は、E02の通常電源単線図だけで成立させない。

E02では安全系電源が別扱いになる可能性を注記し、詳細はリスクアセスメント後の安全回路ページへ分離する。
