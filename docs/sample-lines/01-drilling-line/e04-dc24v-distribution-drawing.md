# 01 Drilling Line — E04 DC24V電源・分岐保護

Status: Draft / 回路図ページ定義

## 1. 目的

E04はPS01以降のDC24V電源分配を、回路図へそのまま転記しやすい形で整理する。

本ページでは分岐系統、負荷群、0V戻り系統、端子台との対応を示す。

各分岐の保護定格、配線サイズ、ヒューズ/ブレーカ種別は、正式負荷電流とメーカー仕様から最終決定する。

## 2. 全体構成

```text
PS01 +24V
   │
   ├─ F24-01 ─ PLC入力 / センサ系
   ├─ F24-02 ─ GOT / OP01表示系
   ├─ F24-03 ─ SOL / 空圧出力系
   ├─ F24-04 ─ INV / 主軸制御I/O系
   ├─ F24-05 ─ 補助 / 通信系
   └─ F24-06 ─ 将来増設予約

PS01 0V
   │
   ├─ 0V-SEN
   ├─ 0V-HMI
   ├─ 0V-SOL
   ├─ 0V-DRV
   └─ 0V-AUX
```

0Vは基準電位を共有するが、配線経路は機能群ごとに整理して追跡性とノイズ耐性を確保する。

## 3. 分岐別割付

| 分岐 | 主負荷 | 主な接続先 | 0V系統 |
|---|---|---|---|
| F24-01 | PLC入力・センサ | XT1搬送/加工センサ、PLC入力系 | 0V-SEN |
| F24-02 | GOT・表示・ブザー | GOT01、PL01～03、BZ01 | 0V-HMI |
| F24-03 | ST/CY/AV電磁弁 | ST01～05、CY01～05、AV01 | 0V-SOL |
| F24-04 | INV/主軸制御I/O | XT6、主軸制御I/O | 0V-DRV |
| F24-05 | 補助・通信 | 中継リレー、Ethernet SW等 | 0V-AUX |
| F24-06 | 将来増設 | XT8、追加I/O周辺 | 予備 |

## 4. XT1との対応

E04ではXT1への24V/0V供給元を明示する。

基準：

- XT1-01～04：OP01用
- XT1-05～08：搬送センサ用
- XT1-09～12：加工STセンサ用
- XT1-13～16：INV・主軸信号用
- XT1-17～20：予備

将来増設端子はXT8側へ逃がし、既設XT1を過密にしない。

## 5. 分岐保護表現

各F24系統は回路図上で独立分岐として描く。

表記例：

```text
+24V BUS ─ [F24-01 保護素子] ─ +24V-SEN
+24V BUS ─ [F24-02 保護素子] ─ +24V-HMI
+24V BUS ─ [F24-03 保護素子] ─ +24V-SOL
```

現時点では定格値を固定せず、`TBD after load/wire check` とする。

## 6. 将来PS02追加時

PS02はPS01と無条件に並列接続しない。

将来負荷増加時は、機能群を分離して移管する構成を優先する。

候補：

- 追加センサ
- 追加ソレノイド
- 画像処理 / 判定機器
- 追加通信機器
- 将来DOユニット周辺負荷

E04ではPS02予約ブロックと、F24-06または新規F24-1x系統へ切り出せる余地を描く。

## 7. 異常切り分けの考え方

分岐電源断が単体故障に見えないよう、ページ上では系統名を明示する。

例：

- F24-01断 → 複数センサOFF
- F24-03断 → 指令ありでも端確認なし
- F24-02断 → GOT/表示のみ喪失

将来必要なら各分岐の電源監視を追加できるよう、XT8/予備DIに余地を残す。
