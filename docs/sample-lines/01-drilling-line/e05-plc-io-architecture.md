# 01 Drilling Line — E05 PLC本体・I/O構成図

Status: Draft / 回路図ページ定義

## 1. 目的

E05は、PLC本体、追加DI、現在の物理X/Y範囲、将来I/O増設予約を1ページで把握できる構成図とする。

対象：

- PLC01：FX5U-64MT/ES
- DI01：FX5-C32EX/DS-TS
- CNV01：FX5-CNV-IF
- 将来DOユニット予約
- Ethernet接続先GOT01

## 2. 基本構成

```text
PLC01 FX5U-64MT/ES
 ├─ Built-in DI : X0～X37
 ├─ Built-in DO : Y0～Y37
 ├─ Ethernet ───────── GOT01
 └─ FX5 expansion path
        │
      CNV01 FX5-CNV-IF
        │
      DI01 FX5-C32EX/DS-TS
        └─ DI : X40～X77

[ FUTURE DO MODULE SPACE ]
16～32 points class / model TBD
アドレス未割付
```

## 3. 入力割付概要

| 範囲 | 機能 |
|---|---|
| X0～X7 | OP01操作入力 |
| X10～X15 | 共通・安全監視 |
| X16～X25 | 搬送ワーク検出 |
| X26～X37 | ST01～ST05端確認 |
| X40～X55 | 加工ST / CY端確認 |
| X56～X67 | INV / 主軸フィードバック |
| X70～X77 | 予備DI |

DI使用：56点

DI予備：8点

## 4. 出力割付概要

| 範囲 | 機能 |
|---|---|
| Y0～Y3 | INV01～04 RUN |
| Y4～Y15 | ST01～05 SOL |
| Y16～Y27 | CY01～05 SOL |
| Y30 | 主軸RUN |
| Y31～Y34 | 表示灯 / ブザー |
| Y35～Y37 | 予備DO |

DO使用：29点

DO予備：3点

Y35～Y37は小変更用とし、4点以上の出力増設は将来DOユニット追加を基本とする。

## 5. 将来DO増設予約

現時点では追加DOの正式形名・点数・物理Yアドレスを確定しない。

E05には以下を明示する。

- PLC周辺に16～32点級DOユニット1台分の盤内スペース予約
- DINレール余裕
- DC24V分岐余裕
- XT8将来DO端子 XT8-09～16
- 配線ダクト余裕
- GX Works3モジュール構成で正式追加後にXY割付を確認すること

架空のYアドレスは先に振らない。

## 6. Ethernet構成

現状はPLC01とGOT01の直接Ethernet接続を基本とする。

```text
PLC01 Ethernet ─ CBL-GOT-01 ─ GOT01
```

将来、保守PC、産業用Ethernetスイッチ、通信機器を追加する場合は、CP01内の予約スペースを使用する。

## 7. 入力コモン方針

外部センサはNPN系を基準とし、PLC入力側のコモン結線はこれと整合させる。

E05では機能構成のみ示し、実際のCOM端子結線はE06～E10の入力ページと正式マニュアルで照合する。

## 8. 出力コモン方針

PLC01内蔵出力はトランジスタ・シンク出力を基準とする。

E05では出力群を機能別に示し、詳細負荷接続はE11～E14へ分離する。

特にSOL群は、

- コモン許容電流
- コイル電流
- サージ抑制
- 相反出力インターロック

を最終回路図で確認する。

## 9. 端子台との関係

入力・出力の外部接続は以下へ展開する。

- XT2 / XT3：OP01
- XT4：搬送・ST
- XT5：加工ST・CY・主軸
- XT6：INV
- XT7：安全監視
- XT8：将来拡張

E05では端子台の詳細番号を詰め込まず、各I/Oページへ参照を飛ばす。

## 10. ページ内注記

E05の図面欄外に以下を注記する。

- X/Y番号は8進数表記
- 現在の物理I/O基準は `physical-io-map.md`
- GX Works3実装時にモジュール構成とXY Assignmentを再確認
- 予備I/Oも図面上で省略しない
- 将来DOユニットは未選定のためアドレス未確定
- 安全機能は通常PLC I/Oだけで成立させない
