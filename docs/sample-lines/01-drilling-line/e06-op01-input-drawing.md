# 01 Drilling Line — E06 OP01操作入力回路

Status: Draft / 回路図作成基準

## 1. 対象

E06はOP01の通常操作入力 X0～X7 を扱う。

対象信号：

| PLC | 信号 | 端子 | 線番 | 操作器 |
|---|---|---|---:|---|
| X0 | 運転準備PB | XT2-01 | 101 | PB01 |
| X1 | 自動起動PB | XT2-02 | 102 | PB02 |
| X2 | 停止PB | XT2-03 | 103 | PB03 |
| X3 | RESET PB | XT2-04 | 104 | PB04 |
| X4 | 投入完了PB | XT2-05 | 105 | PB05 |
| X5 | 手動セレクトSW | XT2-06 | 106 | SW01-MAN |
| X6 | 自動セレクトSW | XT2-07 | 107 | SW01-AUTO |
| X7 | ブザー停止PB | XT2-08 | 108 | PB06 |

## 2. 配線経路

`F24-01 → OP01操作器共通 → PB/SW接点 → CBL-OP-01 → XT2 → PLC X入力`

OP01側端子は XTOP1-01～08 を使用する。

## 3. 回路図表現

各入力回路には以下を併記する。

- 操作器タグ
- 信号名称
- 線番
- OP01端子
- 盤間ケーブルタグ / 芯番
- CP01端子
- PLC物理X
- 参照ページ

## 4. 予備

XT2-09～12およびCBL-OP-01芯09～12を将来DI予備として残す。

## 5. 制御上の注意

- X入力はラダー各所で直接多用せず、入力処理セクションでMへ写像する。
- PBは原則ワンショット化して要求を作る。
- SW01は手動/自動の状態信号として使用し、同時成立などの不整合は入力処理で検出できる構成とする。
- 非常停止EMG01はE06に含めない。安全機能は別設計、PLC監視信号はE07で扱う。
