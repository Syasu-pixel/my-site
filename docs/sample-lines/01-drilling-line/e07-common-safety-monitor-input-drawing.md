# 01 Drilling Line — E07 共通条件・安全監視入力回路

Status: Draft / 通常PLC監視回路の整理

## 1. 対象

E07は X10～X15 の共通条件・安全監視入力を扱う。

| PLC | 監視信号 | CP01端子 |
|---|---|---|
| X10 | 安全回路OK | XT7-01 |
| X11 | エア圧OK | XT7-02 |
| X12 | 非常停止系正常監視 | XT7-03 |
| X13 | 安全扉閉確認 | XT7-04 |
| X14 | ライトカーテンクリア | XT7-05 |
| X15 | 安全リレー正常監視 | XT7-06 |

XT7-07～12は将来監視信号用予備とする。

## 2. 位置付け

このページは**安全機能そのものを構成する回路ではない**。

E07で扱うのは、安全回路・圧力監視などから通常PLCへ返される状態監視信号のみとする。

非常停止、安全扉、ライトカーテン、安全リレー、STO、残圧排気等の安全機能詳細は、実機ではリスクアセスメントと必要安全性能に基づく別設計とする。

## 3. 運転準備との関係

X10～X15は、入力処理後の内部状態を経由して `M320 運転準備条件OK` の成立条件へ使用する。

GOT運転準備画面では、各監視信号を個別表示し「なぜ運転準備できないか」を確認できるようにする。

## 4. エア圧監視

X11はPS12圧力スイッチ由来の監視信号とする。

低圧時は、少なくとも新規自動動作を許可しない方向とし、異常処理は alarm-spec.md の A301 と整合させる。

## 5. 回路図表現ルール

各監視入力には、信号源、安全側装置または圧力スイッチ、XT7端子、PLC X、信号名称、参照先を記載する。

安全側接点の詳細な二重化・診断回路は本ページに描かない。
