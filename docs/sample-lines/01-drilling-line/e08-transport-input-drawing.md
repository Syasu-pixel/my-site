## 2. 電源系

搬送センサはF24-01からXT1搬送センサ分岐を経由してDC24Vを供給する。

入力方式は設備内で統一し、NPN基準のセンサ選定とPLC入力コモンを整合させる。正式結線は採用機器の最新配線図で確認する。

## 3. 通過センサ処理

CV01～CV04通過センサは、単純なOFF判定を完了条件にしない。

制御上は、

`通過センサON確認 → ON→OFF立下り → 通過完了ワンショット`

を基本とする。

## 4. 在荷センサ処理

在荷センサは各ゾーンのワーク占有状態を示す。

搬送完了判定は、通過完了だけでなく、原則として

`送出元在荷OFF + 搬送先在荷ON`

を合わせて確認する。

## 5. ストッパー端確認

ST01～ST05は通常上昇位置を基準とする。

PLCは指令だけで次工程へ進まず、対応する上昇端 / 下降端の実確認後にステップを進める。
