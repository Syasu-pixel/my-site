# 01 Drilling Line — E09 加工ST入力回路

Status: Draft / 回路図作成基準

## 1. 対象

E09は加工ステーション入力 X40～X55 を扱う。

### ワーク・搬出検出

| PLC | 信号 | XT5 | 線番 | 現場タグ |
|---|---|---|---:|---|
| X40 | 加工ST搬送位置在荷 | XT5-01 | 401 | PS-PROC-IN |
| X41 | 加工治具位置在荷 | XT5-02 | 402 | PS-JIG |
| X54 | 搬出満杯 | XT5-13 | 403 | PS-OUT-FULL |
| X55 | 加工ST排出通過 | XT5-14 | 404 | PS-PROC-OUT |

### CY01～CY05 端確認

| PLC | 信号 | XT5 | 線番 | 現場タグ |
|---|---|---|---:|---|
| X42 | CY01搬送面復帰端 | XT5-03 | 421 | LS-CY01-H |
| X43 | CY01加工側端 | XT5-04 | 422 | LS-CY01-W |
| X44 | CY02後退端 | XT5-05 | 423 | LS-CY02-R |
| X45 | CY02前進端 | XT5-06 | 424 | LS-CY02-F |
| X46 | CY03解除端 | XT5-07 | 425 | LS-CY03-R |
| X47 | CY03位置決め端 | XT5-08 | 426 | LS-CY03-P |
| X50 | CY04解除端 | XT5-09 | 427 | LS-CY04-R |
| X51 | CY04クランプ端 | XT5-10 | 428 | LS-CY04-C |
| X52 | CY05上昇端 | XT5-11 | 429 | LS-CY05-U |
| X53 | CY05下降端 | XT5-12 | 430 | LS-CY05-D |

XT5-17～20は加工入力予備とする。

## 2. 電源系

加工STセンサ・オートスイッチはF24-01からXT1加工ST分岐を経由してDC24Vを供給する。

入力方式はNPN基準で統一する方針とし、正式結線はPLC・センサ双方の最新マニュアルで最終確認する。

## 3. 加工ステップとの対応

主要確認条件：

- M503：CY01加工側端 X43
- M504：CY02前進端 X45 + 加工治具位置在荷 X41 + 加工ST搬送位置在荷OFF
- M505：CY03位置決め端 X47
- M506：CY04クランプ端 X51
- M508：CY05下降端 X53
- M509：CY05上昇端 X52
- M510：CY04解除端 X50
- M511：CY03解除端 X46
- M512：CY02後退端 X44 + 加工治具位置在荷OFF + 加工ST搬送位置在荷ON
- M513：CY01搬送面復帰端 X42
- M515：加工ST排出通過 X55 + 加工ST搬送位置在荷OFF

## 4. 搬出満杯

X54搬出満杯は原則として待機条件とする。

満杯時は新規排出・新規加工を待たせるが、単独では設備故障として扱わない。GOTでは状態/警告として表示する。

## 5. センサ矛盾監視

同一シリンダの両端信号が同時成立する、長時間どちらも成立しない等は、配線断・センサずれ・機構異常の診断候補として扱う余地を持たせる。
