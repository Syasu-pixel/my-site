# 01 Drilling Line — E10 INV・主軸フィードバック入力回路

Status: Draft / 回路図作成基準

## 1. 対象

E10はインバータ・主軸の状態入力 X56～X67 と、予備X70～X77を扱う。

| X56 | INV01運転確認 | XT6-11 | 711 | INV01 |
| X57 | INV02運転確認 | XT6-12 | 712 | INV02 |
| X60 | INV03運転確認 | XT6-13 | 713 | INV03 |
| X61 | INV04運転確認 | XT6-14 | 714 | INV04 |

X70～X77は将来DI予備として図面上もSPARE表示する。

## 2. 制御上の意味

RUN指令と運転確認は分けて扱う。

`Y RUN指令ON` は運転要求であり、実際に駆動機器が運転状態へ入ったことはX側フィードバックで確認する。

規定時間内に運転確認が成立しない場合は、タイムアウト監視対象とする。

## 3. INV異常

X62～X65の異常信号は入力処理後に内部Mへ写像し、A401～A404のアラーム判定へ使用する。

リセット方式や異常出力論理は採用インバータの正式仕様に合わせて最終化する。

## 4. 主軸運転確認

加工ステップM507で主軸RUNを要求し、X66主軸運転確認成立後に次工程へ進む。

M508ドリル下降許可には主軸運転確認を含める。

X67主軸異常成立時は加工動作継続を許可しない。

## 5. 予備入力の考え方

X70～X77は現時点で固定用途を割り当てない。

将来候補：

- 周波数到達
- 速度到達
- 工具回転確認
- クランプ圧確認
- 通信異常
- NG判定機器
