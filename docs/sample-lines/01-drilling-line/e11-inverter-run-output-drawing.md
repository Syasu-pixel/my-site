# 01 Drilling Line — E11 INV RUN出力回路

Status: Draft / 教材用回路図詳細

## 1. 目的

E11はCV01～CV04用インバータ INV01～INV04 へのPLC運転指令を整理する。

対象出力：

- Y0：INV01 RUN
- Y1：INV02 RUN
- Y2：INV03 RUN
- Y3：INV04 RUN

通常制御の出力要求は、

`自動要求M / 手動要求M → 共通要求M → 実Y`

の順で統合し、Yを複数箇所から直接駆動しない。

## 2. 出力一覧

| PLC出力 | 共通要求M | 端子 | 線番 | 信号 | 対象 |
|---|---|---|---:|---|---|
| Y0 | M860 | XT6-01 | 701 | INV01 RUN | CV01 |
| Y1 | M861 | XT6-02 | 702 | INV02 RUN | CV02 |
| Y2 | M862 | XT6-03 | 703 | INV03 RUN | CV03 |
| Y3 | M863 | XT6-04 | 704 | INV04 RUN | CV04 |

## 3. 論理構成

各INVのRUN出力は、自動運転時・手動JOG時の要求を共通化する。

例：CV01

```text
M800  自動CV01要求 ─┐
                     ├→ M860 共通CV01要求 → Y0
M830  手動CV01要求 ─┘
```

同様にCV02～04も構成する。

## 4. 運転許可条件

共通要求MからYへ出す前に、通常制御上の最低条件を満たす。

例：

- 安全回路監視OK
- 設備異常なし
- 対応INV異常なし
- 手動時は手動モードかつ自動停止
- 自動時はM305自動運転中

安全機能そのものは通常PLC出力では成立させない。

## 5. 運転確認との関係

RUN指令と運転確認を同一扱いにしない。

- Y0～Y3：指令
- X56～X61：INV運転確認

転送シーケンスでは必要に応じてRUN指令後の運転確認成立を監視し、異常・タイムアウト診断に利用する。

## 6. 速度指令

初期教材ではINV側固定速度設定を基準とする。

PLCからのアナログ速度指令、段速、通信指令は将来拡張とし、XT6-05～08等の予備端子を利用する。

## 7. 電気的インターフェース

INVの実際のデジタル入力端子、共通端子、シンク/ソース条件は採用機器の正式仕様で最終確認する。

必要に応じて中継リレーまたはインターフェースを介し、PLCトランジスタ出力の定格・極性・漏れ電流条件を満たす。

## 8. 図面表現

E11では各4回路を同じフォーマットで並べる。

```text
PLC Y0
  ↓
XT6-01
  ↓ 701
INV01 RUN入力
```

参照：運転確認・異常はE10、AC主回路はE03。
