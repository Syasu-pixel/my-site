# 01 Drilling Line — E12 ST01～ST05 SOL出力回路

Status: Draft / 教材用回路図詳細

## 1. 目的

E12は搬送ストッパーST01～ST05のダブルソレノイド出力を整理する。

対象：Y4～Y15。

## 2. 出力一覧

| PLC出力 | 共通要求M | 端子 | 線番 | 信号 |
|---|---|---|---:|---|
| Y4 | M864 | XT4-21 | 501 | ST01 上昇SOL |
| Y5 | M865 | XT4-22 | 502 | ST01 下降SOL |
| Y6 | M866 | XT4-23 | 503 | ST02 上昇SOL |
| Y7 | M867 | XT4-24 | 504 | ST02 下降SOL |
| Y10 | M868 | XT4-25 | 505 | ST03 上昇SOL |
| Y11 | M869 | XT4-26 | 506 | ST03 下降SOL |
| Y12 | M870 | XT4-27 | 507 | ST04 上昇SOL |
| Y13 | M871 | XT4-28 | 508 | ST04 下降SOL |
| Y14 | M872 | XT4-29 | 509 | ST05 上昇SOL |
| Y15 | M873 | XT4-30 | 510 | ST05 下降SOL |

## 3. 相反出力禁止

各ストッパーは上昇・下降を同時ONさせない。

例：ST01

```text
M864 上昇要求 ----┐
                   ├→ 相互排他 → Y4 / Y5
M865 下降要求 ----┘
```

両方の要求が同時成立した場合は、教材基準として両出力OFFとし、必要なら診断ビット・アラームを立てる。

## 4. 自動・手動統合

ST01の例：

- 自動上昇 M804
- 手動上昇 M834
- 共通上昇 M864
- 自動下降 M805
- 手動下降 M835
- 共通下降 M865

他STも同じ構造とする。

## 5. フィードバック

指令だけで工程を進めず、X26～X37の実端確認を待つ。

例：ST01

- 上昇完了：X26
- 下降完了：X27

タイムアウト時はA111～A115系のストッパー異常へつなげる。

## 6. 通常状態

ストッパーは基本状態をUPとし、ワークを送り出すときだけDOWNへ指令する。

停止・復旧時も無条件にUPへ戻すのではなく、機械状態・ワーク状態・復旧手順を考慮して指令する。

## 7. 電源・保護

SOL系はF24-03から供給する。

実機ではMV01の正式コイル仕様、サージ抑制、PLC出力の許容電流・コモン容量を確認し、必要なら中継インターフェースを追加する。

## 8. 図面表現

各STを2出力1組で表現する。

```text
Y4 → XT4-21 → 501 → SOL-ST01-U
Y5 → XT4-22 → 502 → SOL-ST01-D
```

フィードバックはE08を参照する。
