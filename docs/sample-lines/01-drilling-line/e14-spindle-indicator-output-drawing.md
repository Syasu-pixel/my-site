# 01 Drilling Line — E14 主軸・表示・ブザー出力回路

Status: Draft / 教材用回路図詳細

## 1. 目的

E14は主軸RUN、OP01表示灯、ブザー、およびCPU内蔵出力の残予備を整理する。

対象：Y30～Y37。

## 2. 出力一覧

| PLC出力 | 共通要求M | 端子 | 線番 | 信号 | 対象 |
|---|---|---|---:|---|---|
| Y30 | M884 | XT5-31 | 731 | 穴あけ主軸RUN | 主軸駆動機器 |
| Y31 | M885 | XT3-01 | 151 | 投入可表示灯 | PL01 |
| Y32 | M886 | XT3-02 | 152 | 運転表示灯 | PL02 |
| Y33 | M887 | XT3-03 | 153 | 異常表示灯 | PL03 |
| Y34 | M888 | XT3-04 | 154 | ブザー | BZ01 |
| Y35 | - | XT3-05予定 | 155 | SPARE DO-1 | 将来 |
| Y36 | - | XT3-06予定 | 156 | SPARE DO-2 | 将来 |
| Y37 | - | XT3-07予定 | 157 | SPARE DO-3 | 将来 |

## 3. 主軸RUN

主軸RUNはM884共通要求からY30へ出す。

主軸はモータへ直接接続せず、主軸駆動機器の運転入力へ指令する。

加工シーケンスではRUN指令後にX66主軸運転確認を待ち、確認成立後にドリル下降工程へ進む。

## 4. 投入可表示灯 PL01

PL01は単純な設備電源ON表示ではなく、オペレータが新しいワークを投入してよい状態を示す。

代表条件：

- 設備が投入受入可能
- 上流投入位置に新規ワークを受けられる
- 搬送禁止・異常・安全条件不成立でない

最終条件は運転ロジック確定時にM885へ集約する。

## 5. 運転表示灯 PL02

PL02は原則M305自動運転中を基準とする。

運転準備だけでは点灯させず、実際に自動運転状態へ入ったことを示す。

## 6. 異常表示灯 PL03

PL03は設備異常または安全系異常の代表表示とする。

警告・待機状態まで全て異常灯へまとめず、GOT側で状態・警告・異常を分けて表示する。

## 7. ブザー BZ01

ブザーは重大な異常・安全停止など、オペレータ注意喚起が必要なイベントで鳴動する。

PB06ブザー停止は音だけを停止し、異常そのものを解除しない。

RESETとは独立させる。

## 8. 予備出力 Y35～Y37

Y35～Y37は小規模な追加用に残す。

例：

- 追加表示灯
- 小型補助リレー
- 追加報知

4点以上の追加DOが必要になった場合は、予約済みの将来DOユニットを追加する方針とする。

## 9. 電源系統

- PL01～03 / BZ01：F24-02
- 主軸制御信号：F24-04

負荷定格、サージ、極性、PLC出力コモン容量は正式部品仕様で最終確認する。

## 10. 図面表現

```text
Y30 → XT5-31 → 731 → 主軸駆動機器 RUN
Y31 → XT3-01 → 151 → PL01
Y32 → XT3-02 → 152 → PL02
Y33 → XT3-03 → 153 → PL03
Y34 → XT3-04 → 154 → BZ01
```

Y35～Y37はSPAREとして図面上にも明示する。
