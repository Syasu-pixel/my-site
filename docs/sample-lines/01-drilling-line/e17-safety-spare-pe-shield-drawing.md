# 01 Drilling Line — E17 XT7 / XT8 / PE・シールド図

Status: Draft / 電気図面具体化用

## 1. 目的

E17は、通常PLCが監視する安全関連状態、将来拡張端子台XT8、PE・FG・シールド処理の整理ページとする。

本ページは安全機能そのものの実回路図ではない。非常停止、安全扉、ライトカーテン、安全リレー、駆動停止、残圧排気などの安全機能は、実機ではリスクアセスメントと必要安全性能に基づき別途設計する。

## 2. XT7 — 安全関連監視入力

| XT7 | PLC | 信号 | 用途 |
|---|---|---|---|
| 01 | X10 | 安全回路OK | 通常制御の運転許可判定・GOT表示 |
| 02 | X11 | エア圧OK | 空圧成立監視 |
| 03 | X12 | 非常停止系正常監視 | 非常停止系の状態表示用 |
| 04 | X13 | 安全扉閉確認 | 扉状態表示・通常運転条件 |
| 05 | X14 | ライトカーテンクリア | 状態表示・通常運転条件 |
| 06 | X15 | 安全リレー正常監視 | 安全系状態表示用 |
| 07〜12 | - | SPARE | 将来監視入力 |

E07の入力回路詳細と相互参照する。

## 3. 重要な分離ルール

XT7に入るX10〜X15は、通常PLCが安全機能を実行するための入力ではなく、

- 運転準備条件
- GOT状態表示
- アラーム / ブロック理由表示
- 通常制御側の許可判定

に使用する監視信号である。

安全機能本体を通常PLCのX/Yだけで成立させない。

## 4. XT8 — 将来拡張端子台

XT8は約24端子を基準に、将来改造を既設端子台へ無理に割り込ませないための予約領域とする。

推奨予約：

| XT8 | 予約用途 |
|---|---|
| 01〜08 | 将来DI |
| 09〜16 | 将来DO |
| 17〜18 | +24V予備分配 |
| 19〜20 | 0V予備分配 |
| 21〜24 | 完全予備 |

現時点では架空のX/Yアドレスを割り当てない。

## 5. 将来I/Oとの関係

現行予備：

- DI：X70〜X77 8点
- DO：Y35〜Y37 3点

小規模増設は現行予備を使用できるが、DOが4点以上増える場合は、E05で予約した将来DOユニットを追加する方針とする。

追加I/O導入時は、

`追加I/O → XT8 → 新規現場機器`

を基本経路とし、XT4 / XT5 / XT6の既設配線を崩しにくくする。

## 6. PE / FG / シールドの整理

E17には盤内のPEバー / PE端子群と、シールド処理位置を概念的に表示する。

対象候補：

- CP01筐体
- OP01筐体
- INV01〜04
- 主軸駆動機器
- モータフレーム
- GOT / 通信機器でメーカーが要求するFG
- シールド付きケーブル

実際の接地方式、シールド片端 / 両端処理、クランプ位置、EMC対策は採用機器のメーカー推奨と設備条件に合わせて最終決定する。

## 7. 配線分離

少なくとも以下は無条件に同一経路へまとめない。

- インバータ出力〜モータ
- 主軸モータ線
- DC24Vセンサ / PLC入力
- Ethernet
- 安全関連配線

PE・シールド処理部は保守時に確認しやすい位置へ集約する。

## 8. 図面上の注意書き

E17には次の注記を明記する。

> 本ページに示すX10〜X15は通常PLC監視信号であり、安全機能本体ではない。安全回路は別途リスクアセスメントと採用機器仕様に基づいて設計する。

## 9. 将来安全仕様が確定した後

安全設計が確定した段階で、必要なら別ページ群 `S01〜` を新設し、通常電気図面E系と分離する。

E17はその際も「PLC監視側の受け口」として残す。
