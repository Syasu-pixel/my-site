# 01 Drilling Line — 電気回路図ページ構成

Status: Draft / E01～E18 ページ定義完了

## 1. 目的

本資料は、設備仕様、I/O、端子台、盤間配線、DC24V分配、インバータ・主軸I/Oを実際の電気回路図へ落とし込むためのページ構成を定める。

安全回路については通常制御とページを分離し、実機向け詳細回路はリスクアセスメント・必要安全性能・採用安全機器が確定してから作成する。

## 3. ページ設計方針

### 3.1 1ページ1機能群

異なる機能を1ページへ詰め込みすぎず、保守時に目的の回路を探しやすくする。

### 3.2 PLC入出力は物理I/O順

図面では原則としてPLC物理アドレス順に並べる。

- X0 → X7
- X10 → X15
- X16 → X37
- X40 → X77
- Y0 → Y37

GX Works3のI/O割付と回路図を直接照合しやすくする。

### 3.3 端子台・線番・タグを併記

各信号には可能な範囲で以下を同時表示する。

- PLC X/Y
- 信号名称
- 機器タグ
- 端子台番号
- 線番
- ケーブルタグ
- 参照ページ

## 4. 将来I/O拡張

現在DOは32点中29点使用であるため、E05に将来追加DOユニット予約枠を明示する。

正式機種が未選定の段階では架空のYアドレスを割り振らない。

E17のXT8を将来I/O受け端子として使い、将来改造時に既設XT4 / XT5を崩さず増設できる構成とする。

## 5. 予備I/O

- DI：X70～X77 8点
- DO：Y35～Y37 3点

予備I/Oも図面上でSPAREとして表示する。

Y35～Y37は小規模変更用とし、4点以上の出力追加では追加DOユニット採用を基本とする。

## 6. XT8

E17ではXT8を約24端子の将来拡張領域として示す。

- XT8-01～08：将来DI
- XT8-09～16：将来DO
- XT8-17～20：将来+24V / 0V分配
- XT8-21～24：完全予備

固定I/O割付ではなく予約区分とする。

## 7. 安全関連図面

E07 / E17で扱うのは通常PLCが監視する安全状態信号のみ。

非常停止二重系、安全扉、ライトカーテン、安全リレー / 安全PLC、STO、空圧安全排気等の詳細は、リスクアセスメント後の別ページ群とする。

## 8. クロスリファレンス

E18で、PLC I/O、信号、機器タグ、端子、線番、ケーブル、参照ページを一覧化する。

変更時はE18も同時更新する。

## 9. 図面番号ルール

- 電気回路図：E01～E99
- 空圧回路図：P01～P99
- 機械配置 / 外形：M01～M99
- I/O・一覧表：L01～L99

## 10. 変更管理

図面化後にI/Oや端子を変更する場合、少なくとも以下を同時更新する。

1. physical-io-map.md
2. terminal-block-spec.md
3. 対応する wiring schedule
4. 電気回路図該当ページ
5. E18 cross reference
6. GX Works3デバイスコメント / I/Oコメント
7. 必要に応じてBOM / 盤レイアウト

## 11. CP01盤内設計との接続

盤内レイアウトは `control-panel-final-layout-spec.md` を基準とする。

現行基準：

- CP01 W800 × H1200 × D350 mm級
- INV01～INV05
- XT1～XT8 合計178端子
- DR5A / DR5B / DR6の3段端子台
- PE / SHIELD予約
- 主回路 / INVモータ / DC24V / センサ / Ethernetの配線ルート分離
- 初期盤クーラーなし、後付け余地あり
