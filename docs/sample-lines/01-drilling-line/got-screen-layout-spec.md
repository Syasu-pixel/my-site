# 01 Drilling Line — GOT画面レイアウト詳細仕様

Status: Draft / GT Works3実装直前基準

## 1. 目的

`hmi-spec.md` を画面単位まで具体化し、GT Works3で作成するGOT画面の構成、表示項目、操作項目、遷移、共通ヘッダ、ポップアップ方針を固定する。

本仕様は教材・シミュレーション用の通常制御HMI仕様である。安全機能そのものをGOT操作や通常PLCロジックで代替しない。

## 2. 対象GOT

候補：GT2708-STBD。

画面解像度・最終機種はBOM確定時に最新メーカー仕様で再確認する。

画面設計は、最終解像度が変更されても再配置しやすいよう、上部共通ヘッダ・中央主表示・下部ナビゲーションの3領域を基準とする。

## 3. 画面一覧

| Screen | 名称 | 主用途 |
|---:|---|---|
| G01 | 自動運転 | 設備全体状態・現在工程・運転状態 |
| G02 | 運転準備 / 復旧 | 起動不可理由・原位置・安全監視状態 |
| G03 | 手動搬送 | CV01～04 / ST01～05 手動操作 |
| G04 | 手動加工 | CY01～05 / 主軸 手動操作 |
| G05 | アラーム現在 | 発生中異常・復旧条件 |
| G06 | アラーム履歴 | 発生 / 復旧履歴 |
| G07 | 生産実績 | 数量・サイクル・タクト |
| G08 | メンテナンス | 診断・時間・回数・設定値 |
| G09 | I/Oモニタ | X/M/Y状態確認（表示中心） |
| G10 | 設定 | D110/D111/D112/D120等の設定 |

G01～G07を通常運転員向け、G08～G10を保守向けとする。

## 4. 全画面共通ヘッダ

画面上部には常時以下を表示する。

- 設備名：01 Drilling Line
- モード：AUTO / MANUAL / MODE NOT ESTABLISHED
- M321 運転準備
- M305 自動運転中
- M324 異常総合
- M325 警告総合
- 現在加工ステップ D100
- 現在時刻

異常発生中は、どの画面にいてもG05へ移動できる「ALARM」ボタンを表示する。

## 5. 共通フッタ / ナビゲーション

下部固定ナビゲーション：

- AUTO → G01
- READY → G02
- MANUAL → G03 / G04選択
- ALARM → G05
- PRODUCTION → G07
- MAINT → G08

自動運転中M305では、手動画面へ遷移しても操作ボタンは無効化し、表示のみ可能とする。

## 6. G01 — 自動運転画面

### 6.1 中央設備表示

設備を左から右へ簡略表示する。

```text
LOAD → CV01 → CV02 → CV03 → CV04 → PROCESS ST → OUT
```

各ゾーンに表示する状態：

- CV01：M116 在荷、M430 T1 Busy
- CV02：M117 在荷、M431 T2 Busy
- CV03：M120 在荷、M432 T3 Busy
- CV04：M121 在荷、M433 T4 Busy
- 加工ST搬送位置：M140
- 加工治具位置：M141
- 搬出満杯：M154 / M770

在荷は「空 / ワーク有」、Busyは「待機 / 搬送中」で文字も併記する。

### 6.2 加工工程表示

表示：

- D100 現在ステップ番号
- M500～M517の工程名称
- 主軸運転確認 M166
- CY01～CY05主要位置
- 搬出待ち M770

画面上では現在工程を1つ大きく表示し、その下に「前工程 / 現在 / 次工程」の3段表示を行う。

### 6.3 運転状態

- M320 運転準備条件
- M321 運転準備ラッチ
- M322 自動起動可能
- M323 投入可
- M330 加工ST受入許可
- M305 自動運転中

GOTから自動起動・運転準備を直接実行しない。物理PBの操作状態と成立状態を表示する。

## 7. G02 — 運転準備 / 復旧画面

### 7.1 Readyチェックリスト

1行1条件で表示する。

- M110 安全回路OK
- M111 エア圧OK
- M112 非常停止系正常監視
- M113 安全扉閉
- M114 ライトカーテンクリア
- M115 安全リレー正常
- M142 CY01搬送面復帰
- M144 CY02後退
- M146 CY03解除
- M150 CY04解除
- M152 CY05上昇
- NOT M167 主軸異常なし
- NOT M324 異常なし

各項目を OK / NG だけでなく、実信号名称付きで表示する。

### 7.2 復旧フロー表示

画面下部に標準復旧順を固定表示する。

```text
原因確認 → 必要なら手動復旧 → RESET → READY条件確認
→ 運転準備PB → AUTO選択 → 自動起動PB
```

RESETによって自動再起動しないことを明記する。

## 8. G03 — 手動搬送画面

### 8.1 CV01～CV04

各CVカードに以下を表示する。

- JOG要求：M900～M903
- MANUAL要求：M830～M833
- COMMON要求：M860～M863
- 実RUN状態 Y0～Y3
- 在荷 M116 / M117 / M120 / M121
- 関連通過SEEN / COMPLETE
- 操作可 / 不可理由

JOGはモーメンタリ要求を基準とする。

### 8.2 ST01～ST05

各ストッパーカード：

- UP / DOWN要求 M904～M913
- 上昇端 / 下降端
- MANUAL要求 M834～M843
- COMMON要求 M864～M873
- 実Y
- BLOCK理由 M940～M959

相反側が要求中の場合、反対ボタンは無効表示する。

## 9. G04 — 手動加工画面

### 9.1 CY01～CY05

各機構を同じカード形式で表示する。

表示項目：

- 2方向操作ボタン
- GOT要求 M980～M989
- MANUAL要求 M844～M853
- COMMON要求 M874～M883
- 原位置FB
- 動作位置FB
- 操作可能 / 不可
- BLOCK理由

### 9.2 主軸

表示：

- M990 GOT_SPINDLE_RUN_REQ
- M854 MANUAL要求
- M884 COMMON要求
- Y30 RUN
- M166 運転確認
- M167 異常

主軸停止完了 / ゼロ速度の専用信号は現行I/Oにないため、存在しない状態を画面へ表示しない。

## 10. G05 — 現在アラーム

1アラーム1行で表示：

- Code
- 名称
- 対象機器
- 発生状態
- 現在加工ステップ D100
- 期待フィードバック
- 実フィードバック
- RESET可 / 不可
- RESET不可理由

ブザー停止とRESETを明確に分ける。

- ブザー停止：音だけ停止
- RESET：原因復旧済みラッチ異常のみ解除

GOT上の確認操作が安全機能復帰を代替しない。

## 11. G06 — アラーム履歴

表示項目：

- 発生日時
- Code
- 名称
- 復旧日時
- 確認日時
- 発生時加工ステップ

履歴は故障解析用とし、履歴削除は保守権限側に限定する候補とする。

## 12. G07 — 生産実績

表示：

- D200 総投入数
- D201 総排出数
- D202 OK数（正式判定機構導入後）
- D203 NG数（正式判定機構導入後）
- D210 直近サイクルタイム
- D211 平均
- D212 最大
- D213 最小
- D120 目標タクト
- タクト超過 M774

OK/NG判定装置がない現段階では、D202/D203を実績値として誤認させない表示とする。

## 13. G08 — メンテナンス

表示候補：

- M01～M04運転時間
- 主軸運転時間
- ST01～ST05動作回数
- CY01～CY05動作回数
- 各搬送タイムアウト発生回数
- 各アラーム発生回数
- D300～D399診断値

操作可能項目は通常画面と分離する。

## 14. G09 — I/Oモニタ

表示中心。

カテゴリ：

- OP01入力 X0～X7
- 共通監視 X10～X15
- 搬送 X16～X37
- 加工 X40～X55
- Drive X56～X67
- 出力 Y0～Y34

I/Oモニタ画面からYを直接ON/OFFしない。

## 15. G10 — 設定画面

対象候補：

- D110 搬送タイムアウト
- D111 加工アクチュエータタイムアウト
- D112 穴あけ滞留時間
- D120 目標タクト

設定値は入力範囲チェックを設ける。

正式な上下限はGX Works3実装・シミュレーション条件確定時に決める。実機向け値は設備条件を確認して再設定する。

## 16. 表示優先度

優先度は以下とする。

1. 異常 / 安全監視状態
2. 復旧不可理由
3. 現在工程
4. 操作可否
5. 生産実績
6. 保守情報

異常中でも現在位置・現在工程・期待FBを確認できるようにする。

## 17. ポップアップ

使用候補：

- 新規異常発生
- 操作不可理由詳細
- 設定値変更確認
- 保守画面移行確認

異常ポップアップで画面全体を隠さず、設備状態を確認できる領域を残す。

## 18. 権限レベル

一次案：

- Level 0：表示のみ
- Level 1：通常運転・手動操作
- Level 2：設定変更・履歴管理

安全関連設定や駆動機器パラメータをGOT通常画面から自由変更できる構成にはしない。
