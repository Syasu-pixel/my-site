# 01 Drilling Line — GT Works3 画面作成チェックリスト

Status: Draft / GT Works3実装順序基準

## 1. 目的

GOT画面を場当たり的に作らず、タグ・共通部品・画面・アラーム・シミュレーションを同じ順序で構築するためのチェックリストとする。

## 2. Phase 1 — プロジェクト基礎

- [ ] 対象GOT機種・解像度を確認
- [ ] PLC接続先をFX5U系として設定
- [ ] 画面番号G01～G10を予約
- [ ] 共通ヘッダ/フッタ領域を決定
- [ ] `gtworks3-tag-master.md` を基準にタグ登録
- [ ] GOTからYへ直接書き込むタグがないことを確認

## 3. Phase 2 — 共通部品

- [ ] 設備名
- [ ] AUTO/MANUAL/MODE INVALID表示
- [ ] READY/RUN/ALARM/WARNING表示
- [ ] D100現在工程
- [ ] GOT時刻
- [ ] G01/G02/G03/G04/G05/G07/G08へのナビゲーション
- [ ] ALARM常時アクセス

## 4. Phase 3 — G01 自動運転

- [ ] LOAD→CV01→CV02→CV03→CV04→PROCESS→OUTの設備フロー
- [ ] CV01～04在荷
- [ ] T1～T4 Busy
- [ ] 加工ST搬送位置在荷
- [ ] 治具位置在荷
- [ ] 搬出満杯
- [ ] D100工程番号/工程名称
- [ ] 主軸RUN FB
- [ ] CY01～CY05位置
- [ ] 投入可
- [ ] 加工ST受入可

## 5. Phase 4 — G02 READY/復旧

- [ ] 安全監視状態を1条件1行表示
- [ ] エア圧
- [ ] 各CY原位置
- [ ] 主軸異常なし
- [ ] 異常総合なし
- [ ] M920/M922/M929/M935等表示
- [ ] 復旧標準フローを固定表示
- [ ] RESETで自動再起動しない旨を明記

## 6. Phase 5 — G03/G04 手動

- [ ] CV01～04 JOGはモーメンタリ
- [ ] ST01～05 UP/DOWNは相反排他
- [ ] CY01～05 2方向操作
- [ ] 主軸RUN手動要求
- [ ] 各カードにREQUEST/MANUAL/COMMON/FBを表示
- [ ] M940～M955の操作不可理由を表示
- [ ] M305自動運転中は操作要求を通さない

## 7. Phase 6 — G05/G06 アラーム

- [ ] 現在アラーム表示
- [ ] Code/名称/対象機器
- [ ] RESET可否
- [ ] 不可理由
- [ ] ブザー停止とRESETを別操作
- [ ] M960～M971を必要範囲で割付
- [ ] 履歴に発生/復旧/確認を分離
- [ ] 履歴消去は保守権限候補

## 8. Phase 7 — G07 生産

- [ ] D200総投入
- [ ] D201総排出
- [ ] D202/D203未使用表示
- [ ] D210～D213サイクル実績
- [ ] D120目標タクト
- [ ] M774タクト超過

## 9. Phase 8 — G08～G10 保守

- [ ] G08 診断/動作回数/運転時間
- [ ] G09 X/M/Yモニタ
- [ ] G09からY強制操作を作らない
- [ ] G10 D110/D111/D112/D120設定
- [ ] M938設定変更許可
- [ ] 数値範囲チェック
- [ ] 設定変更確認ポップアップ

## 10. Phase 9 — 画面共通品質

- [ ] ON/OFFを色だけでなく文字でも区別
- [ ] 異常/警告/通常を同じ意味の表示ルールで統一
- [ ] ボタン名称とPLCコメントを一致
- [ ] 自動中の手動ボタン無効化表示
- [ ] 不可理由が見える
- [ ] 画面遷移後も要求が残らない
- [ ] モーメンタリ要求の離し忘れ/画面切替挙動を確認

## 11. Phase 10 — シミュレーション

`gxworks3-simulation-test-matrix.md` と組み合わせて以下を確認する。

- [ ] G01の在荷/Busy/工程表示
- [ ] G02のNG理由
- [ ] G03/G04の手動要求経路
- [ ] 相反出力防止
- [ ] 自動中手動ブロック
- [ ] 新規アラーム表示
- [ ] ブザー停止でアラームが消えない
- [ ] RESET後に自動再起動しない
- [ ] 搬出満杯を警告/待ちとして表示
- [ ] タクト超過を故障と混同しない

## 12. 完成判定

GOT側の教材・シミュレーション版は、以下が満たされたら一旦完成とする。

1. G01～G10が開ける。
2. 全主要タグがPLCデバイスと一致する。
3. GOT→Y直接書込みがない。
4. 手動操作がMANUAL→COMMON→Y経路で動く。
5. 操作不可理由が表示される。
6. アラーム/警告/待ち状態が区別される。
7. RESETで自動再始動しない。
8. GX Works3シミュレーション試験表のGOT関連項目を通過する。

実機導入時は、正式GOT機種、通信設定、権限、安全設計、実機タイムアウト/設定範囲を別途再確認する。
