# 01 Drilling Line — GT Works3 G02 運転準備 / 復旧画面 座標仕様

Status: Draft / GT Works3実装直前基準

## 1. 目的

G02 運転準備 / 復旧画面を、起動不可理由と復旧手順を一画面で追えるよう論理座標・表示優先度・オブジェクト名・参照タグまで固定する。

安全機能の復帰そのものをGOTで代替しない。GOTは通常PLCが受ける監視状態と復旧案内を表示する。

## 2. 論理キャンバス

G01と共通。

- 論理幅：1000
- 論理高さ：750
- Header：Y 0～80
- Main：Y 80～670
- Footer：Y 670～750

## 3. 画面構成

```text
┌──────────────────────────────────────────────────────┐
│ HEADER                                               │
├──────────────────────────────────────────────────────┤
│ [READY CHECK 1]           [READY CHECK 2]            │
│ 安全/空圧/モード             原位置/主軸/異常          │
│                                                      │
│ [総合状態]                  [復旧ガイド]              │
│                                                      │
│ [標準復旧フロー固定表示]                              │
├──────────────────────────────────────────────────────┤
│ AUTO READY MANUAL ALARM PRODUCTION MAINT             │
└──────────────────────────────────────────────────────┘
```

## 4. Header

G01と同じ共通Headerを使用する。

- M928 AUTO
- M927 MANUAL
- M920 READY
- M921 RUN
- M926 WARNING
- M925 ALARM
- D100 STEP
- GOT時刻

G02では `READY` ナビを現在画面として選択表示する。

## 9. 下段 — 標準復旧フロー

領域：x 20～980 / y 565～650。

固定表示：

```text
1 原因確認
→ 2 必要なら手動モードで位置復旧
→ 3 原因復旧確認
→ 4 RESET
→ 5 READY条件確認
→ 6 運転準備PB
→ 7 AUTO選択
→ 8 自動起動PB
```

補足表示：

- RESETだけでは自動運転を再開しない。
- RESETだけでM321をSETしない。
- 位置不整合時は無条件に加工STEPや搬送STEPを初期化しない。

## 10. 操作ボタン

G02は原則表示中心。

設置可：

- `NAV_G03_ManualRecovery`：G03/G04へ画面遷移
- `NAV_G05_CurrentAlarm`：G05へ画面遷移

通常基準ではGOT上RESETを主要操作にしない。物理RESET PB X3を正式操作とする。

M961 GOT RESET要求を将来採用する場合でも、独立確認・RESET許可条件を必須とし、自動起動や安全機能復帰へ連鎖させない。

## 11. NG表示ルール

READYチェック項目は単純な赤/緑だけに依存せず、必ず文字を併記する。

例：

- `OK`
- `NG: CY04クランプ解除端なし`
- `NG: エア圧未成立`

画面を見ただけで「何を確認すべきか」が分かることを合格条件とする。

## 12. Footer

G01共通Footerを使用。

- AUTO G01
- READY G02
- MANUAL G03
- ALARM G05
- PRODUCTION G07
- MAINT G08

## 13. GT Works3実装時チェック

- M110～M115が安全機能そのものとして誤表現されていない。
- M166 OFFをゼロ速度確認と表記していない。
- M167 / M934主軸異常表示がG04/G05とも一致。
- M320/M321/M322の意味を混同していない。
- RESETで自動再始動する画面スクリプトがない。
- 画面操作からYへ直接書き込まない。
- 復旧理由がM940～M955と整合する。
