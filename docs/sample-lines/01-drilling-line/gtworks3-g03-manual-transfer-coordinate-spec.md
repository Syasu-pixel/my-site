# 01 Drilling Line — GT Works3 G03 手動搬送画面 座標仕様

Status: Draft / GT Works3実装直前基準

## 1. 目的

G03 手動搬送画面を、CV01～CV04とST01～ST05の手動操作・フィードバック・COMMON要求・実出力・操作不可理由を同一画面で追えるよう、論理座標とオブジェクト配置まで固定する。

本仕様は教材・シミュレーション用の通常制御HMI仕様である。GOTから実Yへ直接書き込まず、GOT要求 → MANUAL要求 → COMMON要求 → 最終Yの順を維持する。

## 2. 論理キャンバス

G01/G02と共通。

- 論理幅：1000
- 論理高さ：750
- Header：Y 0～80
- Main：Y 80～670
- Footer：Y 670～750

## 3. 画面構成

```text
┌──────────────────────────────────────────────────────┐
│ HEADER                                               │
├──────────────────────────────────────────────────────┤
│ [TRANSFER MANUAL]                         [PROCESS→] │
│ [CV01] [CV02] [CV03] [CV04]                         │
│                                                      │
│ [ST01] [ST02] [ST03] [ST04] [ST05]                  │
│                                                      │
│ [共通BLOCK理由 / 手動操作状態]                       │
├──────────────────────────────────────────────────────┤
│ AUTO READY MANUAL ALARM PRODUCTION MAINT             │
└──────────────────────────────────────────────────────┘
```

## 4. Header / 手動画面サブナビ

G01共通Headerを使用する。

G03ではMANUALナビを選択表示し、以下を強調する。

- M927 MANUAL
- M928 AUTO
- M925 ALARM
- M926 WARNING
- M935 RECOVERY REQUIRED

M927がOFFのとき、操作ボタンは表示しても操作不可状態とする。

G03/G04切替はMain上端のサブナビとして配置し、下段診断表示と重ならないようにする。

| Object | x | y | w | h | 遷移 |

| TXT_ManualSubTitle | 30 | 88 | 220 | 28 | 手動搬送 |
| NAV_G04_ProcessManual | 835 | 86 | 130 | 32 | G04 |

## 6. CV JOG操作ルール

CV JOGは原則モーメンタリ要求とする。

ボタン有効条件の基準：

- M927 手動モード成立
- NOT M925 異常総合表示
- 通常制御上の関連インターロック成立
- 相反・隣接搬送の干渉条件なし

操作不可時はボタンを単純に消さず、M940～M946の主な理由を画面下部へ表示する。

## 8. 相反操作表示

各STカードで、UP要求とDOWN要求が同時成立しないことを監視表示する。

共通表示：

- M943 `BLOCK_相反要求あり`

相反要求が検出された場合：

- 両方向の最終出力を成立させない。
- 画面下部に「相反要求あり」を表示する。
- 手動要求とCOMMON要求の状態を残して診断しやすくする。

## 10. ボタン表示状態

各手動ボタンは最低3状態を持たせる。

1. 操作不可：押せない + 不可理由表示
2. 操作可能：通常表示
3. 押下中：要求MがONであることを明示

実YがONかどうかは別ランプで表示し、「押した＝実出力ON」と誤認させない。

## 11. Footer

G01共通Footerを使用する。

- AUTO G01
- READY G02
- MANUAL G03
- ALARM G05
- PRODUCTION G07
- MAINT G08

G03/G04の相互切替はSection 4のMain上端サブナビを使用し、Footerや下段診断領域には重ねない。

## 12. GT Works3実装時チェック

- M900～M913以外のGOT手動要求へ直接書き込んでいない。
- Y0～Y15は表示専用で、書込オブジェクトがない。
- 手動JOG/UP/DOWNは原則モーメンタリ。
- M940～M946のBLOCK理由が画面上で確認できる。
- STの相反要求がPLC側最終出力でも禁止されている。
- M927 OFF時に手動操作できない。
- 自動運転中は手動要求を通常通さない。
- 画面遷移だけで設備状態が変化しない。
- G04切替ボタンが下段BLOCK/診断表示と重ならない。
