# 01 Drilling Line — GT Works3 G04 手動加工画面 座標仕様

Status: Draft / GT Works3実装直前基準

## 1. 目的

G04 手動加工画面を、CY01～CY05と主軸のGOT要求・MANUAL要求・COMMON要求・実出力・端位置・操作不可理由を同一画面で追えるよう、論理座標とオブジェクト配置まで固定する。

本仕様は教材・シミュレーション用の通常制御HMI仕様である。GOTから実Yへ直接書き込まず、機械干渉防止条件はPLC側で最終判断する。

## 2. 論理キャンバス

G01～G03と共通。

- 論理幅：1000
- 論理高さ：750
- Header：Y 0～80
- Main：Y 80～670
- Footer：Y 670～750

## 3. 画面構成

```text
┌──────────────────────────────────────────────────────┐
│ HEADER                                               │
├──────────────────────────────────────────────────────┤
│ [CY01] [CY02] [CY03]                                 │
│                                                      │
│ [CY04] [CY05] [SPINDLE]                              │
│                                                      │
│ [BLOCK理由 / ワーク・工程状態]                       │
├──────────────────────────────────────────────────────┤
│ AUTO READY MANUAL ALARM PRODUCTION MAINT             │
└──────────────────────────────────────────────────────┘
```

## 4. Header

G01共通Headerを使用する。

G04では以下を重点表示する。

- M927 MANUAL
- M925 ALARM
- M934 主軸異常
- D100 現在加工ステップ
- M935 復旧要求

手動モードでない場合は全操作ボタンを操作不可表示にする。

## 5. CYカード標準構成

各CYカードは以下の情報を同じ並びで持つ。

- タイトル
- 方向Aボタン
- 方向Bボタン
- A端FB
- B端FB
- MANUAL要求A/B
- COMMON要求A/B
- 実Y A/B
- BLOCK理由

ボタンはモーメンタリ要求を基本とする。

## 10. 手動操作の基本許可方針

各ボタンのGOT表示上の許可状態はPLC側の判断結果を反映する。

基本条件：

- M927 手動モード
- 自動運転中ではない
- 対象動作の相反要求なし
- 通常制御上の機械干渉条件成立
- 対象異常なし

安全機能そのものはGOTや通常PLCで代替しない。

## 11. 診断表示ルール

「ボタン押下」「MANUAL要求」「COMMON要求」「実Y」「位置FB」を別々に見えるようにする。

例：CY04クランプ

```text
GOT要求 M987
→ MANUAL M851
→ COMMON M881
→ 実Y25
→ FB M151
```

どこまで進んで止まったかを画面上で追えることを目的とする。

## 12. Footer

G01共通Footerを使用する。

G04内に `NAV_G03_TransferManual` を追加し、搬送手動画面へ戻れるようにする。

推奨位置：x 835 / y 625 / w 130 / h 32。

## 13. GT Works3実装時チェック

- M980～M990のみをGOT加工系操作要求として使用している。
- Y16～Y30は表示専用で、GOTから直接書込まない。
- CY01～CY05の相反方向を同時に最終出力しない。
- M940～M955のBLOCK理由が確認できる。
- M166をゼロ速度確認として使用していない。
- 主軸異常M167/M934がG02/G05と同じ意味。
- 手動操作から自動運転へ自動遷移しない。
- 画面切替だけで出力状態を変更しない。
