# 01 Drilling Line — GT Works3 G07 生産実績画面 座標仕様

Status: Draft / GT Works3実装直前基準

## 1. 目的

G07 生産実績画面を、数量・サイクルタイム・目標タクト・タクト超過を一画面で確認できるよう、論理座標・オブジェクト名・表示ルールまで固定する。

本画面は教材・シミュレーション用の生産状態表示であり、品質判定機構が未実装の項目を確定値として表示しない。

## 2. 論理キャンバス

G01～G06と共通。

- 論理幅：1000
- 論理高さ：750
- Header：Y 0～80
- Main：Y 80～670
- Footer：Y 670～750

## 3. 画面構成

```text
┌──────────────────────────────────────────────────────┐
│ HEADER                                               │
├──────────────────────────────────────────────────────┤
│ [生産数量]                    [サイクルタイム]       │
│                                                      │
│ [タクト状態]                  [状態メッセージ]       │
│                                                      │
│ [注記 / 将来項目]                                    │
├──────────────────────────────────────────────────────┤
│ AUTO READY MANUAL ALARM PRODUCTION MAINT             │
└──────────────────────────────────────────────────────┘
```

## 4. Header

G01共通Headerを使用する。

- M928 AUTO
- M927 MANUAL
- M920 READY
- M921 RUN
- M926 WARNING
- M925 ALARM
- D100 STEP
- GOT時刻

G07ではPRODUCTIONナビを現在画面として選択表示する。

## 9. 下段 — 注記 / 将来項目

領域：x 20～980 / y 575～650。

固定注記：

- D202 / D203は正式判定機構導入後に有効化する。
- 数量カウンタのRESET / 日次切替は本画面から安易に行わない。
- カウンタ初期化・履歴保存方式は保守仕様で別管理する。

表示候補：

| Object | x | y | w | h | 内容 |
|---|---:|---:|---:|---|
| TXT_ProductionNote | 30 | 585 | 920 | 50 | 生産実績に関する注記 |

## 10. 操作方針

G07は原則表示専用。

- 生産数を通常運転員が直接書き換えない。
- D200～D213へGOTから直接任意値を書き込む操作を置かない。
- カウンタRESETが必要になった場合は保守権限・確認操作・別仕様で実装する。

## 11. Footer

G01共通Footerを使用する。

- AUTO G01
- READY G02
- MANUAL G03
- ALARM G05
- PRODUCTION G07
- MAINT G08

## 12. GT Works3実装時チェック

- D200～D213が `gtworks3-tag-master.md` と一致。
- D202/D203を実績値として誤表示していない。
- M774を故障アラームとして扱っていない。
- D120目標タクトがG10設定画面と一致。
- カウンタ書込ボタンが通常画面に存在しない。
- Yデバイスへ書込むオブジェクトが存在しない。
