# 01 Drilling Line — GT Works3 G09 I/Oモニタ画面 座標仕様

Status: Draft / GT Works3実装直前基準

## 1. 目的

G09 I/Oモニタ画面を、物理X/Yと主要内部Mの状態確認に使える読み取り専用診断画面として固定する。

本画面から実Yを強制ON/OFFしない。I/O監視は通常PLCの診断用途であり、安全機能そのものの試験や安全回路バイパスをGOTで代替しない。

## 2. 論理キャンバス

G01～G08と共通。

- 論理幅：1000
- 論理高さ：750
- Header：Y 0～80
- Main：Y 80～670
- Footer：Y 670～750

## 3. 画面構成

```text
┌──────────────────────────────────────────────────────┐
│ HEADER                                               │
├──────────────────────────────────────────────────────┤
│ [入力カテゴリ選択]      [X入力一覧]                  │
│                                                      │
│ [出力カテゴリ]          [Y出力一覧]                  │
│                                                      │
│ [主要内部状態 M]                                     │
├──────────────────────────────────────────────────────┤
│ AUTO READY MANUAL ALARM PRODUCTION MAINT             │
└──────────────────────────────────────────────────────┘
```

## 4. Header

G01共通Headerを使用する。

G09は保守導線から遷移する画面とし、FooterのMAINT系導線から開く。

## 5. 左上 — 入力カテゴリ

領域：x 20～250 / y 100～390。

カテゴリ切替ボタンは画面内タブまたは一覧スクロール用とし、PLC出力を操作しない。

| BTN_IO_OP01 | 35 | 155 | 185 | 42 | X0～X7 |
| BTN_IO_Common | 35 | 207 | 185 | 42 | X10～X15 |

| BTN_IO_Transport2 | 35 | 311 | 185 | 42 | X30～X37 |

## 9. 右端 — 主要内部状態

領域：x 760～980 / y 445～650。

| Device | 表示 |
|---|---|
| M300 | 手動モード |
| M301 | 自動モード |
| M305 | 自動運転中 |
| M320 | READY条件 |
| M321 | READY保持 |
| M322 | 自動起動可 |
| M324 | 異常総合 |
| M325 | 警告総合 |
| M430～M433 | T1～T4 Busy |
| M500～M517 | 加工ステップ |

現在STEPはD100も併記する。

## 10. 表示ルール

- BitはON/OFF文字を併記する。
- Addressだけでなく日本語信号名を必ず表示する。
- 安全監視入力は通常PLC監視であることを明記する。
- XとMの意味変換が不一致の場合に気づけるよう、物理Xと内部Mを同じ行に表示する。
- YとCOMMON要求を同じ行に表示し、要求と実出力の追跡ができるようにする。

## 11. 操作禁止事項

G09では以下を禁止する。

- Y強制ON/OFF
- X疑似入力操作
- 安全入力のバイパス
- M700異常ラッチの解除
- M305/M321のSET

シミュレーション時の入力操作はGX Works3側の試験機能や別の試験手順で行い、通常GOT画面に実装しない。

## 12. Footer

共通Footerを使用。

G09への直接ボタンはMAINT画面G08内に置く候補とし、通常運転員向けFooterには必須としない。

## 13. GT Works3実装時チェック

- X0～X67の名称が `physical-io-map.md` と一致。
- Y0～Y34の名称が `physical-io-map.md` と一致。
- M100帯が `gxworks3-input-mapping-spec.md` と一致。
- COMMON要求M860～M893が `gxworks3-output-request-mapping-spec.md` と一致。
- G09からYを書き込めない。
- 安全監視入力を安全機能本体として誤表示していない。
