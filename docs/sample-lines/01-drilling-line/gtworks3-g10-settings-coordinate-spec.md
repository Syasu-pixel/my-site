# 01 Drilling Line — GT Works3 G10 設定画面 座標仕様

Status: Draft / GT Works3実装直前基準

## 1. 目的

G10 設定画面を、設備調整用の設定値を通常運転画面から分離し、変更可否・入力範囲・変更確認・権限制限を一画面で管理できるよう固定する。

本画面は教材・シミュレーション用の通常制御設定画面である。安全関連設定や駆動機器の危険なパラメータを自由に変更する画面にはしない。

## 2. 論理キャンバス

G01～G09と共通。

- 論理幅：1000
- 論理高さ：750
- Header：Y 0～80
- Main：Y 80～670
- Footer：Y 670～750

## 3. 画面構成

```text
┌──────────────────────────────────────────────────────┐
│ HEADER                                               │
├──────────────────────────────────────────────────────┤
│ [設定変更許可]          [現在設定値]                 │
│                                                      │
│ [D110] [D111] [D112] [D120]                         │
│                                                      │
│ [変更条件]              [注意 / 確認]                │
├──────────────────────────────────────────────────────┤
│ AUTO READY MANUAL ALARM PRODUCTION MAINT             │
└──────────────────────────────────────────────────────┘
```

## 4. Header

G01共通Headerを使用する。

G10は保守向け画面とし、通常はG08メンテナンスから遷移する。

## 7. 中央 — 設定入力カード

領域：x 20～980 / y 290～510。

4カード横並びを基本とする。

### D110 搬送タイムアウト

| Object | x | y | w | h |
|---|---:|---:|---:|---:|
| TXT_SetD110 | 30 | 300 | 210 | 35 |
| NUM_InputD110 | 35 | 345 | 200 | 60 |
| TXT_UnitD110 | 35 | 415 | 200 | 30 |
| TXT_RangeD110 | 35 | 450 | 200 | 40 |

### D111 加工アクチュエータ監視

x 270基準。

### D112 穴あけ滞留

x 510基準。

### D120 目標タクト

x 750基準。

共通ルール：

- 入力部品はM938 ON時のみ編集可能。
- 単位を画面に表示する。
- 正式な上下限はシミュレーション・機械条件確認後に確定する。
- 上下限未確定の段階では仮値を隠して勝手に固定しない。

## 8. 下段左 — 変更条件 / 状態

領域：x 20～500 / y 525～650。

表示：

- M938 設定変更許可
- M305 自動運転状態
- M324 異常総合
- M925 アラームあり
- 権限レベル

設定変更不可の場合、理由を文字で表示する。

例：

- 自動運転中
- 異常発生中
- 権限不足
- 設定変更許可未成立

## 9. 下段右 — 変更確認

領域：x 520～980 / y 525～650。

操作候補：

- `BTN_SettingsApply`：設定変更確認
- `BTN_SettingsCancel`：編集中値破棄
- `TXT_SettingsChanged`：変更あり表示

GT Works3上で直接Dを書き換える場合でも、変更許可M938・入力範囲・確認ポップアップを必須とする。

変更確定時に自動運転を開始したり、異常をRESETしたりしない。

## 10. 変更確認ポップアップ

表示内容：

- 変更対象
- 旧値
- 新値
- 単位
- 適用 / キャンセル

設定変更後は値を再読込し、PLC側に反映された値を表示する。

## 11. 対象設定値

| Device | 名称 | 状態 |
|---|---|---|
| D110 | 搬送タイムアウト | 採用 |
| D111 | 加工アクチュエータ監視時間 | 採用 |
| D112 | 穴あけ滞留時間 | 採用 |
| D120 | 目標タクト | 採用 |

これ以外のD300～D399診断/保守値は、用途確定前に編集対象へしない。

## 12. 変更禁止対象

G10から以下を変更しない。

- 安全機能の設定
- 非常停止や安全扉の有効/無効
- Y出力強制
- PLC出力共通条件
- インバータ主回路・保護設定
- 主軸の危険な駆動パラメータ

それらが必要な場合は、最新メーカー資料と実機条件を確認したうえで別の保守手順に分離する。

## 13. Footer

共通Footerを使用。

G10への遷移はG08メンテナンスから行う候補とする。

## 14. GT Works3実装時チェック

- D110/D111/D112/D120が `gxworks3-setting-initialization-spec.md` と一致。
- M938 OFF時は編集不可。
- 設定変更でM305/M321/M700帯に書き込まない。
- 入力範囲を未確認のまま実機向け数値として固定しない。
- 設定変更から自動再始動しない。
- 安全関連設定をG10に置かない。
