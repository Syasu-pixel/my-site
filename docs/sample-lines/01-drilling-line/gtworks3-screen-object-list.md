# 01 Drilling Line — GT Works3 画面オブジェクト一覧

Status: Draft / GT Works3実装用基準

## 1. 目的

`got-screen-layout-spec.md` をGT Works3で実際に画面作成しやすい粒度へ落とし込み、G01～G10ごとに配置する表示器・ランプ・ボタン・数値表示・アラーム部品を一覧化する。

本仕様は教材・シミュレーション用HMI基準であり、安全機能をGOT操作で代替しない。

## 2. 共通オブジェクト

全画面共通ヘッダ：

- 文字列：設備名 `01 Drilling Line`
- 状態表示：AUTO / MANUAL / MODE INVALID
- ランプ：M321 運転準備
- ランプ：M305 自動運転中
- ランプ：M324 異常総合
- ランプ：M325 警告総合
- 数値表示：D100 現在加工ステップ
- 時計表示：GOTシステム時刻
- ALARM画面切替ボタン：G05

共通フッタ：

- 画面切替：G01 AUTO
- 画面切替：G02 READY
- 画面切替：G03/G04 MANUAL
- 画面切替：G05 ALARM
- 画面切替：G07 PRODUCTION
- 画面切替：G08 MAINT

画面切替ボタンは制御出力を直接操作しない。

## 13. オブジェクト命名ルール

GT Works3オブジェクト名の基準：

- `LMP_`：Bit Lamp
- `BTN_`：操作ボタン
- `NUM_`：数値表示/入力
- `TXT_`：文字列
- `ALM_`：アラーム部品
- `NAV_`：画面切替

例：

- `LMP_CV01_Present`
- `BTN_ST01_Down`
- `NUM_ProcessStep`
- `ALM_Current`
- `NAV_G02_Ready`

## 14. 実装ルール

- GOTから実Yへ直接書かない。
- 手動ボタンは原則モーメンタリ。
- 相反する操作はPLC側でも最終排他する。
- 操作不可時はボタンを消すだけでなく、不可理由を表示する。
- 異常ポップアップは設備状態表示を全面的に隠さない。
- RESET操作から自動起動へ連鎖させない。
