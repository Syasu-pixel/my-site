# 01 Drilling Line — GX Works2 / FX3U ターゲット仕様

Status: Active / 教材・シミュレーション基準

## 1. 結論

GX Works2版の一次ターゲットは次とする。

- CPU: `FX3U-80MT/DS`
- 入力増設: `FX2N-16EX` + `FX2N-8EX-ES/UL`
- エンジニアリング: `GX Works2`
- 用途: 教材・ラダー作成・GX Simulator2での論理確認

この組合せは、現在の設計要求 約58DI / 32DO に対して、

- FX3U-80MT/DS: 40入力 / 40出力
- FX2N-16EX: 16入力
- FX2N-8EX-ES/UL: 8入力
- 合計: 64入力 / 40出力

となり、今回追加したCV05・戻しプッシャを含む約58入力を収容できる。出力側は約32点使用を見込み、8点程度の余裕を残す。

## 2. この構成を選ぶ理由

既存FX5U版の物理I/Oは、実使用入力が概ね `X0～X67`、`X70～X77` が予備、出力は `Y0～Y34` 使用、`Y35～Y37` 予備として整理されている。

FX3U-80MT/DS + FX2N-16EXでは、40点の本体入力に16点を追加できるため、既存の実使用56入力をほぼそのままGX Works2版へ移しやすい。

またFX3U-80MT/DSはトランジスタ・シンク出力のため、現行FX5U版で採っているシンク出力基準との思想差も小さい。

## 3. I/O方針

GX Works2版でも、信号名・機能は `physical-io-map.md` を正とする。

一次方針:

- 既存の実使用入力 `X0～X67` を優先して維持
- `X70～X77` はGX Works2版では予備として確保できない可能性があるため、一旦未割付扱い
- 出力 `Y0～Y34` は維持候補
- `Y35～Y37` も本体40出力範囲内で維持候補

正式なX/Y範囲はGX Works2でCPU/増設構成を作成した後、プロジェクト上の割付表示と照合して確定する。

## 4. 既存ロジックの流用

次の内部デバイス帯は、FX3Uの利用可能範囲と照合しながら、原則として番号を維持する。

- M100番台: 入力処理
- M200番台: passage
- M300番台: 共通/運転
- M400番台: 搬送
- M500～M517: 加工STEP
- M700番台: Fault/Warning
- M800番台: 出力要求
- M900番台: GOT補助
- D100番台: 工程/設定
- D200番台: 生産
- D300番台: 保守

Batch A～Gのロジック構成は作り直さず、GX Works2固有差分のみ変換する。

## 5. GX Works2版で必ず再確認するもの

1. 立上り/立下り検出の正式命令表現
2. タイマ基準とD110/D111/D112/D120の単位
3. ラッチ/保持デバイス範囲
4. 32bit演算と生産統計の実装方式
5. GOT接続方式
6. GX Simulator2での対象CPU・増設構成の扱い
7. デバイスコメント登録方法
8. X/Y実割付

未確認項目を推測で `DONE` / `PASS` にしない。

## 6. 既存TBDは継続

GX Works2移行によって次の設計TBDは自動解決しない。

- M320へST01～ST05全UPを追加するか
- M320へM166 OFFを追加するか
- T4加工ST側の正式搬送駆動方式
- M515搬出の正式駆動方式とtimeout
- 主軸立上り監視時間用D
- 主軸ゼロ速度/停止完了確認
- ダブルソレノイド保持/パルス方式
- 各MACHINE_PERMIT / OUTPUT_PERMIT最終条件
- D101搬送詳細コード
- 生産統計の時間単位・保持・32bit範囲

## 7. 実装開始条件

GX Works2で次を確認できたらBatch Aから実入力を開始する。

1. 新規プロジェクトでFX3U CPUを選択できる
2. `FX3U-80MT/DS` 相当のCPU設定を作成できる
3. 増設入力24点を含むI/O割付を確認できる
4. X/Y番号が本資料の一次方針と矛盾しない

その後、

`COMMENT → LADDER → SIM`

の順でBatch A～Gを実装する。

## 8. 実機適用について

本資料は教材・シミュレーション用のPLC論理設計基準であり、実機主回路・安全回路・保護定格・電源配線を確定する資料ではない。

実機へ適用する場合は、資格・責任を持つ設計者が最新メーカー資料、現地電源条件、機器仕様、リスクアセスメントを確認して別途確定する。


## 9. 2026-09-19 第4回仕様反映

CV05（加工ST搬送コンベヤ）と加工側からCV05へ戻す専用プッシャを追加したため、設備要求を約58DI / 32DOへ更新した。

GX Works2版では従来の56DI構成では不足するため、8点入力増設を追加して64DIを確保する。正式X/Y番地はGX Works2プロジェクト上のI/O割付表示で最終確認する。
