# 01 Drilling Line — GX Works3 Section 11 ACTUAL_OUTPUT 完全マップ

Status: Draft / 教材・シミュレーション実装直前基準

## 1. 目的

Section 11 `ACTUAL_OUTPUT` を、COMMON要求 M860～M893 から実Yへ一元出力する最終マップとして固定する。

本仕様は教材・シミュレーション用の通常PLC出力整理であり、安全機能そのものを通常PLC出力ロジックで代替しない。

## 2. 基本原則

- 実YはSection 11だけで駆動する。
- 同じYを他Sectionで二重コイルにしない。
- ダブルソレノイドの相反ペアは、上位だけでなく最終段でも排他する。
- GOTからYへ直接書き込まない。
- RESET操作から出力を自動再始動させない。

## 3. CV出力

```text
M860 -----------------------------( Y0 )
M861 -----------------------------( Y1 )
M862 -----------------------------( Y2 )
M863 -----------------------------( Y3 )
```

対応：

- Y0 CV01 RUN
- Y1 CV02 RUN
- Y2 CV03 RUN
- Y3 CV04 RUN

## 6. 主軸

```text
M884 -----------------------------( Y30 )
```

Y30は通常RUN指令のみ。運転確認はX66→M166、異常はX67→M167で別確認する。

## 9. 実装チェック

- Y0～Y34に二重コイルがない。
- Y35～Y37は未使用のまま。
- 相反ペアが同時ONしない。
- GOTからYへ直接書き込まない。
- AUTO/MANUALは必ずCOMMON経由。
- 主軸異常時に上位COMMON要求が解除される。
- ブザー停止はY34のみを止め、アラーム保持を解除しない。

## 10. シミュレーション確認

1. M860 ONでY0のみON。
2. M864/M865同時ON時、Y4/Y5ともOFF。
3. M880/M881同時ON時、Y24/Y25ともOFF。
4. M882/M883同時ON時、Y26/Y27ともOFF。
5. M884 ONでY30 ON。
6. M890～M893がY31～Y34へ一対一で反映。
7. 他Sectionで同一Yコイルが存在しない。
