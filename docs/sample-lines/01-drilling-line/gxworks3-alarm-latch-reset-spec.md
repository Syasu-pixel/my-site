# 01 Drilling Line — GX Works3 アラームラッチ / RESET仕様

Status: Draft / 教材・シミュレーション基準

## 1. 目的

M700帯の異常について、発生条件、ラッチ方針、解除条件、RESET操作、運転再開条件を統一する。

本資料は通常PLC側の教材・シミュレーション用仕様である。非常停止、安全扉、ライトカーテン等の安全機能は別の安全回路・安全機器で成立させ、通常PLCのRESETロジックで安全機能を解除・迂回しない。

## 2. 基本方針

アラームは原則として、

1. 異常条件成立
2. 個別アラームMをSET
3. M324 異常総合を成立
4. M305 自動運転中を解除
5. 対象機構の通常出力要求を解除
6. 原因復旧確認
7. RESET要求受付
8. 個別アラームMをRESET
9. 機械位置を再確認
10. 運転準備 → 自動起動をやり直す

の流れとする。

RESETは「アラーム表示を消す操作」であり、機械を自動再始動する操作ではない。

## 3. RESET入力

- 物理入力：X3
- 入力M：M103
- ワンショット候補：M183

GOTからRESET要求を出す場合も、物理RESETと同じPLC側条件判定を通す。

RESET信号で直接M305をSETしない。

## 4. 共通RESET許可条件

個別アラームを解除する前に、少なくとも以下を確認する。

- M110 安全回路OK = ON
- M112 非常停止系正常監視 = ON
- M113 安全扉閉 = ON
- M114 ライトカーテンクリア = ON
- M115 安全リレー正常 = ON
- M111 エア圧OK = ON
- M167 主軸異常 = OFF
- 相反端センサ同時成立なし
- 対象機器の異常入力が復旧済み

共通RESET許可用の内部フラグ候補：

- M340：ALARM RESET COMMON PERMIT

M340は安全機能そのものを成立させる信号ではなく、通常PLC内のアラーム表示解除許可として扱う。

## 5. 搬送タイムアウト A101～A104

対象：

- M701 A101 T1 timeout
- M702 A102 T2 timeout
- M703 A103 T3 timeout
- M704 A104 T4 timeout

### ラッチ

該当搬送Busy中にD110相当の監視時間を超えて完了条件が成立しない場合SET。

### 発生時

- 該当区間モータAUTO要求解除
- 該当区間Busyは異常状態として保持
- M324異常総合ON
- M305自動運転OFF

### RESET許可

- M340 共通RESET許可
- 搬送元/搬送先の在荷状態が確認可能
- 通過SEEN状態を整理済み
- 対象ストッパー端位置が矛盾していない

ワーク位置が不明な場合はRESETだけでBusyを消さず、GOT復旧手順へ移す。

## 6. ストッパー A111～A115

対象：M711～M715。

### ラッチ条件候補

- 指令後、所定時間内に期待端が成立しない
- 上昇端と下降端が同時成立
- 工程上期待していない端位置となる

### RESET許可

- 対応する上昇端/下降端のどちらか一方だけが正常成立
- 相反側同時成立なし
- エア圧正常
- 共通RESET許可成立

端位置がどちらも不明の場合は自動復帰させず、手動復旧対象とする。

## 7. 加工アクチュエータ A201～A206

対象：M721～M726。

### ラッチ

指令に対しD111相当の監視時間内に期待端が成立しない場合SET。

### RESET許可

- 原因となった指令を解除済み
- 対応端センサ状態が矛盾していない
- 治具内ワーク状態を確認済み
- エア圧正常
- 共通RESET許可成立

途中位置の可能性がある場合は、RESET後ただちに自動ステップを進めず、手動復旧で基準位置へ戻す。

## 8. 加工位置未成立 A210

- M730

### SET条件候補

CY02前進完了後もM141 加工治具位置在荷が成立しない、または加工開始前にM141が消失した場合。

### RESET許可

- ワーク位置を作業者が確認済み
- M141の状態が工程と整合
- CY02/CY03/CY04位置が確認可能
- 共通RESET許可成立

ワークが治具から外れている場合は自動再開しない。

## 9. 低エア圧 A301

- M731

### SET条件

自動運転中または運転準備中にM111エア圧OKがOFF。

### RESET許可

- M111 = ON
- 空圧機器端位置が確認可能
- 共通RESET許可成立

圧力復旧だけで途中工程を自動再開しない。

## 10. INV異常 A401～A404

- M741～M744

### SET条件

対応INV異常入力M162～M165成立。

### RESET許可

- 対応INV異常入力OFF
- 対応RUN要求OFF
- 搬送区間が停止状態
- 共通RESET許可成立

INV本体側で別途RESET操作が必要な場合は、その復旧完了後にPLCアラームを解除する。

## 11. 主軸異常 A410

- M750

### SET条件

- M167主軸異常ON
- またはM824 RUN要求後、所定時間内にM166運転確認が成立しない

### 発生時

- M824主軸AUTO要求解除
- M884共通主軸要求解除
- 加工ステップ自動進行停止
- M305自動運転解除

### RESET許可

- M167 = OFF
- 主軸RUN要求OFF
- CY05上昇端M152確認
- ワーククランプ状態を確認可能
- 共通RESET許可成立

主軸停止完了の正式なゼロ速度入力は現在未採用のため、存在しない確認信号をRESET条件に使用しない。

## 12. 安全監視 E001～E005

M760～M764は主として表示・運転不可理由を示す。

- M760：非常停止系正常でない
- M761：安全回路OKでない
- M762：安全扉閉でない
- M763：ライトカーテンクリアでない
- M764：安全リレー正常でない

これらは通常PLC側で勝手にRESETして正常扱いにしない。

元の安全状態が正常へ戻ったことを入力で確認し、その後に通常制御側の運転準備をやり直す。

## 13. M324 異常総合

M324は少なくとも、

- M701～M704
- M711～M715
- M721～M726
- M730
- M731
- M741～M744
- M750

のORで成立させる。

安全監視M760～M764は、M324へ含めてもよいが、GOTでは「安全未成立」と「通常故障」を表示上分離する。

## 14. RESET後のステップ扱い

RESETでM500～M517を一律初期化しない。

基本方針：

- 位置が工程と一致している → 現在ステップ保持、再開可否を確認
- 位置が工程と不一致 → 自動再開禁止、手動復旧
- ワーク位置不明 → 復旧画面へ
- 原位置復帰を実施した → M500待機へ戻す

「とりあえず全部M500へ戻す」というリセット処理は採用しない。

## 15. アラーム確認 / ブザー停止

- ブザー停止PB M107 / M187はブザー音のみ停止可能
- アラームM自体は解除しない
- M327 ブザー消音状態を使用
- 新規重大異常発生時に再鳴動させるかはWARNING_BUZZER仕様で管理

## 16. GOT復旧表示

RESET不可の場合、GOTには最低限以下を出す。

- アラームコード
- 原因入力
- 現在ステップ
- 指令中出力
- 期待端
- 実端状態
- RESET不可理由
- 手動復旧が必要か
