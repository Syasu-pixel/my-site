# 01 Drilling Line — GX Works3 Batch A ネットワーク入力実績記録

Status: Active / 教材・シミュレーション入力用

## 1. 目的

Batch A（Section 00～03）について、GX Works3へ実際に入力する際のネットワーク単位の実績を記録する。

`DESIGN READY` と、実際の `COMMENT / LADDER / SIM` 完了を分離する。GX Works3実プロジェクトを確認していない項目は完了扱いにしない。

本資料は通常PLCの教材・シミュレーション用。非常停止、安全扉、ライトカーテン等の安全機能そのものは通常PLCで成立させず、通常PLC側では監視・通常運転許可にのみ使用する。

## 2. 記録記号

- `[ ]` 未確認
- `[x]` 実プロジェクトで確認済み
- `TBD` 仕様未確定のため保留

## 8. 合格ゲート

Batch Aを `LADDER DONE` とする条件：Section 00～03の対象ネットワークがGX Works3実プロジェクトで確認済み、未登録デバイスの勝手な追加なし、二重コイルなし。

Batch Aを `SIM PASS` とする条件：A-SIM-01～16の必要項目を実シミュレーションで確認し、未解決差分を記録済み。

設計資料だけを根拠に `LADDER DONE` / `SIM PASS` としない。
