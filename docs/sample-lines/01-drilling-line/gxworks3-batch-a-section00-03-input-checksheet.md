# 01 Drilling Line — GX Works3 Batch A Section 00～03 入力チェックシート

Status: Draft / 教材・シミュレーション入力管理用

## 1. 目的

Build Batch A（Section 00～03）をGX Works3へ入力する際に、各項目を「コメント登録」「ラダー入力」「シミュレーション確認」の3段階で記録できるようにする。

対象：

- Section 00 INPUT_PROCESS
- Section 01 PASSAGE_DETECT
- Section 02 COMMON_SAFETY_MON
- Section 03 MODE_RUN

本チェックシートは教材・シミュレーション用。安全機能そのものは通常PLCへ実装せず、安全回路からの監視状態を通常制御の許可条件として扱う。

## 2. 記録ルール

各行は次の3列を独立して確認する。

- COMMENT：GX Works3デバイスコメント登録済み
- LADDER：ラダー入力済み
- SIM：シミュレーション確認済み

記入例：

```text
[ ] COMMENT  [ ] LADDER  [ ] SIM
```

未確認項目を完了扱いにしない。

### 5.2 M320 運転準備条件

一次基準：

```text
M110 AND M111 AND M112 AND M113 AND M114 AND M115
AND NOT M324
AND M142 AND M144 AND M146 AND M150 AND M152
AND NOT M167
```

確認：

- [ ] COMMENT
- [ ] LADDER
- [ ] SIM 全条件成立でM320 ON
- [ ] SIM 低エアでM320 OFF
- [ ] SIM 安全監視1点NGでM320 OFF
- [ ] SIM 主軸異常M167でM320 OFF
- [ ] SIM 原位置1軸不成立でM320 OFF

## 6. Section 03 — MODE_RUN

### 6.1 モード

| Device | 条件 | COMMENT | LADDER | SIM |
|---|---|---|---|---|
| M300 | M105 AND NOT M106 | [ ] | [ ] | [ ] |
| M301 | M106 AND NOT M105 | [ ] | [ ] | [ ] |

試験：

- [ ] 手動SWのみON → M300 ON / M301 OFF
- [ ] 自動SWのみON → M300 OFF / M301 ON
- [ ] 両方OFF → 両方OFF
- [ ] 両方ON → 両方OFF

### 6.2 運転準備ラッチ M321

SET：M320成立 + M180運転準備PB立上り。

RESET候補：安全監視/エア圧喪失、M324成立等。

- [ ] COMMENT
- [ ] LADDER
- [ ] SIM M320だけではM321が勝手にSETされない
- [ ] SIM M180でSET
- [ ] SIM 通常停止PBでは健全時M321保持
- [ ] SIM 異常/安全監視喪失でM321解除
- [ ] SIM RESET M183でM321をSETしない

### 6.3 自動起動可能 M322

一次基準：

```text
M301 AND M321 AND M320 AND NOT M305 AND NOT M324
```

- [ ] COMMENT
- [ ] LADDER
- [ ] SIM 条件成立でM322 ON
- [ ] SIM 手動モードでOFF
- [ ] SIM M321 OFFでOFF
- [ ] SIM M324 ONでOFF

### 6.4 自動運転 M305

SET：M322 + M181自動起動PB立上り。

RESET：M182停止PB、M321解除、M324、必要な安全監視喪失。

- [ ] COMMENT
- [ ] LADDER
- [ ] SIM 自動起動PBだけでは条件不足時SETされない
- [ ] SIM 正常起動でSET
- [ ] SIM 停止PBでOFF
- [ ] SIM STOP後にM321が健全なら保持されることを別確認
- [ ] SIM RESET後にM305が自動再SETされない

### 6.5 M323 投入可

現行方針：下流蓄積能力を考慮し、搬出満杯だけでライン全体を一律投入禁止にしない。

最低確認：

- [ ] 自動運転中のみ成立候補
- [ ] CV01投入位置が受入可能
- [ ] 搬送/加工状態と矛盾しない
- [ ] M324異常中はOFF
- [ ] M154/M770を直接グローバル禁止条件にしない方針と整合確認

M323の最終論理は既存COMMON_RUN仕様と最終監査で確定する。

### 6.6 M330 加工ST受入許可

一次基準：

```text
M305
AND M321
AND M500
AND NOT M140
AND NOT M141
AND M142 AND M144 AND M146 AND M150 AND M152
AND NOT M166
AND NOT M167
AND NOT M154
AND NOT M324
```

- [ ] COMMENT
- [ ] LADDER
- [ ] SIM M500待機/原位置/空きでON
- [ ] SIM 加工中はOFF
- [ ] SIM M140またはM141在荷でOFF
- [ ] SIM 搬出満杯M154でOFF
- [ ] SIM 主軸RUN確認M166 ONでOFF
- [ ] SIM M167/M324でOFF

M330はAUTO用受入許可。MANUALで加工STへ送るときの許可条件にM330をそのまま流用しない。

## 7. Batch A 統合シミュレーション

### A-01 起動前

- [ ] M305 OFF
- [ ] M321 OFF
- [ ] M322 OFF
- [ ] RESETや入力初期化だけで運転開始しない

### A-02 運転準備

- [ ] M320成立
- [ ] 運転準備PBでM321 SET
- [ ] PBを離してもM321保持

### A-03 自動起動

- [ ] AUTOモードM301
- [ ] M322成立
- [ ] 自動起動PBでM305 SET

### A-04 通常停止

- [ ] 停止PBでM305 OFF
- [ ] 条件健全ならM321保持
- [ ] 自動起動PB再操作までM305再SETしない

### A-05 異常喪失

- [ ] 安全監視/低エア/異常成立で運転許可解除
- [ ] 正常復帰だけでは自動再起動しない
- [ ] RESETだけでも自動再起動しない

### A-06 Passage

- [ ] 5系統すべてON→OFFの順序でCOMPLETE成立
- [ ] OFF単独ではCOMPLETE不成立

### A-07 モード矛盾

- [ ] X5/X6同時ONでM300/M301同時成立しない
- [ ] 不成立状態をGOT側で将来M929へ表示可能
