# 01 Drilling Line — GX Works3 Batch D Section 09～11 MANUAL / OUTPUT チェックシート

Status: Draft / 教材・シミュレーション実装チェック用

## 1. 目的

Batch Dとして Section 09 `MANUAL`、Section 10 `OUTPUT_REQUEST`、Section 11 `ACTUAL_OUTPUT` をGX Works3へ実装・確認する際に、各項目を `COMMENT / LADDER / SIM` の3段階で記録できるようにする。

本資料は教材・シミュレーション用の通常制御チェックシートであり、安全機能そのものを通常PLC/GOTで成立させない。

### チェック記号

- `[ ] C` : デバイスコメント / 名称確認
- `[ ] L` : ラダー実装確認
- `[ ] S` : シミュレーション確認

## 2. 共通経路

すべての手動操作で以下の経路を確認する。

```text
GOT REQUEST
→ MANUAL REQUEST
→ COMMON REQUEST
→ ACTUAL Y
→ FB
```

確認：

- [ ] C GOT要求 M900～M913 / M980～M990 のコメントが一致
- [ ] C MANUAL M830～M854 のコメントが一致
- [ ] C COMMON M860～M884 のコメントが一致
- [ ] C Y0～Y34 のコメントが物理I/O表と一致
- [ ] L GOTからYへ直接コイルを書かない
- [ ] L Section 09からYを直接駆動しない
- [ ] L Section 10からYを直接駆動しない
- [ ] L 実YはSection 11だけで駆動
- [ ] S GOT req → MANUAL → COMMON → Y → FB をオンライン監視で追跡可能
