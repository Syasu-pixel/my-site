# 01 Drilling Line — GX Works3 Batch E Section 12～13 Fault / Warning チェックシート

Status: Draft / 教材・シミュレーション実装チェック用

## 1. 目的

Section 12 `TIMEOUT_FAULT` と Section 13 `WARNING_BUZZER` をGX Works3へ実装・試験する際に、各項目を `COMMENT / LADDER / SIM` の3段階で確認する。

本資料は教材・シミュレーション用の通常制御チェックであり、安全機能そのものを通常PLC/GOTで成立させない。

記録例：

- COMMENT：デバイスコメント登録確認
- LADDER：ラダー入力・クロスリファレンス確認
- SIM：GX Works3シミュレーション確認

## 10. 実装完了判定

Batch Eは以下が全て成立したら完了とする。

- [ ] M701～M750がコメント・ラダー・試験で追跡できる。
- [ ] M324とM325が明確に分離されている。
- [ ] RESETで自動再始動しない。
- [ ] 原因未復旧Alarmを解除できない。
- [ ] 警告だけでは自動停止しない。
- [ ] ブザー停止がAlarm RESETになっていない。
- [ ] 安全監視を通常PLC/GOTで解除していない。
- [ ] 未確定の監視時間やAlarm番号を勝手に確定していない。
