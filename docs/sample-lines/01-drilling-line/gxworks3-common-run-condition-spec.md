# 01 Drilling Line — GX Works3 共通運転条件 / M300帯仕様

Status: Draft / 教材・シミュレーション基準

## 1. 目的

`gxworks3-program-architecture-spec.md` の M300～M399 を具体化し、運転準備・自動起動・通常停止・異常時解除・投入可・加工ST受入許可の成立条件を統一する。

本資料は通常PLC側の制御ロジック仕様である。非常停止、安全扉、ライトカーテン等の安全機能そのものは通常PLCで成立させず、PLC側では安全回路から返る監視信号を通常運転許可条件として扱う。

## 2. 基本デバイス

- M300：手動モード成立
- M301：自動モード成立
- M305：自動運転中
- M310：停止要求
- M320：運転準備条件成立
- M321：運転準備ラッチ
- M322：自動起動可能
- M323：投入可条件
- M324：異常総合
- M325：警告総合
- M326：ブザー要求
- M327：ブザー消音状態
- M330：加工ST受入許可

入力Mは `gxworks3-input-mapping-spec.md` を正とする。

## 3. モード成立

### M300 手動モード成立

基準条件：

- M105 手動モードSW = ON
- M106 自動モードSW = OFF

手動/自動が同時成立する構造にしない。

### M301 自動モード成立

基準条件：

- M106 自動モードSW = ON
- M105 手動モードSW = OFF

セレクタの中間・不一致時はどちらも成立させず、GOTにモード未成立を表示できるようにする。

## 4. M324 異常総合

M324は設備を通常自動運転できない異常の総合状態とする。

対象：

- M701～M704 搬送タイムアウト
- M711～M715 ストッパー不一致
- M721～M726 各CY異常
- M730 加工位置未成立
- M731 低エア圧異常扱い時
- M741～M744 INV異常
- M750 主軸異常 / 運転確認異常

安全監視表示 M760～M764 は、異常総合と表示上は分けてもよいが、運転準備条件には必ず反映する。

搬出満杯、投入待ち、下流待ち、タクト超過はM324へ含めない。

## 5. M320 運転準備条件成立

M320は「運転準備PBを受け付けてよい物理・制御状態」を表す。

一次条件：

- M110 安全回路OK
- M111 エア圧OK
- M112 非常停止系正常監視
- M113 安全扉閉
- M114 ライトカーテンクリア
- M115 安全リレー正常
- NOT M324 異常総合
- M142 CY01 搬送面復帰端
- M144 CY02 後退端
- M146 CY03 解除端
- M150 CY04 解除端
- M152 CY05 上昇端
- NOT M167 主軸異常

加工STにワークが存在していても、原位置・安全条件が成立しているならM320自体は成立可能とする。復旧時のワーク残りは別の状態表示と手動復旧フローで扱う。

## 6. M321 運転準備ラッチ

M321 SET条件：

- M320 = ON
- M180 運転準備PB立上り

M321 RESET条件：

- 安全回路OK喪失
- 非常停止系正常監視喪失
- 安全扉閉喪失
- ライトカーテンクリア喪失
- 安全リレー正常喪失
- エア圧OK喪失が停止対象となる場合
- M324 異常総合成立

通常停止PBではM321を落とさない。

RESET PBだけでM321を自動SETしない。

## 7. M322 自動起動可能

基準条件：

- M301 自動モード成立
- M321 運転準備ラッチ
- M320 運転準備条件成立
- NOT M305 自動運転中
- NOT M324 異常総合

M322は自動起動PBを受け付け可能であることを示す表示用・条件用ビットとする。

## 8. M305 自動運転中

M305 SET条件：

- M322 自動起動可能
- M181 自動起動PB立上り

M305 RESET条件：

- M182 停止PB立上り
- M321運転準備ラッチ解除
- M324 異常総合成立
- 安全監視条件喪失

通常停止ではM305のみOFFとし、M321が健全なら再度自動起動PBで再開できる。

異常・安全条件喪失ではM305とM321をともにOFFとする。

## 9. M310 停止要求

M310は停止PB操作を1スキャン以上確実に制御側へ渡すための停止要求とする。

- M182 停止PB立上りで成立
- M305解除処理後にクリア

必要であれば停止処理完了確認用Mを別途追加するが、現段階ではM305解除を主処理とする。

## 10. RESETの扱い

M183 RESET PB立上りで実施するのは、原因が復旧済みのラッチ異常解除のみとする。

RESETで以下は行わない。

- M321の自動SET
- M305の自動SET
- 自動工程の自動再始動
- 安全条件の迂回

異常解除後は、必要に応じて運転準備PB → 自動起動PBの順で再開する。

## 11. M323 投入可条件

M323は作業者へ「新しいワークを投入してよい」ことを示す。

一次条件：

- M305 自動運転中
- M321 運転準備ラッチ
- M116 CV01在荷 = OFF
- NOT M430 CV01→CV02 transfer busy
- NOT M324 異常総合

M154/M770 搬出満杯は、M323を直接OFFする全体投入禁止条件にはしない。下流が満杯でもCV01に投入余地があり、蓄積搬送の通常条件が成立する間は投入を許可できる方針とする。実際の流動停止は各搬送先在荷・M330加工ST受入不可・M514搬出待ちなどの下流条件で自然に伝播させる。

ただし、CV01以降に実質的な空きがなく新規ワークを安全に保持できない状態では、各区間の在荷・busy・受入条件からM323を成立させないようにする。M323へ単純に `NOT M770` を追加する方式は採用しない。

投入完了PB M184は、M323成立中のみ受け付ける。

投入完了PBを押しただけでCV01在荷を仮想的にON扱いしない。実在荷センサM116でワーク存在を確認する。

## 12. M330 加工ST受入許可

M330はCV04→加工STの搬送開始許可とする。

一次条件：

- M305 自動運転中
- M321 運転準備ラッチ
- M500 加工ST待機
- M140 加工ST搬送位置在荷 = OFF
- M141 加工治具位置在荷 = OFF
- M142 CY01搬送面復帰端
- M144 CY02後退端
- M146 CY03解除端
- M150 CY04解除端
- M152 CY05上昇端
- M166 主軸運転確認 = OFF
- M167 主軸異常 = OFF
- M154 搬出満杯 = OFF
- NOT M324 異常総合

主軸の「停止確認」は現I/Oでは専用ゼロ速度信号を持たないため、現段階では「運転確認OFF」を通常停止状態の目安として扱う。正式な停止確認方式を追加する場合は、物理I/O・E10・E14・配線表・GX Works3コメントを同時更新する。

## 13. M325 警告総合

故障停止としない状態をM325へまとめる。

候補：

- 搬出満杯
- 投入待ち
- 下流空き待ち
- タクト超過
- 手動復旧待ち

警告はM305を必ずしも解除しない。個別の設備動作を待機させる条件として使用する。

## 14. M326 / M327 ブザー

M326：ブザー要求

- 新規異常発生
- 必要な重要警告発生

M327：ブザー消音状態

- M187 ブザー停止PB立上りでセット
- 新規の別異常が発生した場合は必要に応じて解除
- 異常表示そのものは消音しても残す

Y34はM326とM327の組合せから一元生成する。

## 15. 起動・停止状態遷移

```text
安全・原位置成立
      ↓
M320 運転準備条件
      ↓ 運転準備PB
M321 運転準備ラッチ
      ↓ 自動モード
M322 自動起動可能
      ↓ 自動起動PB
M305 自動運転中
      ↓ 停止PB
M305 OFF / M321保持
      ↓ 自動起動PB
M305 再SET
```

異常・安全条件喪失時：

```text
M305 OFF
M321 OFF
↓
原因復旧
↓
必要ならRESET
↓
運転準備PB
↓
自動起動PB
```

## 16. 次工程

次はM400帯の4搬送区間を同一パターンで定義し、各区間について

- 搬送要求
- ストッパー下降
- モータRUN
- passage seen / complete
- 搬送元在荷OFF
- 搬送先在荷ON
- 搬送完了
- タイムアウト
- 隣接区間インターロック

を共通テンプレートとして固定する。
