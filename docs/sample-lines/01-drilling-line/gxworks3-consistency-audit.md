# 01 Drilling Line — GX Works3 / 電気図面 整合監査

Status: Draft / 実プロジェクト作成前監査

## 1. 目的

GX Works3実プロジェクトへ転記する前に、物理I/O、端子台、E01～E18、配線表、内部M/D、GOT要求、搬送・加工シーケンスの番号・名称・責任範囲を横断確認する。

本資料は教材・シミュレーション用の通常制御監査であり、安全機能そのものの妥当性確認ではない。実機安全設計は別途リスクアセスメント、必要安全性能、採用安全機器の正式仕様に基づいて行う。

## 2. 監査結果サマリー

現時点の主要な番号体系は概ね一致している。

今回の監査で修正した主な不整合：

1. `gxworks3-device-comment-master.md` に未反映だった M440～M476 搬送サブステップを反映。
2. 同ファイルに M900～M913、M940～M959、M980～M990 GOT関連デバイスを反映。
3. XT8予約区分を `01～08 DI / 09～16 DO / 17～18 +24V / 19～20 0V / 21～24 SPARE` に統一。
4. E18に残っていた「加工ST主軸線番が未修正」という旧注記を除去し、731 / 741 / 742で統一済みとした。

## 7. 加工ステップ

M500～M517は `gxworks3-process-step-spec.md` を正とする。

主要確認：

- M507 主軸準備でM824要求。
- M166 RUN FB成立後にM508へ。
- M508でM823 CY05下降 + M824主軸RUN。
- M509でM822 CY05上昇、上昇端M152成立後に主軸RUNを解除。
- M514搬出満杯は故障でなく待ち。
- M517完了後M500へ戻る。

主軸ゼロ速度専用入力は現行I/Oに存在しない。停止確認信号を架空に追加しない。

## 8. アラーム / RESET

主要アラーム帯：

- M701～704：A101～104 搬送タイムアウト
- M711～715：A111～115 ST異常
- M721～726：A201～206 CY異常
- M730：A210 加工位置
- M731：A301 低エア
- M741～744：A401～404 INV
- M750：A410 主軸

RESET方針：

- 原因復旧後のみラッチ解除可能。
- RESETでM305を自動SETしない。
- RESETでM321を自動SETしない。
- RESETで加工ステップや搬送サブステップを無条件初期化しない。
- 位置不整合時は手動復旧へ。

## 9. GOT

- GOTからYへ直接書かない。
- GOT要求 → MANUAL section → M830～M854 → COMMON → Y。
- 自動運転中M305では通常手動要求を通さない。
- M940～M959で操作不可理由を表示する。
- 手動ボタンは原則モーメンタリ。

## 10. Dデバイス

現行基準：

- D100：現在加工ステップ
- D101：現在搬送状態
- D110：搬送タイムアウト
- D111：加工アクチュエータタイムアウト
- D112：穴あけ滞留時間
- D120：目標タクト
- D200～：生産実績
- D300～：保守 / 診断 / 将来設定

D110 / D111 / D112 / D120は毎スキャン固定値を書かず、初回初期化または設定保持方式とする。

## 12. 実プロジェクト作成判定

教材・シミュレーション用GX Works3プロジェクトについては、現時点で **作成開始可能** と判定する。

ただし、実機へそのまま転用可能という意味ではない。まずGX Works3上でコメント・Section・デバイス割付を作成し、シミュレーションで以下を確認する。

1. PBエッジ
2. モード / 運転準備 / 起動停止
3. T1～T4単独搬送
4. 非隣接同時搬送
5. 隣接排他
6. M500～M517加工遷移
7. タイムアウト / RESET
8. GOT手動要求ブロック
9. 出力相反防止
10. 警告と故障の分離

この監査を基準に、次工程はGX Works3実プロジェクト構築またはシミュレーション試験表作成へ進む。
