# 01 Drilling Line — GOT手動操作 BLOCK / 許可マトリクス

Status: Draft / 教材・シミュレーション基準

## 1. 目的

G03/G04の各手動操作について、GOT要求M、MANUAL要求M、COMMON要求M、実Y、主要フィードバック、代表BLOCK理由を一表で追えるようにする。

本表は通常制御の診断・シミュレーション用であり、安全機能を通常PLC/GOTで代替しない。

## 2. 共通許可

すべての手動操作は最低限、PLC側で次を確認する。

- M300 手動モード成立
- M305 自動運転中 = OFF
- 対象動作の通常制御インターロック成立
- 相反する要求なし
- 対象機器の異常なし
- 安全回路からの通常運転許可監視が成立

GOTボタン表示だけで許可を成立させない。

## 5. 相反要求 M943

次の組は同時要求禁止。

- ST01 UP / DOWN
- ST02 UP / DOWN
- ST03 UP / DOWN
- ST04 UP / DOWN
- ST05 UP / DOWN
- CY01 HOME / PROCESS
- CY02 BACK / FORWARD
- CY03 RELEASE / POSITION
- CY04 RELEASE / CLAMP
- CY05 UP / DOWN

相反要求が同時成立した場合、両方向の最終COMMON要求を成立させない。

## 6. CY05 DOWNの追加確認

CY05下降は加工系の中でも干渉リスクが大きいため、少なくとも通常制御上、次の状態を確認してからMANUAL要求へ通す設計候補とする。

- M141 治具在荷
- M147 位置決め端
- M151 クランプ端
- M166 主軸運転確認
- M167 主軸異常 = OFF
- 関連軸が加工位置に整合

本項は教材・シミュレーション用の論理条件整理であり、実機の安全設計・危険源評価・ガード条件の代替ではない。

## 7. 主軸RUN

主軸RUN要求は、通常制御上少なくとも次を確認する候補とする。

- M141 治具在荷
- M147 位置決め成立
- M151 クランプ成立
- M152 CY05上昇端を基準状態として確認
- M167 主軸異常 = OFF

主軸停止完了/ゼロ速度専用入力は現I/Oにないため、架空の停止確認信号を追加しない。

## 8. 搬出満杯 M954

M154/M770搬出満杯は故障ではない。

ただし、ST05や搬出に直接関係する手動操作で、さらに下流へワークを送る要求を禁止する理由としてM954を表示できる。

上流のすべての手動操作を無条件に禁止するグローバルBLOCKにはしない。

## 9. 診断の見方

例：CY04 CLAMP

```text
M987 GOT要求 ON
↓
M851 MANUAL OFF
↓
M955 工程干渉 ON
```

なら、GOTボタン自体ではなくPLC側許可条件で止まっていると判断できる。

```text
M987 ON
M851 ON
M881 ON
Y25 OFF
```

なら、ACTUAL_OUTPUT側の最終条件を確認する。

```text
Y25 ON
M151 OFF
```

なら、指令は出ているが期待フィードバックが未成立である。

## 10. 実装ルール

- M940～M955は診断表示用であり、制御正本は各手動操作許可ロジックとする。
- BLOCKビットを解除するために安全監視をバイパスしない。
- 手動要求をラッチしっぱなしにせず、原則モーメンタリ操作とする。
- GOT画面切替時に要求Mが残留しないことをGT Works3側でも確認する。
- M900～M913 / M980～M990からYへ直接接続しない。
