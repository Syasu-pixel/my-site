# 01 Drilling Line — GX Works3 入力Mマッピング

Status: Draft / 教材・シミュレーション基準

## 1. 目的

`physical-io-map.md` の物理入力 X0～X67 を、GX Works3 内部入力 M100帯へ1対1で対応させる。

プログラム本体では原則として物理Xを直接多用せず、`INPUT_PROCESS` で内部Mへ受けた後の信号を使用する。

安全監視入力は通常PLC側では監視・通常制御許可判定にのみ使用し、安全機能そのものを通常PLCで成立させない。

## 2. 割付ルール

- M100帯は「物理入力の意味変換」専用とする。
- 押しボタンの立上り/立下りはM100帯そのものではなく、必要に応じてM180帯等のエッジ補助へ分離する。
- 通過センサのSEEN / COMPLETEはM200帯で生成する。
- X70～X77は予備のため、用途確定前は内部Mを固定割当しない。
- 物理入力の論理反転が必要な場合でも、元入力状態と意味信号の関係が分かるコメントを付ける。

## 7. 予備入力 X70～X77

現段階では固定用途を割り当てない。

- X70～X77：SPARE
- 対応M：用途確定時に割付

将来用途が決まった場合は、`physical-io-map.md`、端子台仕様、配線表、E10、GX Works3コメントを同時更新する。

## 8. 押しボタン・エッジ補助

押しボタン類はM100帯へ受けた後、必要に応じて別Mでワンショット化する。

一次候補：

- M180：運転準備PB立上り
- M181：自動起動PB立上り
- M182：停止PB立上り
- M183：RESET PB立上り
- M184：投入完了PB立上り
- M187：ブザー停止PB立上り

固定命令形式はGX Works3プロジェクト実装時に決める。

## 9. 通過センサとの関係

通過入力M122～M125、M155は、そのまま搬送完了には使用しない。

M200帯で以下を生成する。

- M200 / M201：CV01 passage seen / complete
- M202 / M203：CV02 passage seen / complete
- M204 / M205：CV03 passage seen / complete
- M206 / M207：CV04 passage seen / complete
- M208 / M209：加工ST排出 passage seen / complete

`complete` は「ON確認後のOFF」で成立させる。

## 10. GX Works3コメント登録基準

デバイスコメントは、物理信号名と設備タグが追える名前にする。

例：

- M142 `CY01 搬送面復帰端`
- M151 `CY04 クランプ端`
- M166 `主軸 運転確認`

物理Xを変更した場合でも、制御側ではMコメントで意味を追える構造を維持する。
