# 01 Drilling Line — GX Works3 Section 16 MAINTENANCE デバイス割付

Status: Draft / 教材・シミュレーション実装基準

## 1. 目的

G08 メンテナンス画面と Section 16 `MAINTENANCE` で使用する D300～D399 を正式割付し、運転時間・動作回数・異常発生回数・診断値を一貫して扱う。

本資料は通常PLC/HMIの保守支援用。安全機能の診断・安全回路の試験・Y強制操作を本領域で代替しない。

## 2. 割付方針

- D300～D309：運転時間
- D310～D329：機構動作回数
- D330～D359：異常発生回数
- D360～D379：診断 / 復旧統計
- D380～D399：将来予約

各カウンタは単なる出力要求ON回数ではなく、可能な限り「実フィードバック成立」または「異常の新規立上り」をイベントとして更新する。

## 3. 運転時間 D300～D309

| Device | Comment | 更新基準 |
|---|---|---|
| D300 | CV01累積運転時間 | Y0またはM860の実運転成立時間 |
| D301 | CV02累積運転時間 | Y1またはM861 |
| D302 | CV03累積運転時間 | Y2またはM862 |
| D303 | CV04累積運転時間 | Y3またはM863 |
| D304 | 主軸累積運転時間 | M166運転確認を優先 |
| D305 | 自動運転累積時間 | M305 |
| D306～D309 | SPARE | - |

表示単位は「分」を一次基準とする。内部で秒積算する場合は補助ワーク領域を別途使用し、GOT表示値D300～D305は分単位へ正規化する。

主軸はRUN要求ではなくM166運転確認成立時間を基準にすることで、要求だけ出て実際に回っていない時間を累積しない。

## 4. ストッパー動作回数 D310～D314

| Device | Comment | カウントイベント |
|---|---|---|
| D310 | ST01動作回数 | M126/M127の有効端遷移 |
| D311 | ST02動作回数 | M130/M131 |
| D312 | ST03動作回数 | M132/M133 |
| D313 | ST04動作回数 | M134/M135 |
| D314 | ST05動作回数 | M136/M137 |

1回の往復を1回と数えるか、各片道を1回と数えるかは教材表示上の意味を統一する必要がある。本仕様では一次基準として「要求方向の期待端が新たに成立した1動作 = 1カウント」とする。

相反端同時成立など異常な端状態では動作回数を増やさない。

## 9. 保持 / リセット方針

D300～D365は累積保守情報のため、電源断保持候補とする。ただしFX5Uの保持範囲・バックアップ方針は最終GX Works3パラメータ設定時に確認する。

本仕様では保持対象候補を定義するだけで、実機の保持デバイス設定を未確認のまま固定しない。

保守統計クリアを将来実装する場合は、

- Level 2相当の保守権限
- 自動停止中
- 確認ポップアップ
- クリア対象の明示

を条件とし、通常運転員向けG08には即時クリアボタンを置かない。

## 10. オーバーフロー方針

16bit D単体の上限を超える可能性がある累積値については、最終実装時に32bit化または上限飽和処理を選択する。

現段階では値が上限到達時に0へ循環して保守履歴を失う設計を採用しない。

## 11. G08表示対応

G08では以下を表示する。

- 運転時間：D300～D304
- ST動作回数：D310～D314
- CY動作回数：D315～D319
- 搬送/ストッパー異常：D330～D338
- 加工/駆動異常：D339～D351
- 総異常/警告/復旧統計：D360～D365

D305自動運転累積時間は画面密度に余裕があれば表示し、D306～D309、D366～D399は用途確定まで表示しない。

## 12. Section 16 実装順

```text
16-01 運転時間積算
16-02 ST動作完了エッジ → D310～D314
16-03 CY動作完了エッジ → D315～D319
16-04 アラーム新規立上り → D330～D351
16-05 診断イベント → D360～D365
16-06 保持 / オーバーフロー監視
```

## 13. 禁止事項

Section 16から以下を行わない。

- Y出力を直接駆動
- M305/M321をSET
- 安全監視M760～M764を解除
- M700帯アラームをRESET
- インバータ/主軸の危険な設定変更

Section 16は統計と診断の従属処理に限定する。

## 14. シミュレーション確認

1. 同一FBがON保持されても動作回数が毎スキャン増えない。
2. アラームラッチが継続ONでも異常回数が1回だけ増える。
3. 主軸要求だけでD304が増えず、M166成立時のみ積算される。
4. M965新規アラームパルス1回でD360が1増える。
5. M967新規警告パルス1回でD361が1増える。
6. 統計更新がM305/M321/Yへ影響しない。
7. 電源断保持の最終設定が未確認なら、その旨を試験記録へ残す。
