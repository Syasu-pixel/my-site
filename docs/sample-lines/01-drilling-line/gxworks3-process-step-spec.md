# 01 Drilling Line — GX Works3 加工ステップ M500～M517 仕様

Status: Draft / 教材・シミュレーション基準

## 1. 目的

加工ステーションの `M500～M517` を、GX Works3でそのまま追えるステップ構造として固定する。

各ステップについて、

- Entry条件
- 自動出力要求
- 必要フィードバック
- 次ステップ条件
- タイムアウト監視
- 異常時の保持 / 復旧

を明文化し、ラダー実装・GOT表示・アラーム設計を同じ基準へ揃える。

本資料は教材・シミュレーション用の通常制御仕様であり、安全機能そのものは通常PLCロジックで成立させない。

## 2. 共通原則

- 加工ステップは原則として同時に1つだけON。
- 正常遷移は `現在ステップ AND 完了条件 → 次ステップSET / 現在ステップRESET` の考え方を基準とする。
- 時間経過だけで機械を次工程へ送らない。
- アクチュエータを動かした場合は、原則として対応する端確認を見てから次へ進む。
- 主軸はRUN要求だけでなく `M166 主軸運転確認` を確認してから穴あけ動作へ進む。
- `M167 主軸異常`、重大アクチュエータ異常、共通異常 `M324` 成立時は自動進行を停止する。
- RESETだけでは途中工程を勝手に再開させない。
- 通常停止時は現在ステップを保持する基準とし、再開時に現在位置とフィードバックを再確認する。
- 異常復旧で位置関係が崩れた場合はGOT手動復旧で安全な基準位置へ戻した後、運転準備から再開する。

## 4. M500 — 加工ST待機

### Entry

加工STが基準位置で待機可能であること。

基準条件：

- M305 自動運転中
- M321 運転準備ラッチ
- M324 異常総合 = OFF
- M142 CY01搬送面復帰端 = ON
- M144 CY02後退端 = ON
- M146 CY03解除端 = ON
- M150 CY04解除端 = ON
- M152 CY05上昇端 = ON
- 主軸RUN要求 = OFF

### 出力要求

- ST05上昇側を基準状態として保持
- CY01搬送面復帰
- CY02後退
- CY03解除
- CY04解除
- CY05上昇
- 主軸RUN OFF

### 次ステップ

T4完了後、

- M140 加工ST搬送位置在荷 = ON
- M136 ST05上昇端 = ON
- 加工ST原位置条件成立

で `M501` へ。

### 異常・復旧

待機位置が成立しない場合は自動で無理に補正せず、原位置不成立として復旧画面へ誘導する。

## 5. M501 — 搬入成立確認

### フィードバック

- M166 主軸運転確認 = ON

### 次ステップ

M166成立後、必要な安定確認を経て `M508` へ。

## 23. 通常停止時

通常停止PBでM305がOFFした場合：

- 新しい加工ステップへ自動進行しない。
- 現在ステップMは保持する基準。
- 出力要求は共通停止ポリシーに従う。
- 再開時は現在ステップに必要なフィードバックを再確認する。
- 状態が崩れている場合は自動再開せず、復旧画面へ誘導する。

実機での停止カテゴリ・主軸停止方式・機械的な安全停止は別途安全設計で決める。

## 24. 異常時の基本方針

異常成立時：

- M305 自動運転中を解除
- 現在加工ステップは診断用に保持
- 主軸・搬送・シリンダ要求は共通出力ポリシーに従って解除/保持判断
- 異常原因と現在端位置をGOTに表示
- RESETは原因復旧後の異常ラッチ解除に限定
- RESET後も自動起動は別操作

位置が不明な場合は自動で複数軸を一斉復帰させない。

## 25. GOT表示

自動画面・復旧画面では最低限以下を表示する。

- 現在ステップ M500～M517
- D100 現在ステップ番号
- ステップ名称
- 現在待っているフィードバック
- タイムアウト残/成立状態
- ブロック理由
- 各CY端位置
- ST05状態
- 主軸RUN確認 / 異常
- 搬出満杯
