# 01 Drilling Line — GX Works3 プロジェクト作成チェックリスト

Status: Draft / 実プロジェクト作成直前確認

## 1. 目的

これまで作成したI/O、デバイス、シーケンス、アラーム、GOT連携仕様を、GX Works3プロジェクトへ落とし込む前に不整合なく確認する。

## 2. プロジェクト基本

- [ ] PLCシリーズ/CPUを設計基準と一致させる
- [ ] GX Works3プロジェクト名称を設備番号と対応させる
- [ ] コメント言語/表記ルールを統一する
- [ ] Section 00～16を設計順で作成する

## 3. ハードウェア構成

- [ ] CPU：FX5U-64MT/ES
- [ ] 追加DI：FX5-C32EX/DS-TS
- [ ] 変換：FX5-CNV-IF
- [ ] CPU X0～X37、追加DI X40～X77の割付を実機設定画面で照合
- [ ] Y0～Y37のCPU出力範囲を照合
- [ ] 将来DOユニットは機種確定前に架空アドレスを作らない

## 4. 物理I/O

- [ ] `physical-io-map.md` とGX Works3割付を1点ずつ照合
- [ ] X70～X77はSPAREのまま
- [ ] Y35～Y37はSPAREのまま
- [ ] 主軸X66/X67、Y30をE10/E14と照合
- [ ] 安全監視入力を安全機能本体と混同しない

## 5. デバイスコメント

- [ ] X/Yコメントを登録
- [ ] M100入力意味変換を登録
- [ ] M200 passageを登録
- [ ] M300共通運転を登録

- [ ] M700帯アラーム/警告を登録
- [ ] M800帯AUTO/MANUAL/COMMONを登録
- [ ] M900/M940/M980帯GOT関連を登録
- [ ] D100～D213主要Dコメントを登録

## 7. 入力処理

- [ ] 物理Xは原則Section 00で意味Mへ受ける
- [ ] PB立上りM180/M181/M182/M183/M184/M187を作る
- [ ] passageはOFF単独で完了にしない
- [ ] M200～M209のSEEN/COMPLETEを確認

## 8. 運転準備/自動運転

- [ ] M320運転準備条件
- [ ] M321運転準備ラッチ
- [ ] M322自動起動可能
- [ ] M305自動運転中
- [ ] 通常停止でM321を保持する設計確認
- [ ] 異常/安全条件喪失でM305/M321解除
- [ ] RESETだけで自動再始動しない

## 9. 搬送

- [ ] T1～T4 Busy M430～M433
- [ ] T1 M440～M446
- [ ] T2 M450～M456
- [ ] T3 M460～M466
- [ ] T4 M470～M476
- [ ] 隣接区間排他
- [ ] 非隣接区間同時可
- [ ] passage complete + source OFF + destination ONで完了
- [ ] T4完了で加工STへ責任移管

## 10. 加工STEP

- [ ] M500～M517が同時に複数ONしない
- [ ] 指令→FB→次STEPの順を確認
- [ ] 主軸RUN確認M166後に穴あけへ
- [ ] CY05下降端後に滞留時間
- [ ] CY05上昇後に主軸要求解除
- [ ] 搬出満杯はM514で待機、故障扱いしない
- [ ] 現I/Oにないゼロ速度確認を作らない

## 11. 出力

- [ ] AUTO M800帯
- [ ] MANUAL M830帯
- [ ] COMMON M860帯
- [ ] YはSection 11だけで駆動
- [ ] ダブルSOLは上位/最終段の両方で相互排他
- [ ] 表示灯/ブザーはM890～M893で生成

## 12. アラーム/警告

- [ ] A101～A104搬送タイムアウト
- [ ] A111～A115ストッパー
- [ ] A201～A206加工CY
- [ ] A210加工位置
- [ ] A301低エア
- [ ] A401～A404 INV
- [ ] A410主軸
- [ ] 原因復旧前はRESET不可
- [ ] RESET後も自動起動しない
- [ ] 搬出満杯/投入待ち/下流待ち/タクト超過は警告として分離

## 13. GOT

- [ ] GOTからYへ直接書かない
- [ ] 手動要求M900/M980帯を使用
- [ ] M940帯で操作不可理由を表示
- [ ] 指令/原位置FB/動作位置FB/不可理由を同時表示
- [ ] 自動運転中は通常手動要求を遮断
- [ ] アラーム画面に期待FB/実FB/復旧不可理由を表示

## 14. D設定

- [ ] D110 搬送タイムアウト初期値
- [ ] D111 加工アクチュエータタイムアウト初期値
- [ ] D112 穴あけ滞留時間初期値
- [ ] D120 目標タクト初期値
- [ ] 毎スキャン初期値で上書きしない
- [ ] GOT変更値の上下限/反映タイミングを決める

## 15. シミュレーション確認

最低限、以下のシナリオを確認する。

- [ ] 正常起動
- [ ] CV01→CV02正常搬送
- [ ] T1/T3同時搬送
- [ ] 隣接区間同時開始禁止
- [ ] 通過センサONを見ずOFFだけでは完了しない
- [ ] 搬送タイムアウト
- [ ] ストッパー端未成立
- [ ] 加工CY端未成立
- [ ] 主軸RUN確認未成立
- [ ] 主軸異常
- [ ] 搬出満杯待機
- [ ] 通常停止→再開
- [ ] 異常→原因復旧→RESET→運転準備→再起動
- [ ] GOT手動操作不可理由表示

## 16. 実機移行前に未確定のまま残す項目

以下はGX Works3教材プロジェクトで推測確定しない。

- 安全回路詳細
- 安全機器選定/必要安全性能
- 主軸の正式停止/ゼロ速度確認方式
- 実機タイマ最終値
- インバータ最終パラメータ
- 将来DOモジュール機種/アドレス

実機適用時は、最新メーカー資料、機械条件、リスクアセスメント、試運転結果で確定する。

## 17. 完了判定

このチェックリストが通れば、01 Drilling Lineは「仕様整理」から「GX Works3プロジェクト作成」へ移行できる状態とする。
