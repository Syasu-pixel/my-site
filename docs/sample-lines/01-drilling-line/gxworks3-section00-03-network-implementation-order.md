# 01 Drilling Line — GX Works3 Section 00～03 ネットワーク実装順

Status: Draft / 教材・シミュレーション実装基準

## 1. 目的

Section 00～03を、GX Works3へそのまま転記しやすいネットワーク番号順に整理する。

対象：

- Section 00 INPUT_PROCESS
- Section 01 PASSAGE_DETECT
- Section 02 COMMON_SAFETY_MON
- Section 03 MODE_RUN

本資料は教材・シミュレーション用の通常PLCロジックである。非常停止、安全扉、ライトカーテン等の安全機能そのものは別の安全回路・安全機器で成立させ、通常PLC側では監視・通常運転許可にのみ使用する。

## 2. 実装ルール

- 上から下へ意味変換 → エッジ → 通過 → 共通状態 → モード/運転の順で処理する。
- 物理Xを後段Sectionで直接多用しない。
- RESETからM321/M305をSETしない。
- passage COMPLETEは「一度ONを確認後にOFF」で成立させる。
- 安全監視入力は通常制御の許可条件であり、安全機能本体ではない。
- 本資料では主回路・高電圧配線・保護定格を扱わない。

## 4. Section 01 — PASSAGE_DETECT

各通過センサは、RAW入力ONを見た後、OFFへ戻ったときにCOMPLETEを1スキャン生成する。

### Network 01-01 / 01-02 CV01

```text
M122 --------------------------------( SET M200 )
M200 AND NOT M122 -------------------( pulse M201 )
```

M200の解除は、T1完了処理で行う。単なる入力OFFだけではSEENを消さない。

### Network 01-11 / 01-12 CV02

```text
M123 --------------------------------( SET M202 )
M202 AND NOT M123 -------------------( pulse M203 )
```

### Network 01-21 / 01-22 CV03

```text
M124 --------------------------------( SET M204 )
M204 AND NOT M124 -------------------( pulse M205 )
```

### Network 01-31 / 01-32 CV04

```text
M125 --------------------------------( SET M206 )
M206 AND NOT M125 -------------------( pulse M207 )
```

### Network 01-41 / 01-42 加工ST排出

```text
M155 --------------------------------( SET M208 )
M208 AND NOT M155 -------------------( pulse M209 )
```

### Network 01-50 COMPLETE保持方針

- M201/M203/M205/M207/M209は原則1スキャンパルス。
- 搬送完了判定が複数条件を必要とするため、Busy/サブステップ側で必要なら完了状態を保持する。
- passage OFFだけで搬送完了とはしない。

## 5. Section 02 — COMMON_SAFETY_MON

### Network 02-01～02-05 安全監視表示

```text
NOT M112 ----------------------------( M760 )  E001
NOT M110 ----------------------------( M761 )  E002
NOT M113 ----------------------------( M762 )  E003
NOT M114 ----------------------------( M763 )  E004
NOT M115 ----------------------------( M764 )  E005
```

これらは通常PLC側の表示/運転不可理由であり、安全出力を制御する安全機能ではない。

### Network 02-10 M324 異常総合

```text
M701 OR M702 OR M703 OR M704
OR M711 OR M712 OR M713 OR M714 OR M715
OR M721 OR M722 OR M723 OR M724 OR M725 OR M726
OR M730 OR M731
OR M741 OR M742 OR M743 OR M744
OR M750
-------------------------------------( M324 )
```

安全監視M760～M764は表示分類を分離し、M320側で必ず運転準備を禁止する。

### Network 02-20 M325 警告総合

```text
M770 OR M771 OR M772 OR M773 OR M774 OR M775
-------------------------------------( M325 )
```

警告だけでは一律にM305を落とさない。

### Network 02-30 M320 運転準備条件

```text
M110
AND M111
AND M112
AND M113
AND M114
AND M115
AND NOT M324
AND M142
AND M144
AND M146
AND M150
AND M152
AND NOT M167
-------------------------------------( M320 )
```

現行基準では、ST01～ST05全UPおよびM166主軸RUN OFFはM320へまだ追加しない。これは未確定事項として維持する。

## 6. Section 03 — MODE_RUN

### Network 03-01 手動モード

```text
M105 AND NOT M106 -------------------( M300 )
```

### Network 03-02 自動モード

```text
M106 AND NOT M105 -------------------( M301 )
```

M105/M106が同時ONまたは同時OFFなら、M300/M301ともOFF。

### Network 03-10 運転準備ラッチSET

```text
M320 AND M180 -----------------------( SET M321 )
```

### Network 03-11 運転準備ラッチRESET

```text
NOT M110
OR NOT M111
OR NOT M112
OR NOT M113
OR NOT M114
OR NOT M115
OR M324
-------------------------------------( RST M321 )
```

通常停止M182ではM321を落とさない。

### Network 03-20 自動起動可能

```text
M301
AND M321
AND M320
AND NOT M305
AND NOT M324
-------------------------------------( M322 )
```

### Network 03-21 自動運転SET

```text
M322 AND M181 -----------------------( SET M305 )
```

### Network 03-22 自動運転RESET

```text
M182
OR NOT M321
OR M324
OR NOT M110
OR NOT M112
OR NOT M113
OR NOT M114
OR NOT M115
-------------------------------------( RST M305 )
```

### Network 03-30 停止要求

```text
M182 --------------------------------( SET M310 )
NOT M305 ----------------------------( RST M310 )
```

M310は停止操作を処理側へ確実に渡す補助状態。

### Network 03-40 投入可

```text
M305
AND M321
AND NOT M116
AND NOT M430
AND NOT M324
-------------------------------------( M323 )
```

搬出満杯M154/M770をグローバル投入禁止へ直結するかは現行方針では採用しない。投入可の上流制御と加工ST受入は分離して扱う。

M184投入完了パルスは、M323成立中のみ後段で受付する。

### Network 03-50 加工ST受入許可

```text
M305
AND M321
AND M500
AND NOT M140
AND NOT M141
AND M142
AND M144
AND M146
AND M150
AND M152
AND NOT M166
AND NOT M167
AND NOT M154
AND NOT M324
-------------------------------------( M330 )
```

M166 OFFは専用ゼロ速度確認ではない。現I/Oでは単なる主軸RUN FB OFFとして扱う。

### Network 03-60 ブザー消音

```text
M187 OR M962 ------------------------( SET M327 )
```

新規異常発生時のM327解除はSection 13 WARNING_BUZZER側で処理する。

## 7. Section 00～03 実装後の確認順

1. X→M100帯が1対1で追従する。
2. PBを長押ししてもM180/M181/M182/M183/M184/M187は1回だけ発生する。
3. passageはON→OFFを経て初めてCOMPLETEが出る。
4. モードSW不成立時にM300/M301が同時ONしない。
5. 安全監視またはM324異常でM320がOFF。
6. M320 + M180でM321がSET。
7. 停止PBではM305だけOFF、M321は健全なら保持。
8. 異常/安全監視喪失ではM305/M321ともOFF。
9. RESETだけではM321/M305がSETされない。
10. M330は加工ST原位置・空き・主軸RUN FB OFF・搬出空きがそろった時だけ成立する。

## 8. 未確定事項
