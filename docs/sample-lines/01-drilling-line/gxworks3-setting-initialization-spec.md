# 01 Drilling Line — GX Works3 設定Dデバイス初期化仕様

Status: Draft / 教材・シミュレーション基準

## 1. 目的

GX Works3プロジェクト起動時に使用する主要Dデバイスの役割、初期値、変更可否を整理する。

本資料の数値は教材・シミュレーション用の暫定値であり、実機では機械速度、ワーク、メーカー仕様、試運転結果に基づいて再設定する。

## 2. 主要設定D

| Device | 用途 | 初期値候補 | 備考 |
|---|---|---:|---|
| D110 | 搬送タイムアウト | 5.0 s級 | 4区間共通の初期基準 |
| D111 | 加工アクチュエータタイムアウト | 3.0 s級 | 各CY/STの一次基準 |
| D112 | 穴あけ滞留時間 | 1.0 s級 | 下降端成立後の教材用待ち |
| D120 | 目標タクト | 30.0 s | 設備目標 |

時間単位・タイマ換算方法はGX Works3実装時のタイマ命令・周期に合わせて統一する。

## 3. 初期化方法

初回スキャンまたは明示した初期化条件で、未設定時のみデフォルト値をロードする方式を基準とする。

GOTから設定変更できる場合は、毎スキャン初期値で上書きしない。

概念：

```text
IF first-start OR parameter-reset-request THEN
  D110 := default_transfer_timeout
  D111 := default_actuator_timeout
  D112 := default_drill_dwell
  D120 := default_target_takt
END_IF
```

## 4. 設定範囲

GOT入力値には上下限を持たせる。

ただし本資料では危険な機械動作速度や保護設定そのものを決めず、教材上の監視時間・表示基準だけを扱う。

- D110：短すぎて正常搬送を誤検知しない範囲
- D111：各アクチュエータの通常動作より十分長い範囲
- D112：工程説明用の滞留時間
- D120：生産目標表示用

正式上下限は試運転・機械条件確認後に確定する。

## 5. 運転中変更

D110/D111/D112の変更は、自動運転中に即時反映させるより、停止中または次サイクルから反映する方式を推奨する。

変更中に現在監視中のタイマ基準が変わって挙動が分かりにくくならないようにする。

## 6. D100 / D101 状態表示

- D100：現在加工ステップ番号
- D101：現在搬送状態番号

D100はM500～M517から500～517を表示用に生成する。

D101は搬送中の区間/サブステップを表示できるようにする。具体的な表示コードは以下を候補とする。

- 0：搬送なし
- 1xx：T1
- 2xx：T2
- 3xx：T3
- 4xx：T4

下2桁はサブステップ番号として利用できるが、正式コードはGOT画面実装時に固定する。

## 7. 生産D

- D200 総投入数
- D201 総排出数
- D202 OK数（将来）
- D203 NG数（将来）
- D210 直近サイクルタイム
- D211 平均サイクルタイム
- D212 最大サイクルタイム
- D213 最小サイクルタイム

生産カウンタを電源再投入後も保持するかは、GX Works3のラッチ設定・教材方針で決める。

## 8. パラメータ保存と復元

GOTから変更した設定値を保持する場合、保持対象と初期化対象を混在させない。

- 設定値：必要に応じ保持
- 現在ステップ：原則として起動時復旧ロジックに従う
- アラーム履歴：GOT履歴機能側と役割分担
- 生産数：保持方針を別途定義

## 9. 電源投入時の注意

電源投入だけで自動運転や加工工程を再開しない。

起動後は安全監視、機械位置、運転準備条件を確認し、運転準備PBと自動起動PBの操作を必要とする。

## 10. 次工程

GX Works3プロジェクト作成時は、本設定とデバイスコメント、セクション構成、I/O割付をチェックリストで照合する。
