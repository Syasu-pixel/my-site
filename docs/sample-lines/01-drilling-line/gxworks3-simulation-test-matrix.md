# 01 Drilling Line — GX Works3 シミュレーション試験表

Status: Draft / 教材・シミュレーション検証基準

## 1. 目的

GX Works3 / GX Simulator上で、01 Drilling Line の通常PLCロジックを段階的に検証するための試験表を定義する。

本資料は教材・シミュレーション用の通常制御試験であり、実機の安全妥当性確認・安全性能検証・主回路試験を代替しない。

## 2. 合格基準の考え方

各試験は最低限、以下を確認する。

- 入力変化が意図したMへ反映される
- 不要なステップ飛びがない
- 同時成立してはいけない要求が同時ONしない
- 正常フィードバック成立後だけ次ステップへ進む
- 異常時は自動運転が継続しない
- RESETだけで自動再始動しない
- 警告と故障を混同しない
- GOT要求からYへ直接書き込まない

結果欄は `PASS / FAIL / HOLD` を使用する。

## 18. 完了判定

教材・シミュレーション版の一次完了条件：

- A～Nの必須試験に重大FAILなし
- 正常サイクルが連続して成立
- 隣接搬送が同時に成立しない
- 非隣接搬送は許可条件下で同時動作できる
- RESETで自動再起動しない
- 出力相反なし
- GOTからY直接操作なし
- 警告と故障が分離されている
- 既知TBDを未解決のまま「解決済み」と扱っていない

ここまで成立した後に、GOT画面詳細・記事用動作説明・シミュレーション画面キャプチャへ進む。
