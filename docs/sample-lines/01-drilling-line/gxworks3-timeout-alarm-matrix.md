# 01 Drilling Line — GX Works3 タイムアウト / アラーム対応表

Status: Draft / 教材・シミュレーション基準

## 1. 目的

搬送区間 T1～T4 と加工ステップ M500～M517について、監視開始点、期待フィードバック、アラームM、運転停止、復旧条件を一元化する。

本資料は通常PLCの教材・シミュレーション用。安全機能は別の安全回路・安全機器で成立させる。

## 2. 共通ルール

- タイムアウトは「時間で工程を進める」ためではなく、指令に対するフィードバック未成立を検出するために使う。
- 異常成立時は該当動作要求を解除し、M324 異常総合へ反映する。
- M305 自動運転中は解除する。
- RESETだけで自動再起動しない。
- 原因が復旧し、必要位置を確認した後、運転準備→自動起動をやり直す。
- 安全監視喪失時の復旧は通常アラームRESETより優先し、安全系が成立していなければ運転準備しない。

## 11. 警告と故障の分離

次は原則として故障アラームにしない。

- 搬出満杯
- 投入待ち
- 下流空き待ち
- 加工待ち
- タクト超過

これらはM325 警告総合へ集約し、運転可否は個別条件で判断する。

## 12. RESET / 復旧

RESET可能条件は最低限、

- 原因入力が正常へ戻っている
- 安全監視が成立
- エア圧正常
- 相反端同時成立なし
- 主軸異常入力OFF

を確認する。

RESET後もM305は自動でSETしない。

途中停止で機械位置が工程と一致しない場合は、GOT手動復旧で原位置へ戻し、M320運転準備条件を再成立させる。

## 13. GOT表示

アラーム画面では最低限、

- コード
- 名称
- 発生中/履歴
- 関連機構
- 現在ステップ
- 指令状態
- 期待FB
- 実FB
- 復旧不可理由

を表示できる構造にする。
