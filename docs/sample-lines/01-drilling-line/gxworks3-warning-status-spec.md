# 01 Drilling Line — GX Works3 警告 / 待ち状態仕様

Status: Draft / 教材・シミュレーション基準

## 1. 目的

M325 警告総合へ集約する「故障ではないが、運転や投入判断に影響する状態」を整理し、アラーム停止系と明確に分ける。

本資料は通常PLCの表示・運転支援用仕様であり、安全機能そのものを通常PLC表示ロジックで成立させない。

## 2. 警告と故障の区別

故障：

- 機器異常
- 指令に対するフィードバック不成立
- センサ矛盾
- INV / 主軸異常
- 低エア圧など、自動運転継続を許可しない状態

警告 / 待ち：

- 搬出満杯
- 投入待ち
- 下流空き待ち
- 加工ST待ち
- タクト超過
- 一時的な工程待機

警告状態だけで一律にM305を落とさない。

## 3. M325 警告総合

一次候補として以下をOR集約する。

- M770：搬出満杯
- M771：投入待ち
- M772：下流空き待ち
- M773：加工ST待ち
- M774：タクト超過
- M775：自動運転待機中

M325はGOT共通警告表示、黄色表示灯や画面バナー等の基準信号として使用する。

Y33異常表示灯はM324異常総合を基準とし、警告M325とは分ける。

## 4. M770 搬出満杯

元信号：M154 搬出満杯。

### 状態

搬出シュート / ローラ側に新しいワークを排出できない。

### 制御

- M514 DISCHARGE PREPで待機
- M515へ進まない
- 新しい加工開始を抑制する条件へ反映可能
- M324異常総合には含めない
- M305は原則保持

### GOT

表示例：`搬出満杯 — 完成品を取り除いてください`

解除：M154 OFFで自動解除。

## 5. M771 投入待ち

投入可能条件は成立しているが、ワーク投入または投入完了操作を待っている状態。

条件候補：

- 自動運転中
- CV01投入可能
- 上流ワークなし
- M323投入可条件成立
- 投入完了ワンショット未成立

故障ではない。

GOTでは「投入してください」「投入完了PB待ち」など、実状態に応じて表示を分けてもよい。

## 6. M772 下流空き待ち

搬送元にワークがあるが、次区間が占有されていて搬送開始できない状態。

例：

- CV01在荷 + CV02在荷
- CV02在荷 + CV03在荷
- CV03在荷 + CV04在荷
- CV04在荷 + 加工ST受入不可

これは蓄積搬送の正常な待機状態。

M324には含めない。

## 7. M773 加工ST待ち

加工ステーションが次のワークを受け取れないが、故障ではない状態。

条件候補：

- M500待機以外の加工ステップ中
- M330加工ST受入許可OFF
- 搬出満杯による受入抑制
- 加工サイクル処理中

GOTでは「加工中」「受入待ち」など、読者が区別しやすい名称を表示する。

## 8. M774 タクト超過

目標タクト D120 に対し、直近サイクルまたは平均サイクルが基準を超えた状態。

用途：

- 生産性表示
- ボトルネック教材
- 改善学習

タクト超過だけで自動運転を停止しない。

解除方法候補：

- 次サイクルで基準内へ戻れば自動解除
- またはGOT確認で表示履歴のみ残す

## 9. M775 自動運転待機中

M305自動運転中だが、機械が正常理由で動作していない状態。

例：

- 投入待ち
- 下流空き待ち
- 搬出満杯待ち
- 加工受入待ち

「自動運転中なのに動いていない＝異常」と誤解しないためのGOT状態表示に使う。

## 10. ブザー方針

警告は原則として異常ブザーと同じ扱いにしない。

一次基準：

- M324異常総合 → ブザー対象
- M770搬出満杯 → 必要なら短い注意報知候補
- M771～M775 → 原則画面表示のみ

搬出満杯をブザー対象にする場合も、重大故障と鳴動パターンを分ける設計が望ましい。

## 11. 色 / 表示区分

GOT表示基準：

- 赤：故障 / 停止要求
- 黄：警告 / 注意 / 待ち
- 青または白：情報 / 正常待機
- 緑：運転可能 / 運転中

実際の画面色はサイト・GOTデザイン仕様に合わせて確定する。

## 12. 状態優先順位

表示優先度は概念的に、

1. 安全未成立
2. 故障 M324
3. 復旧操作必要
4. 警告 M325
5. 正常待機
6. 運転中

とする。

複数状態が同時成立した場合でも、GOTで最も重要な理由を先頭表示する。

## 13. 生産カウンタとの関係

警告状態そのものでは生産数を増減させない。

- 投入数：投入確定時
- 排出数：搬出完了時
- サイクルタイム：M500受入開始～M517完了など、別仕様で定義

待ち時間はサイクル分析用に別カウンタ / 時間計測へ展開可能。

## 14. 故障への昇格条件

正常な待ち状態が長時間継続しても、必ず故障へ昇格させるとは限らない。

例：搬出満杯は作業者が取り除くまで長時間続いても故障ではない。

ただし、本来成立するはずのフィードバックが欠落して待ち続けている場合は、対応するタイムアウト監視から故障へ移す。

## 15. GOT画面表示候補

自動画面の状態欄：

- 自動運転中
- 投入待ち
- 下流空き待ち
- 加工中
- 搬出満杯
- タクト超過
- 異常停止
- 復旧待ち

単に「停止中」とだけ表示せず、なぜ停止しているのかを表示する。

## 16. 次工程

次はSection 00～16について、GX Works3で実装順が分かる擬似ラダー仕様を作成する。

まず、

- INPUT_PROCESS
- COMMON_SAFETY_MON
- MODE_RUN
- TRANSFER_CV12～CV4ST
- PROCESS_AUTO
- OUTPUT_REQUEST
- ACTUAL_OUTPUT
- TIMEOUT_FAULT

を優先してラダーの骨格へ落とす。
