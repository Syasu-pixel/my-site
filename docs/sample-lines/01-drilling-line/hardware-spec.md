# 01 Drilling Line — PLC / I/O ハードウェア仕様

Status: Draft / GX Works3メイン教材用の暫定正式選定

## 1. 選定方針

本サンプル設備のメイン教材は、今後の新規設備で扱いやすい構成を優先し、`MELSEC iQ-F + GX Works3` を基準とする。

PLCは `FX5U-64MT/ES` を基準機とする。

旧設備・保全向けの学習ではGX Works2も重要なため、MELSEC-L / Q / 旧FX系を扱うGX Works2版は別教材として残す方針とする。

制御思想、I/O名称、内部M、ステップ、GOT、アラーム仕様はPLC世代への依存をできるだけ減らし、GX Works3版とGX Works2版で共通化しやすい構造にする。

## 2. PLC構成

| 区分 | 形名 | 数量 | 用途 |
|---|---|---:|---|
| CPU | FX5U-64MT/ES | 1 | シーケンス制御、32DI + 32DO、Ethernet通信 |
| 変換 | FX5-CNV-IF | 1 | FX5Uとコネクタ型I/Oモジュールの接続 |
| 追加DC入力 | FX5-C32EX/DS-TS | 1 | 32DI追加 |

設計I/O容量：

- DI：64点
- DO：32点

現在の設備要求：

- DI：約58点
- DO：32点

したがって現段階で、

- DI予備：約6点
- DO予備：0点

を確保する。

## 3. CPU選定理由

`FX5U-64MT/ES` を選ぶ理由：

- GX Works3を使用する現行iQ-Fシリーズである。
- CPU本体に32点入力、32点トランジスタ出力（シンク）を持つ。
- 本設備の32点出力をCPU本体で収容する。
- Ethernetポートを内蔵し、GOTとの接続構成を作りやすい。
- RS-485も内蔵し、将来の通信教材へ拡張しやすい。
- 本設備規模に対してiQ-Rほど大規模にならず、初級総まとめ教材として現実的な構成にしやすい。
- 入力だけ32点増設することで、DI64 / DO32という設計要求をきれいに満たせる。

## 4. 入力構成

### CPU内蔵入力

`FX5U-64MT/ES` 内蔵：

- DC24V入力
- 32点
- シンク/ソース対応

### 追加入力

`FX5-C32EX/DS-TS`：

- DC24V入力
- 32点
- シンク/ソース対応
- スプリングクランプ端子台タイプ

FX5Uへ接続するため、`FX5-CNV-IF` を使用する構成とする。

合計入力：64点。

## 5. 出力構成

`FX5U-64MT/ES` 内蔵出力を使用する。

- トランジスタ出力（シンク）
- 32点

本設備の出力要求32点をCPU本体で収容する。

PLC出力から直接大電力負荷を駆動せず、必要に応じて中継リレー、インターフェース、電磁弁側仕様を確認して接続する。

実機設計時の出力電流、突入電流、保護、コモン分けは使用機器仕様から別途確認する。

## 6. GOT通信

GOTはFX5U内蔵Ethernetを利用する構成を基本とする。

用途：

- 自動運転画面
- 運転準備・復旧画面
- 手動操作画面
- アラーム・履歴
- 生産実績
- メンテナンス

GOT正式形名・画面サイズは別途確定する。

## 7. PLC盤内配置イメージ

基本構成：

`FX5U-64MT/ES → FX5-CNV-IF → FX5-C32EX/DS-TS`

実際の盤内では、PLC・端子台・インバータ・電源・ノイズ源との離隔、放熱、配線ダクト、保守スペースを考慮して最終配置する。

## 8. GX Works3プロジェクト基準

- エンジニアリングソフト：GX Works3
- CPUタイプ：FX5U
- 基準CPU：FX5U-64MT/ES
- ラダーは追いやすさを優先する
- X入力は入力処理後にMへ起こす
- Y出力は実出力処理セクションへ集約する
- ダブルコイル禁止
- デバイスコメントを登録する
- 大項目コメントで機能ブロックを分ける
- GX Works3のモジュール構成画面でXY割付を確認する

## 9. I/O番号の考え方

FX5UのX/Yデバイス番号は8進数で扱う。

CPU内蔵32DIは `X0～X37`、CPU内蔵32DOは `Y0～Y37` を使用する。

追加32DIはCPU内蔵入力に続けて `X40～X77` を使用する構成とする。

正式な信号割付は `physical-io-map.md` を正とする。

## 10. GX Works2版の位置付け

GX Works2版は廃止しない。

用途：

- 既設設備の保全
- MELSEC-L / Q / 旧FX系の読解
- 現場で残るGX Works2プロジェクトの学習

ただし本1号機の新規設計メイン版は `GX Works3 + iQ-F` とする。

## 11. 安全上の位置付け

安全回路は本PLCの通常I/Oだけで構成しない。

非常停止、安全扉、ライトカーテン等は、実機ではリスクアセスメントとメーカー仕様に基づく安全回路側で処理する。

PLCは安全回路の状態監視と通常制御の許可条件を担当する。
