# 01 Drilling Line — GOT/HMI 画面仕様

Status: Draft / 設計進行中

## 1. 目的

異常復旧、運転準備、自動運転、設備状態確認をオペレーターが迷わず行えるよう、GOT/HMIの画面構成と基本操作方針を定める。

詳細な画面単位のレイアウトは `got-screen-layout-spec.md`、GOT表示補助 / アラーム補助デバイスは `got-display-device-map.md` を正とする。

## 2. 基本方針

- 手動個別操作は原則GOTへ集約する。
- 手動操作でも実Yを直接駆動しない。GOT操作 → 手動要求M → 干渉防止条件 → 最終出力要求 → Y の順で処理する。
- 手動モード以外では手動操作ボタンを無効化する。
- 安全回路が成立していない場合、危険動作を許可しない。
- 相反する動作（上昇/下降、前進/後退、正逆等）は同時要求を禁止する。
- 現在位置・端確認・在荷状態を同一画面上で確認できるようにする。
- 異常停止後は、必要に応じて手動復旧 → RESET → 運転準備 → 自動切替 → 自動起動の順を必須とする。
- GOTから安全機能を迂回・無効化しない。
- GOTからYを直接ON/OFFしない。

## 3. 画面構成

### G01 自動運転

表示項目：

- 設備全体の簡易レイアウト
- CV01～CV04の在荷状態
- T1～T4搬送Busy
- 加工ST搬送位置の在荷
- 加工治具位置の在荷
- 現在加工ステップ M500～M517 / D100
- 運転準備状態 M320 / M321
- 自動起動可能 M322
- 自動運転状態 M305
- 投入可 M323
- 加工ST受入可能 M330
- 搬出満杯 M154 / M770
- 現在アラーム概要
- 現在サイクルタイム
- 目標タクトとの差

主操作は表示中心とし、機器の個別手動操作は行わない。

### G02 運転準備・復旧

運転準備が成立しない理由を一覧で確認できる画面とする。

表示項目：

- 安全回路 OK / NG
- エア圧 OK / NG
- 非常停止系正常監視
- 安全扉閉
- ライトカーテンクリア
- 安全リレー正常
- 設備異常 あり / なし
- INV01～04 正常 / 異常
- 主軸 正常 / 異常
- ST01～ST05 待機位置確認
- CY01 搬送面待機位置
- CY02 横移載戻り位置
- CY03 位置決め解除位置
- CY04 クランプ解除位置
- CY05 ドリル上昇原点
- 加工ST搬送位置ワーク有無
- 加工治具位置ワーク有無
- 搬出満杯有無
- 運転準備条件 M320
- 運転準備保持 M321
- 自動起動可能 M322

NG項目は原因が分かる表示とし、単なる「準備未完了」だけにしない。

### G03 手動操作 — 搬送系

対象：

- CV01 JOG
- CV02 JOG
- CV03 JOG
- CV04 JOG
- ST01 上昇 / 下降
- ST02 上昇 / 下降
- ST03 上昇 / 下降
- ST04 上昇 / 下降
- ST05 上昇 / 下降

各操作部には、関連する在荷センサ、通過センサ、ストッパー上/下端、MANUAL要求、COMMON要求、実Y、操作不可理由を近接表示する。

コンベヤJOGは押している間だけ要求するモーメンタリ動作を基本とする。

### G04 手動操作 — 加工系

対象：

- CY01 搬送面切替 / 復帰
- CY02 横移載 前進 / 後退
- CY03 位置決め / 解除
- CY04 クランプ / 解除
- CY05 ドリル下降 / 上昇
- 主軸 運転 / 停止

各操作には、機械的干渉を避けるための許可条件を設ける。

具体的な許可条件はPLC手動操作セクションで管理し、GOTはM900帯 / M980帯へ要求を出すだけとする。

### G05 現在アラーム

表示項目：

- 異常番号
- 異常名称
- 対象機器
- 現在加工ステップ
- 指令状態
- 期待FB
- 実FB
- RESET可 / 不可
- RESET不可理由

ブザー停止と異常RESETは別操作とする。ブザー停止は音のみ停止し、異常保持は解除しない。

### G06 アラーム履歴

- 発生日時
- 復旧日時
- 確認日時
- 異常番号
- 異常名称
- 対象機器
- 発生時加工ステップ

### G07 生産実績

- 総投入数 D200
- 総排出数 D201
- OK数 D202（将来判定）
- NG数 D203（将来判定）
- 直近サイクルタイム D210
- 平均 D211
- 最大 D212
- 最小 D213
- 目標タクト D120
- タクト超過 M774

OK/NG判定機構がない現段階ではD202/D203を確定実績として扱わない。

### G08 メンテナンス

- 各モータ運転時間
- 各シリンダ動作回数
- 各ストッパー動作回数
- 主軸運転時間
- アラーム履歴
- 搬送タイムアウト設定値
- シリンダ監視時間設定値
- 加工監視時間設定値

設定値変更は通常運転画面から直接変更できないようにする。

### G09 I/Oモニタ

X0～X67、Y0～Y34および主要内部Mを表示する診断画面とする。

I/Oモニタ画面からYを直接強制ON/OFFしない。

### G10 設定

対象候補：

- D110 搬送タイムアウト
- D111 加工アクチュエータタイムアウト
- D112 穴あけ滞留時間
- D120 目標タクト

設定値は入力範囲チェックを設け、保守権限側に限定する候補とする。

## 4. 手動操作の表示方式

各アクチュエータは最低でも以下を同時表示する。

- GOT操作要求
- MANUAL要求
- COMMON要求
- 実Y
- 原位置端
- 動作位置端
- 手動操作許可 / 禁止
- 禁止時の主な理由

ダブルソレノイドについては、片側要求中は反対側ボタンを無効化する。

## 5. GOTデバイス帯

### 手動操作要求

- M900～M913：搬送 / ST手動要求
- M980～M990：CY / 主軸手動要求

### 表示補助

- M920～M939：画面表示補助

正式割付は `got-display-device-map.md` を正とする。

### 操作不可理由

- M940～M959：BLOCK理由

### アラーム / 履歴補助

- M960～M979：確認、RESET補助、ブザー停止、履歴補助

正式割付は `got-display-device-map.md` を正とする。

## 6. 共通ヘッダ / ナビゲーション

全画面上部に最低限以下を表示する。

- AUTO / MANUAL / MODE NOT ESTABLISHED
- 運転準備
- 自動運転中
- 異常総合
- 警告総合
- 現在加工ステップ

下部固定ナビゲーション候補：AUTO / READY / MANUAL / ALARM / PRODUCTION / MAINT。

自動運転中は手動画面に遷移しても操作要求をPLCへ通さない。

## 7. 復旧時の標準操作フロー

異常停止後：

1. 異常内容を確認する。
2. 原因を除去する。
3. 必要に応じて手動モードへ切替える。
4. GOT手動画面で機器・ワークを自動開始可能状態へ戻す。
5. RESETを行う。
6. 運転準備条件がすべて成立していることを確認する。
7. 操作盤の運転準備PBを押す。
8. セレクトSWを自動へ切替える。
9. 自動起動PBを押す。
10. 自動運転を再開する。

異常復旧のみで自動再始動しない。

## 8. 権限レベル一次案

- Level 0：表示のみ
- Level 1：通常運転 / 手動操作
- Level 2：設定変更 / 履歴管理

安全関連設定や駆動機器パラメータを通常GOT画面から自由変更できる構成にはしない。

## 9. 画面詳細参照
