# 01 Drilling Line — GOT/HMI 画面仕様

Status: Draft / 設計進行中

## 1. 目的

異常復旧、運転準備、自動運転、設備状態確認をオペレーターが迷わず行えるよう、GOT/HMIの画面構成と基本操作方針を定める。

## 2. 基本方針

- 手動個別操作は原則GOTへ集約する。
- 手動操作でも実Yを直接駆動しない。GOT操作 → 手動要求M → 干渉防止条件 → 最終出力要求 → Y の順で処理する。
- 手動モード以外では手動操作ボタンを無効化する。
- 安全回路が成立していない場合、危険動作を許可しない。
- 相反する動作（上昇/下降、前進/後退、正逆等）は同時要求を禁止する。
- 現在位置・端確認・在荷状態を同一画面上で確認できるようにする。
- 異常停止後は、必要に応じて手動復旧 → RESET → 運転準備 → 自動切替 → 自動起動の順を必須とする。

## 3. 画面構成

### 3.1 自動運転画面

表示項目：

- 設備全体の簡易レイアウト
- CV01～CV04の在荷状態
- 加工ST搬送位置の在荷
- 加工治具位置の在荷
- 現在の加工ステップ M500～M517
- 運転準備状態
- 自動運転状態
- 加工ST受入可能状態
- 搬出満杯状態
- 現在アラーム番号・概要
- 現在サイクルタイム
- 目標タクトとの差

主操作は原則表示中心とし、機器の個別手動操作は行わない。

### 3.2 運転準備・復旧画面

運転準備が成立しない理由を一覧で確認できる画面とする。

表示項目：

- 安全回路 OK / NG
- エア圧 OK / NG
- 設備異常 あり / なし
- 安全異常 あり / なし
- INV01～04 正常 / 異常
- 主軸 正常 / 異常
- ST01～ST05 待機位置確認
- CY01 搬送面待機位置
- CY02 横移載戻り位置
- CY03 位置決め解除位置
- CY04 クランプ解除位置
- CY05 ドリル上昇原点
- 加工ST搬送位置ワーク有無
- 加工治具位置ワーク有無
- 搬出満杯有無
- 運転準備条件 M320
- 運転準備保持 M321
- 自動起動可能 M322

NG項目は原因が分かる表示とし、単なる「準備未完了」だけにしない。

### 3.3 手動操作画面 — 搬送系

対象：

- CV01 JOG
- CV02 JOG
- CV03 JOG
- CV04 JOG
- ST01 上昇 / 下降
- ST02 上昇 / 下降
- ST03 上昇 / 下降
- ST04 上昇 / 下降
- ST05 上昇 / 下降

各操作部には、関連する在荷センサ、通過センサ、ストッパー上/下端を近接表示する。

コンベヤJOGは押している間だけ要求するモーメンタリ動作を基本とする。

### 3.4 手動操作画面 — 加工系

対象：

- CY01 搬送面切替 / 復帰
- CY02 横移載 前進 / 後退
- CY03 位置決め / 解除
- CY04 クランプ / 解除
- CY05 ドリル下降 / 上昇
- 主軸 運転 / 停止

各操作には、機械的干渉を避けるための許可条件を設ける。

例：

- CY05下降はクランプ成立、位置決め成立、加工治具在荷、主軸状態等を確認する。
- CY02横移載はクランプ解除、位置決め解除、ドリル上昇等を確認する。
- CY01搬送面切替は横移載位置などの関連条件を確認する。

具体的な許可条件はPLC手動操作セクションで管理する。

## 4. 手動操作の表示方式

各アクチュエータは最低でも以下を同時表示する。

- 指令状態
- 原位置端
- 動作位置端
- 手動操作許可 / 禁止
- 禁止時の主な理由

ダブルソレノイドについては、片側要求中は反対側ボタンを無効化する。

## 5. 異常・履歴画面

分類：

1. 状態表示
2. 警告
3. 異常
4. 安全異常

表示項目：

- 異常番号
- 異常名称
- 発生日時
- 復旧日時
- 確認状態
- 対象機器
- 復旧のために確認すべき状態

ブザー停止と異常RESETは別操作とする。ブザー停止は音のみ停止し、異常保持は解除しない。

## 6. 生産実績画面

- 総生産数
- OK数
- NG数
- 投入数
- 排出数
- 現在サイクルタイム
- 前回サイクルタイム
- 平均サイクルタイム
- 最小 / 最大サイクルタイム
- 目標タクト 30秒

## 7. メンテナンス画面

- 各モータ運転時間
- 各シリンダ動作回数
- 各ストッパー動作回数
- 主軸運転時間
- アラーム履歴
- 搬送タイムアウト設定値
- シリンダ監視時間設定値
- 加工監視時間設定値

設定値変更は通常運転画面から直接変更できないようにする。

## 8. 復旧時の標準操作フロー

異常停止後：

1. 異常内容を確認する。
2. 原因を除去する。
3. 必要に応じて手動モードへ切替える。
4. GOT手動画面で機器・ワークを自動開始可能状態へ戻す。
5. RESETを行う。
6. 運転準備条件がすべて成立していることを確認する。
7. 操作盤の運転準備PBを押す。
8. セレクトSWを自動へ切替える。
9. 自動起動PBを押す。
10. 自動運転を再開する。

異常復旧のみで自動再始動しない。
