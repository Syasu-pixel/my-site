# 01 Drilling Line — CP01 / OP01 盤間配線仕様

Status: Draft / 教材用盤間接続基準

## 1. 目的

本ファイルは、制御盤 `CP01` と操作盤 `OP01` 間の接続を、信号系・電源系・通信系に分けて整理する。

設計方針は、

- 操作信号と通信を分離する
- Ethernetは専用ケーブルで独立させる
- DC24V電源はOP01側で必要負荷のみ供給する
- 将来のPB / 表示灯追加に備えて予備芯を確保する
- 非常停止などの安全機能そのものは通常PLC信号と混同しない

とする。

## 2. 盤間接続の全体構成

概念構成：

`CP01 → CBL-OP-01（操作信号・24V） → OP01`

`CP01 → CBL-GOT-01（Ethernet） → GOT01`

安全系は、実機安全回路仕様確定後に必要に応じて専用経路を設ける。

## 3. OP01側の対象機器

OP01には以下を搭載する。

- GOT01
- PB01 運転準備
- PB02 自動起動
- PB03 停止
- PB04 RESET
- PB05 投入完了
- PB06 ブザー停止
- SW01 手動/自動
- PL01 投入可
- PL02 運転
- PL03 異常
- EMG01 非常停止
- 将来追加PB ×2程度
- 将来追加表示灯 ×2程度
- 将来追加SW / キースイッチ ×1程度

## 4. CBL-OP-01 — 操作信号 / DC24V

CBL-OP-01は、通常操作信号とOP01内のDC24V配電をまとめる多芯ケーブルとする。

### 4.1 必要信号

PLC入力側：

- PB01 運転準備
- PB02 自動起動
- PB03 停止
- PB04 RESET
- PB05 投入完了
- PB06 ブザー停止
- SW01 手動
- SW01 自動

PLC出力側：

- PL01 投入可
- PL02 運転
- PL03 異常
- BZ01をOP01側に搭載する場合のブザー信号

電源系：

- +24V
- 0V

将来予備：

- DI予備 4点以上
- DO予備 2点以上

### 4.2 芯数の考え方

現状必要芯数はおよそ、

- 入力信号 8芯
- 出力信号 4芯
- 電源 2芯
- 将来予備 6芯

合計20芯程度。

したがって教材上は、

**CBL-OP-01：20芯級以上の制御用多芯ケーブルを基準**

とする。

端子番号、線径、シールド要否、許容電流は正式機器・配線長確定後に決める。

## 5. CBL-GOT-01 — Ethernet

GOT01とPLC01の通信はEthernetを基本とする。

構成：

`PLC01 FX5U Ethernet ↔ GOT01 Ethernet`

CBL-GOT-01は操作信号用多芯ケーブルとは分離する。

配線経路も、可能な限りインバータ出力線やモータ線などのノイズ源から離して敷設する。

将来、保守PCやネットワーク機器を追加する場合は、小型産業用Ethernetスイッチの追加余地をCP01内に確保する。

## 6. OP01内の電源構成

OP01内のDC24VはCP01のPS01から供給する。

対象：

- GOT01
- PB / SW入力回路
- 表示灯
- 必要に応じてブザー

GOT01はOP01内で最大級の24V負荷となるため、信号用細線と同一芯で電源供給する前提にせず、電圧降下・電流容量を考慮して電源芯を決める。

長距離になる場合はGOT用24V電源線を別ケーブル化する選択肢も残す。

## 7. 端子台対応

CP01側は `XT2` をOP01操作入力、`XT3` を表示系出力の基準端子台とする。

### CP01側

- XT2：PB / SW入力
- XT3：PL / ブザー出力
- XT1：必要に応じてOP01用DC24V / 0V分岐

### OP01側

OP01内部にも盤間ケーブル受け用端子台を設ける。

仮タグ：

- `XTOP1`：操作入力 / DC24V
- `XTOP2`：表示出力 / 予備

GOT Ethernetは端子台を経由せず、Ethernetコネクタ直結を基本とする。

## 8. 安全系の扱い

EMG01非常停止はOP01に配置するが、通常PLC入力だけで安全機能を成立させない。

安全回路の正式方式はリスクアセスメント後に決める。

本ファイルでは、

- 非常停止操作器の物理位置
- PLC監視用の安全回路正常信号

と、

- 実際の安全停止機能

を明確に分ける。

安全機能用の配線経路・二重化・安全リレー接続等は、本仕様の通常盤間配線とは別設計とする。

## 9. ノイズ分離方針

盤間・盤内ともに、以下を分離する。

- Ethernet / 通信
- DC24Vセンサ / 操作信号
- 電磁弁出力
- インバータ入力側主回路
- インバータ出力～モータ
- 主軸モータ線

Ethernetおよび低レベル信号は、インバータ出力・モータ線と同一ダクトに長距離並走させない方針とする。

## 10. 将来拡張余地

OP01は次の追加を想定する。

- PB 2点
- 表示灯 2点
- セレクタまたはキースイッチ 1点
- Ethernet機器 1台程度

CBL-OP-01はこの増設を吸収できる予備芯を持たせる。

CP01側XT2 / XT3も予備端子を20%程度確保する。

## 11. ケーブルタグ整理

| Tag | 用途 |
|---|---|
| CBL-OP-01 | CP01↔OP01 操作信号・24V |
| CBL-GOT-01 | PLC01↔GOT01 Ethernet |
| CBL-SAFE-01 | 安全回路用盤間配線（将来、必要時） |
