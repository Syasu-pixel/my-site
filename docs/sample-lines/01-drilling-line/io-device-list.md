# 01 Drilling Line — I/O・内部デバイス一覧

Status: Draft / 設計進行中

## 1. 目的

本設備のPLC実装に向けて、外部入力X、入力確定M、内部状態M、自動/手動/共通出力要求M、実出力Yの対応を一元管理する。

本表のX/Y番号は、現時点ではGX Works2で扱いやすいように整理した暫定論理割付である。正式PLC型式・I/Oユニット構成確定後に物理割付を再確認する。

基本方針：

- 外部Xは原則として本体ロジックで直接使用しない。
- X入力は入力確定処理後にMへ起こして使用する。
- 通過センサはON確認後の立下りを通過完了とする。
- 自動・手動ロジックはYを直接駆動しない。
- 自動要求M / 手動要求M → 共通要求M → 最終インターロック → Y とする。
- 安全機能そのものはPLCで代替せず、安全リレー等のハード安全回路側で成立させる。

## 2. I/O規模

第4回のCV05・CY06追加反映後、暫定DIは約58点となる。

- DI使用見込み：約58点
- DI設計確保：64点
- DO使用見込み：32点
- DO設計確保：32点

初期検討時のDI約49点から増えた主因は、運転準備/自動起動の分離、安全状態の個別監視、ブザー停止入力、加工ST排出通過センサ、CY06両端確認を追加したため。

## 15. 端確認矛盾監視

ダブルエンドセンサを持つ各アクチュエータについて、原位置端と動作位置端が同時ONした場合は異常とする。

対象：

- ST01～ST05
- CY01～CY05

また、動作指令後に設定時間以内で目的端が成立しない場合も個別異常とする。
