# 01 Drilling Line — 手動操作・復旧インターロック仕様

Status: Draft / 設計進行中

## 1. 目的

異常停止後の復旧、保守、試運転時に、GOTから各機器を個別操作できるようにする。ただし手動操作でも安全条件・機械干渉防止条件は維持し、実Yを直接操作しない。

基本経路：

GOT手動ボタン → 手動要求M → 手動許可条件 → 共通出力要求M → 最終出力処理 → Y

## 2. 手動操作共通条件

手動操作を受け付ける基本条件を `M340 手動操作共通許可` とする。

少なくとも以下を条件とする。

- 手動モード選択中
- 自動運転中でない
- 安全回路OK
- 対象機器に関連する安全異常がない
- エア圧OK（空圧機器操作時）
- 相反する出力要求が同時成立していない

異常復旧中は設備異常保持が残っていても、原因除去と安全条件が成立している範囲で復旧に必要な手動操作を許可できる構成とする。ただし主軸、ドリル下降、クランプを伴う危険側操作はより厳しい個別条件を要求する。

## 3. GOT操作方式

- コンベヤJOG：押している間だけ要求するモーメンタリ操作
- シリンダ・ストッパー：押している間だけ要求するモーメンタリを基本とする
- 主軸：運転/停止の明示操作とするが、運転要求は手動許可条件が崩れた時点で解除する
- 反対方向の操作ボタンは、片側要求中は無効化する
- 各操作部に「操作可/不可」と「禁止理由」を表示する

## 4. 搬送系手動操作

### 4.1 CV01～CV04 JOG

基本許可条件：

- M340 手動操作共通許可
- 対象INV異常なし
- 対象コンベヤに対応するストッパー・隣接機構との干渉なし
- 加工ST側へ送るCV04は、加工ST搬入部が危険な中間状態でない

原則として1台単独JOGを基本とし、複数CVの同時手動JOGは行わない。復旧目的で複数駆動が必要になった場合は、別の専用復旧操作として設計を追加する。

### 4.2 ST01～ST05 上昇/下降

共通条件：

- M340 手動操作共通許可
- エア圧OK
- 反対側要求OFF

追加方針：

- 上昇側は通常待機位置への復旧操作として比較的優先して許可する
- 下降側はワーク流出のおそれがあるため、対象区間のコンベヤ停止中を基本条件とする
- ST05下降は加工STの搬送面・横移載・加工機構が排出/搬送可能な状態であることを確認する

## 5. 加工系手動操作

### 5.1 CY01 搬送面切替 / 復帰

切替側許可：

- M340
- CY02 横移載が戻り位置
- CY03 位置決め解除
- CY04 クランプ解除
- CY05 ドリル上昇
- 主軸停止

復帰側許可：

- M340
- CY02 横移載が戻り位置
- CY03 位置決め解除
- CY04 クランプ解除
- CY05 ドリル上昇

### 5.2 CY02 横移載 前進 / 後退

前進側許可：

- M340
- CY01 が加工側切替位置
- CY03 位置決め解除
- CY04 クランプ解除
- CY05 ドリル上昇
- 主軸停止
- 搬送位置にワークあり
- 加工治具位置にワークなし

後退側許可：

- M340
- CY01 が加工側切替位置
- CY03 位置決め解除
- CY04 クランプ解除
- CY05 ドリル上昇
- 主軸停止
- 加工治具位置にワークあり、または復旧上後退が必要な状態

### 5.3 CY03 位置決め / 解除

位置決め側許可：

- M340
- CY02 前進端
- 加工治具在荷ON
- CY04 クランプ解除
- CY05 ドリル上昇

解除側許可：

- M340
- CY05 ドリル上昇
- CY04 クランプ解除

### 5.4 CY04 クランプ / 解除

クランプ側許可：

- M340
- CY02 前進端
- CY03 位置決め成立
- 加工治具在荷ON
- CY05 ドリル上昇

解除側許可：

- M340
- CY05 ドリル上昇

### 5.5 CY05 ドリル下降 / 上昇

下降側は最も厳しい手動条件とする。

下降側許可：

- M340
- CY02 前進端
- CY03 位置決め成立
- CY04 クランプ成立
- 加工治具在荷ON
- 主軸運転確認ON
- 搬送面/横移載が加工位置として成立

上昇側許可：

- M340
- 反対側要求OFF

上昇は危険位置から退避する復旧操作のため、下降より条件を少なくする。ただし安全回路OKなどの共通条件は維持する。

### 5.6 主軸 運転 / 停止

運転許可：

- M340
- 加工治具在荷ON
- CY02 前進端
- CY03 位置決め成立
- CY04 クランプ成立
- CY05 ドリル上昇端
- 主軸異常なし

停止操作は常時優先して受け付ける方向とする。

## 6. 復旧優先方向

異常停止後の手動復旧では、原則として危険側へ進めるのではなく、以下の順で安全な待機状態へ戻す。

1. ドリル上昇
2. 主軸停止
3. クランプ解除
4. 位置決め解除
5. 横移載戻り
6. 搬送面復帰
7. ストッパー待機位置
8. 必要に応じてコンベヤJOGでワーク位置を整理

これは一般的な復旧優先順であり、実機では機械構造・残圧・保持条件・メーカー仕様・リスクアセスメントに基づき最終決定する。

## 7. 手動要求デバイス方針

手動要求は自動要求と番号帯を分ける。

例：

- M850～M853：CV01～CV04 手動JOG要求
- M860～M869：ST01～ST05 手動上昇/下降要求
- M870～M879：CY01～CY05 手動往復要求
- M880：主軸手動運転要求

最終出力処理では、自動要求と手動要求を個別に作成した後、モード条件とインターロックを通して1つの実Yへ集約する。

## 8. 禁止理由表示

GOTでは各操作ボタンの近くに、少なくとも以下の禁止理由を表示できるようにする。

- 自動モード中
- 安全回路未成立
- エア圧不足
- 反対側動作中
- ドリル未上昇
- クランプ未解除 / 未成立
- 位置決め未解除 / 未成立
- 横移載位置不成立
- ワークなし / ワークあり
- 主軸未停止 / 未運転
- 対象機器異常

## 9. 実装時の注意

- 安全機能そのものを通常PLCやGOTの手動回路へ依存させない。
- 手動許可条件は機械干渉防止・運転手順上のインターロックとして扱う。
- 実機化する場合は、危険源ごとに安全回路、保持エネルギー、予期しない再起動防止などを別途リスクアセスメントする。
