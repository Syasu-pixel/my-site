# 01 Drilling Line — OP01 操作盤仕様

Status: Draft / 教材用基準配置

## 1. 目的

OP01は、オペレーターがワーク投入・運転準備・自動起動・停止・復旧・手動操作を行うための操作盤とする。

CP01制御盤とは分離し、機械の投入側から加工部を確認しやすい位置へ設置する。

本仕様は教材用の基準レイアウトであり、実機では設置高さ、視認性、危険区域との距離、操作姿勢を含めて再評価する。

## 2. 外形基準

基準外形：

- W500 × H700 × D250 mm級
- 自立形または機械フレーム取付型
- 前面扉にGOT、PB、SW、表示灯、非常停止を配置
- 保守交換を考慮し、裏面に端子・中継部品・ケーブル余長を確保

GOT01：GT2708-STBD 8.4型を中央上部へ配置する。

## 3. 前面配置方針

上段：GOT01

中段：運転モード・主要操作

下段：停止・RESET・投入・ブザー停止

非常停止EMG01は、他の操作器と識別しやすい独立位置へ配置する。

概念配置：

```text
┌──────────────────────┐
│       GOT01 8.4型      │
│                        │
├──────────────────────┤
│ SW01 手動/自動          │
│ PB01 運転準備  PB02 自動起動 │
│                        │
│ PL01 投入可  PL02 運転  PL03 異常 │
├──────────────────────┤
│ PB03 停止   PB04 RESET   │
│ PB05 投入完了 PB06 ブザー停止 │
│                        │
│ EMG01 非常停止           │
└──────────────────────┘
```

## 4. 操作器一覧

| Tag | 名称 | 種類 | 基本動作 |
|---|---|---|---|
| SW01 | 手動/自動セレクト | 2位置保持 | モード選択 |
| PB01 | 運転準備 | モーメンタリ | 運転準備条件成立後にM321セット要求 |
| PB02 | 自動起動 | モーメンタリ | M322成立時にM305セット要求 |
| PB03 | 停止 | モーメンタリ | 通常停止、M305解除 |
| PB04 | RESET | モーメンタリ | 復旧可能条件下で異常リセット |
| PB05 | 投入完了 | モーメンタリ | 手投入完了通知 |
| PB06 | ブザー停止 | モーメンタリ | ブザー消音のみ |
| EMG01 | 非常停止 | 非常停止押しボタン | 安全回路側 |

## 5. 表示灯

| Tag | 表示 | 基本意味 |
|---|---|---|
| PL01 | 投入可 | 新規ワーク投入可能 |
| PL02 | 運転 | 自動運転中 |
| PL03 | 異常 | 設備異常または要確認状態 |

表示色は実際の運用ルール、社内標準、安全規格との整合を確認して最終決定する。

教材では色そのものより、表示条件とPLCロジックの対応を重視する。

## 6. 操作フロー

通常起動：

1. 必要に応じて手動モードで復旧
2. GOTの運転準備・復旧画面で各条件確認
3. 全ての運転準備条件が成立
4. PB01 運転準備
5. SW01 を自動へ
6. PB02 自動起動
7. 自動運転開始

通常停止：

- PB03 停止で自動運転のみ解除
- 運転準備ラッチは原則保持
- 条件健全ならPB02で再開可能

異常・安全停止：

- 自動運転と運転準備を解除
- 原因確認
- 必要なら手動モードへ
- GOT手動画面で安全側へ復旧
- RESET
- 運転準備からやり直す

## 7. GOTとの役割分担

ハードウェア操作器は、頻繁に使う・緊急性が高い・明確な物理操作が望ましい機能に限定する。

GOTへ集約する機能：

- 個別手動操作
- 運転準備条件一覧
- インターロック理由表示
- アラーム履歴
- 生産実績
- メンテナンス情報
- タイムアウト設定

PLCのYをGOTから直接操作せず、GOT要求Mを経由して共通出力要求へ入れる。

## 8. 誤操作防止

- PB01運転準備とPB02自動起動は役割を分離
- RESETと自動起動は離して配置
- 非常停止は他のPBと明確に区別
- 手動/自動の現在位置をGOTでも表示
- GOT手動操作は押下中のみ要求するJOG方式を基本
- 危険方向の手動動作はインターロック成立時のみ許可
- 操作不可時はGOTに禁止理由を表示

## 9. 設置位置

OP01はワーク投入側を基準に、オペレーターが以下を確認しやすい位置に配置する。

- 投入口
- CV01付近
- 加工ST方向
- 非常停止操作位置

ただし安全距離や危険区域へのアクセス条件はリスクアセスメント後に決める。

## 10. 盤内構成

OP01内部は最小限とし、主回路機器は入れない。

主な構成：

- GOT01
- PB / SW / 表示灯
- EMG01接点
- XT-OP端子台
- 必要に応じて中継コネクタ
- ケーブルクランプ
- PE端子
- 将来追加操作器用予備端子

OP01～CP01間は、DC24V操作信号、Ethernet、非常停止監視/安全回路配線を用途別に整理する。

## 11. 将来拡張余地

前面には少なくとも以下を追加できる余白を確保する。

- 追加PB ×2程度
- 追加表示灯 ×2程度
- 3位置セレクタ1個程度
- キースイッチまたは保守用スイッチ1個程度

ただし通常操作器を増やしすぎず、可能な機能はGOT側へ集約する。

## 12. 現時点の結論

- OP01はW500 × H700 × D250 mm級
- GOT01 8.4型を中央上部
- 運転準備、自動起動、停止、RESET、投入完了、ブザー停止をハードPB化
- 手動/自動は2位置セレクタ
- 非常停止は独立配置
- 個別手動操作や詳細状態はGOTへ集約
- 将来操作器追加用の前面・端子余裕を確保
