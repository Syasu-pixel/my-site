# 01 Drilling Line — PE / シールド / 端子色・マーカ / 外部ケーブル引込仕様

Status: Draft / 教材用盤下部レイアウト一次確定

## 1. 目的

CP01下部のDR5A / DR5B / DR6と外部ケーブル引込部について、

- PE端子の必要数
- シールドクランプの必要数
- XT1～XT8の色分け・マーカ
- 電位分配ブリッジの使い方
- 外部ケーブルの一次本数
- ケーブル固定・引込のグルーピング

を整理し、盤下部のレイアウトを完成形に近づける。

本資料は教材用の概念設計であり、実機の保護導体サイズ、接地方式、シールド両端/片端処理、ケーブルグランド選定、主回路施工条件を確定するものではない。正式施工ではメーカー仕様・規格・設備環境・有資格者の設計確認を優先する。

## 2. DR6の役割

DR6（基準長500 mm）は次の順で使用する。

```text
XT8 → FUTURE SIGNAL → PE → SHIELD → RESERVE
```

初期状態でDR6を埋め切らず、将来センサ・I/O・補機の追加先として大きく余白を残す。

## 3. PE端子の一次算定

現段階では保護導体を必要とする可能性が高い機器群を次のように整理する。

- CP01盤筐体 / 取付板：1系統以上
- OP01筐体：1系統
- INV01～INV05：5系統
- M01～M05モータ系：5系統
- PS01：1系統
- 将来PS02：1系統予約
- 主回路関連補機：若干数
- 将来外部金属機器：予備

教材用レイアウト上の一次基準として、**PE端子12～16極級**をDR6に予約する。

推奨初期構成：

- PE01～PE12：初期用
- PE13～PE16：将来用

PE端子は通常信号端子と混同しないよう、PT 2,5-PE系などの専用PE端子を基準候補とする。

## 4. シールドクランプの一次算定

シールド処理対象候補：

- Ethernet / GOT通信
- INV関連制御ケーブルで必要なもの
- モータケーブルでメーカーがシールドを要求する場合
- 将来アナログ / エンコーダ / 高速信号

本設備の現初期構成ではアナログ入力やエンコーダは採用していないため、シールドクランプを過剰実装しない。

一次基準：

- 初期実装：4～6点級
- 将来予約：4～6点級
- 合計予約：**8～12点級**

シールドバーまたは専用クランプ領域はDR6右側へまとめ、信号端子との識別を明確にする。

## 5. DR6幅の一次配分

500 mmレールを次のように使う。

| 区分 | 一次幅目安 | 内容 |
|---|---:|---|
| XT8 | 約145 mm | 24極 + 付帯幅 |
| FUTURE SIGNAL | 約80 mm | 将来追加端子 |
| PE | 約100 mm | 12～16極級 + 付帯幅 |
| SHIELD | 約80 mm | クランプ / バー |
| RESERVE | 約95 mm | 将来変更余地 |

合計：約500 mm。

PE / シールド部は正式部品寸法確認後に微調整する。

## 6. XT1～XT8の色分け方針

色だけに機能を依存させず、**端子番号 + 端子マーカ + 回路図**を正とする。

教材上の推奨：

- 通常信号端子：グレー
- +24V分配：赤系マーカまたは赤識別
- 0V分配：青系マーカまたは青識別
- PE：緑黄の専用PE端子
- 安全監視XT7：通常PLC監視信号なので安全回路そのものの色規則を流用しない
- 予備端子：通常色のまま `SPARE` / `FUTURE` マーカ

重要：端子色は保守支援用であり、安全機能や電位判定を色だけで行わない。

## 7. マーカ命名ルール

端子台側マーカは既存の端子番号をそのまま使用する。

例：

```text
XT4-01
XT4-02
...
XT5-31
XT8-24
PE01
SH01
```

外部ケーブルにはケーブルタグを付け、両端で同じIDを使用する。

基準タグ：

- CBL-OP-*：操作盤
- CBL-CV-*：搬送部
- CBL-PROC-*：加工ステーション
- CBL-INV-*：インバータ制御
- CBL-MTR-*：モータ系
- CBL-GOT-*：GOT / Ethernet
- CBL-SAF-*：安全系（通常制御とは別管理）
- CBL-FUT-*：将来予備

## 8. XT1のブリッジ方針

XT1は+24V / 0V分配に使用するが、全24極を一括共通化しない。

F24-01～F24-06の機能別分岐と0Vグループを維持する。

ブリッジは、

- 同一保護分岐
- 同一電位
- 同一機能群

の範囲だけで使用する。

分岐保護をまたいでブリッジしない。

## 9. 外部ケーブルの一次グループ

現時点の設備構成から、外部ケーブルは機能ごとにまとめる。

### 9.1 OP01系

- CBL-OP-01：操作入力 / 表示出力多芯
- CBL-GOT-PWR-01：GOT DC24V
- CBL-GOT-01：Ethernet
- 安全系：別ケーブル

### 9.2 搬送部

- 搬送センサ群：2～4本程度の多芯ケーブルへ機能単位で集約
- ストッパSOL群：1～2本程度の多芯ケーブル
- INV制御：1～2本程度の多芯ケーブル
- モータ：M01～M04を個別または機械側配線方式に応じて分離

### 9.3 加工ステーション

- 加工センサ群：1～2本程度の多芯ケーブル
- CY SOL群：1～2本程度の多芯ケーブル
- 主軸制御：専用1本
- 主軸モータ：専用1本

### 9.4 安全監視 / 安全機器

安全回路本体は通常PLC信号ケーブルとは分離して扱う。

XT7へ返す監視信号と、実際の安全機能配線は同一概念として扱わない。

## 10. 盤下部引込のグルーピング

盤下部の引込は、少なくとも次のグループに分ける。

```text
左下：DC24V / センサ / OP01 / 通信
中央：SOL / 一般制御
右下：INV / モータ / 主回路系
別管理：安全関連
```

主回路・モータ系と、センサ・Ethernetを同じ束で長距離並走させない。

通信ケーブルはPLC / GOT側へ最短で上げ、INV出力側ダクトから離す。

## 11. ケーブル固定帯

取付板1000～1050 mm帯をケーブル固定・引込調整用として維持する。

用途：

- ケーブルクランプ
- ストレインリリーフ
- シールド処理前の整線
- 端子台への曲げ半径確保
- ケーブルID表示

外部ケーブルを端子台へ直接引っ張らせず、盤入口付近で機械的に固定してから端子へ導く構成を基準とする。

## 12. 予備率

初期完成時でも次を残す。

- PE：4極程度の予備
- シールド：4点程度の予備
- DR6：95 mm前後の空き
- XT8：24極の将来領域
- ケーブル引込：1～2系統分以上の増設余地

現時点の完成状態で盤下部を満杯にしない。

## 13. 盤下部の一次完成形

```text
DR5A 600 mm : XT1 / XT2 / XT3 / XT4
DR5B 600 mm : XT5 / XT6 / XT7
DR6  500 mm : XT8 / FUTURE / PE / SHIELD / RESERVE

下端：ケーブル固定 / 引込
左：弱電・通信
中央：一般制御
右：INV・モータ
```

この構成により、機能の追いやすさ、保守性、ノイズ分離、将来増設性を両立する。
