# 01 Drilling Line — 物理I/O割付

Status: Draft / L02CPU構成基準

## 1. 前提

PLC構成は `hardware-spec.md` を基準とする。

- CPU：L02CPU
- 入力：LX40C6 ×4台（16点 ×4 = 64DI）
- 出力：LY40NT5P ×2台（16点 ×2 = 32DO）
- エンジニアリング：GX Works2

MELSEC-LのI/O番号は16進数で扱う。

モジュール配置は、保守時に分かりやすいよう入力を先、出力を後にまとめる。

`L61P → L02CPU → LX40C6-1 → LX40C6-2 → LX40C6-3 → LX40C6-4 → LY40NT5P-1 → LY40NT5P-2`

この配置を前提に、入力は X0～X3F、出力は Y40～Y5F を使用する。

## 8. 論理I/O一覧との扱い

既存の `io-device-list.md` に記載した `X000`、`X010`、`Y000` 等は設計初期の論理グループ番号である。

GX Works2プロジェクトを作成する段階からは、本ファイルの物理X/Yを正とする。

入力処理後のM番号、自動要求M、手動要求M、共通要求Mはそのまま維持し、X/Yだけ物理割付へ置換する。

例：

- 論理 `X000 運転準備PB` → 物理 `X0`
- 論理 `X020 CV01在荷` → 物理 `X10`
- 論理 `Y000 CV01 RUN` → 物理 `Y40`
- 論理 `Y032 CY05上昇` → 物理 `Y56`

## 9. 配線・端子台設計への引継ぎ

次工程では本物理I/Oを基準に、

- PLCユニット端子番号
- XT1～XT8端子台番号
- 機器タグ
- ケーブル番号
- 24V / 0Vコモン
- 出力電源コモン

を対応させる。

安全信号はPLC監視用入力と安全機能そのものを混同しない。実際の安全回路配線はリスクアセスメント、メーカー仕様、必要な安全性能に基づいて別設計とする。
