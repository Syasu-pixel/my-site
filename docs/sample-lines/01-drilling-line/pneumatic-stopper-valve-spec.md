# 01 Drilling Line — ストッパー / 電磁弁 / チューブ仕様

Status: Draft / 設計進行中

## 1. 目的

ST01～ST05のストッパー機構、電磁弁マニホールド、配管径、速度調整、圧力監視の基本仕様を定める。

本仕様は教材用の設計基準であり、実機適用時はワーク質量、搬送速度、衝撃、必要保持力、配管長、応答時間、安全要求を再確認する。

## 2. ストッパー ST01～ST05

### 2.1 基本方針

- 各搬送ゾーン末端に1台ずつ配置する。
- 通常待機位置は上昇。
- ワークを送出するときだけ下降する。
- 上昇端 / 下降端の両端確認を持つ。
- ダブルソレノイドで保持する。
- 隣接搬送が始まる前に下降端確認を取る。
- 搬送完了後は上昇へ戻し、上昇端確認で区間を終了する。

### 2.2 形式

教材基準として、ST01～ST05は「小型ストッパーシリンダ + ストッパーヘッド」の構成とする。

基準仕様：

- 使用圧力：0.4～0.6 MPa級
- 基準圧力：0.5 MPa
- シリンダ径：φ20～φ25級
- 有効ストローク：10～20 mm級
- 上昇位置でワークを確実に停止
- 下降位置で搬送面から十分に逃げる
- オートスイッチ：上下2点

正式形名は機械レイアウト完成後に決める。

### 2.3 ST05

ST05は加工ST入口・排出制御にも関わるため、ST01～ST04より重要度が高い。

- 加工ST搬入時の位置保持
- 排出時の開放
- サイクル終了時の上昇復帰

を担う。

ST05は加工治具との干渉、CY01搬送面切替、排出方向のワーク挙動を確認して最終形状を決める。

## 3. 電磁弁マニホールド MV01

### 3.1 必要ソレノイド数

対象：

- ST01～ST05：5台 × 2SOL = 10SOL
- CY01～CY05：5台 × 2SOL = 10SOL

合計：20SOL

したがって、MV01は20ソレノイド以上を収容できる構成とする。

### 3.2 推奨構成

教材基準では、24VDC駆動の5ポートダブルソレノイドバルブをマニホールド化する。

要求：

- DC24V
- 5ポート
- ダブルソレノイド
- 各ステーション個別配線または多芯/省配線対応
- 手動オーバーライド付き
- サージ対策付き
- 排気ポートをまとめやすい構成
- 将来増設余地あり

マニホールドは最低10ステーション相当、できれば2～4ステーション程度の予備余地を持たせる。

### 3.3 配列案

| Station | 対象 |
|---:|---|
| 01 | ST01 |
| 02 | ST02 |
| 03 | ST03 |
| 04 | ST04 |
| 05 | ST05 |
| 06 | CY01 |
| 07 | CY02 |
| 08 | CY03 |
| 09 | CY04 |
| 10 | CY05 |
| 11～ | 予備 |

1機器1ステーション・2SOLを基本とする。

## 5. 配管径

### 5.1 基本

シリンダサイズと配管長を考慮し、教材基準では以下を初期値とする。

- ST01～ST05：外径φ4 mm級チューブ
- CY03 / CY04：外径φ4 mm級チューブ
- CY01 / CY02 / CY05：外径φ6 mm級チューブ
- メイン供給：φ8～φ10 mm級

理由：

- ストッパーや小径短ストロークシリンダは流量要求が小さい。
- CY02/CY05はガイド付き・ストローク長が大きめで、応答性確保のためφ6級を基準とする。
- CY01も搬送面切替の応答を安定させるためφ6級を基準とする。

最終配管径は配管長、目標動作時間、継手圧損、バルブ流量特性から確認する。

## 6. スピードコントローラ

各シリンダの給排気側に速度調整を設ける。

基本はメータアウト制御とし、動作終端での衝撃を抑える。

特に速度を慎重に調整する対象：

1. CY04 クランプ
2. CY05 ドリル昇降
3. CY02 横移載
4. ST01～ST05

クランプやストッパーは高速化より衝撃低減を優先する。

## 7. エア供給系

基本構成：

`設備エア → 手動遮断 → フィルタ/レギュレータ AR01 → 圧力スイッチ PS12 → MV01 → 各アクチュエータ`

必要に応じて：

- ソフトスタート/ダンプ弁
- 残圧排気
- ミストセパレータ
- サイレンサ

を追加する。

本設備の安全上必要な残圧処理は、安全設計側で別途判断する。

## 8. 圧力設定

教材基準：

- 常用圧力目安：0.5 MPa
- 正常圧力範囲：0.4～0.6 MPa級
- PS12低圧判定：設備仕様確定後に決定

PS12がNGの場合は設備共通条件を落とし、新規自動動作を許可しない。

## 9. ダブルソレノイドのPLCルール

- 正逆/上下/前後の同時ONは禁止。
- 自動要求と手動要求を共通要求へ集約した後でも相互インターロックを取る。
- 実Y段でも反対側要求を確認する。
- 両側要求が同時成立した場合は出力を両方OFFとし、論理異常として監視対象にできるようにする。

## 10. 復旧方向の優先

手動復旧では、安全な待機方向へ戻す操作を優先する。

代表：

- ST：上昇
- CY01：搬送面復帰
- CY02：後退
- CY03：解除
- CY04：解除
- CY05：上昇

ただし機械干渉の可能性があるため、復旧方向であっても無条件出力にはしない。

## 11. 空圧BOMの現時点整理

- AR01：フィルタレギュレータ 1式
- PS12：圧力スイッチ 1台
- MV01：10ステーション以上のDC24V 5ポートダブルソレノイドマニホールド 1式
- ST01～ST05：ストッパー機構 5式
- CY01～CY05：シリンダ/ガイド付きシリンダ 5式
- オートスイッチ：各アクチュエータ両端用
- スピードコントローラ：各ポート用
- 継手・チューブ・サイレンサ・分岐継手 一式
