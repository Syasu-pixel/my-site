# 01 Drilling Line — 空圧供給・圧力監視・バルブマニホールド仕様

Status: Draft / 教材用基準構成

## 1. 目的

本書は、01 Drilling Line の空圧供給系について、エア源から各アクチュエータまでの基準構成を定める。

対象は以下。

- AR01 フィルタレギュレータ
- PS12 圧力監視
- AV01 ソフトスタートアップ／残圧排気
- MV01 電磁弁マニホールド
- 主配管・枝配管の基準
- PLC監視との関係

実機への適用時は、必要流量、停止カテゴリ、安全要求、残留圧力、保全手順、メーカー仕様を別途確認する。本書は安全回路の認証設計を代替しない。

## 2. 基本空圧フロー

教材上の基準フローは次とする。

`設備エア → 手動遮断 → AR01 → PS12 → AV01 → MV01 → ST01～ST05 / CY01～CY05`

設計圧力の基準は 0.5 MPa とする。

実機では供給圧力、圧力損失、必要推力、同時動作流量から最終調整する。

## 3. AR01 フィルタレギュレータ

### 基準採用

- メーカー：SMC
- シリーズ：AW-D
- 基準形名：`AW30-03-D`
- 接続口径：Rc3/8
- 設定圧力範囲：AW-Dシリーズ標準範囲内
- ろ過度：5 μm

### 採用理由

- フィルタとレギュレータを一体化できる。
- 本設備の主配管候補 φ8～10 mm と接続しやすい Rc3/8 クラス。
- ST5台 + 加工シリンダ5台の教材設備として、AW20より一段余裕を持たせやすい。
- 現行 AW-D 系を基準にできる。

### 注意

圧力計・ブラケット・ドレン仕様は盤内レイアウト確定時にオプションを決定する。

## 4. PS12 圧力監視

### 基準採用

- メーカー：SMC
- シリーズ：ISE20A
- 基準形名：`ISE20A-S-M-01-J`
- 圧力範囲：-0.1～1 MPa
- 出力：NPNオープンコレクタ 2出力 + アナログ電流出力
- 単位：SI固定
- 接続：R1/8
- コネクタ付リード線

本設備ではPLCへの「エア圧OK」監視を主用途とする。

### PLC側の考え方

PS12のデジタル出力をPLC入力に取り込み、入力処理後の内部Mへ変換する。

`PS12 → 物理X → 入力確認M111（エア圧OK）`

圧力低下時は、自動運転継続を許可しない設備異常として扱う。

ただし低圧しきい値・ヒステリシス・ディレー時間は、実機調整値として別途管理する。

## 5. AV01 ソフトスタートアップ／残圧排気

### 採用方針

本設備では採用する。

基準候補：

- メーカー：SMC
- シリーズ：AV-A
- 基準形名：`AV3000-03-5DZ-A`
- 接続：Rc3/8
- コイル：DC24V
- DIN形ターミナル
- ランプ・サージ電圧保護回路付

### 役割

1. エア供給開始時に急激な立上りを避ける。
2. 給気遮断時に下流側を排気できる構成とする。
3. 保全・復旧時の空圧状態を分かりやすくする。

### 重要

AV01を設けたことだけで安全機能が成立するとは扱わない。

人が危険区域へ入る場合のエネルギー遮断、残圧対策、ロックアウト、必要な安全性能はリスクアセスメントと適用規格・メーカー仕様に基づき別設計する。

PLCはAV01の通常制御・状態監視を行う場合があるが、安全機能そのものを通常PLCだけへ依存させない。

## 6. MV01 電磁弁マニホールド

### 基準シリーズ

- メーカー：SMC
- シリーズ：SY3000
- 5ポート
- 2位置ダブルソレノイド
- DC24V
- 10台のアクチュエータを収容

SY3000は2位置ダブル、DC24Vの構成が可能であり、本設備のφ20～32級シリンダを扱う教材設備として基準シリーズとする。

### ステーション構成

現在の必要数：10ステーション。

- ST01
- ST02
- ST03
- ST04
- ST05
- CY01
- CY02
- CY03
- CY04
- CY05

機械的には12ステーション相当を基準とし、

- 10ステーション：使用
- 2ステーション：ブランキングプレート

とする案を採用する。

ただしPLC出力は現在29点使用済みで余裕が3点しかないため、予備ステーションを将来使用する場合は出力点数の追加を再検討する。

### マニホールド接続

A/Bポートはφ6ワンタッチ継手を基準とし、φ4配管が適切な小流量機器はレデューサ等で対応する案とする。

最終のマニホールド注文コードは、

- コネクタ方式
- 配線方式
- DINレール／直付け
- SUP/EXH位置
- ブランキングプレート
- A/Bポート径

を盤レイアウト時に確定してから決める。

現段階ではシリーズ・連数・弁形式までを確定し、完全な注文形名は固定しない。

## 8. ダブルソレノイド制御ルール

各方向SOLはPLCから個別出力するが、同一弁の両SOL同時ONは禁止する。

制御層は次の3段とする。

`自動要求M / 手動要求M → 共通出力要求M → 物理Y`

共通要求生成時と最終Y出力の両方で相互排他を確認する。

例：CY05

- 上昇要求と下降要求が同時成立しない。
- 下降は位置決め、クランプ、ワーク、主軸運転などの工程条件が成立した時だけ許可。
- 上昇は異常復旧方向として、下降より許可条件を少なくする。

## 9. 配管径基準

| 系統 | 基準チューブ |
|---|---|
| メイン供給 | φ8～10級 |
| MV01供給 | φ8級以上を基準 |
| ST01～ST05 | φ4級 |
| CY03 / CY04 | φ4級 |
| CY01 / CY02 / CY05 | φ6級 |

配管長、継手数、同時動作、速度により圧力損失が変わるため、実機では流量計算後に確定する。

## 10. 速度制御

基本はメータアウト速度制御とする。

対象：

- ST01～ST05
- CY01～CY05

特に、

- CY02 横移載
- CY04 クランプ
- CY05 ドリル昇降

は衝撃・機械負荷を抑えるため、速度調整を前提とする。

## 11. 運転準備との関係

運転準備条件 M320 には少なくとも、

- 安全回路正常監視
- PS12 エア圧OK
- 重大故障なし
- ST01～ST05 必要位置
- CY01～CY05 必要位置
- 主軸・INV異常なし

を含める。

エア圧が不足している状態では運転準備を成立させない。

エア圧が自動運転中に失われた場合は設備異常として自動運転M305と運転準備M321を解除する設計方針とする。

## 12. 復旧表示

GOT運転準備／復旧画面では、少なくとも以下を表示する。

- 現在のエア圧OK/NG
- AR01設定圧力の基準値（説明用）
- AV01給気状態
- ST01～ST05 上下端状態
- CY01～CY05 両端状態
- 運転準備を阻害している空圧条件
