# 01 Drilling Line — 主軸M05 駆動方式仕様

Status: Draft / 教材用一次選定

## 1. 目的

穴あけ主軸M05について、電気設計・盤内発熱・Q5分岐設計を先へ進めるため、駆動方式の基準を定める。

本設備は教材用仮想設備であり、実機の切削条件・工具寿命・加工精度・機械安全を保証するものではない。実機では工具メーカー推奨条件、主軸メーカー仕様、機械剛性、ワーク材質、リスクアセスメントに基づいて再選定する。

## 2. 採用する基準方式

初級総まとめ教材では、M05を以下の構成で扱う。

- M05：三相200V 0.4kW級モータ
- INV05：三菱電機 FR-E820-0.4K-1 を基準候補
- 駆動方式：インバータ駆動
- PLC指令：Y30 主軸RUN
- PLC入力：X66 主軸運転確認、X67 主軸異常
- 初期教材：固定回転数運転
- 上級教材：速度切替、通信、負荷監視等へ拡張

専用高速スピンドルは初級教材の基準には採用しない。

## 3. この方式を選ぶ理由

- CV01～CV04で既にFR-E800系を使用するため、機器思想を統一しやすい。
- PLC→RUN、INV→運転確認/異常という既存I/O設計をそのまま利用できる。
- 主軸専用ドライブを追加するより、初級教材として電源・INV・モータ・PLCの関係を追いやすい。
- 0.4kW級で現在の教材上の主軸出力基準と整合する。
- 将来、速度段切替やネットワーク制御へ拡張しやすい。

## 4. INV05基準

基準候補：`FR-E820-0.4K-1`

三相200Vクラス FR-E800シリーズの0.4kW級を基準とする。

メーカー仕様確認時には、最低限以下を確認する。

- 定格出力電流
- 入力電源仕様
- 推奨保護機器
- 発熱/損失
- 許容周囲温度
- 漏れ電流・ノイズ対策
- モータ適用条件

保護定格や配線サイズは本ファイルだけでは固定しない。

## 5. M05モータ

M05は三相200V 0.4kW級を基準とするが、正式形名は未確定とする。

機械側で確認する項目：

- 主軸構造
- 工具保持方式
- 必要回転数範囲
- 必要トルク
- 連続/短時間運転条件
- 軸受・振れ精度
- 冷却条件

教材ではφ8のMCナイロン穴あけを対象としているが、実際の回転数・送り速度は固定値として先に決めない。

## 6. PLC I/Oとの関係

既存I/Oを維持する。

| PLC | 信号 | 用途 |
|---|---|---|
| Y30 | 主軸RUN | INV05運転入力 |
| X66 | 主軸運転確認 | INV05運転状態確認 |
| X67 | 主軸異常 | INV05異常監視 |

制御シーケンス：

1. M507でY30相当の共通出力要求を成立させる。
2. X66相当の運転確認が成立するまで待つ。
3. 運転確認成立後のみM508のCY05下降を許可する。
4. 加工後、CY05上昇端を確認して主軸停止へ進む。

Y30からモータへ直接給電しない。

## 7. 速度指令

初期教材では固定設定を基準とする。

理由：

- PLC初級教材としてI/Oとシーケンスを優先できる。
- 速度指令方式を増やすと、アナログ/通信設定の説明が主題になりやすい。

将来拡張候補：

- 多段速
- アナログ速度指令
- Ethernet/産業ネットワーク経由制御
- 周波数到達確認
- 電流/負荷監視

## 8. E03 / Q5への反映

E03のQ5分岐は、

`Q5 → INV05 FR-E820-0.4K-1候補 → M05 0.4kW級`

を基準構成とする。

Q5の具体的な保護定格はINV05の正式仕様、配線条件、上位Q0との保護協調を確認して決める。

## 9. 盤内発熱への反映

INV05をCP01内へ搭載するため、従来のINV01～04に加えて5台目のインバータ発熱源として扱う。

したがって `control-panel-thermal-spec.md` の次回再計算では、

- INV01～04：0.2kW級 ×4
- INV05：0.4kW級 ×1
- PS01
- PLC / I/O
- 将来PS02 / DO増設余地

を含める。

初期方針の「盤クーラーなし」は維持するが、INV05追加後の正式損失値で再判定する。

## 10. 安全上の位置付け

主軸停止を通常PLCのY30だけに依存して安全機能を成立させない。

実機では、非常停止・ガード・必要な駆動停止方式等をリスクアセスメントとメーカー仕様に基づいて別途安全設計する。

## 11. 現時点の結論

初級総まとめ版の主軸は、

- 0.4kW級三相200Vモータ
- FR-E820-0.4K-1基準候補
- 固定速度インバータ駆動

を標準構成とする。

これによりQ5、盤内発熱、BOM、E03主回路を具体化できる状態にする。
