# 01 Drilling Line — 機器タグ・ケーブル番号仕様

Status: Draft / 設計進行中

## 1. 目的

図面、I/O表、GOT、PLCコメント、部品表、配線表で同一の名称を使用できるように、設備内の主要機器タグとケーブル番号の命名ルールを統一する。

本仕様は教材用サンプル設備のための内部標準であり、実際の顧客標準や社内標準がある場合はそちらを優先する。

## 2. 機器タグ基本ルール

### 2.1 搬送機器

- CV01～CV04：コンベヤゾーン
- M01～M04：各コンベヤモータ
- INV01～INV04：各コンベヤ用インバータ
- PE-CV01～PE-CV04：各CV在荷センサ
- PE-PASS01～PE-PASS04：各CV通過センサ
- ST01～ST05：エアストッパー

### 2.2 加工ステーション

- CY01：搬送面切替シリンダ
- CY02：横移載シリンダ
- CY03：位置決めシリンダ
- CY04：クランプシリンダ
- CY05：ドリル昇降シリンダ
- M05：穴あけ主軸モータ
- PE-ST01：加工ST搬送位置在荷
- PE-JIG01：加工治具位置在荷
- PE-OUT01：加工ST排出通過
- PS-OUT01：搬出満杯センサ

### 2.3 シリンダ端確認

各シリンダ・ストッパーの端確認は、機器タグに位置記号を付ける。

- LS-ST01-U：ST01上昇端
- LS-ST01-D：ST01下降端
- LS-CY01-H：CY01搬送面復帰端
- LS-CY01-W：CY01加工側端
- LS-CY02-R：CY02後退端
- LS-CY02-F：CY02前進端
- LS-CY03-R：CY03解除端
- LS-CY03-P：CY03位置決め端
- LS-CY04-R：CY04解除端
- LS-CY04-C：CY04クランプ端
- LS-CY05-U：CY05上昇端
- LS-CY05-D：CY05下降端

H/W/R/F/P/C/U/D は本設備内での識別用とし、図面凡例に必ず記載する。

## 3. 電磁弁タグ

ダブルソレノイドは、機器タグ + 動作記号で統一する。

- SOL-ST01-U / SOL-ST01-D
- SOL-ST02-U / SOL-ST02-D
- SOL-ST03-U / SOL-ST03-D
- SOL-ST04-U / SOL-ST04-D
- SOL-ST05-U / SOL-ST05-D
- SOL-CY01-H / SOL-CY01-W
- SOL-CY02-R / SOL-CY02-F
- SOL-CY03-R / SOL-CY03-P
- SOL-CY04-R / SOL-CY04-C
- SOL-CY05-U / SOL-CY05-D

PLCデバイスコメント、GOT手動画面、配線表でも同一タグを使用する。

## 4. 操作盤タグ

- PB01：運転準備PB
- PB02：自動起動PB
- PB03：停止PB
- PB04：RESET PB
- PB05：投入完了PB
- PB06：ブザー停止PB
- SW01：手動/自動セレクトSW
- EMG01：非常停止PB
- PL01：投入可表示灯
- PL02：運転表示灯
- PL03：異常表示灯
- GOT01：GOT/HMI

## 5. 共通・安全監視タグ

- PS12：エア圧力スイッチ
- SR01：安全リレー
- GD01：安全扉スイッチ
- LC01：ライトカーテン
- ES-MON01：非常停止系監視接点
- SR-MON01：安全リレー状態監視接点

安全タグはPLC監視用信号名と安全回路本体の機能を明確に分ける。

## 6. 制御盤内タグ

- CP01：制御盤
- OP01：操作盤
- PLC01：FX5U-64MT/ES
- DI01：追加入力ユニット FX5-C32EX/DS-TS
- PS01：DC24V電源
- QF01：主幹保護器
- MV01：電磁弁マニホールド
- XT1～XT8：端子台群

将来、インターフェースリレーを設ける場合は RY01～ のように連番管理する。

## 7. ケーブル番号ルール

ケーブル番号は `CBL-系統-連番` を基本とする。

### 7.1 操作盤

- CBL-OP-01：CP01 ↔ OP01 操作信号
- CBL-OP-02：CP01 ↔ OP01 表示灯・補助
- CBL-GOT-01：PLC01 ↔ GOT01 Ethernet

### 7.2 搬送系

- CBL-CV01-01：CV01在荷/通過センサ
- CBL-CV01-02：ST01端確認
- CBL-CV01-03：CV01モータ/INV関連
- CBL-CV02-01～：同様
- CBL-CV03-01～：同様
- CBL-CV04-01～：同様

### 7.3 加工ST

- CBL-PROC-01：加工ST在荷/治具在荷/排出通過
- CBL-PROC-02：CY01端確認
- CBL-PROC-03：CY02端確認
- CBL-PROC-04：CY03端確認
- CBL-PROC-05：CY04端確認
- CBL-PROC-06：CY05端確認
- CBL-PROC-07：主軸状態
- CBL-PROC-08：搬出満杯

### 7.4 電磁弁

- CBL-SOL-01：ST01～ST05
- CBL-SOL-02：CY01～CY05

### 7.5 安全監視

- CBL-SAFE-MON-01：安全回路PLC監視信号

安全回路本体の配線・ケーブルは、この教材の通常制御ケーブル番号とは分離して管理する。

## 8. 線番との関係

既存の線番ルールを維持する。

- 100番台：操作盤
- 200番台：共通・安全監視
- 300番台：搬送入力
- 400番台：加工ST入力
- 500番台：搬送出力
- 600番台：加工出力
- 700番台：INV・主軸

ケーブル番号は外部配線束を識別し、線番はケーブル内部の個々の芯線を識別する。

## 9. 図面での表記ルール

各信号は可能な範囲で次の4情報を同時に追えるようにする。

`機器タグ / 信号名称 / PLC I/O / 端子台`

例：

`LS-CY05-U / CY05上昇端 / X52 / XT5-11`

`SOL-CY05-D / CY05下降SOL / Y27 / XT5-30`

## 10. PLC・GOTへの反映

GX Works3のデバイスコメントは、タグを先頭に置く形式を推奨する。

例：

- X52 `LS-CY05-U CY05上昇端`
- Y27 `SOL-CY05-D CY05下降SOL`
- M150 `CY05上昇端 確定入力`

GOT表示はオペレーター向け名称を優先し、保守画面ではタグ名も併記する。
