# 01 Drilling Line — 端子台・外部配線区分仕様

Status: Draft / 設計進行中

## 1. 目的

制御盤 CP01 から操作盤 OP01、搬送部、加工部、インバータ、主軸、安全監視系へ出る外部配線を、機能ごとに端子台へ整理する。

本仕様は `physical-io-map.md` を基準とし、GX Works3 + MELSEC iQ-F 構成に合わせる。

安全機能そのものの回路詳細は本ファイルでは扱わない。非常停止、安全扉、ライトカーテン等の安全回路は、実機ではリスクアセスメントとメーカー仕様に基づいて別途設計する。本仕様ではPLCへ返す監視信号の区分のみ整理する。

## 2. 端子台の基本区分

- XT1：DC24V センサ電源・0V 分配
- XT2：OP01 操作盤入力
- XT3：表示灯・ブザー等の操作盤出力
- XT4：搬送部センサ・ストッパー
- XT5：加工ST センサ・シリンダ・主軸周辺
- XT6：インバータ I/O
- XT7：安全回路監視信号
- XT8：予備・将来拡張

端子台は機能ごとに分け、外部配線を盤内で追いやすくする。

## 3. XT1 — DC24V センサ電源

用途：

- 外部センサ用 +24V
- 外部センサ用 0V
- 必要に応じて機能群ごとに分岐

推奨区分：

- XT1-01～04：OP01用 +24V / 0V
- XT1-05～08：搬送センサ用 +24V / 0V
- XT1-09～12：加工STセンサ用 +24V / 0V
- XT1-13～16：INV・主軸信号用 +24V / 0V
- XT1-17～20：予備

実機では電源容量、保護、0V共通の取り方、ノイズ源との分離を別途確認する。

## 9. XT7 — 安全回路監視

XT7は安全機能の主回路を示すものではなく、PLCが状態表示・運転許可判定に使用する監視信号のみを整理する。

| 端子 | 監視信号 | PLC入力 |
|---|---|---|
| XT7-01 | 安全回路OK | X10 |
| XT7-02 | エア圧OK | X11 |
| XT7-03 | 非常停止系正常監視 | X12 |
| XT7-04 | 安全扉閉確認 | X13 |
| XT7-05 | ライトカーテンクリア | X14 |
| XT7-06 | 安全リレー正常監視 | X15 |
| XT7-07～12 | 予備 | - |

安全回路OK以外の各監視信号は、GOTで「なぜ運転準備できないか」を表示するためにも使用する。

## 10. XT8 — 予備・拡張

用途候補：

- 追加センサ
- NG判定機器
- 将来の排出確認
- 保守用入力
- 追加表示灯
- 将来の通信機器I/O

現段階では固定用途を割り当てず、端子余裕として確保する。

## 11. 配線番号ルール（案）

教材として追いやすくするため、将来の回路図では機能群ごとに配線番号帯を分ける。

例：

- 100番台：操作盤入力
- 200番台：安全監視・共通条件
- 300番台：搬送センサ
- 400番台：加工STセンサ
- 500番台：PLC出力～搬送機器
- 600番台：PLC出力～加工機器
- 700番台：インバータ・主軸関連

正式な線番体系は回路図作成時に確定する。
