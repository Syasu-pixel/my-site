# 01 Drilling Line — 搬送部 外部配線表

Status: Draft / 教材用外部配線対応表

## 1. 目的

本ファイルは、制御盤CP01の `XT4` と、搬送部のCV01～CV04、ST01～ST05の間を、端子・線番・ケーブル・PLC I/O・機器タグで追えるように整理する。

本仕様は `terminal-block-spec.md`、`physical-io-map.md`、`tag-cable-spec.md` を基準とする。

安全機能そのものの配線詳細は扱わない。

## 2. ケーブル構成方針

搬送部は機器ごとに細かくケーブルを分けすぎず、保守時に追いやすい単位でまとめる。

基準タグ：

- CBL-CV01-01：CV01センサ系
- CBL-CV02-01：CV02センサ系
- CBL-CV03-01：CV03センサ系
- CBL-CV04-01：CV04センサ系
- CBL-ST01-01 ～ CBL-ST05-01：各ストッパー端検出
- CBL-SOL-TR-01：ST01～ST05 電磁弁出力束

センサ電源はXT1の搬送センサ用DC24V分岐から供給する。

## 3. 線番ルール

搬送部は300番台をセンサ入力、500番台を搬送出力とする。

- 301～308：CV在荷・通過センサ
- 321～330：ST01～ST05 上下端
- 501～510：ST01～ST05 電磁弁

## 7. CV01～CV04 RUN信号

CV01～CV04のRUNはXT6のインバータ信号系を使用するため、本ファイルでは参照のみとする。

- CV01 RUN：Y0 → XT6-01 → INV01
- CV02 RUN：Y1 → XT6-02 → INV02
- CV03 RUN：Y2 → XT6-03 → INV03
- CV04 RUN：Y3 → XT6-04 → INV04

詳細はインバータ配線表で管理する。

## 8. 電源分配

搬送部のセンサ電源はXT1の搬送系分岐を使用する。

基準：

- +24V：XT1搬送センサ系
- 0V：XT1搬送センサ系
- ST電磁弁：MV01側DC24V出力系統

センサ系と電磁弁系は、盤内で分岐保護を分ける前提とする。
