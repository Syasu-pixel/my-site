# Sample Equipment Lines

このディレクトリは、denkicontrol.com で扱う教材用の仮想設備ラインを、実際の設備設計に近い流れで記録・管理するためのものです。

## 基本方針

各サンプル設備は、以下の順番で設計・記録します。

1. 設備目的・仕様書
2. ワーク仕様
3. タクト・能力
4. 機械レイアウト
5. 安全方針
6. 機器表
7. 制御盤・操作盤仕様
8. I/O原票
9. PLC I/O割付
10. 内部デバイス設計
11. ラダー構成
12. GOT/HMI仕様
13. アラーム仕様
14. 決定事項・未決事項の議事録

## 運用ルール

- チャット内で重要な仕様やルールが確定した段階で、その内容をGitHubにも追記する。
- 会話だけに情報を残さず、次回別チャットでもGitHub上の資料を読めば再開できる状態を維持する。
- 共通の制御ルールは `_shared/` に集約する。
- 設備固有の内容は設備ごとのフォルダで管理する。
- 実機安全設計・保護機器定格・安全距離等は、教材上の概念設計と実機設計を明確に分ける。
