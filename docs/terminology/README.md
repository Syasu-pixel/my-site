# Terminology Rules

このフォルダは、記事制作で使う公式用語・採用表記・英語表記を整理するためのルール置き場です。

## 方針

- 公式資料で確認した用語だけを採用候補にする。
- 日本語記事では日本語公式資料の用語を優先する。
- 英語記事では英語公式資料の用語を優先する。
- 英語公式資料がない場合は、日本語公式資料を参照してもよいが、英語記事では一般化して表現する。
- 画像内テキストは、reference-notes またはこの記事で確認した公式用語から選ぶ。
- 未確認の命令語、未確認のデバイス名、未確認の設定名を画像内に入れない。
- 実在UI・実在ロゴ・実在画面スクリーンショット風は作らない。

## 記事ごとの運用

- 記事ごとの詳細は `docs/reference-notes/{slug}.md` に記録する。
- 共通化できる用語が増えた場合だけ、このフォルダに共通メモを追加する。
- 共通メモを作る場合も、公式資料名・確認日・参照URLを記録する。
