# 工具記事改善テンプレート（tool article improvement template）

## 1. 目的
- 工具記事の情報価値と回遊性を高める。
- 読了後の行動（比較・購入・関連記事遷移）を改善する。

## 2. 見た目統一
- サイト全体のデザイン基準に合わせる。
- 固定ヘッダー・右カラム・カード構造を維持する。
- セクション分割と余白設計を統一する。

## 3. 商品カード改善
- 製品名、用途、特徴、推奨ユーザーを明確化。
- 比較しやすい並び順（用途別・価格帯別など）を採用。
- 画像・説明文の粒度を揃える。

## 4. Amazonリンク導線
- 商品カード内に自然なAmazonリンク導線を設置。
- CTA文言を統一し、過剰な訴求を避ける。
- リンク切れ・誤リンクを防ぐため公開前確認を行う。

## 5. 関連記事導線
- 記事末尾に関連記事導線を設置。
- 関連性が高い順に並べる。
- 存在しないURLは設定しない。

## 6. Search Console改善
- タイトル・見出し・内部リンクの整合性を最適化。
- 検索意図に合う要約と導入を整備。
- インデックス性を阻害する要因（重複/欠落メタ等）を点検。

## 7. CODEX指示の出し方（テンプレ）

- 変更範囲：

- リンク方針（Amazon/関連記事）：
- 検証項目（search-index / sitemap / リンク整合）：
