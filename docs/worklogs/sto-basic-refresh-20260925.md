## 現状記事監査
良い点:
- STOの基本、通常停止との違い、安全回路、復帰確認、注意点まで一通りある。
- STO入力を安易に短絡・ジャンパーしない警告がある。
- Hero / 本文図 / 関連記事の基本構造が存在する。

刷新ポイント:
1. 「STO=停止させる機能」と誤読しないよう、トルク生成エネルギ遮断を主語にする。
2. STOは停止過程を制御しない。回転中は惰性停止や機械条件に依存することを明示する。
3. SS1との違いを追加し、「減速→STO」と「STO単独」の時間軸差を説明する。
4. STOは機械ブレーキではないことをより明確にする。
5. STOは感電防止の電源遮断ではないことを明記する。
6. 非常停止は入力機器、STOはドライブ側安全機能であり、両者を同一視しない。
7. 「非常停止→安全リレー/安全PLC→STO」の例は一般構成として扱い、直接接続を固定化しない。
8. STO-A/STO-B、STO1/STO2等の端子名を一般仕様のように扱わない。
9. PL/SIL/Categoryは機種・構成依存として、記事では概念説明に留める。
10. 復帰トラブル章は安全回路をバイパスする方向へ誘導せず、状態確認と公式マニュアル確認を中心にする。
