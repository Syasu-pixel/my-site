    Self-Holding Circuit Basics: Why a Motor Keeps Running After START

    A self-holding circuit is the basic pattern that lets an output stay on after a momentary START pushbutton is released. This article explains the idea using relay contacts and simple PLC ladder logic.

    • See why the STOP button is normally placed before the holding branch.
    • Learn what to check when the circuit turns on but does not stay on.

    What is a self-holding circuit?

    In simple terms, a self-holding circuit is a circuit that keeps its own output energized after the START button is released.

    A START pushbutton is usually a momentary contact. It only closes while someone is pressing it. If the circuit were made only with that pushbutton, the motor or relay would stop as soon as the button was released.

    A self-holding circuit solves this by using an auxiliary contact from the same relay, contactor, or PLC output. Once the output turns on, its own contact creates another path around the START button.

    The key point

    The holding contact is not a separate command. It is a feedback path that becomes true only after the output has already turned on.

    Main parts of a self-holding circuit

    The circuit is easier to understand when you separate the STOP contact, START contact, holding contact, and output coil.

    Part Typical role Beginner-friendly explanation
    STOP button Normally closed contact It normally allows current or logic continuity. Pressing STOP opens the path and releases the hold.
    START button Normally open contact It gives the first ON signal only while pressed.
    Holding contact Auxiliary contact or PLC output contact It creates a parallel path around the START button after the output is energized.
    Output coil Relay, contactor, or PLC output This is the device or internal output that is kept ON by the holding path.

    Why is the STOP contact normally closed?

    In a common start/stop circuit, the STOP contact is placed in series before the START and holding branch. This makes it possible to break both the START path and the holding path with one action.

    How the circuit turns on and stays on

    The easiest way to understand self-holding is to follow the state change in order.

    1. Waiting

    The STOP contact is closed, START is open, and the output is off.

    2. Press START

    The START contact closes and energizes the output coil.

    3. Holding contact closes

    The output’s own contact closes and creates another ON path.

    4. Release START

    The output remains on through the holding contact.

    Senior technician

    Think of the START button as the first push, and the holding contact as the circuit saying, “I can keep myself on now.”

    Junior technician

    So if the holding contact does not close, the output turns on only while I press START?

    Senior technician

    Exactly. That is one of the first things to check when a circuit starts but does not stay on.

    Simple ladder logic example

    In ladder logic, the holding contact is usually drawn in parallel with the START contact.

    The example below is simplified. The STOP contact is in series, and the START contact and holding contact are in parallel. The output coil turns on when either START is pressed or the holding contact is already on.

    Rung
    --[/ STOP ]----+----[ START ]----------------( RUN )
    |
    +----[ RUN ]-------------------

    Field-friendly way to read it

    Read the rung from left to right: STOP must be OK, and then either START or the RUN holding contact must be ON for the RUN coil to stay ON.

    How the STOP button releases the hold

    Pressing STOP opens the common path before both the START contact and the holding contact.

    When STOP is pressed, the circuit path is broken. The output coil turns off, and the holding contact also opens. After that, releasing STOP alone does not restart the output because the holding contact is no longer closed.

    Do not use self-holding as a safety circuit by itself

    A self-holding circuit is a control pattern, not a complete safety design. Emergency stop, safety relay, guard switch, and risk assessment requirements must be handled separately according to the machine and applicable standards.

    What to check when it does not stay on

    If the output turns on only while START is pressed, the holding path is usually not being established.

    1. Is the output actually turning on?

    If the output coil or relay never turns on, the holding contact cannot close either.

    2. Is the holding contact the correct address?

    In PLC logic, confirm that the contact used for holding is linked to the correct output or internal relay.

    3. Is STOP still closed?

    A faulty STOP button, broken wire, or open interlock can prevent the holding path from being maintained.

    4. Is another condition resetting it?

    Some circuits include overload, alarm, mode, or interlock conditions that release the output immediately.

    Common beginner mistake

    Do not only look at the START button. If the circuit turns on while START is pressed, START is probably doing its job. The next focus should be the holding contact and the conditions before it.

    Practical safety and design notes

    A self-holding circuit is simple, but it is often connected to real machines. Treat it carefully.

    In real equipment, the self-holding rung is rarely just STOP, START, and RUN. It may also include overload contacts, safety conditions, mode selections, automatic stop signals, and interlocks.

    Design point Why it matters Typical field check
    Stop and reset behavior The machine should not unexpectedly restart just because a stop condition is released. Confirm that START must be pressed again after STOP or fault reset.
    Interlocks Other machine conditions may need to block the hold. Check guards, pressure, position, mode, and ready signals.
    Output feedback In some systems, the command and actual device feedback are different. Check both PLC output state and real relay or contactor operation.

    Best way to practice

    First learn the basic three-part pattern: STOP, START, and holding contact. After that, add one condition at a time, such as overload, auto stop, or interlock. This makes the ladder much easier to read.
