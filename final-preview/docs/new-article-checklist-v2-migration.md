# 新規記事チェックリスト v2 移行オーバーライド

> 正本: `docs/ai-editorial-master-rules.md`。旧チェックリストと矛盾する場合は本書とマスタールールを優先する。

## Previewへ送る前の必須ゲート
- GitHub main最新版とマスタールール確認済み
- 既存記事・検索意図・重複/カニバリゼーション確認済み
- 最適な完成済み記事をコピー元として使用
- メーカー公式一次情報を優先し、必要な根拠を確認済み
- 最新版がある場合は最新版を優先。ない場合は対象機種対応の旧版公式資料を使用可
- 型式固有の仕様/配線/通信/パラメータ/アラーム/安全/設定手順/注意事項は公式確認済み
- 公式確認できない型式固有情報を「一般例」で回避していない
- 一般原理の例示には必要に応じて「一般例」「機種により異なる」を明示
- TECHNICAL / SEO監査済み
- hero + OGP + 必要な本文画像のみ作成し、枚数合わせの画像なし
- 各画像が生成側自己評価95点以上 + 独立IMAGE REVIEWER通過
- 画像の技術誤りがあった場合、本文と公式資料まで再監査済み
- HTML構造、3カラム、会話、支援導線、関連記事等の既存構造を原則維持
- 全hrefと画像パス実在確認済み
- 正式ドメイン、canonical、OGP等確認済み
- `/seo/sitemap.xml` を変更していない
- Step 1にトップ/カテゴリ/search-index/sitemap/backlog等のStep 2変更が混在していない
- PC/スマホ等の表示確認済み
- GitHub PRからNetlify Deploy Previewが発行され、管理者が目視できる状態

未達項目がある場合は `ARTICLE_READY` としない。
