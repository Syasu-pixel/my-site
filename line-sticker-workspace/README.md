# LINEスタンプ 一時保管

採用済みグリーンバック・マスターを一時保管する作業領域です。

## 制作・登録フロー

1. 制作中は、1商品につき **4×6＝24スタンプのグリーンバック・マスター1枚**を確認用として作る。
2. ユーザーが採用したマスターだけを、この一時保管領域へ保存する。
3. ユーザーが「溜めたものを登録していこう」と指示した段階で、採用マスターから透過・24枚切り出しを行う。
4. LINE登録用の **24スタンプ＋main＋tab＝26 PNG** を作成し、ZIPにまとめて提出する。
5. ZIP作成時点では元のグリーンバック・マスターを削除しない。修正・再生成に戻れる状態を維持する。
6. LINE Creators Marketへの登録完了をユーザーが確認した商品だけ、一時保管していた元マスターを削除する。
7. 一時保管領域には「まだLINE登録が完了していない商品」だけを残す。

## 制作上の注意

- 隣セルへ要素をはみ出させない。
- 透過時に欠け・緑フリンジ・ゴミになりやすい極細線や小さすぎる独立装飾は避ける。
- 意味はキャラクターの表情・ポーズ、大きな文字、透過に耐える大きめの小物を中心に表現する。
- 本番サイト公開用の領域ではない。mainへ混入させない。
